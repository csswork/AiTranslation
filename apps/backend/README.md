# VPS 后端：账号、托管翻译、订阅与管理

本目录是独立后端应用的入口。目前只有职责与实施说明，尚未引入运行框架、数据库依赖或可启动的服务。

## 职责

| 模块 | 后端负责的内容 |
| --- | --- |
| 认证 | 简单注册、Google / X 等平台 OAuth、用户与会话管理；Chrome 登录流程需支持扩展 |
| 额度 | 注册试用点数、服务端余额、预扣、结算、失败退款、幂等账本 |
| 托管翻译 | 文字、图片和视频的受控接口；成本计量、限额、超额停用；模型 Key 由后端保存 |
| 订阅与支付 | 套餐、结账入口、用户订阅状态、支付服务 Webhook 验签及重放防护 |
| 管理 | 用户、订单、订阅、点数、请求成本与异常的管理界面、接口及权限控制 |
| 数据 | 用户、身份绑定、订单、订阅、额度流水与必要的运维记录 |

用户自带 Key 的模式继续由扩展直接调用所选服务商；收费针对托管翻译。试用额度和付费额度必须由后端判断，前端与扩展只展示状态。

支付服务通过适配器接入。现阶段讨论过 Creem 与 Stripe；实际启用的服务商仍需结合商户审核与收款条件确定。订阅是否生效由后端验证支付事件，不能以浏览器跳转到成功页面为依据。

## 实施时的目录

以下是后续新增代码时采用的划分，目前不创建空实现：

```text
src/
  auth/             用户、OAuth、会话
  credits/          额度与账本
  translation/      托管文字、图片、视频翻译
  billing/          套餐、订阅、支付服务适配器
  webhooks/         已验签、可重试、可幂等处理的支付事件
  admin/            管理接口与权限
  config/           服务端配置
migrations/         数据库迁移
test/               服务端测试
deploy/             VPS 容器、反向代理与运维配置
admin/              随 VPS 服务发布的后台管理界面（按所选框架组织）
```

面向用户的前台 HTML 页面放在 `../web`；后台管理界面与管理 API 归本应用，随 VPS 服务部署；Chrome 内界面放在 `../extension`。数据库与密钥位于 VPS，管理权限在服务端执行。数据库建议使用 PostgreSQL；具体后端框架和认证实现将在下一步确定。

## 开始实现的顺序

1. 确定后端运行栈、数据库和 VPS 部署方式，建立基础服务与迁移入口。
2. 用户、OAuth 和扩展登录；接通网站账户页。
3. 额度账本和试用点数；接通托管文字、图片和视频入口与限额。
4. 支付结账、订阅、Webhook 与账单入口。
5. 管理系统、成本观察、限流、备份与上线验证。

托管模式上线前，要补充相应的数据处理和隐私说明，并实测各类翻译成本，再确定点数换算与价格。
