v1.0.0
2026-09-15

Первый выпуск

  • Перевод выделенного текста: выделите текст не на китайском и щёлкните правой кнопкой, чтобы перевести; перевод появляется потоком во всплывающем окне в центре экрана. Если выделенный текст уже на китайском, пункт меню не появляется.
  • Перевод элементов: щёлкните правой кнопкой по области страницы, чтобы закрепить на ней кнопку перевода; при нажатии текст внутри области заменяется на месте. Правила запоминаются по домену, и их можно вести на странице управления.
  • Перевод изображений: щёлкните правой кнопкой по изображению, чтобы распознать текст на нём; перевод накладывается на оригинал в соответствии с распознанными позициями. Длинные изображения сначала разбиваются на фрагменты по содержимому, а линии разреза обходят строки текста.
  • Панель перевода: отдельная страница, слева оригинал, справа перевод; целевой язык выбирается любой.
  • Поддерживается подключение к API ChatGPT (OpenAI), DeepSeek и DeepL; переключаться можно в любое время во всплывающем окне или на странице настроек.
  • API Key хранится в chrome.storage.local и не синхронизируется через аккаунт Chrome.
