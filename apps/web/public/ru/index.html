Расширение для Chrome. Выделите текст, целую область веб-страницы или изображение — и получите перевод на знакомый вам язык. 24 языка интерфейса и целевых языка выбираются независимо; для начала достаточно собственного API Key OpenAI, DeepSeek или DeepL.

Features

Пять точек входа, все в контекстном меню

Без переключения вкладок и без копирования. Там, где находится непонятный вам фрагмент, там и происходит перевод.

01

Перевод выделенного текста

После выделения текста вызовите перевод через контекстное меню — перевод отобразится во всплывающем окне по центру; платформы с потоковым выводом показывают текст по мере поступления. При временной смене целевого языка перевод выполняется заново по исходному тексту.

  • Переводятся китайский, короткие слова и смешанные языки; для чистых цифр, знаков препинания и эмодзи кнопка перевода не отображается
  • Всплывающее окно расположено по центру и перетаскивается, закрывается по Esc или щелчку по фону; это не пузырёк, бегающий за курсором
  • Сворачиваемая панель оригинала, чтобы читать в параллель
  • Есть и сочетание клавиш: Alt+Shift+T (в macOS — Command+Shift+Y)

02

Перевод изображений

Щёлкните правой кнопкой по изображению, распознайте текст на нём и наложите перевод обратно на оригинал в найденных местах.

  • Длинные изображения сначала разбиваются на фрагменты, а линии разреза автоматически смещаются на пустые строки между текстом, чтобы не разорвать предложение пополам
  • Перед отправкой изображение масштабируется по общему числу пикселей, а не по длинной стороне, поэтому ширина длинного изображения не теряется
  • Перевод накладывается поверх исходного изображения; также можно открыть панель изображения, загрузить, вставить изображение или указать его адрес
  • При смене целевого языка распознанный текст используется повторно; после замены изображения распознавание выполняется заново

03

Перевод всего PDF Скоро

В PDF, открытом в Chrome, щёлкните правой кнопкой без выделения текста — весь документ переводится на соседней странице. Перевод накладывается на исходные позиции, вёрстка, схемы и таблицы не меняются.

  • Оригинал и перевод рядом, можно смотреть только перевод или только оригинал
  • Таблицы переводятся по ячейкам, строки, столбцы и линии таблицы сохраняются; не помещающийся перевод автоматически уменьшается
  • Через печать браузера сохраняется как PDF, перевод — выделяемый и доступный для поиска текст
  • Файл обрабатывается только локально, на платформу перевода отправляется лишь извлечённый текст; локальный PDF можно перетащить прямо на страницу перевода. Сканы пока не поддерживаются

04

Перевод элементов

Нажмите правой кнопкой мыши на любую область страницы, чтобы закрепить на ней кнопку перевода. Одно нажатие — текст в области заменяется на выбранный язык, повторное нажатие возвращает исходный текст.

  • Правила запоминаются по домену: при следующем посещении того же сайта кнопка появится автоматически
  • Длинное содержимое отправляется частями и заменяется по мере перевода, так что ждать обработки всего блока не нужно
  • Сохранённые правила можно просматривать и удалять по одному на странице управления

05

Панель перевода

Отдельная страница: слева оригинал, справа перевод — для работы с текстами, которых нет на веб-странице.

  • Доступны 24 целевых языка, охватывающих основные языки мира
  • Исходный язык определяется автоматически или задаётся вручную, целевой язык выбирается отдельно, панель запоминает последний выбор
  • Платформа и целевой язык — на панели инструментов; переключайте и переводите заново в любой момент

Experimental

Субтитры к видео в реальном времени

Экспериментальная функция, отключена по умолчанию. Захватывает звук текущей вкладки, распознаёт его в субтитры и затем переводит; язык распознавания речи и целевой язык перевода задаются отдельно.

По умолчанию распознавание выполняется локально; требуется поддержка браузера и загрузка языкового пакета. Можно вручную переключиться на облачное распознавание Google — в этом случае звук отправляется в Google. Точность и совместимость распознавания по-прежнему ограничены, не рекомендуется полагаться на него для важных материалов. Облачный сервис получает только распознанный текст; загрузка и транскрипция аудио и видео не поддерживаются.

Languages

Читайте мир на своём языке

Язык интерфейса, источник перевода и целевой язык независимы. При первом запуске целевой язык выбирается по языку браузера, также его можно зафиксировать в настройках.

24 языка интерфейса и целевых языка

Китайский упрощённый, китайский традиционный, английский, японский, корейский, испанский, португальский (Бразилия), французский, немецкий, итальянский, нидерландский, русский, украинский, польский, турецкий, арабский, иврит, персидский, хинди, бенгальский, урду, индонезийский, вьетнамский и тайский.

Пункт контекстного меню следует целевому языку

Если выбран японский, меню предлагает перевод на японский; если выбран английский — на английский. Можно переводить и китайский текст — расширение больше не рассчитано только на китайскоязычных читателей.

Справа налево — тоже естественно

Интерфейсы на арабском, иврите, персидском и урду используют раскладку справа налево. Направление исходного текста и перевода определяется отдельно и не меняет вёрстку самой веб-страницы. Фактически доступные языковые пары зависят от выбранной платформы.

Privacy

Содержимое отправляется только при вашем запуске перевода

При использовании своего ключа переводимый текст отправляется напрямую на выбранную вами платформу. При переводе по баллам текст передаётся через наш сервер поставщику модели; сервер не сохраняет изображения, исходный текст или перевод. Об обработке звука при включённых субтитрах к видео см. политику конфиденциальности.

Свой Key: прямое подключение к платформе

Запросы отправляются из вашего браузера напрямую на платформу, выбранную в настройках, минуя нас. API Key хранится в chrome.storage.local и не синхронизируется через аккаунт Chrome.

Облачный сервис: содержимое перевода не сохраняется

Текст и изображения, обрабатываемые облачным сервисом, находятся в памяти лишь на время обработки запроса. В аккаунте хранятся только необходимые адрес электронной почты и имя пользователя; данные об использовании, баллы и записи о подписке используются для предоставления сервиса; аватары, никнеймы и отпечатки устройств не собираются.

Без рекламы и сторонней аналитики

Не используются реклама, трекинг и сторонние SDK аналитики, данные не продаются и не сдаются в аренду. Код расширения и серверной части открыт под GPL-3.0 и доступен для построчной проверки.

Полное описание — в Политике конфиденциальности и Условиях использования, а также в полном исходном коде под GPL-3.0.

Вход по электронной почте или через Google

Войдите с помощью кода подтверждения по электронной почте или аккаунта Google, завершите авторизацию в текущей вкладке браузера и вернитесь в расширение. Требуются только электронная почта и имя пользователя.

Баланс и статус обновляются своевременно

Без подписки отображаются оставшиеся баллы, с подпиской — безлимитное использование. В личном кабинете можно просмотреть своё использование, историю баллов, подписку, заказы и сеансы входа; после выхода из веб-сеанса связанное расширение также выходит из системы.

Возможность использовать свой ключ сохраняется всегда

Перевод через хостинг и со своим ключом можно переключать. Запросы со своим ключом идут напрямую к платформе, не списывают баллы хостинга и не требуют покупки нашей подписки.

Install

Установка из Chrome Web Store

Требуется Chrome 116 или новее; подходят также браузеры на движке Chromium, например Edge.

Откройте страницу магазина На компьютере откройте страницу Chrome Web Store.
Добавьте в Chrome Нажмите «Добавить в Chrome» и подтвердите.
Закрепите на панели инструментов Нажмите значок пазла и закрепите расширение на панели инструментов.
Начните перевод Укажите свой API Key в настройках, выделите текст и переведите его через контекстное меню.
Открыть Chrome Web Store

Также можно загрузить apps/extension в режиме разработчика из исходного кода на GitHub.

Для перевода изображений нужна модель с поддержкой распознавания изображений; расширение не работает на внутренних страницах Chrome, в интернет-магазинах и других защищённых страницах.
