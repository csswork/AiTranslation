v2.0.0
2026-10-20

账户、免 Key 翻译与订阅

免 Key 试用、账户与订阅服务随本版开放。自带 Key 模式继续保留。

  • 账户登录：邮箱验证码或 Google 登录，在当前窗口的标签页授权后回到扩展；弹出页与设置页显示用户名、余额和订阅状态。
  • 试用与点数：提供访客试用与注册赠送，剩余试用点数可转入账户，赠送点数不过期；按实际用量精确扣减，失败返还，不再每次向上取整扣一点。
  • 托管文字与图片：无需自备 Key，支持划词、翻译面板、网页区域和图片识别与翻译。已识别的视频字幕可走托管文字翻译；音视频上传与托管转写尚未提供。
  • 订阅与账单：用户中心管理订阅、订单、用量和登录会话。订阅后按合理使用原则无限使用，支付由 Creem 处理。
  • 状态同步：网页登出会撤销由该网页会话授权的扩展登录，不影响其他浏览器；本地开发与正式环境分别处理。
  • 界面与隐私：移除弹出页重复的余额显示；补齐托管图片说明与可选 Google 云端语音识别的数据处理说明。不保存翻译内容或图片。
v1.1.0
2026-10-13

从中文翻译工具，到 24 种语言

  • 完整多语言界面：提供 24 种界面与目标语言，界面、来源和目标各自独立；首次安装跟随浏览器语言，升级保留已有偏好与 API 配置。
  • 面向不同语言读者的翻译交互：支持中文、短词和混合语言选区，右键菜单按当前目标语言生成，不再只提供「翻译成中文」。
  • 临时切换目标：划词弹窗从原文重译，可明确保存默认目标；翻译面板记住自己的来源与目标选择。
  • 区域与图片改进：区域翻译可恢复原文，失败时回退；图片切换目标时复用识别结果，更换图片后清空缓存。
  • 文字方向与平台能力：支持阿拉伯语等从右往左的界面，原文和译文独立排版；DeepL 按实际支持的语言组合处理，不支持时明确提示。
  • 实验视频字幕：可手动开启当前标签页的语音识别与字幕翻译，默认关闭，识别效果与兼容性仍有限。
v1.0.0
2026-09-15

第一个版本

  • 划词翻译：选中非中文文字后右键翻译，译文在屏幕中央的弹窗里流式显示。选中的文字本身是中文时，菜单不出现。
  • 元素翻译：右键页面上的某个区域给它挂一个翻译按钮，点击后就地替换区域内的文字；规则按域名记住，可在管理页维护。
  • 图片翻译：右键图片识别其中的文字，译文按位置盖回原图。长图会先按内容切块，切缝避开文字行。
  • 翻译面板：独立页面，左原文右译文，目标语言可任选。
  • 支持接入 ChatGPT（OpenAI）、DeepSeek 与 DeepL 的 API，在弹窗或设置页随时切换。
  • API Key 存于 chrome.storage.local，不随 Chrome 账号同步。
