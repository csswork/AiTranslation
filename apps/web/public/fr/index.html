Une extension Chrome. Sélectionnez du texte, une zone entière d'une page web ou une image pour la traduire dans la langue que vous maîtrisez. 24 langues d'interface et langues cibles sont sélectionnables indépendamment ; utilisez votre propre clé API OpenAI, DeepSeek ou DeepL pour commencer.

Installer sur Chrome Voir le code source

Ce navigateur ne peut pas installer d'extensions Chrome : ouvrez cette page sur un ordinateur avec un navigateur basé sur Chromium, comme Chrome ou Edge.

  • Open source GPL-3.0 · 24 langues
  • Chrome 116+
  • Aucune traduction stockée · Aucune statistique tierce
  • Quatre modes de traduction

Features

Quatre entrées, toutes dans le menu contextuel

Pas besoin de changer d’onglet ni de copier-coller. Là où se trouve le passage que vous ne comprenez pas, la traduction s’y produit.

01

Traduction par sélection

Après avoir sélectionné du texte, faites un clic droit pour traduire ; la traduction s'affiche dans une fenêtre centrée et, sur les plateformes prenant en charge le flux, s'affiche caractère par caractère. Changer temporairement de langue cible relance la traduction à partir du texte original.

  • Le chinois, les termes courts et les langues mixtes peuvent être traduits ; les chiffres seuls, la ponctuation et les emojis n'affichent pas d'entrée de traduction
  • La fenêtre est centrée et déplaçable, se ferme avec Esc ou un clic sur l’arrière-plan — pas une petite bulle qui suit le curseur
  • Un panneau de texte source repliable pour lire en regard de la traduction
  • Un raccourci clavier existe aussi : Alt+Shift+T (sur macOS : Command+Shift+Y)
Vidéo de démonstration (emplacement réservé) assets/demo-selection.mp4

02

Traduction d’éléments

Faites un clic droit sur une zone de la page pour y attacher un bouton de traduction. Un clic remplace le texte de la zone par la langue choisie, un second clic restaure le texte original.

  • Les règles sont mémorisées par domaine : la prochaine fois que vous revenez sur le même site, le bouton s’attache automatiquement
  • Les contenus longs sont envoyés par lots et remplacés au fil de la traduction, sans attendre que tout le bloc soit terminé
  • Les règles enregistrées peuvent être consultées et supprimées une par une depuis la page de gestion
Vidéo de démonstration (emplacement réservé) assets/demo-element.mp4

03

Traduction d’images

Faites un clic droit sur une image, reconnaissez le texte qu’elle contient, puis replacez la traduction sur l’image d’origine aux positions détectées.

  • Les images longues sont découpées en blocs avant la reconnaissance, les jointures étant automatiquement déplacées vers les lignes vides entre les textes, pour ne jamais couper une phrase en deux
  • Avant l’envoi, les images sont redimensionnées selon le nombre total de pixels et non selon le côté le plus long : la largeur d’une image longue n’est pas écrasée
  • Superpose la traduction à l'emplacement de l'image d'origine ; permet aussi d'ouvrir le panneau d'image, de téléverser, coller une image ou saisir l'adresse d'une image
  • Changer de langue cible réutilise le texte déjà reconnu ; changer d'image relance la reconnaissance
Vidéo de démonstration (emplacement réservé) assets/demo-image.mp4

04

Panneau de traduction

Une page autonome : le texte source à gauche, la traduction à droite, idéale pour les passages qui ne se trouvent pas sur une page web.

  • 24 langues cibles disponibles, couvrant les principales langues mondiales
  • La langue source peut être détectée automatiquement ou spécifiée manuellement, la langue cible est choisie indépendamment, le panneau mémorise le dernier choix
  • La plateforme et la langue cible sont dans la barre d’outils ; vous pouvez changer et retraduire à tout moment
Vidéo de démonstration (emplacement réservé) assets/demo-panel.mp4

Experimental

Sous-titres en temps réel pour la vidéo

Fonction expérimentale optionnelle, désactivée par défaut. Capture le son de l'onglet actif, le reconnaît en sous-titres puis le traduit ; la langue de reconnaissance vocale et la langue cible de traduction se configurent séparément.

La reconnaissance s'effectue par défaut en local ; le navigateur doit la prendre en charge et télécharger le pack de langue. Il est aussi possible de basculer vers la reconnaissance cloud de Google, auquel cas l'audio est envoyé à Google. La précision et la compatibilité restent limitées ; il est déconseillé de s'y fier pour des contenus importants. Le service hébergé ne reçoit que le texte reconnu et ne propose ni envoi ni transcription d'audio ou de vidéo.

24

Languages

Lire le contenu du monde, dans votre langue

La langue de l'interface, la source de traduction et la cible sont indépendantes. Lors de la première utilisation, la cible par défaut est choisie selon la langue du navigateur ; elle peut aussi être fixée dans les paramètres.

24 langues d'interface et langues cibles

Chinois simplifié, chinois traditionnel, anglais, japonais, coréen, espagnol, portugais (Brésil), français, allemand, italien, néerlandais, russe, ukrainien, polonais, turc, arabe, hébreu, persan, hindi, bengali, ourdou, indonésien, vietnamien et thaï.

L'entrée du menu contextuel suit la langue cible

Si la cible est le japonais, le menu indique une traduction vers le japonais ; si la cible est l'anglais, il indique une traduction vers l'anglais. Le chinois sélectionné peut aussi être traduit ; l'extension n'est plus conçue uniquement pour les lecteurs chinois.

De droite à gauche, une lecture naturelle

Les interfaces en arabe, hébreu, persan et ourdou utilisent une disposition de droite à gauche. Le sens de l'original et celui de la traduction sont déterminés séparément, sans modifier la mise en page de la page web. Les combinaisons de langues réellement disponibles dépendent de la plateforme choisie.

Privacy

Le contenu n'est envoyé que lorsque vous déclenchez la traduction

Avec une clé personnelle, le contenu à traduire est envoyé directement à la plateforme de votre choix. La traduction par points transite par nos serveurs vers le fournisseur de modèles ; les serveurs ne conservent ni les images, ni le texte source, ni la traduction. Le traitement audio après activation des sous-titres vidéo est décrit dans la politique de confidentialité.

Key personnelle : connexion directe à la plateforme

La requête est envoyée directement depuis votre navigateur vers la plateforme sélectionnée dans les paramètres, sans passer par nous. L'API Key est stockée dans chrome.storage.local et n'est pas synchronisée avec le compte Chrome.

Service hébergé : aucune conservation du contenu traduit

Le texte et les images hébergés ne résident que brièvement en mémoire pendant le traitement de la requête. Le compte ne conserve que l'adresse e-mail et le nom d'utilisateur nécessaires ; l'usage, les points et l'historique d'abonnement servent à fournir le service. Aucun avatar, pseudonyme ni empreinte d'appareil n'est collecté.

Aucune publicité ni statistique tierce

Aucune publicité, aucun traceur ni SDK de statistiques tiers, aucune vente ou location de données. Le code de l'extension et du serveur est publié sous GPL-3.0 et peut être vérifié ligne par ligne.

Description complète dans la politique de confidentialité et les conditions d'utilisation, ainsi que dans l'intégralité du code source publié sous GPL-3.0.

Account · 2.0.0

À utiliser dans l'extension, à gérer dans l'espace utilisateur

Le service de compte est lancé avec la version 2.0.0. L'extension est le principal point d'accès à la connexion et à la traduction ; le site officiel et l'espace utilisateur partagent le même compte et les mêmes avantages d'abonnement.

Connexion par e-mail ou Google

Connectez-vous avec un code de vérification par e-mail ou un compte Google, terminez l'autorisation dans l'onglet actuel du navigateur, puis revenez à l'extension. Seuls l'e-mail et le nom d'utilisateur sont nécessaires.

Mise à jour en temps réel du solde et du statut

Sans abonnement, consultez les points restants ; avec abonnement, l'usage illimité s'affiche. L'espace utilisateur permet de consulter votre consommation, l'historique des points, les abonnements, les commandes et les sessions de connexion ; après déconnexion de la session web en cours, l'extension associée se déconnecte également.

Conserver à tout moment le choix de votre propre clé

La traduction hébergée et votre propre clé peuvent être utilisées en alternance. Les requêtes avec votre propre clé se connectent directement à la plateforme, ne déduisent pas de points hébergés et ne nécessitent pas l'achat de notre abonnement.

Install

Installer depuis le Chrome Web Store

Nécessite Chrome 116 ou une version ultérieure ; les navigateurs à moteur Chromium tels qu'Edge sont également compatibles.

Ouvrir la page du magasin Sur ordinateur, ouvrez la page du Chrome Web Store.
Ajouter à Chrome Cliquez sur « Ajouter à Chrome » et confirmez.
Épingler à la barre d'outils Cliquez sur l'icône en forme de pièce de puzzle et épinglez l'extension à la barre d'outils.
Commencer à traduire Saisissez votre propre API Key dans les paramètres, sélectionnez du texte et cliquez avec le bouton droit pour traduire.
Ouvrir le Chrome Web Store

Vous pouvez aussi charger apps/extension en mode développeur depuis le code source GitHub.

La traduction d'images nécessite un modèle prenant en charge la reconnaissance d'images ; l'extension ne fonctionne pas sur les pages protégées de Chrome, ni sur le magasin d'extensions.
