v2.2.0 Nouveauté : lecture bilingue, transformez les articles web en pages de lecture alignées paragraphe par paragraphe.

Sélectionnez, faites un clic droit,
puis continuez à lire.

Une phrase, une image, un PDF ou un article entier sur une page web : un clic droit suffit pour le traduire dans votre langue. Prêt à l'emploi, sans saisir de clé API au préalable ; vous pouvez aussi utiliser votre propre clé OpenAI, DeepSeek ou DeepL.

Installer sur Chrome Installer sur Edge Voir le code source

Ce navigateur ne peut pas installer d'extensions Chrome : ouvrez cette page sur un ordinateur avec un navigateur basé sur Chromium, comme Chrome ou Edge.

  • Open source GPL-3.0 · 24 langues
  • Chrome / Edge 116+
  • Aucune traduction stockée · Aucune statistique tierce
  • Essai possible sans clé

Features

Six entrées, toutes dans le menu contextuel

Chaque fonction est accompagnée d'une démonstration, voir ci-dessous.

01

Lecture bilingueNouveau

Sur une page d'article, faites un clic droit dans une zone vide et choisissez « Lire cet article en bilingue » : une page de lecture contenant uniquement le corps du texte s'ouvre. Original et traduction se font face paragraphe par paragraphe, sans navigation ni publicité.

  • Affichage côte à côte, en vis-à-vis vertical, ou uniquement la traduction ou l'original
  • Cliquez sur un mot de la traduction pour choisir une autre formulation ; les variantes choisies sont ensuite prioritaires
  • L'article et sa traduction peuvent être stockés localement, sans retraduction à la prochaine ouverture
Espace réservé pour la vidéo de démonstration assets/demo-reader.mp4

02

Traduction par sélection

Sélectionnez un passage, faites un clic droit pour traduire : la traduction s'affiche dans une fenêtre au centre de la page.

  • Dans la fenêtre, vous pouvez afficher l'original en regard ou changer temporairement de langue cible
  • Cliquez sur un mot de la traduction pour choisir une autre formulation
  • Raccourci : Alt+Shift+T (sur macOS : Command+Shift+Y)
Vidéo de démonstration (emplacement réservé) assets/demo-selection.mp4

03

Traduction d’images

Faites un clic droit sur une image : le texte qu'elle contient est reconnu et la traduction est superposée à l'emplacement d'origine. L'image traduite peut être téléchargée ou copiée.

  • Le texte vertical des mangas japonais reste vertical lorsqu'il est traduit vers le chinois, le japonais ou le coréen
  • Vous pouvez sélectionner uniquement la partie à traduire, ou ajuster les zones de texte reconnues avant de traduire
  • Vous pouvez aussi importer ou coller une image, ou saisir l'adresse d'une image
Vidéo de démonstration (emplacement réservé) assets/demo-image.mp4

04

Traduction de PDF entier

Ouvrez un PDF dans Chrome et faites un clic droit pour traduire tout le document. La traduction est superposée à l'emplacement d'origine, la mise en page, les graphiques et les tableaux restent inchangés.

  • Original et traduction peuvent être affichés côte à côte
  • Enregistrez au format PDF via la fonction d'impression du navigateur : la traduction reste un texte sélectionnable et consultable par recherche
  • Le fichier est analysé uniquement en local ; seul le texte extrait est transmis. Les documents numérisés ne sont pas encore pris en charge
Emplacement de la vidéo de démonstration assets/demo-pdf.mp4

05

Traduction d’éléments

Faites un clic droit sur une zone d'une page web pour y ajouter un bouton de traduction. Un clic remplace le texte de la zone par sa traduction ; un autre clic rétablit l'original.

  • Les boutons sont mémorisés par site et réapparaissent automatiquement à la prochaine ouverture du même site
  • Les contenus longs sont traduits par segments, chaque segment traduit s'affiche au fur et à mesure
  • Les boutons ajoutés peuvent être consultés et supprimés depuis la page de gestion
Vidéo de démonstration (emplacement réservé) assets/demo-element.mp4

06

Panneau de traduction

Une page de traduction dédiée : collez le texte source à gauche, la traduction s'affiche à droite. Adaptée à la traduction de textes hors page web.

  • La langue source peut être détectée automatiquement ou spécifiée manuellement
  • Après un changement de plateforme ou de langue cible, la traduction peut être relancée directement
Vidéo de démonstration (emplacement réservé) assets/demo-panel.mp4

Experimental

Sous-titres en temps réel pour la vidéo

Fonction expérimentale, désactivée par défaut. Elle reconnaît l'audio de l'onglet actif sous forme de sous-titres, puis le traduit dans votre langue.

La reconnaissance s'effectue par défaut en local. Si vous optez pour la reconnaissance cloud du navigateur, l'audio est envoyé au service vocal du navigateur (Google pour Chrome, Microsoft Azure pour Edge). La précision de la reconnaissance reste limitée ; ne vous y fiez pas pour des contenus importants.

24

Languages

L'interface et les traductions prennent en charge 24 langues

La langue de l'interface, la langue source et la langue cible se configurent séparément. À la première utilisation, la langue cible suit par défaut la langue du navigateur ; elle est modifiable dans les paramètres.

Langues prises en charge

Chinois simplifié, chinois traditionnel, anglais, japonais, coréen, espagnol, portugais (Brésil), français, allemand, italien, néerlandais, russe, ukrainien, polonais, turc, arabe, hébreu, persan, hindi, bengali, ourdou, indonésien, vietnamien et thaï.

Le menu contextuel affiche la langue cible actuelle

Si la langue cible est le japonais, l'élément de menu indique « Traduire en japonais ». Un texte source en chinois peut également être traduit vers d'autres langues.

Langues écrites de droite à gauche prises en charge

Les interfaces en arabe, hébreu, persan et ourdou s'affichent de droite à gauche. Le texte source et la traduction s'affichent chacun selon leur propre direction, sans affecter la mise en page du site web. Les langues effectivement traduisibles dépendent de la plateforme de traduction choisie.

Privacy

Quels contenus quittent votre navigateur

Seuls les contenus que vous traduisez activement sont envoyés. Avec votre propre clé, les contenus sont envoyés directement à la plateforme choisie ; avec la traduction par points, les contenus transitent par notre serveur vers le fournisseur de modèles, le serveur ne conservant ni les images, ni le texte source, ni la traduction. Le traitement audio des sous-titres vidéo est décrit dans la politique de confidentialité.

Avec votre propre clé : sans passer par nous

Les requêtes sont envoyées directement depuis votre navigateur vers la plateforme choisie. La clé API est stockée uniquement dans ce navigateur et n'est pas synchronisée avec le compte Chrome.

Traduction par points : aucun contenu de traduction conservé

Le texte et les images ne restent que brièvement en mémoire sur le serveur pendant le traitement de la requête. Le compte ne conserve que l'adresse e-mail et le nom d'utilisateur, ainsi que les enregistrements d'utilisation, de points et d'abonnement nécessaires à la fourniture du service. Aucun avatar, pseudonyme ni empreinte d'appareil n'est collecté.

Sans publicité ni statistiques tierces

Aucune publicité, aucun suivi, aucun SDK de statistiques tiers, aucune vente ni location de données. Le code de l'extension et du serveur est publié sous GPL-3.0, vous pouvez le vérifier vous-même.

Description complète dans la politique de confidentialité et les conditions d'utilisation, ainsi que dans l'intégralité du code source publié sous GPL-3.0.

Account

Un seul compte, valable pour l'extension et le site web

Après connexion dans l'extension, vous pouvez utiliser la traduction par points. Les points, abonnements et commandes sont consultables dans l'espace utilisateur.

Connexion par e-mail ou Google

Connectez-vous par code de vérification e-mail ou avec un compte Google ; seuls l'adresse e-mail et le nom d'utilisateur sont requis.

Points et abonnements consultables dans l'espace utilisateur

L'espace utilisateur affiche les points restants, l'historique d'utilisation, les abonnements, les commandes et la session de connexion en cours. Si vous vous déconnectez sur le site web, l'extension correspondante se déconnecte également.

Votre propre clé reste utilisable même avec un abonnement

La traduction par points et votre propre clé sont interchangeables à tout moment. L'utilisation de votre propre clé ne déduit pas de points et ne nécessite pas d'abonnement.

Install

Installer depuis le Chrome Web Store ou le Edge Add-ons Store

Installable depuis le Chrome Web Store et le Microsoft Edge Add-ons Store ; le navigateur doit être en version 116 ou supérieure. Les navigateurs à moteur Chromium comme Brave s'installent depuis le Chrome Web Store.

Ouvrir la page du store Sur ordinateur, ouvrez la page du Chrome Web Store ; les utilisateurs d'Edge ouvrent la page du Edge Add-ons Store.
Ajouter l'extension Cliquez sur « Ajouter à Chrome » ou sur « Obtenir » dans Edge, puis confirmez.
Épingler à la barre d'outils Cliquez sur l'icône en forme de pièce de puzzle et épinglez l'extension à la barre d'outils.
Commencer à traduire Sélectionnez un passage, puis traduisez par clic droit. Les points d'essai permettent de commencer sans saisir de clé.
Ouvrir le Chrome Web Store Ouvrir le Edge Add-ons Store

Vous pouvez aussi charger apps/extension en mode développeur depuis le code source GitHub.

La traduction d'images nécessite un modèle prenant en charge la reconnaissance d'images ; l'extension ne fonctionne pas sur les pages protégées de Chrome, ni sur le magasin d'extensions.
