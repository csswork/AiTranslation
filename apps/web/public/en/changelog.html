v1.0.0
2026-09-15

First release

  • Selection translation: select non-Chinese text and right-click to translate; the translation streams into a popup in the middle of the screen. If the selection is already Chinese, the menu item does not appear.
  • Element translation: right-click a region of the page to attach a translate button to it; clicking it replaces the text in place. Rules are remembered per domain and can be managed on the rules page.
  • Image translation: right-click an image to read the text inside it; the translation is placed back over the original at the detected positions. Long images are split into content-aware tiles, with the seams kept between lines of text.
  • Translation panel: a standalone page with the source on the left and the translation on the right; pick any target language.
  • Works with the ChatGPT (OpenAI), DeepSeek and DeepL APIs; switch providers from the popup or the settings page at any time.
  • The API key lives in chrome.storage.local and is not synced through your Chrome account.
