A sentence, an image, a PDF, or an entire article on a web page can be translated into your language with a right-click. It works right after installation, with no API Key required; you can also use your own OpenAI, DeepSeek, or DeepL Key.

Features

Six entry points, all in the right-click menu

Each one comes with a demo; see below.

01

Bilingual readingNew

Right-click on an empty area of an article page and select "Read this article bilingually" to open a reading page with only the main text. Original and translation are paired paragraph by paragraph, with no navigation or ads.

  • View side by side, stacked, or show only the translation or only the original
  • Click a word in the translation to choose an alternative rendering; the chosen wording is preferred afterward
  • Articles and translations can be stored locally, so no re-translation is needed next time
Watch demo video

02

Selection translation

Select a passage of text and right-click to translate; the translation appears in a popup in the middle of the page.

  • In the popup, you can expand the original for comparison or temporarily switch the target language
  • Click a word in the translation to choose an alternative rendering
  • Shortcut: Alt+Shift+T (on macOS, Command+Shift+Y)
Watch demo video

03

Image translation

Right-click an image and the text in it is recognized, with the translation overlaid in place. The translated image can be downloaded or copied.

  • Vertical text in Japanese manga stays vertical when translated into Chinese, Japanese, or Korean
  • You can select only the part to translate, or adjust the recognized text regions before translating
  • You can also upload or paste an image, or enter an image URL
Watch demo video

04

Full PDF translation

Open a PDF in Chrome and right-click to translate the entire document. The translation is overlaid in place, with layout, figures, and tables unchanged.

  • Original and translation can be viewed side by side
  • Save as PDF using the browser's print function; the translation remains selectable and searchable text
  • Files are parsed locally only; only the extracted text is sent. Scanned documents are not supported yet
Watch demo video

05

Element translation

Right-click a region of a web page to add a translate button to it. Click once to replace the text with the translation; click again to restore the original.

  • Buttons are remembered per site and appear automatically the next time you open the same site
  • Long content is translated in batches, showing each translated section as it is ready
  • Added buttons can be viewed and deleted on the management page
Watch demo video

06

Translation panel

A standalone translation page: paste the source text on the left, get the translation on the right. Suitable for translating text that is not on a web page.

  • The source language can be detected automatically or specified manually
  • After switching platforms or target languages, you can translate again directly
Watch demo video

Experimental

Real-time video subtitles

Experimental feature, off by default. It recognizes the audio of the current tab as subtitles, then translates them into your language.

Recognition runs locally by default. If you switch to the browser's cloud recognition, the audio is sent to the browser's speech service (Google for Chrome, Microsoft Azure for Edge). Recognition accuracy is still limited; do not rely on it for important content.

24

Languages

The interface and translations support 24 languages

The interface language, source language, and target language are set separately. On first use, the target language follows the browser language by default and can be changed in settings.

Supported languages

Simplified Chinese, Traditional Chinese, English, Japanese, Korean, Spanish, Portuguese (Brazil), French, German, Italian, Dutch, Russian, Ukrainian, Polish, Turkish, Arabic, Hebrew, Persian, Hindi, Bengali, Urdu, Indonesian, Vietnamese, and Thai.

The context menu shows the current target language

If the target language is set to Japanese, the menu item reads "Translate to Japanese". Even if the source is Chinese, you can translate into other languages.

Support for right-to-left languages

The interfaces for Arabic, Hebrew, Persian, and Urdu are laid out right to left. Source text and translations each display in their own direction, and the page's own layout is unaffected. Which languages can actually be translated depends on the translation platform you choose.

Privacy

What leaves your browser

Only content you actively translate is sent. When using your own Key, content goes directly to the platform you choose; when translating with credits, content is relayed through our server to the model provider, and the server does not store images, source text, or translations. See the privacy policy for how audio from video subtitles is handled.

Using your own Key: does not go through us

Requests are sent directly from your browser to the platform you choose. The API Key is stored only in this browser and is not synced with your Chrome account.

Credit-based translation: translation content is not stored

Text and images stay briefly in server memory only while a request is being processed. Accounts store only an email address and username, plus the usage, credit, and subscription records needed to provide the service. No avatars, nicknames, or device fingerprints are collected.

No ads and no third-party analytics

No ads, no tracking, no third-party analytics SDKs, and no selling or renting of data. Both the extension and server code are public under GPL-3.0, so you can verify this yourself.

For full details, see the Privacy Policy and Terms of Service, as well as all source code published under GPL-3.0.

Install

Install from the Chrome or Edge store

Available in the Chrome Web Store and the Microsoft Edge Add-ons store; browser version 116 or later is required. Chromium-based browsers such as Brave install from the Chrome Web Store.

Open the store page On your computer, open the Chrome Web Store page; Edge users should open the Edge Add-ons store page.
Add the extension Click "Add to Chrome" or "Get" in Edge, then confirm.
Pin to the toolbar Click the puzzle icon and pin the extension to the toolbar.
Start translating Select some text and translate it from the context menu. You can use trial credits first without entering a key.
Open the Chrome Web Store Open the Edge Add-ons store

You can also load apps/extension in developer mode from the GitHub source code.

Image translation requires selecting a model that supports image recognition; the extension cannot be used on protected pages such as Chrome internal pages and the Web Store.
