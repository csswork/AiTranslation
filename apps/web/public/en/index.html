A Chrome extension. Select text, a whole page area, or an image, and translate it into the language you know. 24 interface and target languages can be chosen independently, and you can get started with your own OpenAI, DeepSeek, or DeepL API Key.

Features

Five entry points, all in the context menu

No tab switching, no copy-paste. Wherever the part you cannot read is, that is where the translation happens.

01

Selection translation

After selecting text, right-click to translate, and the translation appears in a centered pop-up; platforms that support streaming output can display it word by word. If you temporarily switch the target language, the original text is translated again.

  • Chinese, short phrases, and mixed-language text can all be translated; pure numbers, punctuation, and emoji do not show the translation entry point
  • The popup is centered and draggable, closes with Esc or a click on the backdrop — not a little bubble chasing your cursor
  • A collapsible source panel to read alongside the translation
  • There is a keyboard shortcut too: Alt+Shift+T (Command+Shift+Y on macOS)

02

Image translation

Right-click an image to recognize the text in it, overlay the full translation directly over the original text, and save the result as a new image.

  • Dialogue, headings, and paragraphs are each translated as a whole block; vertical text and furigana in Japanese manga are also supported
  • The overlay position is corrected based on the strokes in the image, and the background color is automatically sampled from colors near the text; you can also switch to dark, white, black, or a custom color
  • You can select only the areas to translate: rectangles or circles that can be dragged and resized, with multiple selections recognized in one pass
  • Results can be downloaded or copied as a new image, composited locally; you can also open the image panel to upload, paste an image, or enter an image URL
Demo video placeholder assets/demo-image.mp4

03

Full PDF translation Coming soon

In a PDF opened in Chrome, right-click without selecting any text and the entire document is translated in a side panel. Translations are overlaid in place, preserving layout, figures, and tables.

  • View source and translation side by side, or show only the translation or only the source
  • Tables are translated cell by cell, preserving rows, columns, and table lines; text that does not fit is automatically reduced in font size
  • Save as PDF via browser print; the translation is selectable and searchable text
  • Files are parsed locally; only the extracted text is sent to the translation platform. Local PDFs can be dragged directly into the translation page. Scanned documents are not supported yet
Demo video placeholder assets/demo-pdf.mp4

04

Element translation

Right-click a region on the page to attach a translation button to it. Click once and the text in the region is replaced in place with the selected language; click again to restore the original text.

  • Rules are remembered per domain, so the button is attached automatically the next time you visit that site
  • Long content is sent in batches and replaced as it is translated, so you do not wait for the whole region
  • Saved rules can be reviewed and deleted one by one on the rules page
Demo video placeholder assets/demo-element.mp4

05

Translation panel

A standalone page with the source on the left and the translation on the right, for passages that are not on a web page.

  • 24 target languages available, covering major global languages
  • The source language can be auto-detected or specified manually, the target language is selected independently, and the panel remembers the last selection
  • Provider and target language sit in the toolbar; switch and re-translate at any time

Experimental

Real-time video subtitles

Optional experimental feature, off by default. Captures the sound of the current tab, recognizes it into subtitles, then translates them; speech recognition language and translation target are configured separately.

Recognition is performed on-device by default, requiring browser support and a language pack download; you can also switch to Google cloud recognition, in which case audio is sent to Google. Accuracy and compatibility remain limited, and it is not recommended for important content. The hosted service receives only recognized text and does not provide audio or video upload or transcription.

24

Languages

Read the world's content in your language

Interface language, translation source, and target are independent. On first use, the default target is chosen based on the browser language, and you can also fix it in settings.

24 interface and target languages

Simplified Chinese, Traditional Chinese, English, Japanese, Korean, Spanish, Portuguese (Brazil), French, German, Italian, Dutch, Russian, Ukrainian, Polish, Turkish, Arabic, Hebrew, Persian, Hindi, Bengali, Urdu, Indonesian, Vietnamese, and Thai.

Right-click entry follows the translation target

If the target is Japanese, the menu shows translation into Japanese; if the target is English, it shows translation into English. Selected Chinese can also be translated, so it is no longer designed only for Chinese readers.

Right-to-left reads naturally too

Arabic, Hebrew, Persian, and Urdu interfaces use a right-to-left layout. The source text and translation each determine their own direction without changing the page's own layout. The language combinations actually available depend on the selected platform.

Privacy

Content is sent only when you trigger translation

With your own Key, translated content is sent directly to the platform you choose. Credit-based translation routes through our servers to the model provider; the servers do not store images, source text, or translations. For how audio is handled when video subtitles are enabled, see the privacy policy.

Bring your own Key: direct connection

Requests go from your browser directly to the platform you select in settings, without passing through us. The API Key is stored in chrome.storage.local and is not synced through your Chrome account.

Hosted service: translation content is not retained

Hosted text and images remain in memory only briefly while processing requests. Accounts store only the necessary email and username; usage, points, and subscription records are used to provide the service, and avatars, nicknames, or device fingerprints are not collected.

No ads and no third-party analytics

No ads, tracking, or third-party analytics SDKs are used, and no data is sold or rented. Both the extension and server code are public under GPL-3.0 and can be reviewed line by line.

For full details, see the Privacy Policy and Terms of Service, as well as all source code published under GPL-3.0.

Install

Install from the Chrome Web Store

Requires Chrome 116 or later; Chromium-based browsers such as Edge are also supported.

Open the store page On your computer, open the Chrome Web Store page.
Add to Chrome Click "Add to Chrome" and confirm.
Pin to the toolbar Click the puzzle icon and pin the extension to the toolbar.
Start translating Enter your own API Key in settings, select text, and right-click to translate.
Open the Chrome Web Store

You can also load apps/extension in developer mode from the GitHub source code.

Image translation requires selecting a model that supports image recognition; the extension cannot be used on protected pages such as Chrome internal pages and the Web Store.

Install it, then forget about it

Until the next time you select a passage you cannot read.
