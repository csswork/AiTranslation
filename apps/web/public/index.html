一个 Chrome 扩展。选中文字、整块网页区域，或一张图片，就能译成你熟悉的语言。24 种界面与目标语言可独立选择，用自己的 OpenAI、DeepSeek 或 DeepL API Key 即可开始。

安装到 Chrome 查看源码

这个浏览器装不了 Chrome 扩展：请在电脑上用 Chrome、Edge 等 Chromium 内核浏览器打开本页。

  • 开源 GPL-3.0 · 24 种语言
  • Chrome 116+
  • 不存译文 · 无第三方统计
  • 五种翻译方式

Features

五个入口，都在右键菜单里

不用切换标签页，不用复制粘贴。看不懂的那一段在哪，翻译就发生在哪。

01

划词翻译

选中文字后右键翻译，译文在居中弹窗里显示；支持流式输出的平台可逐字呈现。临时换个目标语言，会用原文重新翻译。

  • 中文、短词和混合语言都可以翻译；纯数字、标点和表情不显示翻译入口
  • 弹窗居中且可拖动，Esc 或点背景关闭，不是追着光标跑的小气泡
  • 可折叠的原文面板，对照着读
  • 也有快捷键：Alt+Shift+T（macOS 为 Command+Shift+Y）
演示视频占位 assets/demo-selection.mp4

02

图片翻译

右键一张图片，识别图里的文字，把整段译文贴着原文的位置盖回去，还能存成一张新图片。

  • 对话框、标题、段落各按整段翻译，日文漫画的竖排文字和注音假名也能处理
  • 按图上的笔画校正遮盖位置，底色自动取文字周围的相近色，也可换成深色、白、黑或自定义颜色
  • 可以只框选要翻译的地方：矩形或圆形，能拖动、调整大小，多个选区一次识别
  • 结果可下载或复制成新图片，在本机合成；也可打开图片面板，上传、粘贴图片或输入图片地址
演示视频占位 assets/demo-image.mp4

03

整份 PDF 翻译

在 Chrome 打开的 PDF 里，不选文字直接右键，整份文档在旁边的页面里翻译。译文按原位置盖回去，版面、图表和表格都不变。

  • 原文和译文并排对照，也可以只看译文或只看原文
  • 表格逐格翻译，行列与表格线保持原样；放不下的译文自动缩小字号
  • 通过浏览器打印另存为 PDF，译文是可选中、可搜索的文字
  • 文件只在本机解析，只有提取出的文字发给翻译平台；本地 PDF 可以直接拖进翻译页。暂不支持扫描件
演示视频占位 assets/demo-pdf.mp4

04

元素翻译

右键页面上的某个区域，给它挂一个翻译按钮。点一下，区域里的文字就地换成所选语言，再点可恢复原文。

  • 规则按域名记住，下次再来同一个网站，按钮自动挂上
  • 长内容分批送出，边译边替换，不用等整块跑完
  • 攒下的规则可以在管理页逐条查看和删除
演示视频占位 assets/demo-element.mp4

05

翻译面板

一个独立页面，左边贴原文右边出译文，适合处理成段的、不在网页上的文字。

  • 24 种目标语言可选，覆盖全球主流语言
  • 来源语言可自动识别或手动指定，目标语言独立选择，面板记住上次选择
  • 平台和目标语言就在工具栏上，随时切换重译
演示视频占位 assets/demo-panel.mp4

Experimental

视频实时字幕

可选的实验功能，默认关闭。读取当前标签页的声音，识别成字幕后再翻译；语音识别语言与翻译目标分别设置。

默认在本机识别，需浏览器支持并下载语言包；也可主动切换到浏览器的云端识别，此时声音会发给浏览器语音服务（Chrome 为 Google，Edge 为 Microsoft Azure）。识别准确度和兼容性仍有限，不建议依赖它处理重要内容。托管服务只接收识别后的文字，不提供音视频上传与转写。

24

Languages

用你的语言，读世界的内容

界面语言、翻译来源和目标各自独立。首次使用会根据浏览器语言选择默认目标，也可以在设置里固定下来。

24 种界面与目标语言

简体中文、繁体中文、英语、日语、韩语、西班牙语、葡萄牙语（巴西）、法语、德语、意大利语、荷兰语、俄语、乌克兰语、波兰语、土耳其语、阿拉伯语、希伯来语、波斯语、印地语、孟加拉语、乌尔都语、印尼语、越南语与泰语。

右键入口跟随翻译目标

目标选日语，菜单就提示译成日语；目标选英语，就提示译成英语。选中中文也能翻译，不再只为中文读者设计。

从右往左，也读得自然

阿拉伯语、希伯来语、波斯语和乌尔都语界面使用从右往左的布局。原文与译文各自判断方向，不改变网页本身的排版。实际可用的语言组合取决于所选平台。

Privacy

你触发翻译，内容才会发送

自带 Key 时，翻译内容直接发往你选的平台。点数翻译会经我们的服务器转给模型服务商，服务器不保存图片、原文或译文。视频字幕开启后的声音处理方式见隐私政策。

自带 Key：直连平台

请求从你的浏览器直接发往你在设置里选的那家平台，不经过我们。API Key 存在 chrome.storage.local，不走 Chrome 账号同步。

托管服务：不留存翻译内容

托管文字与图片只在处理请求时短暂停留于内存。账户只保存必要的邮箱与用户名；用量、点数和订阅记录用于提供服务，不采集头像、昵称或设备指纹。

没有广告与第三方统计

不使用广告、埋点或第三方统计 SDK，不出售或出租任何数据。扩展与服务端代码都以 GPL-3.0 公开，可以逐行核对。

完整说明见隐私政策与服务条款，以及 GPL-3.0 下公开的全部源码。

Install

从 Chrome 应用商店安装

需要 Chrome 116 或更高版本，Edge 等 Chromium 内核浏览器同样适用。

打开商店页面 在电脑上打开Chrome 应用商店页面。
添加至 Chrome 点「添加至 Chrome」并确认。
固定到工具栏 点拼图图标，把扩展固定到工具栏。
开始翻译 在设置里填入自己的 API Key，选中文字，右键翻译。
打开 Chrome 应用商店

也可以从 GitHub 源码以开发者模式加载 apps/extension。

图片翻译需选择支持图片识别的模型；扩展无法在 Chrome 内部页面、应用商店等受保护页面中使用。
