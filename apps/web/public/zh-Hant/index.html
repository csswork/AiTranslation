v2.2.0 新版：雙語閱讀，把網頁文章變成逐段對照的閱讀頁。

選取，按右鍵，
然後繼續閱讀。

網頁上的一句話、一張圖片、一份 PDF，或者一整篇文章，按右鍵就能翻譯成你的語言。裝好就能用，不用先填 API Key；想用自己的 OpenAI、DeepSeek 或 DeepL Key 也可以。

安裝到 Chrome 安裝到 Edge 檢視原始碼

這個瀏覽器無法安裝 Chrome 擴充功能：請在電腦上使用 Chrome、Edge 等 Chromium 核心瀏覽器開啟本頁。

  • 開源 GPL-3.0 · 24 種語言
  • Chrome / Edge 116+
  • 不儲存譯文 · 無第三方統計
  • 不填 Key 也能試用

Features

六個入口，都在右鍵選單裡

每一種都配了一段演示，往下看。

01

雙語閱讀新功能

在文章頁面的空白處按右鍵，選「雙語閱讀這篇文章」，會開啟一個只有正文的閱讀頁。原文和譯文一段對一段，沒有導覽和廣告。

  • 可以左右並排、上下對照，也可以只看譯文或只看原文
  • 點譯文裡的詞能換一種譯法，換過的說法之後會優先使用
  • 文章和譯文可以存在本機，下次開啟不用重新翻譯
觀看示範影片

02

劃詞翻譯

選取一段文字，按右鍵翻譯，譯文顯示在頁面中間的彈窗裡。

  • 彈窗裡可以展開原文對照，也可以臨時換一種目標語言
  • 點譯文裡的詞能換一種譯法
  • 快速鍵：Alt+Shift+T（macOS 為 Command+Shift+Y）
觀看示範影片

03

圖片翻譯

對一張圖片按右鍵，圖裡的文字會被辨識出來，譯文蓋在原來的位置上。譯好的圖可以下載或複製。

  • 日文漫畫的直排文字譯成中文、日文或韓文時保持直排
  • 可以只框選要翻譯的部分，也可以先調整辨識出的文字區域再翻譯
  • 也能上傳、貼上圖片，或輸入圖片網址
觀看示範影片

04

整份 PDF 翻譯

在 Chrome 裡開啟 PDF，按右鍵就能翻譯整份文件。譯文蓋在原來的位置，版面、圖表和表格不變。

  • 原文和譯文可以並排對照
  • 用瀏覽器的列印功能另存為 PDF，譯文仍是可以選取和搜尋的文字
  • 檔案只在本機解析，送出的只有擷取出的文字。暫不支援掃描件
觀看示範影片

05

元素翻譯

對網頁上的某一塊區域按右鍵，給它加一個翻譯按鈕。點一下，這塊文字換成譯文；再點一下，換回原文。

  • 按網站記住按鈕，下次開啟同一網站時會自動出現
  • 內容較長時分批翻譯，譯好一段顯示一段
  • 新增過的按鈕可在管理頁面檢視和刪除
觀看示範影片

06

翻譯面板

獨立的翻譯頁面：左邊貼上原文，右邊顯示譯文。適合翻譯不在網頁上的文字。

  • 原文語言可自動辨識，也可手動指定
  • 更換平台或目標語言後可直接重新翻譯
觀看示範影片

Experimental

影片即時字幕

實驗功能，預設關閉。它會將目前分頁的聲音辨識為字幕，再翻譯成你的語言。

辨識預設在本機進行。若改用瀏覽器的雲端辨識，聲音會傳送給瀏覽器的語音服務（Chrome 為 Google，Edge 為 Microsoft Azure）。辨識準確度仍有限，重要內容請勿依賴此功能。

24

Languages

介面與譯文皆支援 24 種語言

介面語言、原文語言與目標語言分開設定。首次使用時，目標語言預設跟隨瀏覽器語言，可在設定中變更。

支援的語言

簡體中文、繁體中文、英語、日語、韓語、西班牙語、葡萄牙語（巴西）、法語、德語、義大利語、荷蘭語、俄語、烏克蘭語、波蘭語、土耳其語、阿拉伯語、希伯來語、波斯語、印地語、孟加拉語、烏爾都語、印尼語、越南語與泰語。

右鍵選單顯示目前的目標語言

目標語言設為日語時，選單項目即為「翻譯成日語」。原文為中文時，也可翻譯成其他語言。

支援由右至左書寫的語言

阿拉伯語、希伯來語、波斯語與烏爾都語的介面由右至左排版。原文與譯文各自依其方向顯示，網頁本身的排版不受影響。實際可翻譯的語言取決於你選擇的翻譯平台。

Privacy

哪些內容會離開你的瀏覽器

只有你主動翻譯的內容會被傳送。使用自己的 Key 時，內容直接傳送給你選擇的平台；使用點數翻譯時，內容經我們的伺服器轉給模型服務商，伺服器不保存圖片、原文與譯文。影片字幕的聲音處理方式請見隱私政策。

使用自己的 Key：不經過我們

請求從你的瀏覽器直接傳送給你選擇的平台。API Key 只存在於此瀏覽器，不隨 Chrome 帳號同步。

點數翻譯：不保存翻譯內容

文字和圖片只在處理請求時短暫留在伺服器記憶體裡。帳戶只保存電子郵件和使用者名稱，另有提供服務所需的用量、點數和訂閱記錄。不蒐集頭像、暱稱和裝置指紋。

沒有廣告和第三方統計

不放廣告，不做埋點，不接第三方統計 SDK，不出售或出租資料。擴充功能和伺服器端的程式碼都以 GPL-3.0 公開，可以自行核對。

完整說明見隱私政策與服務條款，以及 GPL-3.0 下公開的全部原始碼。

Install

從 Chrome 或 Edge 商店安裝

Chrome 線上應用程式商店和 Microsoft Edge 擴充功能商店都能安裝，瀏覽器需要 116 或更高版本。Brave 等 Chromium 核心瀏覽器請從 Chrome 線上應用程式商店安裝。

開啟商店頁面 在電腦上開啟Chrome 應用商店頁面，Edge 使用者開啟Edge 載入項商店頁面。
新增擴充功能 點「新增至 Chrome」或 Edge 的「取得」，並確認。
固定到工具列 點拼圖圖示，把擴充功能固定到工具列。
開始翻譯 選取一段文字，按右鍵翻譯。不填 Key 也能先使用試用點數。
開啟 Chrome 線上應用程式商店 開啟 Edge 載入項商店

也可以從 GitHub 原始碼以開發者模式載入 apps/extension。

圖片翻譯需選擇支援圖片辨識的模型；擴充功能無法在 Chrome 內部頁面、應用程式商店等受保護頁面中使用。
