一個 Chrome 擴充功能。選取文字、整塊區域和圖片裡的文字，都能翻譯成你選擇的語言。24 種目標語言，介面語言獨立設定；可以用你自己的 API Key 直接連接所選平台，也可以用免費點數，不需要任何 Key。

安裝到 Chrome 檢視原始碼
Chrome 116+ 不存譯文 · 無第三方統計 四種翻譯方式

Features

四個入口，都在右鍵選單裡

不用切換分頁，不用複製貼上。看不懂的那一段在哪裡，翻譯就發生在哪裡。

01

劃詞翻譯

選取任意語言的文字，右鍵選擇翻譯，譯文在彈窗裡逐字出現。可臨時切換目標語言，用原文重新翻譯。

  • 中文、短詞和混合語言都可以翻譯；純數字、標點和表情不顯示翻譯入口
  • 彈出視窗置中且可拖曳，按 Esc 或點擊背景即可關閉，不是追著游標跑的小氣泡
  • 可收合的原文面板，方便對照閱讀
  • 也有鍵盤快速鍵：Alt+Shift+T（macOS 為 Command+Shift+Y）
示範影片預留位置 assets/demo-selection.mp4

02

元素翻譯

右鍵頁面上的某個區域，給它掛一個翻譯按鈕。點一下，區域裡的文字就地換成所選語言，再點可恢復原文。

  • 規則會依網域記住，下次再來同一個網站，按鈕會自動掛上
  • 長內容分批送出，邊翻譯邊取代，不用等整塊完成
  • 累積的規則可以在管理頁面逐條查看和刪除
示範影片預留位置 assets/demo-element.mp4

03

圖片翻譯

在圖片上按右鍵，辨識圖片裡的文字，再把譯文依辨識到的位置覆蓋回原圖上。

  • 長圖會先切塊再辨識，切縫會自動移到文字之間的空白行，不會把一句話切成兩半
  • 送交辨識前依總像素縮放，而不是依最長邊，長圖的寬度不會被壓縮掉
  • 結果會在獨立視窗中開啟，可以和原圖對照觀看
示範影片預留位置 assets/demo-image.mp4

04

翻譯面板

一個獨立頁面，左邊貼原文、右邊輸出譯文，適合處理成段的、不在網頁上的文字。

  • 24 種目標語言可選，覆蓋全球主流語言
  • 來源語言可自動識別或手動指定，目標語言獨立選擇，面板記住上次選擇
  • 平台和目標語言就在工具列上，隨時切換重新翻譯
示範影片預留位置 assets/demo-panel.mp4

Privacy

只在你翻譯時，文字才離開瀏覽器

兩種用法都只在你主動觸發翻譯時傳送內容：自帶 Key 時直接傳往你選的平台；用點數翻譯時經我們的伺服器轉給模型服務商，伺服器不保存原文和譯文。

自帶 Key：直連平台

請求從你的瀏覽器直接傳往你在設定裡選的那家平台，不經過我們。API Key 存在 chrome.storage.local，不走 Chrome 帳號同步。

點數翻譯：不留存內容

文字經 HTTPS 傳到我們的伺服器，轉給模型服務商完成翻譯。伺服器只記錄字數、token 與扣點，用於計費和防濫用，不保存原文和譯文。

沒有廣告與第三方統計

不使用廣告、埋點或第三方統計 SDK，不出售或出租任何資料。擴充功能與服務端程式碼都以 GPL-3.0 公開，可以逐行核對。

完整說明見隱私政策與服務條款，以及 GPL-3.0 下公開的全部原始碼。

Install

四步裝好

目前以開發者模式載入，需要 Chrome 116 或更高版本。安裝後即可用免費點數翻譯，也可以填入自己的 API Key。

取得原始碼 ——在 GitHub 上 Download ZIP 後解壓縮，或直接 git clone 儲存庫。
開啟擴充功能頁面 ——在網址列輸入 chrome://extensions/，開啟右上角的「開發人員模式」。
載入擴充功能 ——點選「載入未封裝項目」，選取剛才那個資料夾。
開始翻譯 ——首次安裝會自動領取免費點數並開啟歡迎頁，選取文字就能翻譯。想用自己的 Key，在設定頁選好平台、貼上 Key，點「測試連線」確認能通。

支援串接 ChatGPT（OpenAI）與 DeepSeek 的 API，隨時可以切換。兩者都預設選用各自最便宜的等級——翻譯是高頻率、短輸入的工作，沒必要用貴的。
