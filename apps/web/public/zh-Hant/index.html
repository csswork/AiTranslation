一個 Chrome 擴充功能。選取文字、整塊網頁區域，或一張圖片，就能譯成你熟悉的語言。24 種介面與目標語言可獨立選擇，用自己的 OpenAI、DeepSeek 或 DeepL API Key 即可開始。

安裝到 Chrome 檢視原始碼

這個瀏覽器無法安裝 Chrome 擴充功能：請在電腦上使用 Chrome、Edge 等 Chromium 核心瀏覽器開啟本頁。

  • Chrome 116+
  • 不儲存譯文 · 無第三方統計

Features

四個入口，都在右鍵選單裡

不用切換分頁，不用複製貼上。看不懂的那一段在哪裡，翻譯就發生在哪裡。

01

劃詞翻譯

選取文字後右鍵翻譯，譯文在居中彈窗裡顯示；支援串流輸出的平台可逐字呈現。臨時換個目標語言，會用原文重新翻譯。

  • 中文、短詞和混合語言都可以翻譯；純數字、標點和表情不顯示翻譯入口
  • 彈出視窗置中且可拖曳，按 Esc 或點擊背景即可關閉，不是追著游標跑的小氣泡
  • 可收合的原文面板，方便對照閱讀
  • 也有鍵盤快速鍵：Alt+Shift+T（macOS 為 Command+Shift+Y）
示範影片預留位置 assets/demo-selection.mp4

02

元素翻譯

右鍵頁面上的某個區域，給它掛一個翻譯按鈕。點一下，區域裡的文字就地換成所選語言，再點可恢復原文。

  • 規則會依網域記住，下次再來同一個網站，按鈕會自動掛上
  • 長內容分批送出，邊翻譯邊取代，不用等整塊完成
  • 累積的規則可以在管理頁面逐條查看和刪除
示範影片預留位置 assets/demo-element.mp4

03

圖片翻譯

在圖片上按右鍵，辨識圖片裡的文字，再把譯文依辨識到的位置覆蓋回原圖上。

  • 長圖會先切塊再辨識，切縫會自動移到文字之間的空白行，不會把一句話切成兩半
  • 送交辨識前依總像素縮放，而不是依最長邊，長圖的寬度不會被壓縮掉
  • 在原圖位置覆蓋譯文；也可開啟圖片面板，上傳、貼上圖片或輸入圖片位址
  • 切換目標語言複用已識別的文字；更換圖片後重新識別
示範影片預留位置 assets/demo-image.mp4

04

翻譯面板

一個獨立頁面，左邊貼原文、右邊輸出譯文，適合處理成段的、不在網頁上的文字。

  • 24 種目標語言可選，覆蓋全球主流語言
  • 來源語言可自動識別或手動指定，目標語言獨立選擇，面板記住上次選擇
  • 平台和目標語言就在工具列上，隨時切換重新翻譯
示範影片預留位置 assets/demo-panel.mp4

Experimental

影片即時字幕

可選的實驗功能，預設關閉。讀取目前分頁的聲音，識別成字幕後再翻譯；語音識別語言與翻譯目標分別設定。

預設在本機識別，需瀏覽器支援並下載語言包；也可主動切換到 Google 雲端識別，此時聲音會發給 Google。識別準確度和相容性仍有限，不建議依賴它處理重要內容。2.0.0 的託管服務只接收識別後的文字，不提供音影片上傳與轉寫。

24

Languages

用你的語言，讀世界的內容

介面語言、翻譯來源和目標各自獨立。首次使用會根據瀏覽器語言選擇預設目標，也可以在設定裡固定下來。

24 種介面與目標語言

簡體中文、繁體中文、英語、日語、韓語、西班牙語、葡萄牙語（巴西）、法語、德語、義大利語、荷蘭語、俄語、烏克蘭語、波蘭語、土耳其語、阿拉伯語、希伯來語、波斯語、印地語、孟加拉語、烏爾都語、印尼語、越南語與泰語。

右鍵入口跟隨翻譯目標

目標選日語，選單就提示譯成日語；目標選英語，就提示譯成英語。選取中文也能翻譯，不再只為中文讀者設計。

從右往左，也讀得自然

阿拉伯語、希伯來語、波斯語和烏爾都語介面使用從右往左的佈局。原文與譯文各自判斷方向，不改變網頁本身的排版。實際可用的語言組合取決於所選平台。

Privacy

你觸發翻譯，內容才會傳送

自帶 Key 時，翻譯內容直接發往你選的平台。即將上線的點數翻譯會經我們的伺服器轉給模型服務商，伺服器不保存圖片、原文或譯文。影片字幕開啟後的聲音處理方式見隱私政策。

自帶 Key：直連平台

請求從你的瀏覽器直接傳往你在設定裡選的那家平台，不經過我們。API Key 存在 chrome.storage.local，不走 Chrome 帳號同步。

託管服務：不留存翻譯內容

託管文字與圖片只在處理請求時短暫停留於記憶體。帳戶只保存必要的電子郵件與使用者名稱；用量、點數和訂閱記錄用於提供服務，不蒐集頭像、暱稱或裝置指紋。

沒有廣告與第三方統計

不使用廣告、埋點或第三方統計 SDK，不出售或出租任何資料。擴充功能與服務端程式碼都以 GPL-3.0 公開，可以逐行核對。

完整說明見隱私政策與服務條款，以及 GPL-3.0 下公開的全部原始碼。

Install

從 Chrome 線上應用程式商店安裝

需要 Chrome 116 或更高版本，Edge 等 Chromium 核心瀏覽器同樣適用。

開啟商店頁面 在電腦上開啟Chrome 應用程式商店頁面。
新增至 Chrome 點「新增至 Chrome」並確認。
固定到工具列 點拼圖圖示，把擴充功能固定到工具列。
開始翻譯 在設定裡填入自己的 API Key，選取文字，右鍵翻譯。
開啟 Chrome 線上應用程式商店

也可以從 GitHub 原始碼以開發者模式載入 apps/extension。

圖片翻譯需選擇支援圖片辨識的模型；擴充功能無法在 Chrome 內部頁面、應用程式商店等受保護頁面中使用。
