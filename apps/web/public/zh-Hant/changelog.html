v2.0.0
即將發佈

帳戶、免 Key 翻譯與訂閱

本版功能已可在本地測試，後端尚未部署，試用點數與訂閱尚未向公眾開放。自帶 Key 模式繼續保留。

  • 帳戶登入：電子郵件驗證碼或 Google 登入，在當前視窗的標籤頁授權後回到擴充功能；彈出頁與設定頁顯示使用者名稱、餘額和訂閱狀態。
  • 試用與點數：計劃提供訪客試用與註冊贈送，剩餘試用點數可轉入帳戶，贈送點數不過期；按實際用量精確扣減，失敗返還，不再每次向上取整扣一點。
  • 託管文字與圖片：無需自備 Key，支援劃詞、翻譯面板、網頁區域和圖片識別與翻譯。已識別的影片字幕可走託管文字翻譯；音影片上傳與託管轉寫尚未提供。
  • 訂閱與帳單：使用者中心管理訂閱、訂單、用量和登入工作階段。訂閱後按合理使用原則無限使用，支付計劃透過 Creem 處理，正式收款仍待上線驗證。
  • 狀態同步：網頁登出會撤銷由該網頁工作階段授權的擴充功能登入，不影響其他瀏覽器；本地開發與正式環境分別處理。
  • 介面與隱私：移除彈出頁重複的餘額顯示；補齊託管圖片說明與可選 Google 雲端語音辨識的資料處理說明。不儲存翻譯內容或圖片。
v1.1.0
2026-10-13

從中文翻譯工具，到 24 種語言

  • 完整多語言介面：提供 24 種介面與目標語言，介面、來源和目標各自獨立；首次安裝跟隨瀏覽器語言，升級保留已有偏好與 API 設定。
  • 面向不同語言讀者的翻譯互動：支援中文、短詞和混合語言選區，右鍵選單按當前目標語言產生，不再只提供「翻譯成中文」。
  • 臨時切換目標：劃詞彈窗從原文重譯，可明確儲存預設目標；翻譯面板記住自己的來源與目標選擇。
  • 區域與圖片改進：區域翻譯可恢復原文，失敗時回退；圖片切換目標時重複使用識別結果，更換圖片後清空快取。
  • 文字方向與平台能力：支援阿拉伯語等從右往左的介面，原文和譯文獨立排版；DeepL 按實際支援的語言組合處理，不支援時明確提示。
  • 實驗影片字幕：可手動開啟當前標籤頁的語音辨識與字幕翻譯，預設關閉，識別效果與相容性仍有限。
v1.0.0
2026-09-15

第一個版本

  • 劃詞翻譯：選取非中文文字後按右鍵翻譯，譯文會在螢幕中央的彈出視窗中串流顯示。選取的文字本身是中文時，選單不會出現。
  • 元素翻譯：在網頁上的某個區域按右鍵，為它掛上一個翻譯按鈕，點擊後就地替換區域內的文字；規則會依網域記住，可在管理頁面維護。
  • 圖片翻譯：在圖片上按右鍵以辨識其中的文字，譯文會依位置覆蓋回原圖。長圖會先依內容切塊，切縫會避開文字行。
  • 翻譯面板：獨立頁面，左邊原文、右邊譯文，目標語言可任選。
  • 支援串接 ChatGPT（OpenAI）、DeepSeek 與 DeepL 的 API，在彈出視窗或設定頁面隨時切換。
  • API Key 儲存於 chrome.storage.local，不會隨 Chrome 帳號同步。
