Privacy policy

隱私權政策

最後更新：2026-10-21 · Markdown 原稿

一句話總結

帳戶、點數與訂閱服務已隨 2.0.0 上線，以下說明這些服務的資料處理方式。

AI Selection Translator 有兩種用法。自帶 Key：你要翻譯的內容直接傳送至你自己設定的 AI 平台，不經過我們。點數翻譯：內容經我們的伺服器轉給模型服務商完成翻譯，伺服器不儲存原文與譯文。帳戶、計費與防濫用僅保留運行所必需的資料，不用於廣告，也不出售。

翻譯時會傳送的內容

僅在你主動觸發翻譯時（右鍵選單、快速鍵、點擊翻譯按鈕），以下內容才會透過 HTTPS 傳送：

內容傳送時機自帶 Key 時傳往點數翻譯時傳往
你選取的文字使用劃詞翻譯時你選擇的平台我們的伺服器，再轉給模型服務商
你指定區域內的文字點擊區域上的翻譯按鈕時同上同上
你在翻譯面板輸入的文字點擊翻譯時同上同上
影片字幕的辨識文字開啟影片字幕翻譯時同上同上
你翻譯的 PDF 中提取的文字使用「翻譯整個 PDF」，或在 PDF 翻譯頁開啟檔案時同上同上
你選擇翻譯的圖片使用圖片翻譯時你選擇的視覺平台我們的伺服器，再轉給 DeepSeek

自帶 Key 可選 OpenAI（ChatGPT）、DeepSeek 與 DeepL，請求分別傳往 https://api.openai.com、https://api.deepseek.com，以及 DeepL 的 https://api-free.deepl.com（付費 Key 為 https://api.deepl.com）。

點數翻譯的請求發往 https://app.huaci.app，由伺服器轉給 DeepSeek；DeepSeek 暫時不可用時，文字翻譯改用 Fireworks AI（美國節點）上的同款模型。圖片識別使用 DeepSeek Flash。 圖片、識別文字與譯文只在處理請求時短暫停留在記憶體裡，不寫入資料庫或日誌。

這些平台如何處理收到的內容，適用其各自的隱私政策：

  • OpenAI：openai.com/policies/privacy-policy
  • DeepSeek：platform.deepseek.com/downloads
  • DeepL：deepl.com/en/privacy
  • Fireworks AI：fireworks.ai/privacy-policy

不會傳送：你未主動翻譯的頁面內容、瀏覽歷史、Cookie、表單資料。擴充功能不會在背景自動掃描或上傳任何東西。

實驗影片字幕的聲音處理

影片字幕預設關閉。開啟後，預設在本機辨識目前分頁的聲音，可能需要下載瀏覽器語言包；只有你主動選擇「改用雲端辨識」時，聲音才會傳送至 Google 的語音辨識服務，適用 Google 隱私權政策。辨識後的字幕文字再按所選翻譯模式傳送給翻譯平台或我們的伺服器。我們不接收或保存影片、音訊，不提供託管音視訊轉寫。

整份 PDF 翻譯

此功能尚未隨 Chrome 商店版本發佈。你在 Chrome 內建 PDF 閱讀器裡選擇「翻譯整個 PDF」時，擴充功能會從同一網站重新讀取該分頁裡開啟的 PDF，和閱讀器一樣使用瀏覽器快取與該網站自己的 Cookie；你也可以在 PDF 翻譯頁選擇或拖入檔案。檔案只在你的裝置上解析和顯示，不會上傳給我們或翻譯平台；只有從中提取的文字會按上表分批傳送。渲染出的頁面和譯文只保存在該頁面的記憶體裡，關閉後即丟棄。「下載 PDF」透過瀏覽器的列印視窗產生，檔案保存在你選擇的位置。

帳戶資料

註冊或登入後，我們儲存：

  • 電子郵件與使用者名稱——用於登入、找回與聯絡你。不儲存姓名、頭像或其他資料。
  • 登入方式——使用 Google 登入時僅儲存 Google 帳戶的識別碼與已驗證的電子郵件。
  • 登入工作階段——僅記錄類型（網站或擴充功能）與時間，不記錄裝置型號、位置或裝置指紋。
  • 點數與訂閱——點數的發放、扣除與返還記錄，訂閱狀態，以及訂單的金額、幣種、退款狀態與帳單國家。

使用記錄

每次點數翻譯會記錄：字數、扣除的點數、模型與服務商、輸入和輸出的 token 數、目標語言與來源語言、耗時、結果（成功、失敗或被拒絕及原因），以及由網路服務商提供的兩位國家代碼。這些記錄用於計費、防止濫用和服務統計，不包含原文或譯文。你可以在使用者中心的「用量與點數」裡查看自己的記錄。

免費試用的防重複領取

安裝擴充功能後會自動領取一次免費點數。為防止同一網路或同一瀏覽器反覆領取，我們保存：網路位址經加密處理後的不可還原摘要（不保存位址本身，IPv6 只取前 64 位），以及歡迎頁在 app.huaci.app 上寫入的一個隨機標記 Cookie（資料庫裡只存它的摘要）。我們不使用裝置指紋。

付款

訂閱付款由 Creem 作為經銷商（Merchant of Record）處理，包括收款、稅費與收據。信用卡等付款資訊直接提交給 Creem，我們看不到也不保存。我們只保存 Creem 提供的訂閱與訂單編號、狀態、金額、幣種和帳單國家。Creem 如何處理你的資料，適用其隱私政策（creem.io/privacy）。

Cookie

  • 登入工作階段——app.huaci.app 上的 HttpOnly Cookie，用於保持網頁登入。
  • 偏好——語言與配色（lang、theme），官網與使用者中心共用。
  • 瀏覽器標記——見上文「免費試用的防重複領取」。

沒有廣告 Cookie，也沒有第三方統計 Cookie。

只儲存在你本機的內容

以下資料透過 chrome.storage.local 保存在你這台裝置上，不走 Chrome 帳號同步：

  • API Key——僅用於在請求標頭中向你選擇的平台鑑權，不會發給我們
  • 擴充功能的登入權杖——僅發給 app.huaci.app，用於點數翻譯與帳戶狀態
  • 偏好設定——目標語言、使用的模型、各項開關
  • 區域翻譯規則——你手動新增的「網域 + CSS 選擇器」

你可以隨時在設定頁面清除這些資料，或直接移除擴充功能（移除時會一併刪除）。

保存期限與刪除

帳戶、點數、訂單與使用記錄保存到你刪除帳戶為止；法律要求保留的交易記錄（例如稅務）會按要求保留。如需匯出或刪除你的帳戶及相關資料，請寄電子郵件到 support@huaci.app，我們會在 30 天內處理。

我們不做的事

  • 不保存你翻譯的原文和譯文
  • 不使用廣告、埋點或第三方統計 SDK
  • 不出售、不出租你的資料，也不用於廣告
  • 不使用你的翻譯內容訓練模型
