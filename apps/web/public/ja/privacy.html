Privacy policy

プライバシーポリシー

最終更新：2026-10-25 · Markdown 原稿

一言でいうと

アカウント、ポイント、サブスクリプションサービスは 2.0.0 で公開されました。以下ではこれらのサービスのデータ処理方法について説明します。

AI Selection Translator には 2 つの使い方があります。自分の Key を使う：翻訳する内容は、あなたが設定した AI プラットフォームへ直接送信され、当社を経由しません。ポイント翻訳：内容は当社のサーバーを経由してモデルサービス提供者に転送され、サーバーは原文と訳文を保存しません。アカウント、課金、不正利用防止のために、運用に必要なデータのみを保持し、広告には利用せず、販売もしません。

翻訳時に送信される内容

あなたが自ら翻訳を実行した場合（右クリックメニュー、ショートカット、翻訳ボタンのクリック）に限り、以下の内容が HTTPS で送信されます：

自分の Key では OpenAI（ChatGPT）、DeepSeek、DeepL を選択でき、リクエストはそれぞれ https://api.openai.com、https://api.deepseek.com、および DeepL の https://api-free.deepl.com（有料 Key は https://api.deepl.com）へ送信されます。

ポイント翻訳のリクエストは https://app.huaci.app に送信され、サーバーから DeepSeek に転送されます。DeepSeek が一時的に利用できない場合、テキスト翻訳は Fireworks AI（米国ノード）上の同一モデルに切り替わります。画像認識には DeepSeek Flash を使用します。画像、認識テキスト、訳文はリクエスト処理時に一時的にメモリ上に留まるのみで、データベースやログには書き込まれません。

これらのプラットフォームにおける受信内容の取り扱いには、各社のプライバシーポリシーが適用されます：

  • OpenAI：openai.com/policies/privacy-policy
  • DeepSeek：platform.deepseek.com/downloads
  • DeepL：deepl.com/en/privacy
  • Fireworks AI：fireworks.ai/privacy-policy

送信しません：自ら翻訳していないページ内容、閲覧履歴、Cookie、フォームデータ。拡張機能がバックグラウンドで自動的にスキャンやアップロードを行うことはありません。

実験的動画字幕の音声処理

動画字幕は既定でオフです。有効にすると、既定では現在のタブの音声を本機で認識し、ブラウザの言語パックのダウンロードが必要になる場合があります。「クラウド認識に切り替える」を自ら選択した場合にのみ、音声はブラウザの音声認識サービスに送信されます。Chrome は Google（Google プライバシーポリシー）、Microsoft Edge は Microsoft Azure（Microsoft プライバシーステートメント）を使用します。本機認識は対応するブラウザのバージョンと言語にのみ適用され、拡張機能が自動的にクラウド認識へ切り替わることはありません。認識後の字幕テキストは、選択した翻訳モードに従って翻訳プラットフォームまたは当社のサーバーに送信されます。当社は動画・音声を受信または保存せず、ホスト型の音声・動画文字起こしは提供しません。

PDF 全体の翻訳

ブラウザ内蔵のPDFリーダーで「PDF全体を翻訳」を選択すると、拡張機能は同じWebサイトからそのタブで開かれているPDFを再読み込みします。リーダーと同様にブラウザのキャッシュとそのサイト自身のCookieを使用します。PDF翻訳ページでファイルを選択したりドラッグしたりすることもできます。ファイルはお使いのデバイス上でのみ解析・表示され、当社や翻訳プラットフォームにアップロードされることはありません。抽出されたテキストのみが上記の表に従って分割送信されます。レンダリングされたページと翻訳文はそのページのメモリ内にのみ保存され、閉じると破棄されます。「PDFをダウンロード」はブラウザの印刷ウィンドウから生成され、ファイルは選択した場所に保存されます。

アカウントデータ

登録またはログイン後、以下を保存します：

  • メールアドレスとユーザー名——ログイン、復旧、連絡に使用します。氏名、アイコン、その他のプロフィールは保存しません。
  • ログイン方法——Google ログインの場合、Google アカウントの識別子と確認済みメールアドレスのみを保存します。
  • ログインセッション——種類（ウェブサイトまたは拡張機能）と時刻のみを記録し、端末モデル、位置情報、端末フィンガープリントは記録しません。
  • ポイントとサブスクリプション——ポイントの付与、消費、返還の記録、サブスクリプション状態、および注文の金額、通貨、返金状態、請求先国。

使用記録

ポイント翻訳のたびに、文字数、消費ポイント、モデルとプロバイダー、入力・出力トークン数、対象言語と原言語、所要時間、結果（成功・失敗・拒否とその理由）、およびネットワーク事業者が提供する2桁の国コードを記録します。これらの記録は課金、不正利用の防止、サービス統計に使用し、原文や訳文は含みません。ユーザーセンターの「利用量とポイント」で自分の記録を確認できます。

無料トライアルの重複受取防止

拡張機能をインストールすると、無料ポイントが一度だけ自動付与されます。同一ネットワークや同一ブラウザでの重複受取を防ぐため、以下を保存します。ネットワークアドレスを暗号化処理した復元不可能なダイジェスト（アドレス自体は保存せず、IPv6 は先頭 64 ビットのみ）、およびウェルカムページが app.huaci.app に書き込むランダムなマーカー Cookie（データベースにはそのダイジェストのみ保存）。デバイスフィンガープリントは使用しません。

支払い

サブスクリプションの支払いは Creem が販売業者（Merchant of Record）として処理し、代金回収、税金、領収書を含みます。カードなどの支払い情報は直接 Creem に送信され、当社は閲覧も保存もできません。当社が保存するのは Creem から提供されるサブスクリプションと注文の番号、ステータス、金額、通貨、請求先国のみです。Creem によるデータの取り扱いには、同社のプライバシーポリシーが適用されます（creem.io/privacy）。

Cookie

  • ログインセッション——app.huaci.app 上の HttpOnly Cookie。Web ログインの維持に使用します。
  • 設定——言語と配色（lang、theme）。公式サイトとユーザーセンターで共用します。
  • ブラウザマーカー——上記「無料トライアルの重複受取防止」を参照。

広告 Cookie も第三者統計 Cookie もありません。

お使いの端末にのみ保存される内容

以下のデータは chrome.storage.local によりお使いのデバイス上に保存され、Chrome アカウント同期は行いません。

  • API Key——選択したプラットフォームへのリクエストヘッダーでの認証にのみ使用し、当社には送信されません
  • 拡張機能のログイントークン——app.huaci.app にのみ送信し、ポイント翻訳とアカウント状態に使用します
  • 設定——対象言語、使用モデル、各種スイッチ
  • 領域翻訳ルール——手動で追加した「ドメイン + CSS セレクター」

これらのデータは設定ページからいつでも消去できますし、拡張機能をアンインストールしてもかまいません（アンインストール時にすべて削除されます）。

保存期間と削除

アカウント、ポイント、注文、使用記録はアカウントを削除するまで保存されます。法律上保持が必要な取引記録（税務など）は所定の期間保持します。アカウントおよび関連データのエクスポートや削除をご希望の場合は、support@huaci.app までメールでご連絡ください。30 日以内に対応します。

私たちが行わないこと

  • 翻訳した原文と訳文は保存しません
  • 広告、トラッキング、第三者統計 SDK は使用しません
  • データを販売・貸与せず、広告にも使用しません
  • 翻訳内容をモデルの学習に使用しません

拡張機能とサーバー側の全ソースコードは GPL-3.0 で公開されており、ご自身で確認できます： github.com/csswork/AiTranslation。
