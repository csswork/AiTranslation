v2.2.0 新版：バイリンガル読書で、ウェブ記事を段落ごとに対照できる読書ページに変えます。

選択して、右クリック、
そしてそのまま読み続ける。

ウェブページ上の一文、一枚の画像、一つの PDF、あるいは記事全体を、右クリックするだけであなたの言語に翻訳します。インストールすればすぐに使え、API Key の入力は不要です。自分の OpenAI、DeepSeek、DeepL の Key を使うこともできます。

Chrome にインストール Edge にインストール ソースコードを見る

このブラウザには Chrome 拡張機能をインストールできません。パソコンで Chrome、Edge などの Chromium ベースのブラウザを使用して本ページを開いてください。

Features

6 つの入口はすべて右クリックメニューにあります

それぞれにデモを用意しています。以下をご覧ください。

01

バイリンガル読書新機能

記事ページの空白部分で右クリックし、「この記事をバイリンガルで読む」を選ぶと、本文だけの閲覧ページが開きます。原文と訳文が段落ごとに対応し、ナビゲーションや広告はありません。

  • 左右に並べる、上下に対照する、訳文のみまたは原文のみで表示する、といった切り替えができます
  • 訳文中の語をクリックすると別の訳し方に変更でき、変更した表現は以後優先的に使われます
  • 記事と訳文は本機に保存でき、次回開くときに再翻訳は不要です
デモ動画を見る

02

選択翻訳

テキストを選択して右クリックで翻訳すると、訳文がページ中央のポップアップに表示されます。

  • ポップアップ内で原文との対照を展開したり、一時的に目標言語を切り替えたりできます
  • 訳文中の語をクリックすると別の訳し方に変更できます
  • ショートカット：Alt+Shift+T（macOS では Command+Shift+Y）
デモ動画を見る

03

画像翻訳

画像を右クリックすると、画像内の文字が認識され、訳文が元の位置に重ねて表示されます。翻訳後の画像はダウンロードまたはコピーできます。

  • 日本語漫画の縦書き文字を中国語、日本語、韓国語に翻訳する際は縦書きを維持します
  • 翻訳する部分だけを範囲選択したり、認識された文字領域を調整してから翻訳したりできます
  • 画像のアップロード、貼り付け、画像アドレスの入力にも対応しています
デモ動画を見る

04

PDF 全体の翻訳

Chrome で PDF を開き、右クリックするだけで文書全体を翻訳できます。訳文は元の位置に重ねて表示され、レイアウト、図表、表は変わりません。

  • 原文と訳文を並べて対照できます
  • ブラウザの印刷機能で PDF として保存しても、訳文は選択・検索できるテキストのままです
  • ファイルは本機でのみ解析され、送信されるのは抽出された文字だけです。スキャン文書には現在対応していません
デモ動画を見る

05

要素翻訳

ウェブページ上の任意の領域を右クリックして、翻訳ボタンを追加できます。クリックするとその部分の文字が訳文に、もう一度クリックすると原文に戻ります。

  • ボタンはサイトごとに記憶され、次回同じサイトを開くと自動的に表示されます
  • 内容が長い場合は分割して翻訳し、訳ができた部分から順に表示します
  • 追加したボタンは管理ページで確認・削除できます
デモ動画を見る

06

翻訳パネル

独立した翻訳ページです。左に原文を貼り、右に訳文が表示されます。ウェブページ上にないテキストの翻訳に適しています。

  • 原文の言語は自動認識のほか、手動で指定することもできます
  • プラットフォームや翻訳先の言語を変更した後、そのまま再翻訳できます
デモ動画を見る

Experimental

動画のリアルタイム字幕

実験的な機能で、既定では無効です。現在のタブの音声を認識して字幕にし、あなたの言語に翻訳します。

認識は既定では本機で行われます。ブラウザのクラウド認識に切り替えた場合、音声はブラウザの音声サービス（Chrome は Google、Edge は Microsoft Azure）に送信されます。認識精度にはまだ限界があるため、重要な内容をこれに依存しないでください。

24

Languages

インターフェースと訳文は 24 言語に対応

インターフェース言語、原文言語、翻訳先言語は個別に設定します。初回使用時、翻訳先言語は既定でブラウザの言語に従い、設定で変更できます。

対応言語

簡体字中国語、繁体字中国語、英語、日本語、韓国語、スペイン語、ポルトガル語（ブラジル）、フランス語、ドイツ語、イタリア語、オランダ語、ロシア語、ウクライナ語、ポーランド語、トルコ語、アラビア語、ヘブライ語、ペルシア語、ヒンディー語、ベンガル語、ウルドゥー語、インドネシア語、ベトナム語、タイ語。

右クリックメニューに現在の翻訳先言語を表示

翻訳先言語を日本語に設定すると、メニュー項目は「日本語に翻訳」になります。原文が中国語の場合も、他の言語に翻訳できます。

右から左に書く言語に対応

アラビア語、ヘブライ語、ペルシア語、ウルドゥー語のインターフェースは右から左に組まれます。原文と訳文はそれぞれの方向で表示され、ウェブページ自体の組版には影響しません。実際に翻訳できる言語は、選択した翻訳プラットフォームによって異なります。

Privacy

どの内容がブラウザの外に出るか

送信されるのは、あなたが自ら翻訳した内容のみです。自分の Key を使う場合、内容は選択したプラットフォームに直接送信されます。ポイントで翻訳する場合、内容は当社のサーバーを経由してモデルサービス提供者に転送され、サーバーは画像、原文、訳文を保存しません。動画字幕の音声の取り扱いについてはプライバシーポリシーをご覧ください。

自分の Key を使う場合：当社を経由しません

リクエストはあなたのブラウザから選択したプラットフォームに直接送信されます。API Key はこのブラウザにのみ保存され、Chrome アカウントとは同期されません。

ポイント翻訳：翻訳内容を保存しません

テキストと画像は処理リクエスト時にのみサーバーメモリに一時的に保持されます。アカウントにはメールアドレスとユーザー名のみを保存し、別途サービス提供に必要な利用量、ポイント、サブスクリプション記録を保存します。アバター、ニックネーム、デバイスフィンガープリントは収集しません。

広告と第三者統計はありません

広告は掲載せず、トラッキングも行わず、第三者統計SDKも導入せず、データの販売や貸与も行いません。拡張機能とサーバー側のコードはGPL-3.0で公開されており、ご自身で確認できます。

詳細はプライバシーポリシーと利用規約、および GPL-3.0 で公開されている全ソースコードをご覧ください。

Install

Chrome または Edge ストアからインストール

Chrome ウェブストアとMicrosoft Edge アドオンストアの両方からインストールでき、ブラウザはバージョン116以上が必要です。BraveなどのChromiumベースのブラウザはChrome ウェブストアからインストールしてください。

ストアページを開く パソコンでChrome ウェブストアのページを開きます。Edge ユーザーはEdge アドオンストアのページを開きます。
拡張機能を追加 「Chrome に追加」または Edge の「取得」をクリックし、確認します。
ツールバーに固定 パズルアイコンをクリックし、拡張機能をツールバーに固定します。
翻訳を開始 テキストを選択して右クリックで翻訳します。Keyを入力しなくても試用ポイントでまず利用できます。
Chrome ウェブストアを開く Edge アドオンストアを開く

GitHub のソースから開発者モードで apps/extension を読み込むこともできます。

画像翻訳には画像認識に対応したモデルを選択する必要があります。拡張機能は Chrome の内部ページやアプリストアなど保護されたページでは使用できません。
