Chrome 拡張機能です。テキスト、Web ページの領域、または画像を選択するだけで、使い慣れた言語に翻訳できます。24 種類の UI 言語と翻訳先言語は個別に選択でき、ご自身の OpenAI、DeepSeek、または DeepL の API Key で利用を開始できます。

Chrome にインストール ソースコードを見る

このブラウザには Chrome 拡張機能をインストールできません。パソコンで Chrome、Edge などの Chromium ベースのブラウザを使用して本ページを開いてください。

Features

5つの入口はすべて右クリックメニューにあります

タブを切り替える必要も、コピー＆ペーストする必要もありません。読めない部分がある場所で、そのまま翻訳が行われます。

01

選択翻訳

テキストを選択して右クリックで翻訳すると、訳文が中央のポップアップに表示されます。ストリーミング出力に対応するプラットフォームでは、文字ごとに表示されます。一時的に翻訳先言語を変更すると、原文から再翻訳されます。

  • 中国語、短い語句、混在言語も翻訳可能。数字のみ、句読点、絵文字には翻訳入口を表示しない
  • ポップアップは中央に表示され、ドラッグ可能です。Esc または背景のクリックで閉じられ、カーソルを追いかける小さなバブルではありません
  • 折りたたみ可能な原文パネルで、照らし合わせて読めます
  • キーボードショートカットもあります：Alt+Shift+T（macOS では Command+Shift+Y）
デモ動画のプレースホルダー assets/demo-selection.mp4

02

要素翻訳

ページ上の任意の領域を右クリックして、翻訳ボタンを割り当てます。クリックすると、その領域内のテキストが選択した言語にその場で置き換わり、もう一度クリックすると原文に戻ります。

  • ルールはドメインごとに記憶され、次に同じサイトを訪れたときはボタンが自動的に付きます
  • 長い内容は分割して送信し、翻訳しながら置き換えるため、領域全体の完了を待つ必要はありません
  • 保存したルールは管理ページで 1 件ずつ確認・削除できます
デモ動画のプレースホルダー assets/demo-element.mp4

03

画像翻訳

画像を右クリックすると中のテキストを認識し、訳文を認識した位置に合わせて元の画像に重ねます。

  • 長い画像は先に分割してから認識し、継ぎ目は自動的にテキスト間の空白行へ移されるため、一文が真っ二つになることはありません
  • 送信前に最長辺ではなく総ピクセル数で縮小するため、長い画像の幅がつぶれません
  • 元の画像の位置に訳文を重ねて表示します。画像パネルを開いて、画像のアップロード、貼り付け、または画像 URL の入力もできます
  • 翻訳先言語を切り替えると、認識済みのテキストを再利用します。画像を変更すると再認識します
デモ動画のプレースホルダー assets/demo-image.mp4

04

PDF 全体の翻訳 近日公開

Chrome で開いた PDF 内で、テキストを選択せずに右クリックすると、文書全体が隣のページで翻訳されます。訳文は元の位置に重ねて表示され、レイアウト、図表、表は変わりません。

  • 原文と訳文を並べて対照表示、訳文のみまたは原文のみの表示も可能
  • 表はセルごとに翻訳され、行・列と罫線はそのまま維持されます。収まらない訳文は自動的に文字サイズが縮小されます
  • ブラウザの印刷から PDF として保存でき、訳文は選択・検索可能なテキストです
  • ファイルは本機でのみ解析され、抽出されたテキストのみが翻訳プラットフォームに送信されます。ローカルの PDF は翻訳ページに直接ドラッグできます。スキャン文書には未対応です
デモ動画プレースホルダー assets/demo-pdf.mp4

05

翻訳パネル

独立したページで、左に原文を貼り、右に訳文が表示されます。ウェブページ上にない段落を扱うのに適しています。

  • 24 種類のターゲット言語から選択可能で、世界の主要言語をカバー
  • ソース言語は自動認識または手動指定が可能で、ターゲット言語は個別に選択でき、パネルは前回の選択を記憶します
  • プロバイダと対象言語はツールバーにあり、いつでも切り替えて再翻訳できます
デモ動画のプレースホルダー assets/demo-panel.mp4

Experimental

動画のリアルタイム字幕

任意の実験的機能で、デフォルトではオフです。現在のタブの音声を読み取り、字幕として認識してから翻訳します。音声認識言語と翻訳先はそれぞれ設定します。

既定では本機で認識し、ブラウザの対応と言語パックのダウンロードが必要です。Google のクラウド認識へ能動的に切り替えることもでき、その場合音声は Google へ送信されます。認識精度と互換性には依然として限界があり、重要な内容の処理をこれに依存することは推奨しません。ホストサービスは認識後のテキストのみを受信し、音声・動画のアップロードや文字起こしは提供しません。

24

Languages

あなたの言語で、世界の内容を読む

UI 言語、翻訳元、翻訳先はそれぞれ独立しています。初回利用時はブラウザの言語に基づいてデフォルトの翻訳先が選択され、設定で固定することもできます。

24 種類の UI 言語と翻訳先言語

簡体字中国語、繁体字中国語、英語、日本語、韓国語、スペイン語、ポルトガル語（ブラジル）、フランス語、ドイツ語、イタリア語、オランダ語、ロシア語、ウクライナ語、ポーランド語、トルコ語、アラビア語、ヘブライ語、ペルシア語、ヒンディー語、ベンガル語、ウルドゥー語、インドネシア語、ベトナム語、タイ語。

右クリックメニューは翻訳先に追従

翻訳先に日本語を選ぶと、メニューには日本語への翻訳と表示されます。翻訳先に英語を選ぶと、英語への翻訳と表示されます。中国語を選択しても翻訳でき、もはや中国語話者のためだけに設計されていません。

右から左への言語も自然に読める

アラビア語、ヘブライ語、ペルシア語、ウルドゥー語の UI は右から左へのレイアウトを使用します。原文と訳文はそれぞれ方向を判定し、Web ページ自体のレイアウトは変更しません。実際に利用可能な言語の組み合わせは、選択したプラットフォームによって異なります。

Privacy

翻訳を実行したときのみ、内容が送信されます

独自キーの場合、翻訳内容は選択したプラットフォームへ直接送信されます。ポイント翻訳では当社のサーバーを経由してモデルサービス提供者へ転送され、サーバーは画像、原文、訳文を保存しません。動画字幕を有効にした際の音声の取り扱いについてはプライバシーポリシーを参照してください。

Key を持ち込む場合：プラットフォームへ直接接続

リクエストはブラウザから設定で選択したプラットフォームへ直接送信され、当社を経由しません。API Key は chrome.storage.local に保存され、Chrome アカウントの同期は使用しません。

ホスト型サービス：翻訳内容を保持しません

ホスト型のテキストと画像は、リクエストの処理中に一時的にメモリ上にのみ留まります。アカウントには必要なメールアドレスとユーザー名のみを保存します。利用量、ポイント、サブスクリプションの記録はサービスの提供に使用し、アバター、ニックネーム、デバイスフィンガープリントは収集しません。

広告と第三者統計はありません

広告、トラッキング、第三者統計 SDK は使用せず、いかなるデータも販売または貸与しません。拡張機能とサーバー側のコードは GPL-3.0 で公開されており、行単位で確認できます。

詳細はプライバシーポリシーと利用規約、および GPL-3.0 で公開されている全ソースコードをご覧ください。

Install

Chrome ウェブストアからインストール

Chrome 116 以降が必要です。Edge など Chromium ベースのブラウザでも同様に利用できます。

ストアページを開く パソコンでChrome ウェブストアのページを開きます。
Chrome に追加 「Chrome に追加」をクリックして確認します。
ツールバーに固定 パズルアイコンをクリックし、拡張機能をツールバーに固定します。
翻訳を開始 設定で自身の API Key を入力し、テキストを選択して右クリックで翻訳します。
Chrome ウェブストアを開く

GitHub のソースから開発者モードで apps/extension を読み込むこともできます。

画像翻訳には画像認識に対応したモデルを選択する必要があります。拡張機能は Chrome の内部ページやアプリストアなど保護されたページでは使用できません。
