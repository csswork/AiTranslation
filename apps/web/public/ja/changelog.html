v2.0.0
近日公開

アカウント、Key 不要の翻訳、サブスクリプション

本バージョンの機能はローカルでテスト可能ですが、バックエンドはまだデプロイされておらず、試用ポイントとサブスクリプションは一般には公開されていません。独自 Key モードは引き続き利用できます。

  • アカウントログイン：メール認証コードまたは Google ログインに対応。現在のウィンドウのタブで認証後、拡張機能に戻ります。ポップアップと設定ページにユーザー名、残高、サブスクリプション状態を表示します。
  • 試用とポイント：ゲスト試用と登録特典を提供予定。残りの試用ポイントはアカウントに移行でき、特典ポイントは期限切れになりません。実際の使用量に応じて正確に差し引き、失敗時は返還され、毎回切り上げて 1 ポイント差し引くことはなくなります。
  • ホスティング文字・画像翻訳：独自 Key は不要で、選択テキスト、翻訳パネル、Web ページ領域、画像の認識と翻訳に対応します。認識済みの動画字幕はホスティング文字翻訳を利用できます。音声・動画のアップロードとホスティング文字起こしはまだ提供していません。
  • サブスクリプションと請求：ユーザーセンターでサブスクリプション、注文、使用量、ログインセッションを管理します。サブスクリプション後は合理的な使用の原則のもとで無制限に利用でき、支払いプランは Creem で処理されますが、正式な収款はまだ提供開始前の検証段階です。
  • 状態同期：Web ページからのログアウトは、その Web ページセッションで認証された拡張機能のログインを取り消しますが、他のブラウザには影響しません。ローカル開発環境と本番環境でそれぞれ処理します。
  • インターフェースとプライバシー：ポップアップの重複した残高表示を削除しました。ホスティング画像の説明と、オプションの Google クラウド音声認識のデータ処理に関する説明を追加しました。翻訳内容や画像は保存しません。
v1.1.0
2026-10-13

中国語翻訳ツールから、24 言語へ

  • 完全な多言語インターフェース：24 種類のインターフェース言語とターゲット言語を提供し、インターフェース、ソース、ターゲットはそれぞれ独立しています。初回インストール時はブラウザの言語に従い、アップグレード時は既存の設定と API 構成を保持します。
  • 多様な言語の読者に向けた翻訳操作：中国語、短い単語、混在言語の選択に対応し、右クリックメニューは現在のターゲット言語に応じて生成され、「中国語に翻訳」だけではなくなりました。
  • ターゲットの一時切り替え：選択テキストのポップアップは原文から再翻訳し、デフォルトのターゲットを明示的に保存できます。翻訳パネルは独自のソースとターゲットの選択を記憶します。
  • 領域と画像の改善：領域翻訳は原文を復元でき、失敗時はフォールバックします。画像のターゲット切り替え時は認識結果を再利用し、画像を変更するとキャッシュをクリアします。
  • 文字方向とプラットフォーム機能：アラビア語など右から左へのインターフェースに対応し、原文と訳文を独立してレイアウトします。DeepL は実際にサポートする言語の組み合わせに応じて処理し、非対応の場合は明確に通知します。
  • 実験的な動画字幕：現在のタブで音声認識と字幕翻訳を手動で有効にできます。デフォルトはオフで、認識精度と互換性はまだ限定的です。
v1.0.0
2026-09-15

最初のバージョン

  • 選択翻訳：中国語以外のテキストを選択して右クリックで翻訳すると、訳文が画面中央のポップアップにストリーミング表示されます。選択したテキスト自体が中国語のときは、メニューは表示されません。
  • 要素翻訳：ページ上の任意の領域を右クリックすると翻訳ボタンが付き、クリックするとその領域内のテキストがその場で置き換わります。ルールはドメインごとに記憶され、管理ページで保守できます。
  • 画像翻訳：画像を右クリックすると中のテキストを認識し、訳文が位置に合わせて元の画像に重ねられます。長い画像は先に内容に応じて分割され、継ぎ目はテキスト行を避けます。
  • 翻訳パネル：独立したページで、左に原文、右に訳文を表示し、対象言語は自由に選べます。
  • ChatGPT（OpenAI）、DeepSeek、DeepL の API に対応し、ポップアップまたは設定ページからいつでも切り替えられます。
  • API Key は chrome.storage.local に保存され、Chrome アカウントでは同期されません。
