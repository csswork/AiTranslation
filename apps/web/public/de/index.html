Eine Chrome-Erweiterung. Text markieren, einen ganzen Seitenbereich oder ein Bild auswählen und in die vertraute Sprache übersetzen. 24 Oberflächen- und Zielsprachen sind unabhängig wählbar; mit einem eigenen OpenAI-, DeepSeek- oder DeepL-API Key kann es sofort losgehen.

In Chrome installieren Quellcode ansehen

In diesem Browser können keine Chrome-Erweiterungen installiert werden: Bitte öffnen Sie diese Seite auf einem Computer mit einem Chromium-basierten Browser wie Chrome oder Edge.

Features

Fünf Einstiegspunkte, alle im Kontextmenü

Kein Tab-Wechsel, kein Kopieren und Einfügen. Wo die Passage steht, die Sie nicht verstehen, dort findet auch die Übersetzung statt.

01

Auswahlübersetzung

Nach dem Markieren von Text per Rechtsklick übersetzen; die Übersetzung erscheint in einem zentrierten Popup. Plattformen mit Streaming-Ausgabe können den Text zeichenweise anzeigen. Beim vorübergehenden Wechsel der Zielsprache wird der Ausgangstext neu übersetzt.

  • Chinesisch, kurze Wörter und gemischte Sprachen lassen sich übersetzen; bei reinen Zahlen, Satzzeichen und Emojis wird kein Übersetzungseinstieg angezeigt
  • Das Popup ist zentriert und verschiebbar, schließt mit Esc oder einem Klick auf den Hintergrund – keine kleine Sprechblase, die dem Cursor folgt
  • Ein einklappbarer Ausgangstextbereich zum Mitlesen
  • Es gibt auch einen Kurzbefehl: Alt+Shift+T (unter macOS Command+Shift+Y)
Platzhalter für Demo-Video assets/demo-selection.mp4

02

Elementübersetzung

Rechtsklick auf einen Bereich der Seite, um ihm eine Übersetzungsschaltfläche zuzuweisen. Ein Klick ersetzt den Text im Bereich direkt durch die gewählte Sprache, ein weiterer Klick stellt das Original wieder her.

  • Regeln werden pro Domain gespeichert; beim nächsten Besuch derselben Website wird die Schaltfläche automatisch angebracht
  • Lange Inhalte werden in Stapeln gesendet und während der Übersetzung ersetzt, sodass Sie nicht auf den gesamten Bereich warten müssen
  • Gespeicherte Regeln lassen sich auf der Verwaltungsseite einzeln ansehen und löschen
Platzhalter für Demo-Video assets/demo-element.mp4

03

Bildübersetzung

Ein Rechtsklick auf ein Bild erkennt den darin enthaltenen Text; anschließend wird die Übersetzung an der erkannten Position über das Originalbild gelegt.

  • Lange Bilder werden vor der Erkennung in Kacheln geteilt; die Schnittkanten werden automatisch in die Leerzeilen zwischen den Textzeilen verschoben, sodass kein Satz geteilt wird
  • Vor der Übergabe wird nach Gesamtpixelzahl statt nach der längsten Kante skaliert, damit die Breite langer Bilder nicht zusammengedrückt wird
  • Die Übersetzung wird an der Position des Originalbilds überlagert; alternativ lässt sich das Bildfenster öffnen, um Bilder hochzuladen, einzufügen oder eine Bild-URL einzugeben
  • Beim Wechsel der Zielsprache wird der bereits erkannte Text wiederverwendet; nach dem Austausch des Bilds wird neu erkannt
Platzhalter für Demo-Video assets/demo-image.mp4

04

Übersetzung ganzer PDF-Dokumente Demnächst verfügbar

In einem in Chrome geöffneten PDF ohne Textauswahl direkt das Kontextmenü öffnen: Das gesamte Dokument wird auf einer benachbarten Seite übersetzt. Die Übersetzung wird an der ursprünglichen Position eingeblendet; Layout, Diagramme und Tabellen bleiben unverändert.

  • Original und Übersetzung im direkten Vergleich nebeneinander; auch nur die Übersetzung oder nur das Original lässt sich anzeigen
  • Tabellen werden Zelle für Zelle übersetzt, Zeilen, Spalten und Tabellenlinien bleiben erhalten; zu lange Übersetzungen werden automatisch verkleinert
  • Über den Browser-Druck als PDF speichern; die Übersetzung ist auswählbarer und durchsuchbarer Text
  • Dateien werden ausschließlich lokal verarbeitet; nur der extrahierte Text wird an die Übersetzungsplattform gesendet. Lokale PDFs lassen sich direkt in die Übersetzungsseite ziehen. Gescannte Dokumente werden derzeit nicht unterstützt
Platzhalter für Demovideo assets/demo-pdf.mp4

05

Übersetzungsbereich

Eine eigenständige Seite: links der Ausgangstext, rechts die Übersetzung – geeignet für zusammenhängende Textpassagen, die nicht auf einer Webseite stehen.

  • 24 Zielsprachen zur Auswahl, die wichtigsten Sprachen weltweit abgedeckt
  • Die Ausgangssprache kann automatisch erkannt oder manuell festgelegt werden, die Zielsprache wird separat gewählt, das Panel merkt sich die letzte Auswahl
  • Anbieter und Zielsprache befinden sich in der Symbolleiste; jederzeit umschalten und neu übersetzen
Platzhalter für Demo-Video assets/demo-panel.mp4

Experimental

Echtzeit-Untertitel für Videos

Optionales experimentelles Feature, standardmäßig deaktiviert. Der Ton des aktuellen Tabs wird erfasst, als Untertitel erkannt und anschließend übersetzt; Spracherkennungssprache und Übersetzungsziel werden getrennt eingestellt.

Standardmäßig erfolgt die Erkennung lokal; der Browser muss dies unterstützen und das Sprachpaket herunterladen. Es kann auch aktiv auf die Google-Cloud-Erkennung umgeschaltet werden, wobei die Audiodaten an Google gesendet werden. Erkennungsgenauigkeit und Kompatibilität sind weiterhin begrenzt; es wird nicht empfohlen, sich bei wichtigen Inhalten darauf zu verlassen. Der gehostete Dienst erhält nur den erkannten Text; Audio- und Video-Uploads sowie Transkription werden nicht angeboten.

24

Languages

In deiner Sprache die Inhalte der Welt lesen

Oberflächensprache, Übersetzungsquelle und Ziel sind jeweils unabhängig. Bei der ersten Nutzung wird anhand der Browsersprache ein Standardziel gewählt; in den Einstellungen kann es auch festgelegt werden.

24 Oberflächen- und Zielsprachen

Vereinfachtes Chinesisch, traditionelles Chinesisch, Englisch, Japanisch, Koreanisch, Spanisch, Portugiesisch (Brasilien), Französisch, Deutsch, Italienisch, Niederländisch, Russisch, Ukrainisch, Polnisch, Türkisch, Arabisch, Hebräisch, Persisch, Hindi, Bengalisch, Urdu, Indonesisch, Vietnamesisch und Thailändisch.

Rechtsklick-Einstieg folgt dem Übersetzungsziel

Ist Japanisch als Ziel gewählt, zeigt das Menü die Übersetzung ins Japanische an; ist Englisch als Ziel gewählt, die Übersetzung ins Englische. Auch markiertes Chinesisch kann übersetzt werden; es ist nicht mehr nur für chinesische Leser gedacht.

Auch von rechts nach links natürlich lesbar

Die Oberflächen für Arabisch, Hebräisch, Persisch und Urdu verwenden ein Layout von rechts nach links. Ausgangstext und Übersetzung bestimmen ihre Richtung jeweils selbst und verändern das Layout der Webseite nicht. Die tatsächlich verfügbaren Sprachkombinationen hängen von der gewählten Plattform ab.

Privacy

Inhalte werden erst gesendet, wenn du die Übersetzung auslöst

Bei eigenem Key werden die Übersetzungsinhalte direkt an die gewählte Plattform gesendet. Bei der Punkteübersetzung werden sie über unsere Server an den Modellanbieter weitergeleitet; die Server speichern weder Bilder noch Ausgangstext oder Übersetzung. Wie Audiodaten bei aktivierten Videountertiteln verarbeitet werden, ist in der Datenschutzerklärung beschrieben.

Eigener Key: direkte Verbindung zur Plattform

Die Anfrage geht direkt von Ihrem Browser an die in den Einstellungen gewählte Plattform und nicht über uns. Der API Key wird in chrome.storage.local gespeichert und nicht über das Chrome-Konto synchronisiert.

Gehosteter Dienst: keine Speicherung von Übersetzungsinhalten

Gehosteter Text und gehostete Bilder verbleiben nur während der Verarbeitung einer Anfrage kurzzeitig im Arbeitsspeicher. Das Konto speichert nur die erforderliche E-Mail-Adresse und den Benutzernamen; Nutzung, Punkte und Abonnementdaten dienen der Bereitstellung des Dienstes. Avatare, Anzeigenamen oder Gerätefingerabdrücke werden nicht erfasst.

Keine Werbung und keine Statistiken Dritter

Es werden keine Werbung, kein Tracking und keine Statistik-SDKs Dritter eingesetzt; Daten werden weder verkauft noch vermietet. Der Code der Erweiterung und des Servers ist unter GPL-3.0 offengelegt und kann Zeile für Zeile geprüft werden.

Vollständige Angaben finden Sie in der Datenschutzerklärung und den Nutzungsbedingungen sowie im vollständigen, unter GPL-3.0 offengelegten Quellcode.

Aus dem Chrome Web Store installieren

Erfordert Chrome 116 oder höher; auch Chromium-basierte Browser wie Edge werden unterstützt.

Store-Seite öffnen Öffnen Sie am Computer die Seite im Chrome Web Store.
Zu Chrome hinzufügen Klicken Sie auf „Zu Chrome hinzufügen“ und bestätigen Sie.
An die Symbolleiste anheften Klicken Sie auf das Puzzleteil-Symbol und heften Sie die Erweiterung an die Symbolleiste.
Übersetzung starten Hinterlegen Sie in den Einstellungen Ihren eigenen API Key, markieren Sie Text und übersetzen Sie per Rechtsklick.
Chrome Web Store öffnen
