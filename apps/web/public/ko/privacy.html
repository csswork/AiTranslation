한 문장 요약

계정, 포인트 및 구독 서비스는 2.0.0과 함께 출시되었으며, 아래에서는 이러한 서비스의 데이터 처리 방식을 설명합니다.

AI Selection Translator는 두 가지 방식으로 사용할 수 있습니다. 자체 Key 사용: 번역할 내용을 사용자가 직접 설정한 AI 플랫폼으로 전송하며, 저희를 거치지 않습니다. 포인트 번역: 내용이 저희 서버를 통해 모델 제공업체로 전달되어 번역이 완료되며, 서버는 원문과 번역문을 저장하지 않습니다. 계정, 과금, 오남용 방지를 위해 운영에 필요한 최소한의 데이터만 보관하며, 광고에 사용하거나 판매하지 않습니다.

자체 Key는 OpenAI(ChatGPT), DeepSeek, DeepL을 선택할 수 있으며, 요청은 각각 https://api.openai.com, https://api.deepseek.com, 그리고 DeepL의 https://api-free.deepl.com(유료 Key는 https://api.deepl.com)으로 전송됩니다.

포인트 번역 요청은 https://app.huaci.app로 전송되며, 서버에서 DeepSeek로 전달됩니다. DeepSeek을 일시적으로 사용할 수 없을 때는 텍스트 번역이 Fireworks AI(미국 노드)의 동일 모델로 전환됩니다. 이미지 인식은 DeepSeek Flash를 사용합니다. 이미지, 인식된 텍스트 및 번역문은 요청 처리 중에만 메모리에 일시적으로 남으며 데이터베이스나 로그에 기록되지 않습니다.

이 플랫폼들이 수신한 내용을 처리하는 방식에는 각 플랫폼의 개인정보 처리방침이 적용됩니다:

  • OpenAI：openai.com/policies/privacy-policy
  • DeepSeek：platform.deepseek.com/downloads
  • DeepL：deepl.com/en/privacy
  • Fireworks AI：fireworks.ai/privacy-policy

전송하지 않음: 사용자가 직접 번역하지 않은 페이지 내용, 방문 기록, 쿠키, 양식 데이터. 확장 프로그램은 백그라운드에서 아무것도 자동으로 스캔하거나 업로드하지 않습니다.

실험적 동영상 자막의 음성 처리

동영상 자막은 기본적으로 꺼져 있습니다. 활성화하면 기본적으로 현재 탭의 소리를 본 기기에서 인식하며, 브라우저 언어 팩을 다운로드해야 할 수 있습니다. 사용자가 직접 「클라우드 인식으로 전환」을 선택한 경우에만 소리가 Google의 음성 인식 서비스로 전송되며, Google 개인정보처리방침이 적용됩니다. 인식된 자막 텍스트는 선택한 번역 모드에 따라 번역 플랫폼 또는 당사 서버로 전송됩니다. 당사는 동영상과 오디오를 수신하거나 저장하지 않으며, 음성·영상 전사 호스팅 서비스를 제공하지 않습니다.

전체 PDF 번역

이 기능은 아직 Chrome 스토어 버전으로 출시되지 않았습니다. Chrome 내장 PDF 리더에서 「전체 PDF 번역」을 선택하면 확장 프로그램이 동일한 웹사이트에서 해당 탭에 열린 PDF를 다시 읽으며, 리더와 마찬가지로 브라우저 캐시와 해당 웹사이트 자체의 Cookie를 사용합니다. PDF 번역 페이지에서 파일을 선택하거나 끌어다 놓을 수도 있습니다. 파일은 사용자의 기기에서만 파싱되고 표시되며, 당사나 번역 플랫폼으로 업로드되지 않습니다. 추출된 텍스트만 위 표에 따라 나누어 전송됩니다. 렌더링된 페이지와 번역문은 해당 페이지의 메모리에만 저장되며 닫으면 폐기됩니다. 「PDF 다운로드」는 브라우저 인쇄 창을 통해 생성되며 파일은 사용자가 선택한 위치에 저장됩니다.

계정 데이터

가입 또는 로그인 후 저희가 저장하는 항목:

  • 이메일과 사용자 이름——로그인, 계정 복구, 연락에 사용합니다. 이름, 프로필 사진 또는 기타 정보는 저장하지 않습니다.
  • 로그인 방식——Google 로그인 시 Google 계정 식별자와 인증된 이메일만 저장합니다.
  • 로그인 세션——유형(웹사이트 또는 확장 프로그램)과 시간만 기록하며, 기기 모델, 위치, 기기 지문은 기록하지 않습니다.
  • 포인트와 구독——포인트 지급, 차감, 반환 기록, 구독 상태, 그리고 주문의 금액, 통화, 환불 상태, 청구 국가.

사용 기록

번역을 요청할 때마다 다음 항목이 기록됩니다: 글자 수, 차감된 포인트, 모델과 서비스 제공자, 입력 및 출력 token 수, 대상 언어와 원본 언어, 소요 시간, 결과(성공, 실패 또는 거부 및 사유), 그리고 네트워크 서비스 제공자가 제공하는 두 자리 국가 코드. 이 기록은 과금, 남용 방지 및 서비스 통계에 사용되며, 원문이나 번역문은 포함하지 않습니다. 사용자 센터의 「사용량과 포인트」에서 본인의 기록을 확인할 수 있습니다.

무료 체험의 중복 수령 방지

확장 프로그램을 설치하면 무료 포인트가 한 번 자동으로 지급됩니다. 동일한 네트워크나 동일한 브라우저에서 반복 수령하는 것을 방지하기 위해 다음을 저장합니다: 네트워크 주소를 암호화 처리한 복원 불가능한 요약값(주소 자체는 저장하지 않으며, IPv6는 앞 64비트만 사용), 그리고 환영 페이지가 app.huaci.app에 기록하는 무작위 표시 Cookie(데이터베이스에는 그 요약값만 저장). 기기 지문은 사용하지 않습니다.

결제

구독 결제는 Creem이 판매자(Merchant of Record)로서 처리하며, 대금 수납, 세금 및 영수증을 포함합니다. 카드 등 결제 정보는 Creem에 직접 제출되며, 당사는 이를 볼 수 없고 저장하지도 않습니다. 당사는 Creem이 제공하는 구독 및 주문 번호, 상태, 금액, 통화 및 청구 국가만 저장합니다. Creem의 데이터 처리에는 해당 개인정보 처리방침이 적용됩니다(creem.io/privacy).

Cookie

  • 로그인 세션——app.huaci.app의 HttpOnly Cookie로, 웹 로그인 유지에 사용됩니다.
  • 환경설정——언어와 테마(lang, theme), 공식 사이트와 사용자 센터에서 공유됩니다.
  • 브라우저 표시——위의 「무료 체험의 중복 수령 방지」를 참조하십시오.

광고 Cookie도, 제3자 통계 Cookie도 없습니다.

내 기기에만 저장되는 내용

다음 데이터는 chrome.storage.local을 통해 이 기기에 저장되며, Chrome 계정 동기화를 거치지 않습니다:

  • API Key——선택한 플랫폼에 요청 헤더로 인증할 때만 사용되며, 당사에 전송되지 않습니다
  • 확장 프로그램의 로그인 토큰——app.huaci.app에만 전송되며, 포인트 번역과 계정 상태에 사용됩니다
  • 환경설정——대상 언어, 사용할 모델, 각종 스위치
  • 영역 번역 규칙——직접 추가한 「도메인 + CSS 선택자」

설정 페이지에서 언제든지 이 데이터를 지울 수 있으며, 확장 프로그램을 삭제해도 됩니다(삭제하면 함께 지워집니다).

보존 기간과 삭제

계정, 포인트, 주문 및 사용 기록은 계정을 삭제할 때까지 보존됩니다. 법률상 보존이 요구되는 거래 기록(예: 세무)은 요구에 따라 보존됩니다. 계정 및 관련 데이터의 내보내기나 삭제가 필요하면 support@huaci.app으로 이메일을 보내주십시오. 30일 이내에 처리합니다.

하지 않는 일

  • 번역한 원문과 번역문을 저장하지 않습니다
  • 광고, 트래킹 또는 제3자 통계 SDK를 사용하지 않습니다
  • 데이터를 판매하거나 대여하지 않으며, 광고에 사용하지도 않습니다
  • 사용자의 번역 내용을 모델 학습에 사용하지 않습니다

확장 프로그램과 서버의 전체 소스 코드는 GPL-3.0으로 공개되어 있으니 직접 확인할 수 있습니다: github.com/csswork/AiTranslation.
