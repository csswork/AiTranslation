웹페이지의 문장 하나, 이미지 하나, PDF 한 개, 또는 글 전체를 마우스 오른쪽 버튼으로 클릭해 내 언어로 번역할 수 있습니다. 설치하면 바로 사용할 수 있으며 API Key를 먼저 입력할 필요가 없습니다. 원하는 경우 자신의 OpenAI, DeepSeek 또는 DeepL Key를 사용할 수도 있습니다.

Chrome에 설치 Edge에 설치 소스 코드 보기

이 브라우저에는 Chrome 확장 프로그램을 설치할 수 없습니다. 컴퓨터에서 Chrome, Edge 등 Chromium 기반 브라우저로 이 페이지를 열어 주세요.

Features

여섯 개의 진입점, 모두 마우스 오른쪽 메뉴에 있습니다

각 기능마다 데모가 준비되어 있습니다. 아래에서 확인하세요.

01

이중 언어 읽기새 기능

글 페이지의 빈 공간에서 마우스 오른쪽 버튼을 클릭하고 「이 글을 이중 언어로 읽기」를 선택하면 본문만 있는 읽기 페이지가 열립니다. 원문과 번역문이 문단별로 대응되며 내비게이션과 광고는 없습니다.

  • 좌우 나란히, 위아래 대조, 또는 번역문만 보기나 원문만 보기도 가능
  • 번역문의 단어를 클릭하면 다른 번역 표현으로 바꿀 수 있으며, 변경한 표현은 이후에 우선 사용됩니다
  • 글과 번역문을 로컬에 저장할 수 있어 다음에 열 때 다시 번역할 필요가 없습니다
데모 영상 보기

02

선택 번역

텍스트를 선택하고 마우스 오른쪽 버튼으로 번역하면 번역문이 페이지 중앙의 팝업에 표시됩니다.

  • 팝업에서 원문 대조를 펼치거나 대상 언어를 임시로 변경할 수 있습니다
  • 번역문의 단어를 클릭하면 다른 번역 표현으로 바꿀 수 있습니다
  • 단축키: Alt+Shift+T (macOS는 Command+Shift+Y)
데모 영상 보기

03

이미지 번역

이미지에서 마우스 오른쪽 버튼을 클릭하면 이미지 속 텍스트가 인식되고 번역문이 원래 위치에 덮어 표시됩니다. 번역된 이미지는 다운로드하거나 복사할 수 있습니다.

  • 일본 만화의 세로쓰기 텍스트를 중국어, 일본어 또는 한국어로 번역할 때 세로쓰기를 유지
  • 번역할 부분만 선택하거나 인식된 텍스트 영역을 먼저 조정한 후 번역할 수 있습니다
  • 이미지를 업로드하거나 붙여넣거나 이미지 주소를 입력할 수도 있습니다
데모 영상 보기

04

전체 PDF 번역

Chrome에서 PDF를 열고 마우스 오른쪽 버튼을 클릭하면 문서 전체를 번역할 수 있습니다. 번역문이 원래 위치에 덮어 표시되며 레이아웃, 차트, 표는 그대로 유지됩니다.

  • 원문과 번역문을 나란히 대조 가능
  • 브라우저의 인쇄 기능으로 PDF로 저장해도 번역문은 선택 및 검색 가능한 텍스트로 유지됩니다
  • 파일은 로컬에서만 분석되며 전송되는 것은 추출된 텍스트뿐입니다. 스캔 문서는 아직 지원하지 않습니다
데모 영상 보기

05

요소 번역

웹페이지의 특정 영역에서 마우스 오른쪽 버튼을 클릭해 번역 버튼을 추가할 수 있습니다. 한 번 클릭하면 해당 영역의 텍스트가 번역문으로 바뀌고, 다시 클릭하면 원문으로 돌아갑니다.

  • 버튼은 웹사이트별로 기억되며, 다음에 같은 웹사이트를 열면 자동으로 나타납니다
  • 내용이 길면 나누어 번역하고, 번역된 부분부터 차례로 표시합니다
  • 추가한 버튼은 관리 페이지에서 확인하고 삭제할 수 있습니다
데모 영상 보기

06

번역 패널

별도의 번역 페이지: 왼쪽에 원문을 붙여넣으면 오른쪽에 번역문이 나옵니다. 웹페이지에 없는 텍스트를 번역할 때 적합합니다.

  • 원문 언어는 자동으로 인식하거나 직접 지정할 수 있습니다
  • 플랫폼이나 대상 언어를 바꾼 후 바로 다시 번역할 수 있습니다
데모 영상 보기

Experimental

동영상 실시간 자막

실험 기능이며 기본적으로 꺼져 있습니다. 현재 탭의 소리를 인식해 자막으로 만들고, 다시 사용자의 언어로 번역합니다.

인식은 기본적으로 기기에서 수행됩니다. 브라우저의 클라우드 인식을 사용하는 경우 소리는 브라우저의 음성 서비스(Chrome은 Google, Edge는 Microsoft Azure)로 전송됩니다. 인식 정확도에는 아직 한계가 있으므로 중요한 내용은 이 기능에 의존하지 마십시오.

24

Languages

인터페이스와 번역문 모두 24개 언어를 지원합니다

인터페이스 언어, 원문 언어, 대상 언어는 각각 따로 설정합니다. 처음 사용할 때 대상 언어는 기본적으로 브라우저 언어를 따르며, 설정에서 변경할 수 있습니다.

지원 언어

마우스 오른쪽 버튼 메뉴에 현재 대상 언어 표시

대상 언어를 일본어로 설정하면 메뉴 항목은 「일본어로 번역」이 됩니다. 원문이 중국어여도 다른 언어로 번역할 수 있습니다.

오른쪽에서 왼쪽으로 쓰는 언어 지원

아랍어, 히브리어, 페르시아어, 우르두어 인터페이스는 오른쪽에서 왼쪽으로 배치됩니다. 원문과 번역문은 각자의 방향에 따라 표시되며, 웹페이지 자체의 배치는 영향을 받지 않습니다. 실제로 번역할 수 있는 언어는 선택한 번역 플랫폼에 따라 다릅니다.

Privacy

어떤 내용이 브라우저를 벗어나는가

사용자가 직접 번역한 내용만 전송됩니다. 자체 Key를 사용할 때는 내용이 선택한 플랫폼으로 직접 전송되며, 포인트로 번역할 때는 내용이 당사 서버를 거쳐 모델 서비스 제공업체로 전달되고, 서버는 이미지, 원문, 번역문을 저장하지 않습니다. 영상 자막의 음성 처리 방식은 개인정보 처리방침을 참조하십시오.

자체 Key 사용: 당사를 거치지 않음

요청은 브라우저에서 선택한 플랫폼으로 직접 전송됩니다. API Key는 이 브라우저에만 저장되며 Chrome 계정으로 동기화되지 않습니다.

포인트 번역: 번역 내용을 저장하지 않음

텍스트와 이미지는 요청 처리 중에만 서버 메모리에 잠시 남습니다. 계정에는 이메일과 사용자 이름만 저장되며, 서비스 제공에 필요한 사용량, 포인트, 구독 기록이 함께 저장됩니다. 프로필 사진, 닉네임, 기기 지문은 수집하지 않습니다.

광고와 제3자 통계 없음

광고를 넣지 않고, 트래킹을 하지 않으며, 제3자 통계 SDK를 연동하지 않고, 데이터를 판매하거나 대여하지 않습니다. 확장 프로그램과 서버 코드는 모두 GPL-3.0으로 공개되어 직접 확인할 수 있습니다.

자세한 내용은 개인정보 처리방침과 서비스 약관, 그리고 GPL-3.0으로 공개된 전체 소스 코드를 참고하세요.

Install

Chrome 또는 Edge 스토어에서 설치

Chrome 웹 스토어와 Microsoft Edge 추가 기능 스토어에서 모두 설치할 수 있으며, 브라우저는 116 이상이어야 합니다. Brave 등 Chromium 기반 브라우저는 Chrome 웹 스토어에서 설치합니다.

스토어 페이지 열기 컴퓨터에서 Chrome 웹 스토어 페이지를 열고, Edge 사용자는 Edge 추가 기능 스토어 페이지를 엽니다.
확장 프로그램 추가 「Chrome에 추가」 또는 Edge의 「받기」를 클릭하고 확인합니다.
툴바에 고정 퍼즐 아이콘을 클릭하여 확장 프로그램을 툴바에 고정합니다.
번역 시작 텍스트를 선택하고 마우스 오른쪽 버튼으로 번역하세요. Key를 입력하지 않아도 체험 포인트로 먼저 사용할 수 있습니다.
