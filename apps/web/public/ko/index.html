Chrome 확장 프로그램입니다. 텍스트, 웹페이지의 특정 영역 또는 이미지를 선택하면 익숙한 언어로 번역합니다. 24가지 인터페이스 언어와 대상 언어를 각각 선택할 수 있으며, 본인의 OpenAI, DeepSeek 또는 DeepL API Key로 바로 시작할 수 있습니다.

Chrome에 설치 소스 보기

이 브라우저에는 Chrome 확장 프로그램을 설치할 수 없습니다. 컴퓨터에서 Chrome, Edge 등 Chromium 기반 브라우저로 이 페이지를 열어 주세요.

  • 오픈 소스 GPL-3.0 · 24개 언어
  • Chrome 116+
  • 번역문 미저장 · 제3자 통계 없음
  • 네 가지 번역 방식

Features

다섯 개의 진입점, 모두 우클릭 메뉴에 있습니다

탭을 전환할 필요도, 복사해서 붙여 넣을 필요도 없습니다. 이해하지 못한 문단이 있는 곳에서 바로 번역이 이루어집니다.

01

선택 번역

텍스트를 선택한 후 우클릭으로 번역하면 번역문이 화면 중앙 팝업에 표시됩니다. 스트리밍 출력을 지원하는 플랫폼에서는 글자 단위로 표시됩니다. 임시로 대상 언어를 변경하면 원문으로 다시 번역합니다.

  • 중국어, 짧은 단어, 혼합 언어 모두 번역 가능하며 숫자, 문장 부호, 이모지만 있는 경우 번역 진입점을 표시하지 않습니다
  • 팝업은 화면 중앙에 있고 드래그할 수 있으며 Esc 또는 배경 클릭으로 닫힙니다. 커서를 따라다니는 작은 말풍선이 아닙니다
  • 접을 수 있는 원문 패널로 나란히 읽습니다
  • 단축키도 있습니다: Alt+Shift+T(macOS는 Command+Shift+Y)

02

이미지 번역

이미지를 마우스 오른쪽 버튼으로 클릭해 이미지 속 텍스트를 인식하고, 번역문을 인식된 위치에 맞춰 원본 이미지 위에 덮어씁니다.

  • 긴 이미지는 먼저 분할한 뒤 인식하며, 이음매는 텍스트 사이의 빈 줄로 자동 이동해 한 문장이 두 동강 나지 않습니다
  • 검사 전에 가장 긴 변이 아니라 총픽셀 기준으로 축소하므로 긴 이미지의 너비가 사라지지 않습니다
  • 원본 이미지 위치에 번역문을 덮어씁니다. 이미지 패널을 열어 이미지를 업로드하거나 붙여넣거나 이미지 주소를 입력할 수도 있습니다
  • 대상 언어를 전환하면 이미 인식된 텍스트를 재사용합니다. 이미지를 교체하면 다시 인식합니다
데모 영상 자리 표시자 assets/demo-image.mp4

03

PDF 전체 번역 출시 예정

Chrome에서 연 PDF에서 텍스트를 선택하지 않고 바로 우클릭하면 문서 전체가 옆 페이지에서 번역됩니다. 번역문은 원래 위치에 그대로 덮어씌워지며 레이아웃, 도표, 표가 모두 유지됩니다.

  • 원문과 번역문을 나란히 대조하며 볼 수 있고, 번역문만 또는 원문만 볼 수도 있습니다
  • 표는 셀 단위로 번역되며 행과 열, 표 테두리가 그대로 유지됩니다. 공간에 맞지 않는 번역문은 글자 크기가 자동으로 축소됩니다
  • 브라우저 인쇄로 PDF로 저장하면 번역문이 선택 및 검색 가능한 텍스트로 남습니다
  • 파일은 로컬에서만 분석되며, 추출된 텍스트만 번역 플랫폼으로 전송됩니다. 로컬 PDF는 번역 페이지로 직접 끌어다 놓을 수 있습니다. 스캔 문서는 현재 지원하지 않습니다
데모 영상 자리 표시자 assets/demo-pdf.mp4

04

요소 번역

페이지의 특정 영역을 우클릭하여 번역 버튼을 추가합니다. 클릭하면 영역의 텍스트가 선택한 언어로 즉시 바뀌고, 다시 클릭하면 원문으로 복원됩니다.

  • 규칙은 도메인별로 기억되므로 다음에 같은 사이트에 오면 버튼이 자동으로 붙습니다
  • 긴 내용은 나누어 보내고 번역되는 대로 교체하므로 영역 전체가 끝날 때까지 기다릴 필요가 없습니다
  • 저장된 규칙은 관리 페이지에서 하나씩 확인하고 삭제할 수 있습니다
데모 영상 자리 표시자 assets/demo-element.mp4

05

번역 패널

왼쪽에 원문을 붙여 넣으면 오른쪽에 번역문이 나오는 독립된 페이지로, 웹페이지에 없는 문단 단위 텍스트를 다루기에 적합합니다.

  • 24개 대상 언어 선택 가능, 전 세계 주요 언어 지원
  • 원본 언어는 자동 감지 또는 수동 지정 가능, 대상 언어는 별도 선택, 패널이 마지막 선택을 기억합니다
  • 플랫폼과 대상 언어는 도구 모음에 있어 언제든 전환해 다시 번역할 수 있습니다

Experimental

동영상 실시간 자막

선택적 실험 기능이며 기본적으로 꺼져 있습니다. 현재 탭의 소리를 읽어 자막으로 인식한 후 번역합니다. 음성 인식 언어와 번역 대상은 각각 설정합니다.

기본적으로 기기에서 인식하며 브라우저 지원과 언어 팩 다운로드가 필요합니다. Google 클라우드 인식으로 직접 전환할 수도 있으며, 이 경우 음성이 Google로 전송됩니다. 인식 정확도와 호환성은 여전히 제한적이므로 중요한 내용 처리에 의존하는 것은 권장하지 않습니다. 호스팅 서비스는 인식된 텍스트만 수신하며 음성·영상 업로드 및 변환은 제공하지 않습니다.

Languages

당신의 언어로, 세계의 콘텐츠를 읽습니다

인터페이스 언어, 번역 소스 및 대상은 각각 독립적입니다. 처음 사용 시 브라우저 언어에 따라 기본 대상이 선택되며, 설정에서 고정할 수도 있습니다.

24가지 인터페이스 및 대상 언어

중국어 간체, 중국어 번체, 영어, 일본어, 한국어, 스페인어, 포르투갈어(브라질), 프랑스어, 독일어, 이탈리아어, 네덜란드어, 러시아어, 우크라이나어, 폴란드어, 터키어, 아랍어, 히브리어, 페르시아어, 힌디어, 벵골어, 우르두어, 인도네시아어, 베트남어, 태국어.

우클릭 진입점이 번역 대상에 따라 표시

대상이 일본어면 메뉴에 일본어로 번역이라고 표시됩니다. 대상이 영어면 영어로 번역이라고 표시됩니다. 중국어를 선택해도 번역할 수 있으며, 더 이상 중국어 사용자만을 위한 설계가 아닙니다.

오른쪽에서 왼쪽으로도 자연스럽게 읽힙니다

아랍어, 히브리어, 페르시아어, 우르두어 인터페이스는 오른쪽에서 왼쪽으로 배치됩니다. 원문과 번역문이 각각 방향을 판단하며 웹페이지 자체의 레이아웃은 변경하지 않습니다. 실제 사용 가능한 언어 조합은 선택한 플랫폼에 따라 다릅니다.

Privacy

번역을 실행할 때만 콘텐츠가 전송됩니다

자체 키를 사용할 경우 번역 내용은 선택한 플랫폼으로 직접 전송됩니다. 포인트 번역은 당사 서버를 거쳐 모델 서비스 제공업체로 전달되며, 서버는 이미지, 원문, 번역문을 저장하지 않습니다. 영상 자막 활성화 후 음성 처리 방식은 개인정보 처리방침을 참고하세요.

자체 Key: 플랫폼 직접 연결

요청은 당사를 거치지 않고 브라우저에서 설정에서 선택한 플랫폼으로 직접 전송됩니다. API Key는 chrome.storage.local에 저장되며 Chrome 계정 동기화를 사용하지 않습니다.

호스팅 서비스: 번역 내용을 보관하지 않음

호스팅되는 텍스트와 이미지는 요청 처리 중에만 메모리에 일시적으로 머무릅니다. 계정에는 필요한 이메일과 사용자 이름만 저장되며, 사용량, 포인트 및 구독 기록은 서비스 제공을 위해 사용됩니다. 프로필 사진, 닉네임 또는 기기 지문은 수집하지 않습니다.

광고 및 제3자 통계 없음

광고, 트래킹, 제3자 통계 SDK를 사용하지 않으며 어떠한 데이터도 판매하거나 대여하지 않습니다. 확장 프로그램과 서버 코드는 GPL-3.0으로 공개되어 줄 단위로 확인할 수 있습니다.

자세한 내용은 개인정보 처리방침과 서비스 약관, 그리고 GPL-3.0으로 공개된 전체 소스 코드를 참고하세요.

계정 서비스는 2.0.0과 함께 출시됩니다. 확장 프로그램은 로그인과 번역의 주요 진입점이며, 공식 웹사이트와 사용자 센터는 동일한 계정 및 구독 혜택을 공유합니다.

이메일 또는 Google 로그인

이메일 인증 코드 또는 Google 계정으로 로그인하며, 현재 브라우저 탭에서 인증을 완료한 후 확장 프로그램으로 돌아갑니다. 이메일과 사용자 이름만 필요합니다.

잔액 및 상태 실시간 업데이트

구독하지 않은 경우 남은 포인트를 확인하고, 구독 후에는 무제한 사용이 표시됩니다. 사용자 센터에서 자신의 사용량, 포인트 기록, 구독, 주문 및 로그인 세션을 확인할 수 있습니다. 현재 웹 세션에서 로그아웃하면 연결된 확장 프로그램도 로그아웃됩니다.

언제든 자체 Key 선택 유지

호스팅 번역과 자체 Key를 전환하여 사용할 수 있습니다. 자체 Key 요청은 플랫폼에 직접 연결되며 호스팅 포인트가 차감되지 않고, 당사 구독도 필요하지 않습니다.
