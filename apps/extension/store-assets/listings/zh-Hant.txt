• 更自然的措辭：修訂後的風格指南改善了中文及其他目標語言的措辭、術語和語氣。
• 更佳的 automatic 圖像翻譯：改進了文字形狀、字型大小、對齊、直排文字和背景顏色。移動段落、編輯其翻譯或大小，或僅重新翻譯該段落。匯出的圖像會保留您的編輯。可選擇翻譯音效；辨識的圖像會快取在目前頁面，並可在圖像之間瀏覽。

▍雙語閱讀

在頁面任何位置按右鍵（不選取文字），然後選擇「雙語閱讀這篇文章」。一道光會掃過頁面，同時偵測標題和內文，然後在旁邊開啟一個乾淨的閱讀頁面，每個原始段落都與其翻譯並排對齊。導覽、側邊欄、廣告版位和推薦小工具會被排除，且永遠不會被送去翻譯。

• 並排顯示，每個段落對都從相同高度開始；您也可以堆疊它們，或僅顯示翻譯或僅顯示原文
• 淺色、深色或跟隨系統外觀，加上可調整的調色盤、字型、大小、行高和頁面寬度——全部都會記住
• 「儲存」會將文章及其翻譯保留在您的裝置上；從右側清單再次開啟即可，無需重新翻譯，或不再需要時刪除

▍點擊單字以查看其他措辭——並保留您偏好的術語

在閱讀頁面、選取彈出視窗、翻譯面板和 PDF 頁面上，點擊翻譯中的單字——或拖曳選取幾個單字——即可查看多種替代譯法及簡短註解，或自行輸入。一次取代其他地方出現的相同單字。

您選擇的措辭會作為措辭偏好記住在您的裝置上：之後包含相同來源術語的文字翻譯會遵循您的選擇。在設定中檢閱和刪除它們。

▍翻譯工具

• 選取的文字
選取文字，然後從右鍵選單中選擇「翻譯成…」。翻譯會顯示在置中彈出視窗中，若供應商支援串流，則會逐字顯示。您也可以使用選取文字旁的浮動按鈕，或 macOS 上的快速鍵 ⌘⇧Y / 其他平台上的 Alt+Shift+T。彈出視窗可拖曳，可依需求顯示原文，並在您切換目標語言時重新翻譯原文。

• 圖像
在圖像上按右鍵以辨識其文字。每個段落會沿其筆畫描繪輪廓，翻譯會放回原文上方，且段落不會互相覆蓋。直排日文（如漫畫）在翻譯成中文、日文或韓文時會保持直排。先檢查偵測到的形狀——移動、編輯、刪除或繪製新形狀——再進行翻譯，或僅選取您需要的區域（矩形或圓形）。將結果下載或複製為新圖像。

• 整份 PDF
在瀏覽器內建的 PDF 檢視器中，不選取文字按右鍵，即可在旁邊的頁面中翻譯整份文件。翻譯會覆蓋在原始位置上，因此版面配置、圖形和表格線條會保持不變。並排比較、僅顯示翻譯或僅顯示原文，並透過列印對話方塊將結果儲存為 PDF。您也可以將本機 PDF 拖放到翻譯頁面上。

• 頁面區域
在頁面的某個區域按右鍵，為其新增翻譯按鈕。按一下即可將該區域的文字替換為翻譯，再按一下即可還原原文。規則會按網站記住。

• 翻譯面板
一個專用頁面，左側為原文，右側為翻譯，適用於較長的段落或來自瀏覽器外部的文字。自動偵測來源語言或自行選擇。

▍翻譯模式

• 免金鑰額度翻譯
新的合格安裝會獲得訪客試用（領取次數依網路有限制），使用電子郵件或 Google 註冊可獲得更多額度。額度永不過期，並按實際翻譯的文字量扣除（每 500 字元 1 點額度）；翻譯失敗不會收費。試用額度用完後，額度翻譯需要訂閱，訂閱提供無限使用（合理使用），自動續訂，並可隨時取消。請參閱網站和您的帳戶中心以了解目前的試用額度和價格。

• 您自己的 API 金鑰
輸入您自己的 OpenAI、DeepSeek 或 DeepL 金鑰。請求會直接從您的瀏覽器傳送至該供應商，由該供應商向您收取使用費。圖像辨識需要具備視覺能力的模型；DeepL 不提供圖像辨識或替代措辭。
