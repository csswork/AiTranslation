選取、按右鍵，然後繼續讀。整篇文章逐段對照閱讀；選取的文字、圖片和 PDF，都能就地譯成你的語言——不用切換分頁，不用複製貼上。

劃詞 – AI 翻譯與雙語閱讀是一個開源的瀏覽器擴充功能（Manifest V3）。安裝後免 API Key 就能用點數翻譯，也可以填入自己的 OpenAI、DeepSeek 或 DeepL API Key。

▍雙語閱讀（2.2.0 新功能）

在網頁上不選文字直接按右鍵，選「雙語閱讀這篇文章」。頁面上一道光帶掃過，辨識出標題和正文，在旁邊開啟一個乾淨的閱讀頁：原文與譯文逐段對齊，導覽、側欄、廣告版位和推薦模組都不會出現，也不會送去翻譯。

• 左右並排時每段頂端對齊，也可以上下對照、只看譯文或只看原文
• 外觀可選淺色、深色或跟隨系統；配色、字型、字級、行距與版面寬度都能調，並會記住
• 「儲存」把文章連同譯文留在本機，右側清單隨時開啟，不用再翻譯；不需要時可以刪除

▍點詞換說法，記住你的用詞

在閱讀頁、劃詞彈窗、翻譯面板和 PDF 翻譯頁裡，點譯文裡的一個詞，或拖選幾個詞，就能看到幾種其他譯法和簡短說明，也可以自己改寫。別處相同的詞可以一起替換。

換過的說法會作為用詞偏好記在本機：之後翻譯含有同一原文詞語的文字時，優先使用你的譯法。偏好可以在設定頁查看和刪除。

▍六種翻譯方式，都在右鍵選單裡

• 劃詞翻譯
選取文字後按右鍵「翻譯成…」，譯文在置中彈窗裡顯示，支援串流輸出的平台會逐字呈現。也可以用選取區旁的浮動按鈕，或快速鍵 ⌘⇧Y（macOS）/ Alt+Shift+T。彈窗可拖動，可折疊顯示原文；臨時換個目標語言會用原文重新翻譯。

• 圖片翻譯
對一張圖片按右鍵，辨識圖裡的文字，按筆畫勾出每段文字的形狀，把譯文貼著原位蓋回去，形狀之間互不遮擋。日文漫畫的直排文字譯成中文、日文或韓文時保持直排。可以先看辨識出的形狀，移動、刪改或新畫後再翻譯；也可以只框選要翻譯的區域（矩形或圓形）。結果可下載或複製成一張新圖片。

• 整份 PDF 翻譯
在瀏覽器內建 PDF 閱讀器裡不選文字直接按右鍵，整份文件在旁邊的頁面裡翻譯。譯文按原位置蓋回去，版面、圖表和表格線不變；可並排對照、只看譯文或只看原文，並透過列印另存為 PDF。本機 PDF 可以直接拖進翻譯頁。

• 區域翻譯
對頁面上的某個區域按右鍵，給它掛一個翻譯按鈕。點一下，區域裡的文字就地換成譯文，再點可恢復原文。規則按網站記住，下次自動出現。

• 翻譯面板
一個獨立頁面，左邊貼原文右邊出譯文，適合處理成段的、不在網頁上的文字。來源語言可自動辨識或手動指定。

24 種介面與目標語言：簡體中文、繁體中文、英語、西班牙語、葡萄牙語、法語、德語、義大利語、荷蘭語、俄語、烏克蘭語、波蘭語、土耳其語、阿拉伯語、希伯來語、波斯語、印地語、孟加拉語、烏爾都語、印尼語、越南語、泰語、日語和韓語。介面語言、來源語言和目標語言各自獨立；阿拉伯語、希伯來語、波斯語和烏爾都語介面使用從右往左的版面。

▍兩種用法

• 免 API Key 的點數翻譯
新安裝可領取訪客試用（同一網路有領取次數限制），用電子郵件或 Google 註冊帳號再送點數。點數不會過期，按實際翻譯的字數扣減（每 500 個字元 1 點），翻譯失敗不扣點。試用點數用完後，點數翻譯需要訂閱；訂閱後無限使用（合理使用），自動續訂，隨時可以取消。目前的試用額度與價格以官網和使用者中心顯示為準。

• 自帶 API Key
填入自己的 OpenAI、DeepSeek 或 DeepL API Key，請求從瀏覽器直接發往該平台，費用由平台按用量收取。圖片辨識需要支援視覺的模型；DeepL 不提供圖片辨識和「換說法」。
