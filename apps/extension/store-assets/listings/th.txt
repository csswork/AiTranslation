เลือก คลิกขวา แล้วอ่านต่อ อ่านบทความทั้งหมดแบบเคียงข้างกันพร้อมคำแปล และแปลข้อความที่เลือก รูปภาพ และ PDF ได้ทันทีในตำแหน่งนั้น—โดยไม่ต้องสลับแท็บหรือคัดลอกและวาง

Huaci – นักแปล AI และตัวอ่านสองภาษา เป็นส่วนขยายเบราว์เซอร์โอเพนซอร์สที่สร้างบน Manifest V3 ใช้การแปลข้อความแบบโลคอลฟรีเมื่อรองรับ ใช้เครดิตโฮสต์ที่ไม่ต้องใช้คีย์ หรือใช้คีย์ API OpenAI, DeepSeek หรือ DeepL ของคุณเอง

การแปลเว็บไซต์แบบโลคอลและอัตโนมัติ (ใหม่ใน 2.3.0)

• การแปลข้อความแบบโลคอล: บนเบราว์เซอร์และอุปกรณ์ที่รองรับ ดาวน์โหลดคู่ภาษาในการตั้งค่าและแปลแบบออฟไลน์ได้ฟรี โดยไม่ต้องใช้คีย์ API หรือเครดิต ข้อความจะอยู่บนอุปกรณ์ของคุณ ใช้สำหรับข้อความที่เลือก พื้นที่บนหน้า เว็บไซต์ แผงข้อความ PDF การอ่านสองภาษา และคำบรรยายที่รู้จำได้ ความพร้อมใช้งานและภาษาขึ้นอยู่กับเบราว์เซอร์และแพ็กที่ดาวน์โหลด โหมดโลคอลไม่รองรับการรู้จำภาพหรือถ้อยคำทางเลือก ส่วนควบคุมที่ไม่รองรับจะถูกซ่อน
• การแปลเว็บไซต์อัตโนมัติ: คลิกขวาและเปิด “แปลเว็บไซต์นี้” ข้อความใกล้บริเวณที่มองเห็นจะถูกแปลขณะเลื่อนหน้า รวมถึงในการเข้าชมครั้งต่อๆ ไป จนกว่าคุณจะปิด ข้อความที่ซ้ำบนหน้าจะใช้คำแปลซ้ำ เลือกผู้ให้บริการแยกต่างหากในการตั้งค่า การใช้ผู้ให้บริการแบบเสียเงินครั้งแรกจะขอการยืนยัน
• ถ้อยคำที่เป็นธรรมชาติมากขึ้น: คู่มือสไตล์ที่ปรับปรุงช่วยให้การเลือกคำ ศัพท์ และน้ำเสียงดีขึ้นสำหรับภาษาจีนและภาษาเป้าหมายอื่นๆ
• การแปลภาพอัตโนมัติที่ดีขึ้น: รูปร่างข้อความ การปรับขนาดฟอนต์ การจัดตำแหน่ง ข้อความแนวตั้ง และสีพื้นหลังดีขึ้น ย้ายข้อความ แก้ไขคำแปลหรือขนาด หรือแปลเฉพาะข้อความนั้นใหม่ ภาพที่ส่งออกจะคงการแก้ไขของคุณไว้ เลือกแปลเสียงเอฟเฟกต์ได้ตามต้องการ ภาพที่รู้จำได้จะถูกแคชบนหน้าปัจจุบัน พร้อมการนำทางระหว่างภาพ

▍การอ่านสองภาษา

คลิกขวาที่ใดก็ได้บนหน้าโดยไม่เลือกข้อความ แล้วเลือก “อ่านบทความนี้แบบสองภาษา” แสงจะกวาดผ่านหน้าเมื่อตรวจพบชื่อเรื่องและเนื้อหา จากนั้นหน้าอ่านที่สะอาดตาจะเปิดขึ้นข้างๆ โดยแต่ละย่อหน้าต้นฉบับจัดเรียงเคียงข้างคำแปล เมนูนำทาง แถบด้านข้าง ช่องโฆษณา และวิดเจ็ตแนะนำจะถูกตัดออกและไม่ถูกส่งไปแปล

• เคียงข้างกัน แต่ละคู่ย่อหน้าเริ่มต้นที่ความสูงเดียวกัน คุณยังสามารถวางซ้อนกัน หรือแสดงเฉพาะคำแปลหรือเฉพาะต้นฉบับ
• รูปลักษณ์สว่าง มืด หรือตามระบบ พร้อมจานสี ฟอนต์ ขนาด ความสูงบรรทัด และความกว้างหน้าปรับได้—ทั้งหมดถูกจดจำไว้
• “บันทึก” เก็บบทความและคำแปลไว้บนอุปกรณ์ของคุณ เปิดอีกครั้งจากรายการทางขวาโดยไม่ต้องแปลใหม่ หรือลบเมื่อไม่ต้องการแล้ว

▍คลิกที่คำเพื่อดูถ้อยคำอื่น—และเก็บคำที่คุณต้องการ

บนหน้าอ่าน ในป๊อปอัปการเลือก ในแผงแปล และบนหน้า PDF คลิกที่คำในคำแปล—หรือลากเลือกหลายคำ—เพื่อดูการแปลทางเลือกหลายแบบพร้อมหมายเหตุสั้นๆ หรือพิมพ์ของคุณเอง แทนที่คำเดียวกันที่อื่นได้ในครั้งเดียว

ถ้อยคำที่คุณเลือกจะถูกจดจำบนอุปกรณ์ของคุณเป็นการตั้งค่าถ้อยคำ คำแปลในภายหลังของข้อความที่มีคำต้นฉบับเดียวกันจะตามการเลือกของคุณ ตรวจสอบและลบได้ในการตั้งค่า

▍เครื่องมือแปล

• ข้อความที่เลือก
เลือกข้อความแล้วเลือก “แปลเป็น…” จากเมนูคลิกขวา คำแปลจะปรากฏในป๊อปอัปตรงกลาง ทีละคำเมื่อผู้ให้บริการรองรับการสตรีม คุณยังสามารถใช้ปุ่มลอยข้างข้อความที่เลือก หรือทางลัด ⌘⇧Y บน macOS / Alt+Shift+T บนระบบอื่น ป๊อปอัปสามารถลากได้ แสดงต้นฉบับเมื่อต้องการ และแปลต้นฉบับอีกครั้งเมื่อคุณสลับภาษาเป้าหมาย

• รูปภาพ
คลิกขวาที่รูปภาพเพื่อรู้จำข้อความ แต่ละข้อความจะถูกวาดเส้นรอบตามเส้นตัวอักษร และคำแปลจะถูกวางกลับทับต้นฉบับโดยที่ข้อความไม่ทับกัน ข้อความญี่ปุ่นแนวตั้ง เช่น ในมังงะ จะคงแนวตั้งเมื่อแปลเป็นภาษาจีน ญี่ปุ่น หรือเกาหลี ตรวจสอบรูปร่างที่ตรวจพบก่อน—ย้าย แก้ไข ลบ หรือวาดใหม่—ก่อนแปล หรือเลือกเฉพาะพื้นที่ที่ต้องการ (สี่เหลี่ยมหรือวงกลม) ดาวน์โหลดหรือคัดลอกผลลัพธ์เป็นภาพใหม่

• PDF ทั้งไฟล์
ในตัวอ่าน PDF ในตัวของเบราว์เซอร์ คลิกขวาโดยไม่เลือกข้อความเพื่อแปลเอกสารทั้งหมดในหน้าใหม่ข้างๆ คำแปลจะถูกวางทับตำแหน่งเดิม เพื่อให้เค้าโครง รูปภาพ และเส้นตารางคงอยู่ เปรียบเทียบเคียงข้างกัน แสดงเฉพาะคำแปลหรือเฉพาะต้นฉบับ และบันทึกผลลัพธ์เป็น PDF ผ่านกล่องโต้ตอบพิมพ์ คุณยังสามารถลากไฟล์ PDF ในเครื่องมาวางบนหน้าแปลได้

• พื้นที่บนหน้า
คลิกขวาที่พื้นที่ของหน้าเพื่อเพิ่มปุ่มแปลให้ คลิกครั้งเดียวเพื่อแทนที่ข้อความในพื้นที่นั้นด้วยคำแปล และอีกครั้งเพื่อคืนต้นฉบับ กฎจะถูกจดจำแยกตามเว็บไซต์

• แผงแปล
หน้าพิเศษที่มีต้นฉบับทางซ้ายและคำแปลทางขวา สำหรับข้อความยาวหรือข้อความจากนอกเบราว์เซอร์ ตรวจจับภาษาต้นฉบับอัตโนมัติหรือเลือกเอง

24 ภาษาอินเทอร์เฟซและภาษาเป้าหมาย: จีนตัวย่อ จีนตัวเต็ม อังกฤษ สเปน โปรตุเกส ฝรั่งเศส เยอรมัน อิตาลี ดัตช์ รัสเซีย ยูเครน โปแลนด์ ตุรกี อาหรับ ฮิบรู เปอร์เซีย ฮินดี เบงกาลี อูรดู อินโดนีเซีย เวียดนาม ไทย ญี่ปุ่น และเกาหลี อินเทอร์เฟซ ภาษาต้นฉบับ และภาษาเป้าหมายเป็นการตั้งค่าแยกกัน และอินเทอร์เฟซภาษาอาหรับ ฮิบรู เปอร์เซีย และอูรดูใช้เลย์เอาต์จากขวาไปซ้าย

▍โหมดการแปล

• การแปลด้วยเครดิตที่ไม่ต้องใช้คีย์
การติดตั้งใหม่ที่มีสิทธิ์จะได้รับทดลองใช้แบบแขก (การรับสิทธิ์จำกัดตามเครือข่าย) และการสมัครด้วยอีเมลหรือ Google จะเพิ่มเครดิตให้ เครดิตไม่มีวันหมดอายุและถูกหักตามปริมาณข้อความที่แปลจริง (1 เครดิตต่อ 500 ตัวอักษร) การแปลที่ล้มเหลวจะไม่ถูกเรียกเก็บเงิน เมื่อเครดิตทดลองใช้หมด การแปลด้วยเครดิตต้องสมัครสมาชิก ซึ่งให้ใช้ได้ไม่จำกัด (ภายใต้นโยบายการใช้งานที่เป็นธรรม) ต่ออายุอัตโนมัติ และยกเลิกได้ทุกเมื่อ ดูจำนวนทดลองใช้และราคาปัจจุบันได้ที่เว็บไซต์และศูนย์บัญชีของคุณ

• คีย์ API ของคุณเอง
ป้อนคีย์ OpenAI, DeepSeek หรือ DeepL ของคุณเอง คำขอจะส่งจากเบราว์เซอร์ของคุณไปยังผู้ให้บริการนั้นโดยตรง ซึ่งจะเรียกเก็บเงินค่าการใช้งานจากคุณ การรู้จำภาพต้องใช้โมเดลที่รองรับภาพ DeepL ไม่มีการรู้จำภาพหรือถ้อยคำทางเลือก

▍ความเป็นส่วนตัว

• การแปลแบบโลคอลเก็บข้อความไว้บนอุปกรณ์ของคุณ โหมดออนไลน์ส่งเนื้อหาที่ร้องขอไปยังบริการที่เลือก การแปลเว็บไซต์อัตโนมัติประมวลผลข้อความเฉพาะบนเว็บไซต์ที่คุณเปิดใช้อย่างชัดเจน รวมถึงการเข้าชมครั้งต่อๆ ไป
• เมื่อใช้คีย์ของคุณเอง เนื้อหาจะไปยังผู้ให้บริการที่คุณเลือกโดยตรง ไม่ผ่านเรา
• เมื่อใช้การแปลด้วยเครดิต เนื้อหาจะผ่านเซิร์ฟเวอร์ของเราไปยังผู้ให้บริการโมเดล เซิร์ฟเวอร์ไม่เก็บข้อความ คำแปล หรือภาพของคุณ
• คีย์ API การตั้งค่าถ้อยคำ และบทความที่บันทึกไว้จะอยู่บนอุปกรณ์ของคุณและไม่ซิงค์ผ่านบัญชีเบราว์เซอร์ของคุณ
• ไม่มีโฆษณา การติดตาม หรือการวิเคราะห์จากบุคคลที่สาม ซอร์สโค้ดทั้งหมดพร้อมใช้งานภายใต้ GPL-3.0

คำบรรยายวิดีโอสดเป็นฟีเจอร์ทดลอง ปิดไว้โดยค่าเริ่มต้น เสียงจะถูกรู้จำบนอุปกรณ์ของคุณโดยค่าเริ่มต้น หากคุณเลือกการรู้จำบนคลาวด์อย่างชัดเจน เสียงจะถูกส่งไปยังบริการรู้จำเสียงของเบราว์เซอร์ของคุณ

▍ข้อจำกัดที่ทราบ

• หน้าที่ได้รับการป้องกันโดยเบราว์เซอร์ เช่น หน้า chrome:// ภายในและร้านค้าส่วนขยาย ไม่สามารถใช้ได้
• การเลือกหนึ่งครั้งสามารถมีได้สูงสุด 6,000 ตัวอักษร การเลือกที่ยาวกว่าจะถูกตัดทอนพร้อมแจ้งเตือน
• การอ่านสองภาษาตรวจพบบทความจากโครงสร้างหน้า ฟอรัม เครือข่ายสังคม และหน้าที่อยู่หลังการเข้าสู่ระบบอาจตรวจพบได้ไม่สมบูรณ์
• PDF ที่สแกนและที่ป้องกันด้วยรหัสผ่านยังไม่รองรับ
