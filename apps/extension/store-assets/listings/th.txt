เลือก คลิกขวา แล้วอ่านต่อ อ่านทั้งบทความแบบเทียบเคียงทีละย่อหน้า และแปลข้อความที่เลือก รูปภาพ และ PDF ได้ทันทีในตำแหน่งเดิม—โดยไม่ต้องสลับแท็บหรือคัดลอกวาง

Huaci – นักแปล AI และตัวอ่านสองภาษา เป็นส่วนขยายเบราว์เซอร์โอเพนซอร์สที่สร้างบน Manifest V3 เริ่มแปลได้ทันทีหลังติดตั้งด้วยเครดิตที่ไม่ต้องใช้คีย์ หรือใช้ API Key ของ OpenAI, DeepSeek หรือ DeepL ของคุณเอง

▍การอ่านแบบสองภาษา (ใหม่ใน 2.2.0)

คลิกขวาที่ตำแหน่งใดก็ได้บนหน้าเว็บโดยไม่เลือกข้อความ แล้วเลือก "อ่านบทความนี้แบบสองภาษา" แถบแสงจะกวาดผ่านหน้าเว็บขณะตรวจจับชื่อเรื่องและเนื้อหา จากนั้นหน้าอ่านที่สะอาดตาจะเปิดขึ้นข้าง ๆ โดยแต่ละย่อหน้าต้นฉบับจัดเรียงเคียงข้างคำแปล เมนูนำทาง แถบด้านข้าง พื้นที่โฆษณา และวิดเจ็ตแนะนำจะถูกตัดออกและไม่ถูกส่งไปแปล

• เมื่อวางเคียงข้างกัน ทุกคู่ย่อหน้าเริ่มต้นที่ความสูงเดียวกัน คุณยังสามารถวางซ้อนกัน หรือแสดงเฉพาะคำแปลหรือเฉพาะต้นฉบับได้
• รูปลักษณ์แบบสว่าง มืด หรือตามระบบ พร้อมพาเลตต์สี ฟอนต์ ขนาด ความสูงบรรทัด และความกว้างหน้าเว็บที่ปรับได้—ทั้งหมดจะถูกจดจำไว้
• "บันทึก" เก็บบทความและคำแปลไว้บนอุปกรณ์ของคุณ เปิดอีกครั้งจากรายการทางขวาโดยไม่ต้องแปลใหม่ หรือลบเมื่อไม่ต้องการแล้ว

▍คลิกที่คำเพื่อเลือกสำนวนอื่น—และเก็บคำที่คุณต้องการ

บนหน้าอ่าน ในป๊อปอัปการเลือกข้อความ ในแผงแปล และบนหน้าหนังสือ PDF คลิกที่คำในคำแปล—หรือลากเลือกหลายคำ—เพื่อดูทางเลือกในการแปลหลายแบบพร้อมคำอธิบายสั้น ๆ หรือพิมพ์ของคุณเอง แทนที่คำเดียวกันในที่อื่นได้ในครั้งเดียว

สำนวนที่คุณเลือกจะถูกจดจำไว้บนอุปกรณ์ของคุณเป็นการตั้งค่าคำ: การแปลครั้งต่อ ๆ ไปของข้อความที่มีคำต้นฉบับเดียวกันจะใช้ตามที่คุณเลือก ตรวจดูและลบได้ในการตั้งค่า

▍หกวิธีในการแปล ทั้งหมดอยู่ในเมนูคลิกขวา

• ข้อความที่เลือก
เลือกข้อความแล้วเลือก "แปลโดยตรง" จากเมนูคลิกขวา คำแปลจะปรากฏในป๊อปอัปตรงกลาง ทีละคำในกรณีที่ผู้ให้บริการรองรับการสตรีม คุณยังสามารถใช้ปุ่มลอยข้างข้อความที่เลือก หรือใช้คีย์ลัด ⌘⇧Y บน macOS / Alt+Shift+T บนระบบอื่น ป๊อปอัปสามารถลากได้ แสดงต้นฉบับเมื่อต้องการ และแปลต้นฉบับใหม่เมื่อคุณเปลี่ยนภาษาเป้าหมาย

• รูปภาพ
คลิกขวาที่รูปภาพเพื่อrecognizeข้อความในภาพ แต่ละข้อความจะถูกวาดกรอบตามเส้นตัวอักษร และคำแปลจะถูกวางทับตำแหน่งเดิมโดยไม่ทับซ้อนกัน ข้อความญี่ปุ่นแนวตั้ง เช่น ในมังงะ จะคงแนวตั้งไว้เมื่อแปลเป็นภาษาจีน ญี่ปุ่น หรือเกาหลี ตรวจดูรูปร่างที่ตรวจจับได้ก่อน—ย้าย แก้ไข ลบ หรือวาดใหม่—ก่อนแปล หรือเลือกเฉพาะพื้นที่ที่ต้องการ (สี่เหลี่ยมหรือวงกลม) ดาวน์โหลดหรือคัดลอกผลลัพธ์เป็นรูปภาพใหม่

• PDF ทั้งไฟล์
ในโปรแกรมอ่าน PDF ในตัวของเบราว์เซอร์ คลิกขวาโดยไม่เลือกข้อความเพื่อแปลเอกสารทั้งหมดในหน้าที่เปิดข้าง ๆ คำแปลจะถูกวางทับตำแหน่งเดิม เพื่อให้เค้าโครง รูปภาพ และเส้นตารางยังคงอยู่ เปรียบเทียบแบบเคียงข้าง แสดงเฉพาะคำแปลหรือเฉพาะต้นฉบับ และบันทึกผลลัพธ์เป็น PDF ผ่านกล่องโต้ตอบการพิมพ์ คุณยังสามารถลาก PDF ในเครื่องไปยังหน้าคำแปลได้

• บริเวณบนหน้าเว็บ
คลิกขวาที่บริเวณหนึ่งของหน้าเว็บเพื่อเพิ่มปุ่มแปลให้กับบริเวณนั้น คลิกครั้งเดียวเพื่อแทนที่ข้อความในบริเวณนั้นด้วยคำแปล และคลิกอีกครั้งเพื่อคืนต้นฉบับ กฎจะถูกจดจำแยกตามเว็บไซต์

• แผงแปล
หน้าที่แยกต่างหากโดยมีต้นฉบับทางซ้ายและคำแปลทางขวา สำหรับข้อความยาวหรือข้อความจากภายนอกเบราว์เซอร์ ตรวจจับภาษาต้นทางโดยอัตโนมัติหรือเลือกด้วยตัวเอง

24 ภาษาของอินเทอร์เฟซและภาษาเป้าหมาย: จีนตัวย่อ จีนตัวเต็ม อังกฤษ สเปน โปรตุเกส ฝรั่งเศส เยอรมัน อิตาลี ดัตช์ รัสเซีย ยูเครน โปแลนด์ ตุรกี อาหรับ ฮีบรู เปอร์เซีย ฮินดี เบงกาลี อูรดู อินโดนีเซีย เวียดนาม ไทย ญี่ปุ่น และเกาหลี ภาษาของอินเทอร์เฟซ ภาษาต้นทาง และภาษาเป้าหมายเป็นการตั้งค่าแยกกัน และอินเทอร์เฟซภาษอาหรับ ฮีบรู เปอร์เซีย และอูรดูใช้เลย์เอาต์จากขวาไปซ้าย

▍สองวิธีในการใช้งาน

• การแปลด้วยเครดิตที่ไม่ต้องใช้คีย์
การติดตั้งใหม่ที่เข้าเกณฑ์จะได้รับสิทธิ์ทดลองใช้แบบผู้เยี่ยมชม (จำกัดจำนวนการรับสิทธิ์ต่อเครือข่าย) และการสมัครด้วยอีเมลหรือ Google จะได้รับเครดิตเพิ่มเติม เครดิตไม่มีวันหมดอายุและหักตามปริมาณข้อความที่แปลจริง (1 เครดิตต่อ 500 ตัวอักษร) การแปลที่ไม่สำเร็จจะไม่ถูกหักเครดิต เมื่อเครดิตทดลองใช้หมด การแปลด้วยเครดิตต้องสมัครสมาชิก ซึ่งให้ใช้งานได้ไม่จำกัด (ภายใต้การใช้งานอย่างสมเหตุสมผล) ต่ออายุอัตโนมัติ และยกเลิกได้ทุกเมื่อ ดูจำนวนเครดิตทดลองและราคาปัจจุบันได้ที่เว็บไซต์และศูนย์บัญชีของคุณ

• API Key ของคุณเอง
ป้อนคีย์ OpenAI, DeepSeek หรือ DeepL ของคุณเอง คำขอจะส่งจากเบราว์เซอร์ของคุณไปยังผู้ให้บริการนั้นโดยตรง ซึ่งจะเรียกเก็บค่าบริการตามการใช้งาน การรู้จำรูปภาพต้องใช้โมเดลที่รองรับการมองเห็น DeepL ไม่มีบริการรู้จำรูปภาพหรือการเลือกสำนวนอื่น

▍ความเป็นส่วนตัว

• เนื้อหาจะถูกส่งก็ต่อเมื่อคุณเลือกที่จะแปลเท่านั้น ส่วนขยายจะไม่สแกนหรืออัปโหลดหน้าเว็บในเบื้องหลัง
• เมื่อใช้คีย์ของคุณเอง เนื้อหาจะส่งไปยังผู้ให้บริการที่คุณเลือกโดยตรง ไม่ผ่านเรา
• เมื่อใช้การแปลด้วยเครดิต เนื้อหาจะผ่านเซิร์ฟเวอร์ของเราไปยังผู้ให้บริการโมเดล เซิร์ฟเวอร์ไม่จัดเก็บข้อความ คำแปล หรือรูปภาพของคุณ
• API Key การตั้งค่าคำ และบทความที่บันทึกไว้จะอยู่บนอุปกรณ์ของคุณและไม่ถูกซิงค์ผ่านบัญชีเบราว์เซอร์ของคุณ
• ไม่มีโฆษณา การติดตาม หรือการวิเคราะห์จากบุคคลที่สาม ซอร์สโค้ดทั้งหมดเปิดเผยภายใต้ GPL-3.0

คำบรรยายวิดีโอแบบเรียลไทม์เป็นฟีเจอร์ทดลอง ปิดไว้โดยค่าเริ่มต้น เสียงจะถูกรู้จำบนอุปกรณ์ของคุณโดยค่าเริ่มต้น หากคุณเลือกการรู้จำบนคลาวด์อย่างชัดเจน เสียงจะถูกส่งไปยังบริการรู้จำเสียงของเบราว์เซอร์ของคุณ

• หน้าเว็บที่เบราว์เซอร์ป้องกัน เช่น หน้า chrome:// ภายใน และร้านค้าส่วนขยาย ไม่สามารถใช้งานได้
• การเลือกข้อความครั้งหนึ่งสามารถมีได้สูงสุด 6,000 ตัวอักษร ข้อความที่เลือกยาวกว่านี้จะถูกตัดทอนพร้อมแจ้งเตือน
• การอ่านแบบสองภาษาตรวจหาบทความจากโครงสร้างหน้าเว็บ ฟอรัม เครือข่ายสังคม และหน้าที่ต้องเข้าสู่ระบบอาจตรวจหาไม่ครบถ้วน

• ภาษาที่ใช้ได้ การรู้จำรูปภาพ และการสตรีมขึ้นอยู่กับผู้ให้บริการและโมเดลที่คุณเลือก
