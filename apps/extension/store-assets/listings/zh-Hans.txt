本地与自动网站翻译（2.3.0 新增）

• 本地文本翻译：在支持的浏览器和设备上，在设置中下载语言对，即可离线免费翻译，无需 API 密钥或额度。文本保留在你的设备上。可用于选区、页面区域、网站、文本面板、PDF、双语阅读和识别出的字幕。可用性和语言取决于浏览器和已下载的语言包。本地模式不提供图像识别或替代措辞；不支持的控制项会被隐藏。
• 自动网站翻译：右键单击并启用“翻译此网站”。当你滚动时，视口附近的文本会被翻译，包括之后的访问，直到你将其禁用。页面上重复的文本会复用译文。在设置中选择单独的提供商；首次使用付费提供商时会要求确认。
• 更自然的措辞：修订后的风格指南改进了中文及其他目标语言的措辞、术语和语气。
• 更好的自动图像翻译：改进了文字形状、字体大小、对齐、竖排文字和背景颜色。移动一段文字、编辑其译文或大小，或仅重新翻译该段文字。导出的图片会保留你的编辑。可选择翻译拟声词；识别出的图片会在当前页面缓存，并可在图片之间导航。

▍双语阅读

在页面上任意位置右键单击（不选择文本），然后选择“双语阅读这篇文章”。随着标题和正文被检测到，一道光会扫过页面，随后在旁边打开一个简洁的阅读页面，每个原始段落与其译文对齐。导航、侧边栏、广告位和推荐组件会被排除，绝不会被发送用于翻译。

• 并排显示，每对段落从相同高度开始；你也可以将它们堆叠显示，或仅显示译文或仅显示原文
• 浅色、深色或跟随系统外观，以及可调整的调色板、字体、大小、行高和页面宽度——全部会被记住
• “保存”会将文章及其译文保留在你的设备上；从右侧列表中再次打开即可，无需重新翻译，或在不再需要时将其删除

▍单击单词查看另一种措辞——并保留你偏好的术语

在阅读页面、选区弹窗、翻译面板和 PDF 页面上，单击译文中的某个单词——或拖选几个单词——即可查看多种替代译法及简短说明，或自行输入。一次性替换其他地方出现的同一单词。

你选择的措辞会作为措辞偏好保存在你的设备上：之后翻译包含相同源术语的文本时会遵循你的选择。在设置中查看和删除它们。

▍翻译工具

• 所选文本
选择文本，然后从右键菜单中选择“翻译为…”。译文会显示在居中的弹窗中，在提供商支持流式传输时逐词显示。你也可以使用选区旁的浮动按钮，或使用快捷键 ⌘⇧Y（macOS）/ Alt+Shift+T（其他平台）。弹窗可拖动，可按需显示原文，并在你切换目标语言时重新翻译原文。

• 图片
右键单击图片以识别其文字。每段文字沿其笔画描边，译文会被放回原文之上，且各段文字不会相互遮挡。竖排日文（如漫画中的）在翻译为中文、日文或韩文时保持竖排。先检查检测到的形状——移动、编辑、删除或绘制新的形状——然后再翻译，或仅选择你需要的区域（矩形或圆形）。将结果下载或复制为新图片。

• 整个 PDF
在浏览器内置的 PDF 查看器中，不选择文本直接右键单击，即可在旁边的页面中翻译整个文档。译文会覆盖在原始位置上，因此布局、图形和表格线保持原位。并排比较，仅显示译文或仅显示原文，并通过打印对话框将结果保存为 PDF。你也可以将本地 PDF 拖放到翻译页面上。

• 页面区域
右键单击页面的某个区域，为其添加翻译按钮。单击一次将该区域的文本替换为其译文，再次单击恢复原文。规则按网站记住。

• 翻译面板
一个专用页面，左侧为原文，右侧为译文，适用于较长的段落或来自浏览器外部的文本。自动检测源语言或自行选择。

24 界面和目标语言：简体中文、繁体中文、英语、西班牙语、葡萄牙语、法语、德语、意大利语、荷兰语、俄语、乌克兰语、波兰语、土耳其语、阿拉伯语、希伯来语、波斯语、印地语、孟加拉语、乌尔都语、印度尼西亚语、越南语、泰语、日语和韩语。界面、源语言和目标语言是独立的设置，阿拉伯语、希伯来语、波斯语和乌尔都语界面使用从右到左的布局。

▍翻译模式

• 免密钥额度翻译
新的符合条件的安装会获得访客试用（领取按网络受限），使用电子邮件或 Google 注册会增加更多额度。额度永不过期，并按实际翻译的文本量扣除（每 500 个字符 1 额度）；翻译失败不收费。试用额度用完后，额度翻译需要订阅，订阅提供无限使用（合理使用），自动续订并可随时取消。当前试用额度和价格请参阅网站和你的账户中心。

• 你自己的 API 密钥
输入你自己的 OpenAI、DeepSeek 或 DeepL 密钥。请求会直接从你的浏览器发送到该提供商，由其向你收取使用费用。图像识别需要具备视觉能力的模型；DeepL 不提供图像识别或替代措辞。

▍隐私

• 本地翻译将文本保留在你的设备上。在线模式会将请求的内容发送到所选服务。自动网站翻译仅在你明确启用的网站上处理文本，包括之后的访问。
• 使用你自己的密钥时，内容会直接发送到你选择的提供商，绝不经过我们。
• 使用额度翻译时，内容会通过我们的服务器传递给模型提供商；服务器不会存储你的文本、译文或图片。
• API 密钥、措辞偏好和保存的文章保留在你的设备上，不会通过你的浏览器账户同步。
