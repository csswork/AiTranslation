选中，右键，然后接着读。整篇文章逐段对照阅读；选中的文字、图片和 PDF，都能就地译成你的语言——不用切换标签页，不用复制粘贴。

划词 – AI 翻译与双语阅读是一个开源的浏览器扩展（Manifest V3）。安装后免 Key 就能用点数翻译，也可以填入自己的 OpenAI、DeepSeek 或 DeepL API Key。

▍双语阅读（2.2.0 新功能）

在网页上不选文字直接右键，选「双语阅读这篇文章」。页面上一道光带扫过，识别出标题和正文，在旁边打开一个干净的阅读页：原文与译文逐段对齐，导航、侧栏、广告位和推荐模块都不会出现，也不会送去翻译。

• 左右并排时每段顶端对齐，也可以上下对照、只看译文或只看原文
• 外观可选浅色、深色或跟随系统；配色、字体、字号、行距与版心都能调，并会记住
• 「保存」把文章连同译文留在本机，右侧列表随时打开，不用再翻译；不需要时可以删除

▍点词换说法，记住你的用词

在阅读页、划词弹窗、翻译面板和 PDF 翻译页里，点译文里的一个词，或拖选几个词，就能看到几种其他译法和简短说明，也可以自己改写。别处相同的词可以一起替换。

换过的说法会作为用词偏好记在本机：之后翻译含有同一原文词语的文字时，优先使用你的译法。偏好可以在设置页查看和删除。

▍六种翻译方式，都在右键菜单里

• 划词翻译
选中文字后右键「翻译成…」，译文在居中弹窗里显示，支持流式输出的平台会逐字呈现。也可以用选区旁的浮动按钮，或快捷键 ⌘⇧Y（macOS）/ Alt+Shift+T。弹窗可拖动，可折叠显示原文；临时换个目标语言会用原文重新翻译。

• 图片翻译
右键一张图片，识别图里的文字，按笔画勾出每段文字的形状，把译文贴着原位盖回去，形状之间互不遮挡。日文漫画的竖排文字译成中文、日文或韩文时保持竖排。可以先看识别出的形状，移动、删改或新画后再翻译；也可以只框选要翻译的区域（矩形或圆形）。结果可下载或复制成一张新图片。

• 整份 PDF 翻译
在浏览器内置 PDF 阅读器里不选文字直接右键，整份文档在旁边的页面里翻译。译文按原位置盖回去，版面、图表和表格线不变；可并排对照、只看译文或只看原文，并通过打印另存为 PDF。本地 PDF 可以直接拖进翻译页。

• 区域翻译
右键页面上的某个区域，给它挂一个翻译按钮。点一下，区域里的文字就地换成译文，再点可恢复原文。规则按网站记住，下次自动出现。

• 翻译面板
一个独立页面，左边贴原文右边出译文，适合处理成段的、不在网页上的文字。来源语言可自动识别或手动指定。

24 种界面与目标语言：简体中文、繁体中文、英语、西班牙语、葡萄牙语、法语、德语、意大利语、荷兰语、俄语、乌克兰语、波兰语、土耳其语、阿拉伯语、希伯来语、波斯语、印地语、孟加拉语、乌尔都语、印度尼西亚语、越南语、泰语、日语和韩语。界面语言、来源语言和目标语言各自独立；阿拉伯语、希伯来语、波斯语和乌尔都语界面使用从右往左的布局。

▍两种用法

• 免 Key 的点数翻译
新安装可领取访客试用（同一网络有领取次数限制），用邮箱或 Google 注册账号再送点数。点数不过期，按实际翻译的字数扣减（每 500 个字符 1 点），翻译失败不扣点。试用点数用完后，点数翻译需要订阅；订阅后无限使用（合理使用），自动续订，随时可以取消。当前的试用额度与价格以官网和用户中心显示为准。

• 自带 API Key
填入自己的 OpenAI、DeepSeek 或 DeepL Key，请求从浏览器直接发往该平台，费用由平台按用量收取。图片识别需要支持视觉的模型；DeepL 不提供图片识别和「换说法」。

▍隐私

• 只有你主动触发翻译时，内容才会发送。扩展不会在后台扫描或上传网页。
• 自带 Key 时，内容直接发往你选择的平台，不经过我们。
• 点数翻译时，内容经我们的服务器转给模型服务商完成翻译；服务器不保存原文、译文或图片。
• API Key、用词偏好和保存的文章都只存在你的设备上，不经 Chrome 账号同步。
• 没有广告、埋点或第三方统计；全部源码以 GPL-3.0 公开。

视频实时字幕是默认关闭的实验功能：默认在本机识别语音，主动选择云端识别时声音会发给浏览器的语音服务。

▍已知限制

• 浏览器保护的页面（chrome:// 等内部页面和应用商店）无法使用扩展。
• 单次划词最多翻译 6,000 个字符，更长的选区会截断并提示。
• 双语阅读按页面结构识别正文，论坛、社交网络和需要登录的页面可能识别不全。
• 扫描版、有密码的 PDF 暂不支持。
• 可用语言、图片识别和流式输出取决于所选平台和模型。
