## 文案口径

- 当前版本使用用户自己的 OpenAI、DeepSeek 或 DeepL API Key；API 费用由所选服务商收取。
- 24 种目标语言及界面语言；源语言、目标语言和界面语言独立。
- 划词、区域、图片及独立翻译面板；视频字幕翻译属于可选实验功能。
- 图片识别需要支持视觉的服务商和模型；不同服务商的语言、流式输出及功能支持不同。
- 浏览器支持时可本地语音识别；可选云端识别会将音频发送给浏览器语音服务。
- 当前未提供账号、试用点数、托管翻译或订阅，因此文案未包含这些未来功能。

英文原稿为 `en.txt`。其余版本使用 DeepSeek `deepseek-flash` 翻译，已检查段落、列表、数字、技术名称和链接完整性，未经过母语人工审校。
