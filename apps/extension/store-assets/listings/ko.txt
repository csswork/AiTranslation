선택하고, 마우스 오른쪽 버튼을 누르고, 계속 읽으세요. 글 전체를 번역문과 나란히 읽고, 선택한 텍스트, 이미지, PDF를 탭을 전환하거나 복사·붙여넣기 없이 바로 그 자리에서 번역합니다.

Huaci – AI 번역 및 이중 언어 읽기는 Manifest V3 기반의 오픈 소스 브라우저 확장 프로그램입니다. 설치 후 키 없이 크레딧으로 바로 번역을 시작하거나, 본인의 OpenAI, DeepSeek 또는 DeepL API 키를 사용할 수 있습니다.

▍이중 언어 읽기 (2.2.0 신규 기능)

페이지에서 텍스트를 선택하지 않고 아무 곳이나 마우스 오른쪽 버튼으로 클릭한 뒤 "이 글을 이중 언어로 읽기"를 선택하세요. 페이지 위로 빛이 스캔되며 제목과 본문이 감지되면, 원문 단락마다 번역문이 나란히 정렬된 깔끔한 읽기 페이지가 옆에 열립니다. 내비게이션, 사이드바, 광고 영역, 추천 위젯은 제외되며 번역을 위해 전송되지도 않습니다.

• 나란히 보기에서는 모든 단락 쌍이 같은 높이에서 시작하며, 위아래로 쌓거나 번역문만 또는 원문만 표시할 수도 있습니다
• 밝게, 어둡게 또는 시스템 설정 따르기 테마와 조정 가능한 색상 팔레트, 글꼴, 크기, 줄 간격, 페이지 너비—모두 기억됩니다
• "저장"을 누르면 글과 번역문이 기기에 보관되며, 오른쪽 목록에서 다시 열어 번역 없이 볼 수 있고, 필요 없어지면 삭제할 수 있습니다

▍단어를 클릭해 다른 표현을 확인하고, 선호하는 용어를 유지하세요

읽기 페이지, 선택 팝업, 번역 패널, PDF 페이지에서 번역문의 단어를 클릭하거나 몇 개의 단어를 드래그하면 짧은 설명과 함께 여러 대체 표현을 볼 수 있고, 직접 입력할 수도 있습니다. 같은 단어를 다른 곳에서도 한 번에 바꿀 수 있습니다.

선택한 표현은 기기에 표현 선호로 저장되어, 나중에 같은 원문 용어가 포함된 텍스트를 번역할 때 선택한 표현을 따릅니다. 설정에서 확인하고 삭제할 수 있습니다.

▍여섯 가지 번역 방법, 모두 마우스 오른쪽 버튼 메뉴에서

• 선택한 텍스트
텍스트를 선택하고 마우스 오른쪽 버튼 메뉴에서 "번역 대상…"을 선택하세요. 번역문은 화면 중앙 팝업에 표시되며, 스트리밍을 지원하는 제공업체의 경우 단어 단위로 나타납니다. 선택 영역 옆의 플로팅 버튼이나 macOS의 단축키 ⌘⇧Y / 그 외 환경의 Alt+Shift+T를 사용할 수도 있습니다. 팝업은 드래그할 수 있고, 필요할 때 원문을 표시하며, 대상 언어를 바꾸면 원문을 다시 번역합니다.

• 이미지
이미지를 마우스 오른쪽 버튼으로 클릭해 텍스트를 인식하세요. 각 텍스트 영역은 획을 따라 윤곽이 그려지고, 번역문은 원본 위에 다시 배치되며 영역끼리 겹치지 않습니다. 만화처럼 세로로 쓰인 일본어 텍스트는 중국어, 일본어, 한국어로 번역할 때 세로 방향을 유지합니다. 번역 전에 감지된 영역을 먼저 검토하여 이동, 편집, 삭제하거나 새로 그릴 수 있고, 필요한 영역(사각형 또는 원형)만 선택할 수도 있습니다. 결과를 새 이미지로 다운로드하거나 복사할 수 있습니다.

• PDF 전체
브라우저의 내장 PDF 뷰어에서 텍스트를 선택하지 않고 마우스 오른쪽 버튼으로 클릭하면 문서 전체가 옆 페이지에서 번역됩니다. 번역문은 원래 위치 위에 겹쳐져 레이아웃, 그림, 표 선이 그대로 유지됩니다. 나란히 비교하거나 번역문만 또는 원문만 표시할 수 있고, 인쇄 대화상자를 통해 결과를 PDF로 저장할 수 있습니다. 로컬 PDF를 번역 페이지로 끌어다 놓을 수도 있습니다.

• 페이지 영역
페이지의 특정 영역을 마우스 오른쪽 버튼으로 클릭하면 그 영역에 번역 버튼을 추가합니다. 한 번 클릭하면 영역의 텍스트가 번역문으로 바뀌고, 다시 클릭하면 원문으로 복원됩니다. 규칙은 웹사이트별로 기억됩니다.

• 번역 패널
원문은 왼쪽, 번역문은 오른쪽에 표시하는 전용 페이지로, 긴 텍스트나 브라우저 외부의 텍스트에 적합합니다. 원문 언어를 자동 감지하거나 직접 선택할 수 있습니다.

24개 인터페이스 및 대상 언어: 중국어 간체, 중국어 번체, 영어, 스페인어, 포르투갈어, 프랑스어, 독일어, 이탈리아어, 네덜란드어, 러시아어, 우크라이나어, 폴란드어, 터키어, 아랍어, 히브리어, 페르시아어, 힌디어, 벵골어, 우르두어, 인도네시아어, 베트남어, 태국어, 일본어, 한국어. 인터페이스 언어, 원문 언어, 대상 언어는 각각 독립적인 설정이며, 아랍어, 히브리어, 페르시아어, 우르두어 인터페이스는 오른쪽에서 왼쪽으로 쓰는 레이아웃을 사용합니다.

▍두 가지 사용 방법

• 키 없는 크레딧 번역
새로 설치한 유효한 설치에는 게스트 체험(네트워크당 신청 횟수 제한)이 제공되며, 이메일 또는 Google로 가입하면 크레딧이 추가됩니다. 크레딧은 만료되지 않으며 실제로 번역된 텍스트 양에 따라 차감됩니다(500자당 1 크레딧). 번역 실패 시에는 차감되지 않습니다. 체험 크레딧이 소진되면 크레딧 번역에는 구독이 필요하며, 구독 시 무제한 사용(공정 사용)이 가능하고 자동 갱신되며 언제든지 취소할 수 있습니다. 현재 체험 크레딧과 가격은 웹사이트와 계정 센터를 참고하세요.

• 본인 API 키
본인의 OpenAI, DeepSeek 또는 DeepL 키를 입력하세요. 요청은 브라우저에서 해당 제공업체로 직접 전송되며, 사용량에 따라 제공업체가 과금합니다. 이미지 인식에는 비전 지원 모델이 필요하며, DeepL은 이미지 인식과 대체 표현을 제공하지 않습니다.

▍개인정보 보호

• 콘텐츠는 번역을 선택할 때만 전송됩니다. 확장 프로그램은 백그라운드에서 페이지를 스캔하거나 업로드하지 않습니다.
• 본인 키를 사용하면 콘텐츠는 선택한 제공업체로 직접 전송되며, 절대 저희를 거치지 않습니다.
• 크레딧 번역을 사용하면 콘텐츠가 저희 서버를 통해 모델 제공업체로 전달되며, 서버는 텍스트, 번역문, 이미지를 저장하지 않습니다.
• API 키, 표현 선호, 저장된 글은 기기에 보관되며 브라우저 계정을 통해 동기화되지 않습니다.
• 광고, 추적, 제3자 분석은 없습니다. 전체 소스 코드는 GPL-3.0으로 공개되어 있습니다.

실시간 동영상 자막은 기본적으로 꺼져 있는 실험적 기능입니다. 음성은 기본적으로 기기에서 인식되며, 클라우드 인식을 명시적으로 선택하면 오디오가 브라우저의 음성 인식 서비스로 전송됩니다.

▍알려진 제한 사항

• chrome:// 내부 페이지 및 확장 프로그램 스토어 등 브라우저가 보호하는 페이지에서는 사용할 수 없습니다.
• 한 번의 선택은 최대 6,000자까지 가능하며, 더 긴 선택은 안내와 함께 잘립니다.
• 이중 언어 읽기는 페이지 구조에서 글을 감지하므로, 포럼, 소셜 네트워크, 로그인 후 페이지는 완전히 감지되지 않을 수 있습니다.
• 스캔본 및 비밀번호로 보호된 PDF는 아직 지원되지 않습니다.
• 사용 가능한 언어, 이미지 인식, 스트리밍은 선택한 제공업체와 모델에 따라 달라집니다.

Chrome 또는 Edge 116 이상이 필요합니다.

독립적인 오픈 소스 프로젝트이며, OpenAI, DeepSeek, DeepL 또는 그 계열사와 제휴, 보증, 후원 관계가 없습니다. ChatGPT, DeepSeek, DeepL 및 기타 명칭은 각 소유자의 상표이며, 호환되는 서비스를 식별하기 위해서만 사용됩니다.
