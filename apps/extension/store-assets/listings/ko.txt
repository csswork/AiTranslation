• 로컬 텍스트 번역: 지원되는 브라우저와 기기에서 설정에서 언어 쌍을 다운로드하면 API 키나 크레딧 없이 무료로 오프라인 번역할 수 있습니다. 텍스트는 기기에 남습니다. 선택 항목, 페이지 영역, 웹사이트, 텍스트 패널, PDF, 이중 언어 읽기 및 인식된 캡션에 사용할 수 있습니다. 가용성과 언어는 브라우저 및 다운로드한 팩에 따라 달라집니다. 로컬 모드는 이미지 인식이나 대체 표현을 제공하지 않으며, 지원되지 않는 컨트롤은 숨겨집니다.
• 자동 웹사이트 번역: 마우스 오른쪽 버튼을 클릭하고 “이 웹사이트 번역”을 활성화하세요. 뷰포트 근처의 텍스트는 스크롤할 때 번역되며, 이후 방문 시에도 비활성화할 때까지 번역됩니다. 페이지에서 반복되는 텍스트는 번역을 재사용합니다. 설정에서 별도의 제공자를 선택하세요. 유료 제공자를 처음 사용할 때는 확인을 요청합니다.
• 더 자연스러운 표현: 개정된 스타일 가이드는 중국어 및 기타 대상 언어의 문구, 용어 및 어조를 개선합니다.
• 더 나은 자동 이미지 번역: 텍스트 모양, 글꼴 크기, 정렬, 세로 텍스트 및 배경색이 개선되었습니다. 구절을 이동하거나, 번역 또는 크기를 편집하거나, 해당 구절만 다시 번역할 수 있습니다. 내보낸 이미지는 편집 내용을 유지합니다. 선택적으로 효과음을 번역할 수 있으며, 인식된 이미지는 현재 페이지에 캐시되고 이미지 간 탐색이 가능합니다.

▍이중 언어 읽기

텍스트를 선택하지 않은 상태에서 페이지 아무 곳이나 마우스 오른쪽 버튼을 클릭하고 “이 글을 이중 언어로 읽기”를 선택하세요. 제목과 본문이 감지되는 동안 페이지 위로 빛이 스쳐 지나가고, 각 원문 단락이 번역 옆에 정렬된 깔끔한 읽기 페이지가 옆에 열립니다. 탐색, 사이드바, 광고 슬롯 및 추천 위젯은 제외되며 번역을 위해 전송되지 않습니다.

• 나란히 보기: 모든 단락 쌍이 같은 높이에서 시작합니다. 쌓아서 표시하거나 번역만 또는 원문만 표시할 수도 있습니다
• 라이트, 다크 또는 시스템 설정 따르기 모드, 조정 가능한 색상 팔레트, 글꼴, 크기, 줄 높이 및 페이지 너비—모두 기억됩니다
• “저장”은 기사와 번역을 기기에 보관합니다. 오른쪽 목록에서 다시 번역하지 않고 열거나, 더 이상 필요 없을 때 삭제하세요

▍단어를 클릭하여 다른 표현 확인—선호 용어 유지

읽기 페이지, 선택 팝업, 번역 패널 및 PDF 페이지에서 번역의 단어를 클릭하거나 몇 개의 단어를 드래그하면 짧은 설명과 함께 여러 대체 표현을 볼 수 있으며, 직접 입력할 수도 있습니다. 같은 단어를 다른 곳에서도 한 번에 바꾸세요.

선택한 표현은 기기에 표현 선호도로 저장됩니다. 동일한 원문 용어가 포함된 텍스트의 이후 번역은 선택을 따릅니다. 설정에서 검토하고 삭제하세요.

▍번역 도구

• 선택한 텍스트
텍스트를 선택하고 마우스 오른쪽 버튼 메뉴에서 “번역 대상…”을 선택하세요. 번역은 중앙 팝업에 표시되며, 제공자가 스트리밍을 지원하는 경우 단어별로 표시됩니다. 선택 항목 옆의 플로팅 버튼이나 macOS의 단축키 ⌘⇧Y / 기타 환경의 Alt+Shift+T를 사용할 수도 있습니다. 팝업은 드래그할 수 있고, 필요 시 원문을 표시하며, 대상 언어를 전환하면 원문을 다시 번역합니다.

• 이미지
이미지를 마우스 오른쪽 버튼으로 클릭하여 텍스트를 인식하세요. 각 구절은 획을 따라 윤곽이 표시되고, 구절이 서로 겹치지 않도록 번역이 원본 위에 배치됩니다. 만화처럼 세로 일본어 텍스트는 중국어, 일본어 또는 한국어로 번역할 때 세로로 유지됩니다. 번역 전에 감지된 모양을 먼저 검토하세요—이동, 편집, 삭제 또는 새로 그리기—또는 필요한 영역만 선택하세요(사각형 또는 원). 결과를 새 이미지로 다운로드하거나 복사하세요.

• 전체 PDF
브라우저 내장 PDF 뷰어에서 텍스트를 선택하지 않은 상태로 마우스 오른쪽 버튼을 클릭하여 전체 문서를 옆 페이지에 번역하세요. 번역은 원래 위치 위에 배치되어 레이아웃, 그림 및 표 선이 그대로 유지됩니다. 나란히 비교하거나, 번역만 또는 원문만 표시하고, 인쇄 대화상자를 통해 결과를 PDF로 저장하세요. 로컬 PDF를 번역 페이지에 끌어다 놓을 수도 있습니다.

• 페이지 영역
페이지의 영역을 마우스 오른쪽 버튼으로 클릭하여 번역 버튼을 추가하세요. 한 번 클릭하면 해당 영역의 텍스트가 번역으로 바뀌고, 다시 클릭하면 원문이 복원됩니다. 규칙은 웹사이트별로 기억됩니다.

• 번역 패널
원문은 왼쪽, 번역은 오른쪽에 표시되는 전용 페이지로, 긴 구절이나 브라우저 외부의 텍스트에 사용합니다. 원문 언어를 자동으로 감지하거나 직접 선택하세요.

▍번역 모드

• 키가 필요 없는 크레딧 번역
새로운 적격 설치에는 게스트 체험판이 제공되며(청구는 네트워크별로 제한됨), 이메일 또는 Google로 가입하면 크레딧이 추가됩니다. 크레딧은 만료되지 않으며 실제로 번역된 텍스트 양에 따라 차감됩니다(500자당 1크레딧). 실패한 번역은 청구되지 않습니다. 체험 크레딧이 소진되면 크레딧 번역에는 구독이 필요하며, 무제한 사용(공정 사용)을 제공하고 자동 갱신되며 언제든지 취소할 수 있습니다. 현재 체험 금액 및 가격은 웹사이트 및 계정 센터를 참조하세요.

• 본인의 API 키
본인의 OpenAI, DeepSeek 또는 DeepL 키를 입력하세요. 요청은 브라우저에서 해당 제공자로 직접 전송되며, 사용량에 대해 제공자가 청구합니다. 이미지 인식에는 비전 지원 모델이 필요하며, DeepL은 이미지 인식이나 대체 표현을 제공하지 않습니다.

▍개인정보 보호

• 로컬 번역은 텍스트를 기기에 유지합니다. 온라인 모드는 요청된 콘텐츠를 선택한 서비스로 전송합니다. 자동 웹사이트 번역은 명시적으로 활성화한 웹사이트에서만 텍스트를 처리하며, 이후 방문 시에도 마찬가지입니다.
• 본인의 키를 사용하면 콘텐츠는 선택한 제공자로 직접 전송되며, 절대 당사를 거치지 않습니다.
• 크레딧 번역을 사용하면 콘텐츠가 당사 서버를 통해 모델 제공자로 전달됩니다. 서버는 텍스트, 번역 또는 이미지를 저장하지 않습니다.
• API 키, 표현 선호도 및 저장된 기사는 기기에 남으며 브라우저 계정을 통해 동기화되지 않습니다.
• 광고, 추적 또는 타사 분석이 없습니다. 전체 소스 코드는 GPL-3.0 에서 확인할 수 있습니다.

실시간 비디오 캡션은 실험적 기능이며 기본적으로 꺼져 있습니다. 음성은 기본적으로 기기에서 인식됩니다. 클라우드 인식을 명시적으로 선택하면 오디오가 브라우저의 음성 인식 서비스로 전송됩니다.
