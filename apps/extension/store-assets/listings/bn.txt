ওয়েবপেজে টেক্সট নির্বাচন করুন, ডান-ক্লিক করুন, এবং ট্যাব পরিবর্তন বা কপি-পেস্ট ছাড়াই একটি ভাসমান প্যানেলে অনুবাদ দেখুন।

AI Selection Translator হলো Manifest V3-এর উপর নির্মিত একটি ওপেন-সোর্স Chrome এক্সটেনশন। আপনার নিজের OpenAI, DeepSeek, বা DeepL API কী ব্যবহার করে নির্বাচিত টেক্সট, পেজের নির্দিষ্ট অংশ এবং ছবির ভেতরের টেক্সট আপনার পছন্দের ভাষায় অনুবাদ করুন।

▍অনুবাদের চারটি উপায়

• নির্বাচিত টেক্সট
টেক্সট নির্বাচন করুন এবং ডান-ক্লিক মেনু থেকে “Translate to…” নির্বাচন করুন। অনুবাদটি একটি কেন্দ্রীভূত প্যানেলে দেখা যায়, যেখানে সমর্থিত ক্ষেত্রে স্ট্রিমিং আউটপুট এবং একটি প্রসারিতযোগ্য মূল-টেক্সট ভিউ থাকে।

যেকোনো ভাষার নির্বাচন—চীনা সহ—অনুবাদ করা যায়। শুধু সংখ্যা, বিরামচিহ্ন, বা ইমোজি থাকা নির্বাচনে অনুবাদের প্রস্তাব দেখানো হয় না।

মূল নির্বাচনটি আবার অনুবাদ করতে প্যানেলেই লক্ষ্য ভাষা পরিবর্তন করুন। আপনি চাইলে এটি আপনার ডিফল্ট হিসেবে সংরক্ষণ করুন।

• পেজের নির্দিষ্ট অংশ
ওয়েবপেজের একটি নির্দিষ্ট এলাকায় একটি অনুবাদ বোতাম যোগ করুন। সেটিতে ক্লিক করে ওই এলাকার টেক্সট তার অনুবাদ দিয়ে প্রতিস্থাপন করুন, এবং প্রয়োজন হলে মূল টেক্সট ফিরিয়ে আনুন।

নিয়মগুলো ডোমেইন অনুযায়ী সংরক্ষিত হয়, তাই ওয়েবসাইটে আবার এলে বোতামটি ফিরে আসে। বড় এলাকাগুলো ব্যাচে প্রক্রিয়া করা হয়, এবং অনুবাদগুলো ধীরে ধীরে দেখা যায়।

• ছবি
একটি ছবিতে ডান-ক্লিক করে তার টেক্সট শনাক্ত করুন এবং শনাক্ত করা অবস্থানে অনুবাদ ওভারলে করুন। লম্বা ছবিগুলো শনাক্তের জন্য ছোট ছোট অংশে ভাগ করা হয়।

লক্ষ্য ভাষা পরিবর্তন করলে শনাক্ত করা টেক্সট পুনরায় ব্যবহার করা হয়, তাই একই ছবি আবার স্ক্যান করার প্রয়োজন হয় না। ছবি শনাক্তের জন্য ভিশন-সক্ষম প্রোভাইডার ও মডেল প্রয়োজন।

• অনুবাদ প্যানেল
বাঁ দিকে মূল টেক্সট এবং ডান দিকে অনুবাদ সহ একটি ডেডিকেটেড পেজ খুলুন। দীর্ঘ অনুচ্ছেদ বা ব্রাউজারের বাইরের টেক্সটের জন্য এটি ব্যবহার করুন।

24টি লক্ষ্য ভাষা থেকে বেছে নিন: সরলীকৃত চীনা, ঐতিহ্যবাহী চীনা, ইংরেজি, স্প্যানিশ, পর্তুগিজ, ফরাসি, জার্মান, ইতালীয়, ডাচ, রুশ, ইউক্রেনীয়, পোলিশ, তুর্কি, আরবি, হিব্রু, ফারসি, হিন্দি, বাংলা, উর্দু, ইন্দোনেশীয়, ভিয়েতনামীয়, থাই, জাপানি, এবং কোরিয়ান।

উৎস ভাষা স্বয়ংক্রিয়ভাবে শনাক্ত করুন বা স্পষ্টভাবে নির্বাচন করুন। উৎস ভাষা, লক্ষ্য ভাষা, এবং ইন্টারফেস ভাষা স্বতন্ত্র সেটিংস। প্রোভাইডার সমর্থন ভাষা ও ফিচার অনুযায়ী ভিন্ন হয়।

▍দৈনন্দিন পড়ার জন্য ডিজাইন করা

• পেজেই থাকুন: আপনার কাজের ধারা ব্যাহত না করে পড়ার সময়ই অনুবাদ করুন।
• স্ট্রিমিং আউটপুট: সমর্থিত ক্ষেত্রে অনুবাদগুলো ধীরে ধীরে দেখা যায়।
• লাইট ও ডার্ক থিম আপনার সিস্টেম পছন্দ অনুসরণ করে।
• অনুবাদ প্যানেলটি টেনে সরান, অথবা বন্ধ করতে Esc চাপুন।
• কীবোর্ড শর্টকাট: macOS-এ ⌘⇧Y বা অন্য প্ল্যাটফর্মে Alt+Shift+T।
• 24টি ভাষার জন্য স্থানীয়কৃত ইন্টারফেস, ডান-থেকে-বাঁ লেআউট সহ।
• ইন্টারফেস ভাষা থেকে স্বতন্ত্রভাবে আপনার ডিফল্ট অনুবাদ ভাষা বেছে নিন।

পরীক্ষামূলক ভিডিও সাবটাইটেল অনুবাদও একটি ঐচ্ছিক ফিচার হিসেবে উপলব্ধ। স্পিচ রিকগনিশন সমর্থন আপনার ব্রাউজার, ডিভাইস, এবং উৎস ভাষার উপর নির্ভর করে।

▍গোপনীয়তা

• ডেভেলপার-পরিচালিত কোনো অনুবাদ সার্ভার নেই। অনুবাদ অনুরোধ সরাসরি আপনার কনফিগার করা প্রোভাইডার বা কাস্টম এন্ডপয়েন্টে যায়।
• কোনো অ্যানালিটিক্স, ট্র্যাকিং, বা বিজ্ঞাপন নেই।
• আপনার API কী স্থানীয়ভাবে chrome.storage.local-এ সংরক্ষিত থাকে এবং আপনার Chrome অ্যাকাউন্টের মাধ্যমে সিঙ্ক হয় না।
• আপনি সক্রিয়ভাবে অনুরোধ করলেই কনটেন্ট অনুবাদের জন্য পাঠানো হয়। ডেভেলপার আপনার অনুবাদের ইতিহাস পান না।
• সমর্থিত ডিভাইসে ভিডিও স্পিচ রিকগনিশন স্থানীয়ভাবে চলতে পারে। ঐচ্ছিক ক্লাউড রিকগনিশন অডিও ব্রাউজারের স্পিচ রিকগনিশন সেবায় পাঠায়।
• সম্পূর্ণ সোর্স কোড পরিদর্শনের জন্য GPL-3.0-এর অধীনে উপলব্ধ।

▍শুরু করা

1. ইনস্টল করার পর, সেটিংস পেজ স্বয়ংক্রিয়ভাবে খোলে। একটি প্রোভাইডার বেছে নিন, আপনার নিজের API কী লিখুন, এবং আপনার কনফিগারেশন যাচাই করতে “Test connection” ব্যবহার করুন।
2. আপনার ইন্টারফেস ভাষা এবং ডিফল্ট অনুবাদ লক্ষ্য বেছে নিন।
3. শুরু করতে একটি ওয়েবপেজে টেক্সট নির্বাচন করুন, ডান-ক্লিক করুন, এবং “Translate to…” বেছে নিন।

Chrome 116 বা তার পরের সংস্করণ প্রয়োজন। পরীক্ষামূলক ভিডিও ফিচারের জন্য নতুন ব্রাউজার এবং অতিরিক্ত সেটআপ প্রয়োজন হতে পারে।

এই সংস্করণ আপনার নিজের প্রোভাইডার ক্রেডেনশিয়াল ব্যবহার করে। যেকোনো API চার্জ আপনার নির্বাচিত প্রোভাইডার বিল করে।

▍পরিচিত সীমাবদ্ধতা

• ব্রাউজার-সুরক্ষিত পেজ, যার মধ্যে chrome:// পেজ এবং Chrome Web Store রয়েছে, সেখানে কনটেন্ট-স্ক্রিপ্ট ইনজেকশন অনুমোদিত নয়। সেখানে অনুবাদ ওভারলে উপলব্ধ নয়।
• একক টেক্সট অনুবাদ 6,000 অক্ষরে সীমাবদ্ধ। দীর্ঘ নির্বাচন কেটে দেওয়া হয়, এবং প্যানেলে একটি নোটিশ দেখানো হয়।
• কাস্টম API এন্ডপয়েন্টের জন্য তাদের ডোমেইনের আলাদা অনুমতি প্রয়োজন এবং অবশ্যই HTTPS ব্যবহার করতে হবে।
• উপলব্ধ ভাষা, ছবি শনাক্তকরণ, এবং স্ট্রিমিং সক্ষমতা আপনার প্রোভাইডার ও মডেলের উপর নির্ভর করে।

▍এই প্রকল্প সম্পর্কে

একটি স্বাধীন, ওপেন-সোর্স প্রকল্প। এটি OpenAI, DeepSeek, DeepL, বা তাদের সংশ্লিষ্ট কোম্পানিগুলোর সাথে সম্পর্কিত, অনুমোদিত, বা স্পনসরকৃত নয়।

ChatGPT, DeepSeek, DeepL, এবং অন্যান্য পণ্যের নাম তাদের নিজ নিজ মালিকদের ট্রেডমার্ক এবং শুধুমাত্র সামঞ্জস্যপূর্ণ সেবা শনাক্ত করতে ব্যবহৃত হয়।
