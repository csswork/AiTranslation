## Description

```
Huaci is a browser extension for Chrome and Edge that translates what you are looking at, where you are looking at it: text inside images, whole articles, PDFs, and entire websites.

WHAT YOU SEE IN THIS VIDEO
• Image translation — right-click any image. Huaci finds every piece of text, traces its shape, and puts the translation back in the same place and size. Compare with the original, edit a single line, select just an area, then copy or download the translated image.
• Bilingual reader — turn an article into a clean side-by-side read, without ads and sidebars. Click a word in the translation to pick another wording. Save articles on your device.
• Selection translation — select text and the translation streams in.
• Whole-PDF translation — the layout is kept; the file is parsed locally and never uploaded.
• Page blocks — translate one block of a page in place.
• Whole-website translation — tick "Translate this website" once and its pages are translated as you scroll.
• Translate panel — paste a passage and get the translation.
• Local translation — uses the browser's built-in translation model: free, no API key, and the text never leaves your device (needs a browser that provides the built-in Translator; no image recognition).

HOW YOU PAY FOR TRANSLATION
• Credits: a hosted mode with a free trial, no key needed
• Local translation: free, on your device
• Your own API key: ChatGPT (OpenAI), DeepSeek or DeepL — the key stays in the browser

NOTE
• The interface is available in 24 languages, and you can translate into any of them. This demo translates Japanese images and Chinese web pages into English.
• Image recognition and its translations in this video are real model output. The other clips use pre-written demo translations on the real extension UI.
• Comic pages: Pepper&Carrot episode 1 by David Revoy, Japanese translation by guruguru, CC BY 4.0.
• Music: synthesized for this video.
```

## 中文版（配 `huaci-promo-zh.mp4`）

标题：

```
划词：图片翻译、双语阅读、整份 PDF、整站翻译，一个扩展都能翻
```

说明：

```
划词是 Chrome 和 Edge 上的翻译扩展：图片里的字、整篇文章、整份 PDF、整个网站，在原来的地方直接翻译。

这段视频里有：
• 图片自动翻译：在图片上右键，自动找出每段文字、按笔画勾出形状，译文按原来的位置和字号排回图上，竖排还是竖排；
  可以和原图对照、改单段译文、只框选一部分，译好的图能复制或下载。
• 双语阅读：把文章整理成原文和译文逐段对照，去掉广告和侧栏；点译文里的词换一种说法；文章保存在本机。
• 划词翻译、整份 PDF 翻译（文件在本机解析，不上传）、网页区域翻译、整站翻译、翻译面板。
• 本机翻译：用浏览器内置的翻译模型，免费、不需要 Key、文字不出本机（需要浏览器提供内置 Translator，不支持图片识别）。

翻译方式：点数翻译（可免费试用）、本机翻译，或自带 API Key（ChatGPT / DeepSeek / DeepL）。

说明：视频里图片识别与译文是真实模型当次返回的结果；其余片段的译文是预置的演示文案，界面和操作是真实扩展。
漫画：Pepper&Carrot 第 1 话，David Revoy，日文翻译 guruguru，CC BY 4.0。

官网：https://huaci.app/
```
