## Description

```
Huaci is a browser extension for Chrome, Edge and Firefox that translates what you are looking at, where you are looking at it: selected text, text inside images, whole articles, PDFs and entire websites.

WHAT YOU SEE IN THIS VIDEO
• Selection translation — select text, click the floating button, and the translation streams in.
• Image translation — right-click an image and choose "Translate text in image". The translation goes back in place; switch to the original at any time.
• Bilingual reader — right-click an article and choose "Read this article bilingually". Huaci finds the main text and opens a clean side-by-side or stacked read.
• Whole-PDF translation — right-click a PDF and choose "Translate entire PDF". The layout is kept; the file is parsed locally and never uploaded.
• Whole-website translation — right-click a page and choose "Translate this website". Every page of that site is translated as you browse, until you turn it off.

HOW YOU PAY FOR TRANSLATION
• Credits: a hosted mode with a free trial, no key needed
• Local translation: free, on your device (in browsers with a built-in Translator)
• Your own API key: ChatGPT (OpenAI), DeepSeek or DeepL — the key stays in the browser

NOTE
• The interface is available in 24 languages, and you can translate into any of them. This demo translates Chinese and Japanese into English.
• The video is recorded in Chrome. In Firefox, you pick a PDF file from the toolbar popup instead of right-clicking, and local translation is not available.
• The video shows the real extension. Translations are pre-written demo text, and Chrome's right-click menu is drawn on screen because it can't be screen-recorded.
• Sample article: "在Medium上写技术文章的几个经验" by 李帅的地球Online on Medium.
• Music: synthesized for this video.
```
