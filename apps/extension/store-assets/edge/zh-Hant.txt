邊讀邊譯：將網頁文章變成左右並排的雙語閱讀頁面，或選取文字、按右鍵，直接在頁面上查看翻譯。

劃詞 – AI 翻譯與雙語閱讀 是一款開源的 Microsoft Edge 擴充功能，用於雙語閱讀，以及翻譯選取文字、網頁區域、圖片和整份 PDF 文件。無需 API 金鑰即可使用託管翻譯，或連接你自己的 OpenAI、DeepSeek 或 DeepL 帳戶。

雙語閱讀（2.2.0 版新增）

在未選取文字的普通網頁上按右鍵，選擇「雙語閱讀這篇文章」。擴充功能會在你的裝置上偵測文章的標題和正文，略過導覽列、側邊欄、廣告位和推薦小工具，並在分頁旁開啟一個乾淨的閱讀頁面，每個原文段落與其譯文並排對齊。只有清理後的文章文字會被傳送進行翻譯。

• 並排、上下堆疊、僅譯文或僅原文；淺色、深色或跟隨系統外觀；可調整調色盤、字型、大小、行高和頁面寬度。
• 將文章連同譯文儲存在你的裝置上，日後可從右側清單重新開啟，無需再次翻譯；可隨時刪除已儲存的文章。

替代措辭與措辭偏好

在閱讀頁面、選取彈出視窗、翻譯面板和 PDF 頁面上，點擊譯文中的某個詞（或選取幾個詞），即可查看附有簡短說明的替代譯法，或自行輸入。你的選擇會作為措辭偏好儲存在你的裝置上，並套用於之後包含相同原文詞彙的翻譯。可在設定中管理這些偏好。DeepL 不提供替代措辭。

六種翻譯方式

• 雙語閱讀：如上所述。
• 選取文字：在可移動的彈出視窗中翻譯任何語言的文字，包括中文。在支援的情況下串流顯示結果，展開原文以供對照，複製譯文，或變更目標語言。
• 網頁區域：為網站中選定的部分新增翻譯按鈕。規則依網域儲存，且你可以還原原始文字。
• 圖片：辨識文字，沿著筆畫描繪每一段文字，並將譯文放回原文上方，且各段落不會互相覆蓋。直排日文翻譯成中文、日文或韓文時仍保持直排。翻譯前可檢視並編輯偵測到的形狀，翻譯選取的區域，並匯出翻譯後的圖片。辨識需要具備視覺能力的模型；託管模式包含圖片辨識。
• 整份 PDF：在瀏覽器中開啟 PDF，並從右鍵選單選擇整份文件翻譯。PDF 在本機解析；只有擷取出的文字會被傳送進行翻譯。對照原文與譯文，保留頁面版面、圖形和表格，並可列印或另存為 PDF。無法擷取文字的掃描頁面不支援整份文件翻譯。
• 翻譯面板：將一段文字貼到專用的原文與譯文檢視中，選擇來源語言和目標語言，無需在網頁上選取即可翻譯。

實驗性影片字幕

選用的影片字幕預設為關閉。語音辨識取決於瀏覽器版本、裝置和語言，且可能無法使用。在支援的情況下會使用本機辨識；絕不會悄悄切換為雲端辨識。只有在你明確選擇雲端辨識時，分頁音訊才會傳送至瀏覽器語音服務（Edge 中為 Microsoft Azure）。辨識出的文字會依你選取的翻譯模式處理。我們不提供託管的音訊/影片轉錄。此實驗性功能不保證每部影片都能翻譯。

開始使用

安裝、選擇你偏好的目標語言，並使用託管試用或在設定中配置你自己的 API 金鑰。在普通網頁上，未選取文字時按右鍵並選擇「雙語閱讀這篇文章」，或選取文字並選擇「翻譯成…」。鍵盤快速鍵：Alt+Shift+T，或在 macOS 上為 Command+Shift+Y。
