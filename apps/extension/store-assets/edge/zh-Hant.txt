邊讀邊譯：選取文字、按右鍵，翻譯就會顯示在頁面上。

AI Translator 是一款開源的 Microsoft Edge 擴充功能，可翻譯選取的文字、網頁區域、圖片和整份 PDF 文件。無需 API 金鑰即可使用託管翻譯，或連接你自己的 OpenAI、DeepSeek 或 DeepL 帳戶。

五種翻譯方式

• 選取文字：在可移動的彈出視窗中翻譯任何語言的文字，包括中文。在支援的情況下串流顯示結果、展開原文以供對照、複製譯文，或變更目標語言。
• 網頁區域：為網站中選定的部分新增翻譯按鈕。規則依網域儲存，且你可以還原原始文字。
• 圖片：辨識文字並將譯文疊加在圖片上。翻譯選取的區域、在本機調整文字方塊，並匯出翻譯後的圖片。辨識需要具備視覺能力的模型；託管模式包含圖片辨識。
• 整份 PDF：在瀏覽器中開啟 PDF，並從右鍵選單選擇整份文件翻譯。PDF 在本機解析；只有擷取出的文字會傳送以供翻譯。對照原文與譯文，保留頁面版面、圖表和表格，並可列印或另存為 PDF。無法擷取文字的掃描頁面不支援整份文件翻譯。
• 翻譯面板：將一段文字貼到專用的原文與譯文檢視中，選擇來源語言和目標語言，無需在網頁上選取即可翻譯。

實驗性影片字幕

選用的影片字幕預設為關閉。語音辨識取決於瀏覽器版本、裝置和語言，且可能無法使用。在支援的情況下會使用本機辨識；絕不會悄悄切換為雲端辨識。只有在你明確選擇雲端辨識時，分頁音訊才會傳送至瀏覽器語音服務（Edge 中為 Microsoft Azure）。辨識出的文字會依你選取的翻譯模式處理。我們不提供託管的音訊/影片轉錄。此實驗性功能不保證每部影片都能翻譯。

隱私

• 自備金鑰的要求會直接傳送至你選擇的供應商或 HTTPS 端點。你的金鑰會保留在擴充功能的本機儲存空間中，不會透過你的瀏覽器帳戶同步。
• 託管模式會將要求的文字或圖片經由我們的伺服器傳送至模型供應商。我們的伺服器不會保留原始文字、圖片或譯文。
• 整份 PDF 檔案會在本機處理，不會上傳。
• 帳戶會保留電子郵件地址、使用者名稱，以及驗證、使用量、額度和帳務所需的記錄。沒有廣告、追蹤 SDK 或裝置指紋辨識。
• 所有可執行的擴充功能程式碼都包含在套件中。原始碼依 GPL-3.0 提供。

開始使用

安裝、選取你偏好的目標語言，並使用託管試用或在設定中配置你自己的 API 金鑰。在一般網頁上選取文字，然後從右鍵選單選擇「翻譯為…」。鍵盤快速鍵：Alt+Shift+T，或在 macOS 上為 Command+Shift+Y。

受瀏覽器保護的頁面和擴充功能商店不允許翻譯覆蓋層。單一文字要求限制為 6,000 個字元；PDF 和區域翻譯會使用批次處理。自訂 API 端點需要 HTTPS 以及所選主機的權限。
