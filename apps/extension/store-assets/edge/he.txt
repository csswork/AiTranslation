קראו תוך כדי תרגום: הפכו מאמר אינטרנט לעמוד קריאה דו-לשוני זה לצד זה, או בחרו טקסט, לחצו לחיצה ימנית וראו את התרגום ישירות על העמוד.

Huaci – מתרגם AI וקורא דו-לשוני הוא הרחבה בקוד פתוח של Microsoft Edge לקריאה דו-לשונית ולתרגום טקסט נבחר, אזורים בעמוד אינטרנט, תמונות ומסמכי PDF שלמים. השתמשו בתרגום מתארח ללא מפתח API, או חברו חשבון OpenAI, DeepSeek או DeepL משלכם.

תרגום אתרים מקומי ואוטומטי (חדש ב-2.3.0)

• תרגום טקסט מקומי: בדפדפנים ובמכשירים נתמכים, הורידו זוגות שפות בהגדרות ותרגמו באופן לא מקוון בחינם, ללא מפתח API או קרדיטים. הטקסט נשאר במכשיר שלכם. השתמשו בכך לבחירות, אזורים בעמוד, אתרים, פאנל הטקסט, קובצי PDF, קריאה דו-לשונית וכתוביות מזוהות. הזמינות והשפות תלויות בדפדפן ובחבילות שהורדו. מצב מקומי אינו מספק זיהוי תמונות או ניסוחים חלופיים; פקדים לא נתמכים מוסתרים.
• תרגום אתרים אוטומטי: לחצו לחיצה ימנית והפעילו "תרגם אתר זה". טקסט בקרבת אזור התצוגה מתורגם תוך כדי גלילה, כולל בביקורים מאוחרים יותר, עד שתשביתו זאת. טקסט חוזר בעמוד עושה שימוש חוזר בתרגומים. בחרו ספק נפרד בהגדרות; השימוש הראשון בספק בתשלום מבקש אישור.
• ניסוח טבעי יותר: מדריכי סגנון מתוקנים משפרים את הניסוח, המינוח והטון עבור סינית ושפות יעד אחרות.
• תרגום תמונות אוטומטי משופר: צורות טקסט משופרות, גודל גופן, יישור, טקסט אנכי וצבעי רקע. העבירו קטע, ערכו את התרגום או הגודל שלו, או תרגמו מחדש רק את הקטע הזה. תמונות מיוצאות שומרות על העריכות שלכם. אפשר לתרגם גם אפקטי קול; תמונות מזוהות נשמרות במטמון בעמוד הנוכחי, עם ניווט בין תמונות.

קריאה דו-לשונית

לחצו לחיצה ימנית על עמוד אינטרנט רגיל מבלי לבחור טקסט ובחרו "קראו את המאמר הזה בדו-לשוני". ההרחבה מזהה את כותרת המאמר וגופו במכשיר שלכם, משמיטה ניווט, סרגלי צד, מקומות פרסום ווידג'טים של המלצות, ופותחת עמוד קריאה נקי לצד הלשונית כאשר כל פסקה מקורית מיושרת לצד התרגום שלה. רק טקסט המאמר המנוקה מעובד על ידי מצב התרגום הנבחר.

• זה לצד זה, מוערם, תרגום בלבד או מקור בלבד; מראה בהיר, כהה או לפי המערכת; לוח צבעים, גופן, גודל, גובה שורה ורוחב עמוד הניתנים להתאמה.
• שמרו מאמר עם התרגום שלו במכשיר שלכם ופתחו אותו מחדש מאוחר יותר מהרשימה מימין מבלי לתרגם אותו שוב; מחקו מאמרים שמורים בכל עת.

ניסוחים חלופיים והעדפות ניסוח

בעמוד הקריאה, בחלון הבחירה הקופץ, בפאנל התרגום ובעמוד ה-PDF, לחצו על מילה בתרגום (או בחרו כמה מילים) כדי לראות ניסוחים חלופיים עם הערות קצרות, או הקלידו ניסוח משלכם. הבחירות שלכם נשמרות במכשיר שלכם כהעדפות ניסוח ומיושמות בתרגומים מאוחרים יותר המכילים את אותו מונח מקור. נהלו אותן בהגדרות. DeepL ותרגום מקומי אינם מספקים ניסוחים חלופיים.

כלי תרגום

• קריאה דו-לשונית: כמתואר לעיל.
• טקסט נבחר: תרגמו טקסט בכל שפה, כולל סינית, בחלון קופץ שניתן להזזה. הזרימו את התוצאה היכן שנתמך, הרחיבו את המקור להשוואה, העתיקו את התרגום, או שנו את שפת היעד.
• אזורים בעמוד אינטרנט: הוסיפו כפתור תרגום לחלק נבחר באתר. כללים נשמרים לפי דומיין, ותוכלו לשחזר את הטקסט המקורי.
• תמונות: זהו טקסט, תחמו כל קטע לאורך הקווים שלו והניחו את התרגום בחזרה מעל המקור מבלי שקטעים יכסו זה את זה. טקסט יפני אנכי נשאר אנכי כאשר מתרגמים לסינית, יפנית או קוריאנית. סקרו וערכו את הצורות שזוהו לפני התרגום, תרגמו אזור נבחר וייצאו את התמונה המתורגמת. זיהוי דורש מודל בעל יכולת ראייה; מצב מתארח כולל זיהוי תמונות.
• קובצי PDF שלמים: פתחו PDF בדפדפן ובחרו תרגום מסמך שלם מתפריט ההקשר. ה-PDF מנותח באופן מקומי; רק טקסט שחולץ מעובד על ידי מצב התרגום הנבחר. השוו בין המקור לתרגום, שמרו על פריסת העמוד, איורים וטבלאות, והדפיסו או שמרו כ-PDF. עמודים סרוקים ללא טקסט שניתן לחלץ אינם נתמכים על ידי תרגום מסמך שלם.
• פאנל תרגום: הדביקו קטע בתצוגה ייעודית של מקור ותרגום, בחרו שפת מקור ושפת יעד, ותרגמו אותו ללא בחירה בעמוד אינטרנט.

חשבונות, ניסיון חינם ומנויים אופציונליים

תרגום מתארח אינו דורש מפתח API. התקנת דפדפן חדשה וזכאית מקבלת ניסיון אורח; התחברות עם קוד אימות בדוא"ל או Google מספקת חשבון וקרדיטי ניסיון נוספים. קרדיטי ניסיון אינם פגים ומנוכים לפי כמות הטקסט המתורגם (קרדיט 1 לכל 500 תווים); תרגומים שנכשלו אינם מחויבים. היתרה, המנוי והשימוש שלכם משותפים עם מרכז המשתמשים בכתובת https://app.huaci.app/.

לאחר שאזלו קרדיטי הניסיון, תרגום מתארח דורש מנוי פעיל. התוכניות הנוכחיות הן US$3.99 לחודש או US$29.99 לשנה, בתוספת מיסים החלים. מנויים מתחדשים אוטומטית עד לביטולם. בטלו חידוש עתידי במרכז המשתמשים; הגישה נמשכת עד תום התקופה ששולמה. השימוש המתארח כפוף למגבלות שימוש סביר ומניעת ניצול לרעה. Creem מעבדת תשלומים. אשרו את המחיר והתנאים הנוכחיים בעמוד התוכניות לפני הרכישה: https://app.huaci.app/plans.

התקנת ההרחבה ושימוש במפתח API משלכם הם בחינם. ספק ה-API שבחרתם עשוי לחייב בנפרד. מנוי להרחבה זו אינו נדרש למצב הבאת מפתח משלכם. DeepL אינו מספק זיהוי תמונות.

כתוביות וידאו ניסיוניות

כתוביות וידאו אופציונליות כבויות כברירת מחדל. זיהוי דיבור תלוי בגרסת הדפדפן, במכשיר ובשפה ועשוי שלא להיות זמין. זיהוי מקומי משמש כאשר נתמך; הוא לעולם אינו עובר בשקט לזיהוי בענן. רק אם תבחרו במפורש זיהוי בענן, אודיו של הלשונית יישלח לשירות הדיבור של הדפדפן (Microsoft Azure ב-Edge). הטקסט המזוהה פועל לפי מצב התרגום שנבחר. איננו מספקים תמלול אודיו/וידאו מתארח. תכונה ניסיונית זו אינה הבטחה שכל סרטון ניתן לתרגם.

פרטיות

• תרגום טקסט מקומי נשאר במכשיר שלכם. תרגום אוטומטי פועל רק באתרים שאתם מפעילים במפורש, כולל ביקורים מאוחרים יותר.
• בקשות של הבאת מפתח משלכם עוברות ישירות לספק או לנקודת קצה HTTPS שבחרתם. המפתח שלכם נשמר באחסון המקומי של ההרחבה ואינו מסונכרן דרך חשבון הדפדפן שלכם.
• מצב מתארח שולח טקסט או תמונות מבוקשים דרך השרת שלנו לספק מודל. השרת שלנו אינו שומר טקסט מקורי, תמונות או תרגומים.
• קובצי PDF שלמים מעובדים באופן מקומי ואינם מועלים. קריאה דו-לשונית מזהה מאמרים במכשיר שלכם; מאמרים שמורים והעדפות ניסוח נשארים באחסון המקומי של ההרחבה.
• חשבונות שומרים את כתובת הדוא"ל, שם המשתמש ורשומות הנדרשות לאימות, שימוש, קרדיטים וחיוב. ללא פרסום, ערכות SDK למעקב או טביעת אצבע של מכשיר.
• כל קוד ההרחבה הניתן להרצה כלול בחבילה. קוד המקור זמין תחת GPL-3.0.

תחילת העבודה

התקינו, בחרו את שפת היעד המועדפת עליכם, והשתמשו בניסיון המתארח או הגדירו מפתח API משלכם בהגדרות. בעמוד אינטרנט רגיל, לחצו לחיצה ימנית מבלי לבחור טקסט ובחרו "קראו את המאמר הזה בדו-לשוני", או בחרו טקסט ובחרו "תרגם ל...". קיצור מקלדת: Alt+Shift+T, או Command+Shift+Y ב-macOS.

עמודים מוגנים על ידי הדפדפן וחנויות הרחבות אינם מאפשרים שכבת תרגום. בקשות טקסט בודדות מוגבלות ל-6,000 תווים; תרגום PDF, אזור וקריאה דו-לשונית משתמשים באצוות. זיהוי מאמרים הוא היוריסטי, ולכן פורומים, רשתות חברתיות ועמודים מאחורי התחברות עשויים שלא להתגלות במלואם. נקודות קצה מותאמות של API דורשות HTTPS והרשאה למארח הנבחר.

פרויקט עצמאי; אינו קשור ל-Microsoft, OpenAI, DeepSeek או DeepL. השמות מזהים שירותים תואמים ונשארים סימני המסחר של בעליהם.
