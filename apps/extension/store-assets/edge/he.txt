תרגם תוך כדי קריאה: בחר טקסט, לחץ לחיצה ימנית וראה את התרגום מופיע על העמוד.

AI Translator הוא הרחבה בקוד פתוח של Microsoft Edge לתרגום טקסט נבחר, אזורים בדפי אינטרנט, תמונות ומסמכי PDF שלמים. השתמש בתרגום מתארח ללא מפתח API, או חבר את חשבון OpenAI, DeepSeek או DeepL שלך.

חמש דרכים לתרגם

• טקסט נבחר: תרגם טקסט בכל שפה, כולל סינית, בחלון קופץ שניתן להזיז. הזרם את התוצאה היכן שנתמך, הרחב את המקור להשוואה, העתק את התרגום או שנה את שפת היעד.
• אזורים בדף אינטרנט: הוסף כפתור תרגום לחלק נבחר באתר. כללים נשמרים לפי דומיין, ותוכל לשחזר את הטקסט המקורי.
• תמונות: זהה טקסט והצג טקסט מתורגם בשכבת-על על התמונה. תרגם אזור נבחר, התאם תיבות טקסט באופן מקומי וייצא את התמונה המתורגמת. זיהוי דורש מודל בעל יכולת ראייה; מצב מתארח כולל זיהוי תמונות.
• מסמכי PDF שלמים: פתח PDF בדפדפן ובחר תרגום של המסמך כולו מתפריט ההקשר. ה-PDF מנותח באופן מקומי; רק הטקסט שחולץ נשלח לתרגום. השווה בין המקור לתרגום, שמור על פריסת העמוד, איורים וטבלאות, והדפס או שמור כ-PDF. עמודים סרוקים ללא טקסט שניתן לחלץ אינם נתמכים בתרגום של המסמך כולו.
• פאנל תרגום: הדבק קטע בתצוגה ייעודית של מקור ותרגום, בחר שפת מקור ושפת יעד ותרגם אותו ללא בחירה בדף אינטרנט.

24 שפות

בחר סינית מפושטת, סינית מסורתית, אנגלית, ספרדית, פורטוגזית, צרפתית, גרמנית, איטלקית, הולנדית, רוסית, אוקראינית, פולנית, טורקית, ערבית, עברית, פרסית, הינדי, בנגלית, אורדו, אינדונזית, וייטנאמית, תאית, יפנית או קוריאנית. שפת הממשק, שפת המקור ויעד התרגום בלתי תלויים זה בזה. התמיכה של הספק משתנה לפי שפה ותכונה. ממשקים מימין לשמאל נתמכים.

חשבונות, ניסיון חינם ומנויים אופציונליים

תרגום מתארח אינו דורש מפתח API. התקנת דפדפן חדשה וזכאית מקבלת ניסיון אורח; התחברות עם קוד אימות בדוא"ל או Google מספקת חשבון וקרדיטי ניסיון נוספים. קרדיטי הניסיון אינם פגים. היתרה, המנוי והשימוש שלך משותפים עם מרכז המשתמשים בכתובת https://app.huaci.app/.

לאחר שקרדיטי הניסיון נגמרים, תרגום מתארח דורש מנוי פעיל. התוכניות הנוכחיות הן US$3.99 לחודש או US$29.99 לשנה, בתוספת מיסים רלוונטיים. מנויים מתחדשים אוטומטית עד לביטול. בטל חידוש עתידי במרכז המשתמשים; הגישה נמשכת עד תום התקופה ששולמה. השימוש המתארח כפוף למגבלות שימוש סביר ומניעת ניצול לרעה. Creem מעבדת תשלומים. אשר את המחיר והתנאים הנוכחיים בעמוד התוכניות לפני הרכישה: https://app.huaci.app/plans.

התקנת ההרחבה ושימוש במפתח API משלך הם בחינם. ספק ה-API שבחרת עשוי לגבות בנפרד. מנוי להרחבה זו אינו נדרש למצב bring-your-own-key. DeepL אינה מספקת זיהוי תמונות.

כתוביות וידאו ניסיוניות

כתוביות וידאו אופציונליות כבויות כברירת מחדל. זיהוי דיבור תלוי בגרסת הדפדפן, במכשיר ובשפה ועלול שלא להיות זמין. זיהוי מקומי משמש כאשר נתמך; הוא לעולם אינו עובר בשקט לזיהוי בענן. רק אם תבחר במפורש זיהוי בענן, אודיו של הלשונית יישלח לשירות הדיבור של הדפדפן (Microsoft Azure ב-Edge). הטקסט שזוהה פועל לפי מצב התרגום שבחרת. איננו מספקים תמלול אודיו/וידאו מתארח. תכונה ניסיונית זו אינה הבטחה שכל סרטון ניתן לתרגם.

פרטיות

• בקשות bring-your-own-key נשלחות ישירות לספק שבחרת או לנקודת קצה HTTPS. המפתח שלך נשמר באחסון המקומי של ההרחבה ואינו מסונכרן דרך חשבון הדפדפן שלך.
• מצב מתארח שולח טקסט או תמונות מבוקשים דרך השרת שלנו לספק מודל. השרת שלנו אינו שומר טקסט מקורי, תמונות או תרגומים.
• קבצי PDF שלמים מעובדים באופן מקומי ואינם מועלים.
• חשבונות שומרים את כתובת הדוא"ל, שם המשתמש והרשומות הנדרשות לאימות, שימוש, קרדיטים וחיוב. ללא פרסום, ערכות SDK למעקב או טביעת אצבע של מכשיר.
• כל קוד ההרחבה הניתן להרצה כלול בחבילה. קוד המקור זמין תחת GPL-3.0.

תחילת עבודה

התקן, בחר את שפת היעד המועדפת עליך והשתמש בניסיון המתארח או הגדר מפתח API משלך בהגדרות. בחר טקסט בדף אינטרנט רגיל ובחר "Translate to…" מתפריט ההקשר. קיצור מקלדת: Alt+Shift+T, או Command+Shift+Y ב-macOS.

דפים מוגנים על ידי הדפדפן וחנויות הרחבות אינם מאפשרים שכבת-על לתרגום. בקשות טקסט בודדות מוגבלות ל-6,000 תווים; תרגום PDF ואזורים משתמשים באצוות. נקודות קצה מותאמות של API דורשות HTTPS והרשאה למארח שנבחר.

פרויקט עצמאי; אינו מזוהה עם Microsoft, OpenAI, DeepSeek או DeepL. השמות מזהים שירותים תואמים ונשארים סימני המסחר של בעליהם.
