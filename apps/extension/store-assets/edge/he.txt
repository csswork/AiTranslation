קראו תוך כדי תרגום: הפכו מאמר אינטרנט לעמוד קריאה דו-לשוני זה לצד זה, או בחרו טקסט, לחצו לחיצה ימנית וראו את התרגום ישירות על העמוד.

Huaci – מתרגם AI וקורא דו-לשוני הוא הרחבה בקוד פתוח של Microsoft Edge לקריאה דו-לשונית ולתרגום טקסט נבחר, אזורים בדפי אינטרנט, תמונות ומסמכי PDF שלמים. השתמשו בתרגום מתארח ללא מפתח API, או חברו חשבון OpenAI, DeepSeek או DeepL משלכם.

קריאה דו-לשונית (חדש ב-2.2.0)

לחצו לחיצה ימנית על דף אינטרנט רגיל מבלי לבחור טקסט ובחרו "קראו את המאמר הזה בדו-לשוני". ההרחבה מזהה את כותרת המאמר וגופו במכשיר שלכם, משמיטה ניווט, סרגלי צד, מקומות פרסום ווידג'טים של המלצות, ופותחת עמוד קריאה נקי לצד הלשונית כאשר כל פסקה מקורית מיושרת לצד התרגום שלה. רק טקסט המאמר המנוקה נשלח לתרגום.

• זה לצד זה, מוערם, תרגום בלבד או מקור בלבד; מראה בהיר, כהה או לפי המערכת; ערכת צבעים, גופן, גודל, גובה שורה ורוחב עמוד הניתנים להתאמה.
• שמרו מאמר עם התרגום שלו במכשיר שלכם ופתחו אותו מחדש מאוחר יותר מהרשימה מימין מבלי לתרגם אותו שוב; מחקו מאמרים שמורים בכל עת.

ניסוחים חלופיים והעדפות ניסוח

בעמוד הקריאה, בחלון הבחירה, בפאנל התרגום ובעמוד ה-PDF, לחצו על מילה בתרגום (או בחרו כמה מילים) כדי לראות ניסוחים חלופיים עם הערות קצרות, או הקלידו ניסוח משלכם. הבחירות שלכם נשמרות במכשיר שלכם כהעדפות ניסוח ומוחלות על תרגומים מאוחרים יותר המכילים את אותו מונח מקור. נהלו אותן בהגדרות. DeepL אינו מספק ניסוחים חלופיים.

שש דרכים לתרגם

• קריאה דו-לשונית: כמתואר לעיל.
• טקסט נבחר: תרגמו טקסט בכל שפה, כולל סינית, בחלון קופץ שניתן להזזה. הזרימו את התוצאה היכן שנתמך, הרחיבו את המקור להשוואה, העתיקו את התרגום, או שנו את שפת היעד.
• אזורים בדפי אינטרנט: הוסיפו כפתור תרגום לחלק נבחר באתר. הכללים נשמרים לפי דומיין, ותוכלו לשחזר את הטקסט המקורי.
• תמונות: זהו טקסט, סמנו כל קטע לאורך הקווים שלו והניחו את התרגום בחזרה מעל המקור מבלי שקטעים יכסו זה את זה. טקסט יפני אנכי נשאר אנכי כאשר מתרגמים אותו לסינית, יפנית או קוריאנית. סקרו וערכו את הצורות שזוהו לפני התרגום, תרגמו אזור נבחר וייצאו את התמונה המתורגמת. הזיהוי דורש מודל בעל יכולת ראייה; המצב המתארח כולל זיהוי תמונות.
• מסמכי PDF שלמים: פתחו PDF בדפדפן ובחרו תרגום מסמך שלם מתפריט ההקשר. ה-PDF מנותח באופן מקומי; רק טקסט שחולץ נשלח לתרגום. השוו בין המקור לתרגום, שמרו על פריסת העמוד, איורים וטבלאות, והדפיסו או שמרו כ-PDF. עמודים סרוקים ללא טקסט שניתן לחילוץ אינם נתמכים בתרגום מסמך שלם.
• פאנל תרגום: הדביקו קטע בתצוגת מקור ותרגום ייעודית, בחרו שפת מקור ושפת יעד, ותרגמו אותו ללא בחירה בדף אינטרנט.

בחרו סינית מפושטת, סינית מסורתית, אנגלית, ספרדית, פורטוגזית, צרפתית, גרמנית, איטלקית, הולנדית, רוסית, אוקראינית, פולנית, טורקית, ערבית, עברית, פרסית, הינדי, בנגלית, אורדו, אינדונזית, וייטנאמית, תאית, יפנית או קוריאנית. שפת הממשק, שפת המקור ויעד התרגום בלתי תלויים זה בזה. התמיכה של הספק משתנה לפי שפה ותכונה. ממשקים מימין לשמאל נתמכים.

חשבונות, ניסיון חינם ומנויים אופציונליים

תרגום מתארח אינו דורש מפתח API. התקנת דפדפן חדשה וזכאית מקבלת ניסיון אורח; התחברות עם קוד אימות בדוא"ל או Google מספקת חשבון וקרדיטי ניסיון נוספים. קרדיטי הניסיון אינם פגים ומנוכים לפי כמות הטקסט המתורגם (קרדיט 1 לכל 500 תווים); תרגומים שנכשלו אינם מחויבים. היתרה, המנוי והשימוש שלכם משותפים עם מרכז המשתמשים בכתובת https://app.huaci.app/.

לאחר שתם קרדיט הניסיון, תרגום מתארח דורש מנוי פעיל. התוכניות הנוכחיות הן US$3.99 לחודש או US$29.99 לשנה, בתוספת מיסים החלים. מנויים מתחדשים אוטומטית עד לביטולם. בטלו חידוש עתידי במרכז המשתמשים; הגישה נמשכת עד תום התקופה ששולמה. השימוש המתארח כפוף למגבלות שימוש סביר ומניעת ניצול לרעה. Creem מעבדת תשלומים. אשרו את המחיר והתנאים הנוכחיים בעמוד התוכניות לפני הרכישה: https://app.huaci.app/plans.

התקנת ההרחבה ושימוש במפתח API משלכם הם בחינם. ספק ה-API שבחרתם עשוי לחייב בנפרד. אין צורך במנוי להרחבה זו עבור מצב הבאת מפתח משלכם. DeepL אינו מספק זיהוי תמונות.

כתוביות וידאו ניסיוניות

כתוביות וידאו אופציונליות כבויות כברירת מחדל. זיהוי דיבור תלוי בגרסת הדפדפן, במכשיר ובשפה ועשוי שלא להיות זמין. זיהוי מקומי משמש היכן שנתמך; הוא לעולם אינו עובר בשקט לזיהוי בענן. רק אם תבחרו במפורש זיהוי בענן, אודיו של הלשונית יישלח לשירות הדיבור של הדפדפן (Microsoft Azure ב-Edge). הטקסט שזוהה עוקב אחר מצב התרגום שבחרתם. איננו מספקים תמלול אודיו/וידאו מתארח. תכונה ניסיונית זו אינה הבטחה שכל סרטון ניתן לתרגם.

פרטיות

• בקשות של הבאת מפתח משלכם עוברות ישירות לספק או לנקודת קצה HTTPS שבחרתם. המפתח שלכם נשאר באחסון המקומי של ההרחבה ואינו מסונכרן דרך חשבון הדפדפן שלכם.
• המצב המתארח שולח טקסט או תמונות מבוקשים דרך השרת שלנו לספק מודל. השרת שלנו אינו שומר טקסט מקורי, תמונות או תרגומים.
• קבצי PDF שלמים מעובדים באופן מקומי ואינם מועלים. קריאה דו-לשונית מזהה מאמרים במכשיר שלכם; מאמרים שמורים והעדפות ניסוח נשארים באחסון המקומי של ההרחבה.
• חשבונות שומרים את כתובת הדוא"ל, שם המשתמש והרשומות הנדרשות לאימות, שימוש, קרדיטים וחיוב. ללא פרסום, ערכות SDK למעקב או טביעת אצבע של מכשיר.
• כל קוד ההרחבה הניתן להרצה כלול בחבילה. קוד המקור זמין תחת GPL-3.0.

תחילת העבודה

התקינו, בחרו את שפת היעד המועדפת עליכם, והשתמשו בניסיון המתארח או הגדירו מפתח API משלכם בהגדרות. בדף אינטרנט רגיל, לחצו לחיצה ימנית מבלי לבחור טקסט ובחרו "קראו את המאמר הזה בדו-לשוני", או בחרו טקסט ובחרו "תרגם ל...". קיצור מקלדת: Alt+Shift+T, או Command+Shift+Y ב-macOS.

דפים מוגנים על ידי הדפדפן וחנויות הרחבות אינם מאפשרים שכבת תרגום. בקשות טקסט בודדות מוגבלות ל-6,000 תווים; תרגום PDF, אזור וקריאה דו-לשונית משתמשים באצוות. זיהוי מאמרים הוא היוריסטי, ולכן פורומים, רשתות חברתיות ודפים מאחורי התחברות עשויים שלא להתגלות במלואם. נקודות קצה מותאמות של API דורשות HTTPS והרשאה למארח הנבחר.
