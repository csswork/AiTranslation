อ่านไปแปลไป: เปลี่ยนบทความบนเว็บให้เป็นหน้าอ่านสองภาษาคู่กัน หรือเลือกข้อความ คลิกขวา แล้วดูคำแปลได้ทันทีบนหน้าเว็บ

Huaci – นักแปล AI และตัวอ่านสองภาษา เป็นส่วนขยาย Microsoft Edge โอเพนซอร์สสำหรับการอ่านสองภาษาและการแปลข้อความที่เลือก พื้นที่บนหน้าเว็บ รูปภาพ และเอกสาร PDF ทั้งฉบับ ใช้การแปลแบบโฮสต์ได้โดยไม่ต้องใช้คีย์ API หรือเชื่อมต่อบัญชี OpenAI, DeepSeek หรือ DeepL ของคุณเอง

การแปลเว็บไซต์ในเครื่องและอัตโนมัติ (ใหม่ใน 2.3.0)

• การแปลข้อความในเครื่อง: บนเบราว์เซอร์และอุปกรณ์ที่รองรับ ดาวน์โหลดคู่ภาษาในการตั้งค่าและแปลแบบออฟไลน์ได้ฟรี โดยไม่ต้องใช้คีย์ API หรือเครดิต ข้อความจะอยู่ในอุปกรณ์ของคุณ ใช้สำหรับการเลือกข้อความ พื้นที่บนหน้าเว็บ เว็บไซต์ แผงข้อความ PDF การอ่านสองภาษา และคำบรรยายที่รู้จำได้ ความพร้อมใช้งานและภาษาขึ้นอยู่กับเบราว์เซอร์และแพ็กที่ดาวน์โหลด โหมดในเครื่องไม่มีการรู้จำรูปภาพหรือคำเลือกอื่น และตัวควบคุมที่ไม่รองรับจะถูกซ่อน
• การแปลเว็บไซต์อัตโนมัติ: คลิกขวาและเปิดใช้ “แปลเว็บไซต์นี้” ข้อความใกล้บริเวณที่มองเห็นจะถูกแปลขณะเลื่อนหน้า รวมถึงการเข้าชมครั้งต่อๆ ไป จนกว่าคุณจะปิดใช้งาน ข้อความที่ซ้ำกันบนหน้าจะใช้คำแปลเดิม เลือกผู้ให้บริการแยกต่างหากได้ในการตั้งค่า การใช้ผู้ให้บริการแบบเสียเงินครั้งแรกจะขอการยืนยัน
• ถ้อยคำที่เป็นธรรมชาติมากขึ้น: คู่มือสไตล์ที่ปรับปรุงแล้วช่วยปรับปรุงการเรียบเรียง คำศัพท์ และน้ำเสียงสำหรับภาษาจีนและภาษาเป้าหมายอื่นๆ
• การแปลรูปภาพอัตโนมัติที่ดีขึ้น: รูปร่างข้อความ การปรับขนาดฟอนต์ การจัดตำแหน่ง ข้อความแนวตั้ง และสีพื้นหลังที่ดีขึ้น ย้ายข้อความ แก้ไขคำแปลหรือขนาด หรือแปลเฉพาะข้อความนั้นใหม่ รูปภาพที่ส่งออกจะคงการแก้ไขของคุณไว้ เลือกแปลเสียงเอฟเฟกต์ได้ตามต้องการ รูปภาพที่รู้จำได้จะถูกแคชไว้ในหน้าปัจจุบัน พร้อมการนำทางระหว่างรูปภาพ

การอ่านสองภาษา

คลิกขวาบนหน้าเว็บทั่วไปโดยไม่เลือกข้อความ แล้วเลือก “อ่านบทความนี้แบบสองภาษา” ส่วนขยายจะตรวจจับชื่อเรื่องและเนื้อหาของบทความบนอุปกรณ์ของคุณ โดยไม่รวมการนำทาง แถบด้านข้าง ช่องโฆษณา และวิดเจ็ตแนะนำ และเปิดหน้าอ่านที่สะอาดตาถัดจากแท็บ โดยแต่ละย่อหน้าต้นฉบับจะเรียงคู่กับคำแปล มีเพียงข้อความบทความที่ทำความสะอาดแล้วเท่านั้นที่ถูกประมวลผลโดยโหมดการแปลที่เลือก

• แบบเคียงข้าง แบบเรียงซ้อน แบบแปลเท่านั้น หรือแบบต้นฉบับเท่านั้น รูปลักษณ์สว่าง มืด หรือตามระบบ ปรับจานสี ฟอนต์ ขนาด ความสูงบรรทัด และความกว้างหน้าได้
• บันทึกบทความพร้อมคำแปลไว้ในอุปกรณ์และเปิดใหม่ภายหลังจากรายการทางขวาโดยไม่ต้องแปลอีกครั้ง ลบบทความที่บันทึกไว้ได้ทุกเมื่อ

คำเลือกอื่นและการตั้งค่าคำเลือก

บนหน้าอ่าน ในป๊อปอัปการเลือกข้อความ ในแผงการแปล และบนหน้า PDF คลิกที่คำในคำแปล (หรือเลือกสองสามคำ) เพื่อดูคำเลือกอื่นพร้อมบันทึกสั้นๆ หรือพิมพ์ของคุณเอง ตัวเลือกของคุณจะถูกบันทึกไว้ในอุปกรณ์เป็นการตั้งค่าคำเลือก และจะถูกนำไปใช้กับการแปลครั้งต่อๆ ไปที่มีคำต้นฉบับเดียวกัน จัดการได้ในการตั้งค่า DeepL และการแปลในเครื่องไม่มีคำเลือกอื่น

เครื่องมือแปล

• การอ่านสองภาษา: ตามที่อธิบายไว้ข้างต้น
• ข้อความที่เลือก: แปลข้อความในภาษาใดก็ได้ รวมถึงภาษาจีน ในป๊อปอัปที่ย้ายได้ สตรีมผลลัพธ์เมื่อรองรับ ขยายต้นฉบับเพื่อเปรียบเทียบ คัดลอกคำแปล หรือเปลี่ยนภาษาเป้าหมาย
• พื้นที่บนหน้าเว็บ: เพิ่มปุ่มแปลในส่วนที่เลือกของเว็บไซต์ กฎจะถูกบันทึกตามโดเมน และคุณสามารถคืนค่าข้อความต้นฉบับได้
• รูปภาพ: รู้จำข้อความ วาดโครงร่างแต่ละข้อความตามเส้นตัวอักษร และวางคำแปลกลับทับต้นฉบับโดยไม่ให้ข้อความทับกัน ข้อความญี่ปุ่นแนวตั้งจะคงแนวตั้งเมื่อแปลเป็นภาษาจีน ญี่ปุ่น หรือเกาหลี ตรวจสอบและแก้ไขรูปร่างที่ตรวจจับได้ก่อนแปล แปลพื้นที่ที่เลือก และส่งออกรูปภาพที่แปลแล้ว การรู้จำต้องใช้โมเดลที่รองรับภาพ โหมดโฮสต์รวมการรู้จำรูปภาพ
• PDF ทั้งฉบับ: เปิด PDF ในเบราว์เซอร์และเลือกแปลทั้งเอกสารจากเมนูคลิกขวา PDF จะถูกแยกวิเคราะห์ในเครื่อง มีเพียงข้อความที่แยกออกมาเท่านั้นที่ถูกประมวลผลโดยโหมดการแปลที่เลือก เปรียบเทียบต้นฉบับและคำแปล รักษาเค้าโครงหน้า รูปภาพ และตาราง และพิมพ์หรือบันทึกเป็น PDF หน้าที่สแกนโดยไม่มีข้อความที่แยกออกมาไม่รองรับการแปลทั้งเอกสาร
• แผงการแปล: วางข้อความลงในมุมมองต้นฉบับและคำแปลโดยเฉพาะ เลือกภาษาต้นฉบับและภาษาเป้าหมาย และแปลโดยไม่ต้องเลือกบนหน้าเว็บ

24 ภาษา

เลือกจีนตัวย่อ จีนตัวเต็ม อังกฤษ สเปน โปรตุเกส ฝรั่งเศส เยอรมัน อิตาลี ดัตช์ รัสเซีย ยูเครน โปแลนด์ ตุรกี อาหรับ ฮิบรู เปอร์เซีย ฮินดี เบงกาลี อูรดู อินโดนีเซีย เวียดนาม ไทย ญี่ปุ่น หรือเกาหลี ภาษาของอินเทอร์เฟซ ภาษาต้นฉบับ และภาษาเป้าหมายเป็นอิสระต่อกัน การรองรับของผู้ให้บริการแตกต่างกันตามภาษาและคุณสมบัติ รองรับอินเทอร์เฟซแบบขวาไปซ้าย

บัญชี ทดลองใช้ฟรี และการสมัครสมาชิกเสริม

การแปลแบบโฮสต์ไม่ต้องใช้คีย์ API การติดตั้งเบราว์เซอร์ใหม่ที่มีสิทธิ์จะได้รับการทดลองใช้แบบแขก การลงชื่อเข้าใช้ด้วยรหัสยืนยันทางอีเมลหรือ Google จะให้บัญชีและเครดิตทดลองใช้เพิ่มเติม เครดิตทดลองใช้ไม่มีวันหมดอายุและจะถูกหักตามปริมาณข้อความที่แปล (1 เครดิตต่อ 500 ตัวอักษร) การแปลที่ล้มเหลวจะไม่ถูกเรียกเก็บเงิน ยอดคงเหลือ การสมัครสมาชิก และการใช้งานของคุณจะใช้ร่วมกับศูนย์ผู้ใช้ที่ https://app.huaci.app/

หลังจากเครดิตทดลองใช้หมด การแปลแบบโฮสต์ต้องมีการสมัครสมาชิกที่ใช้งานอยู่ แผนปัจจุบันคือ US$3.99 ต่อเดือน หรือ US$29.99 ต่อปี บวกภาษีที่เกี่ยวข้อง การสมัครสมาชิกจะต่ออายุอัตโนมัติจนกว่าจะยกเลิก ยกเลิกการต่ออายุในอนาคตได้ที่ศูนย์ผู้ใช้ การเข้าถึงจะดำเนินต่อไปจนสิ้นสุดระยะเวลาที่ชำระเงิน การใช้งานแบบโฮสต์อยู่ภายใต้ขีดจำกัดการใช้งานที่สมเหตุสมผลและการป้องกันการละเมิด Creem ดำเนินการชำระเงิน ยืนยันราคาและข้อกำหนดปัจจุบันในหน้าแผนก่อนซื้อ: https://app.huaci.app/plans

การติดตั้งส่วนขยายและการใช้คีย์ API ของคุณเองนั้นฟรี ผู้ให้บริการ API ที่คุณเลือกอาจเรียกเก็บเงินแยกต่างหาก ไม่จำเป็นต้องสมัครสมาชิกส่วนขยายนี้สำหรับโหมดนำคีย์มาเอง DeepL ไม่มีการรู้จำรูปภาพ

คำบรรยายวิดีโอทดลอง

คำบรรยายวิดีโอเสริมปิดอยู่โดยค่าเริ่มต้น การรู้จำเสียงขึ้นอยู่กับเวอร์ชันเบราว์เซอร์ อุปกรณ์ และภาษา และอาจไม่พร้อมใช้งาน ใช้การรู้จำในเครื่องเมื่อรองรับ จะไม่สลับไปใช้การรู้จำบนคลาวด์โดยไม่แจ้ง และจะส่งเสียงจากแท็บไปยังบริการเสียงของเบราว์เซอร์ (Microsoft Azure ใน Edge) ก็ต่อเมื่อคุณเลือกการรู้จำบนคลาวด์อย่างชัดเจนเท่านั้น ข้อความที่รู้จำได้จะเป็นไปตามโหมดการแปลที่คุณเลือก เราไม่ให้บริการถอดเสียง/วิดีโอแบบโฮสต์ คุณสมบัติทดลองนี้ไม่รับประกันว่าทุกวิดีโอจะแปลได้

ความเป็นส่วนตัว

• การแปลข้อความในเครื่องจะอยู่ในอุปกรณ์ของคุณ การแปลอัตโนมัติทำงานเฉพาะบนเว็บไซต์ที่คุณเปิดใช้อย่างชัดเจน รวมถึงการเข้าชมครั้งต่อๆ ไป
• คำขอแบบนำคีย์มาเองจะส่งตรงไปยังผู้ให้บริการที่คุณเลือกหรือปลายทาง HTTPS คีย์ของคุณจะอยู่ในที่จัดเก็บของส่วนขยายในเครื่องและจะไม่ซิงค์ผ่านบัญชีเบราว์เซอร์ของคุณ
• โหมดโฮสต์จะส่งข้อความหรือรูปภาพที่ร้องขอผ่านเซิร์ฟเวอร์ของเราไปยังผู้ให้บริการโมเดล เซิร์ฟเวอร์ของเราไม่เก็บข้อความต้นฉบับ รูปภาพ หรือคำแปล
• ไฟล์ PDF ทั้งฉบับจะถูกประมวลผลในเครื่องและไม่ถูกอัปโหลด การอ่านสองภาษาจะตรวจจับบทความบนอุปกรณ์ของคุณ บทความที่บันทึกไว้และการตั้งค่าคำเลือกจะอยู่ในที่จัดเก็บของส่วนขยายในเครื่อง
• บัญชีจะเก็บที่อยู่อีเมล ชื่อผู้ใช้ และบันทึกที่จำเป็นสำหรับการรับรองความถูกต้อง การใช้งาน เครดิต และการเรียกเก็บเงิน ไม่มีโฆษณา ไม่มี SDK ติดตาม หรือการสร้างลายนิ้วมืออุปกรณ์
• โค้ดส่วนขยายที่เรียกใช้งานได้ทั้งหมดรวมอยู่ในแพ็กเกจ ซอร์สโค้ดมีให้ใช้งานภายใต้ GPL-3.0

เริ่มต้นใช้งาน

ติดตั้ง เลือกภาษาเป้าหมายที่ต้องการ และใช้การทดลองใช้แบบโฮสต์หรือกำหนดค่าคีย์ API ของคุณเองในการตั้งค่า บนหน้าเว็บทั่วไป คลิกขวาโดยไม่เลือกข้อความแล้วเลือก “อ่านบทความนี้แบบสองภาษา” หรือเลือกข้อความแล้วเลือก “แปลเป็น…” คีย์ลัด: Alt+Shift+T หรือ Command+Shift+Y บน macOS

หน้าที่ได้รับการป้องกันโดยเบราว์เซอร์และร้านค้าส่วนขยายไม่อนุญาตให้แสดงคำแปลซ้อนทับ คำขอข้อความเดี่ยวจำกัดที่ 6,000 ตัวอักษร การแปล PDF พื้นที่ และการอ่านสองภาษาใช้การแบตช์ การตรวจจับบทความใช้ฮิวริสติก ดังนั้นฟอรัม เครือข่ายสังคม และหน้าที่อยู่หลังการเข้าสู่ระบบอาจตรวจจับได้ไม่สมบูรณ์ ปลายทาง API ที่กำหนดเองต้องใช้ HTTPS และได้รับอนุญาตสำหรับโฮสต์ที่เลือก
