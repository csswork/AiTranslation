แปลขณะอ่าน: เลือกข้อความ คลิกขวา และดูคำแปลปรากฏบนหน้าเว็บ

AI Translator เป็นส่วนขยาย Microsoft Edge แบบโอเพนซอร์สสำหรับแปลข้อความที่เลือก พื้นที่บนหน้าเว็บ รูปภาพ และเอกสาร PDF ทั้งฉบับ ใช้การแปลแบบโฮสต์โดยไม่ต้องใช้คีย์ API หรือเชื่อมต่อบัญชี OpenAI, DeepSeek หรือ DeepL ของคุณเอง

ห้าวิธีในการแปล

• ข้อความที่เลือก: แปลข้อความในภาษาใดก็ได้ รวมถึงภาษาจีน ในป๊อปอัปที่ย้ายได้ สตรีมผลลัพธ์ในกรณีที่รองรับ ขยายต้นฉบับเพื่อเปรียบเทียบ คัดลอกคำแปล หรือเปลี่ยนภาษาเป้าหมาย
• พื้นที่บนหน้าเว็บ: เพิ่มปุ่มแปลให้กับส่วนที่เลือกของเว็บไซต์ กฎจะถูกบันทึกตามโดเมน และคุณสามารถคืนค่าข้อความต้นฉบับได้
• รูปภาพ: รู้จำข้อความและวางคำแปลทับบนรูปภาพ แปลพื้นที่ที่เลือก ปรับกล่องข้อความในเครื่อง และส่งออกรูปภาพที่แปลแล้ว การรู้จำต้องใช้โมเดลที่รองรับการมองเห็น โหมดโฮสต์รวมการรู้จำรูปภาพไว้ด้วย
• PDF ทั้งฉบับ: เปิด PDF ในเบราว์เซอร์และเลือกแปลทั้งเอกสารจากเมนูบริบท PDF จะถูกแยกวิเคราะห์ในเครื่อง เฉพาะข้อความที่แยกออกมาจะถูกส่งไปแปล เปรียบเทียบต้นฉบับและคำแปล รักษาเค้าโครงหน้า รูปภาพ และตาราง และพิมพ์หรือบันทึกเป็น PDF หน้าเอกสารที่สแกนซึ่งไม่มีข้อความที่แยกออกมาได้จะไม่รองรับการแปลทั้งเอกสาร
• แผงการแปล: วางข้อความลงในมุมมองต้นฉบับและคำแปลโดยเฉพาะ เลือกภาษาต้นฉบับและภาษาเป้าหมาย และแปลโดยไม่ต้องเลือกบนหน้าเว็บ

24 ภาษา

เลือกภาษาจีนตัวย่อ จีนตัวเต็ม อังกฤษ สเปน โปรตุเกส ฝรั่งเศส เยอรมัน อิตาลี ดัตช์ รัสเซีย ยูเครน โปแลนด์ ตุรกี อาหรับ ฮีบรู เปอร์เซีย ฮินดี เบงกาลี อูรดู อินโดนีเซีย เวียดนาม ไทย ญี่ปุ่น หรือเกาหลี ภาษาของอินเทอร์เฟซ ภาษาต้นฉบับ และภาษาเป้าหมายในการแปลเป็นอิสระต่อกัน การรองรับของผู้ให้บริการแตกต่างกันตามภาษาและฟีเจอร์ รองรับอินเทอร์เฟซแบบขวาไปซ้าย

บัญชี การทดลองใช้ฟรี และการสมัครสมาชิกแบบเลือกได้

การแปลแบบโฮสต์ไม่ต้องใช้คีย์ API การติดตั้งเบราว์เซอร์ใหม่ที่เข้าเกณฑ์จะได้รับการทดลองใช้แบบผู้เยี่ยมชม การลงชื่อเข้าใช้ด้วยรหัสยืนยันทางอีเมลหรือ Google จะให้บัญชีและเครดิตทดลองใช้เพิ่มเติม เครดิตทดลองใช้ไม่มีวันหมดอายุ ยอดคงเหลือ การสมัครสมาชิก และการใช้งานของคุณจะใช้ร่วมกับศูนย์ผู้ใช้ที่ https://app.huaci.app/

หลังจากเครดิตทดลองใช้หมด การแปลแบบโฮสต์ต้องมีการสมัครสมาชิกที่ใช้งานอยู่ แผนปัจจุบันคือ US$3.99 ต่อเดือน หรือ US$29.99 ต่อปี บวกภาษีที่เกี่ยวข้อง การสมัครสมาชิกจะต่ออายุอัตโนมัติจนกว่าจะยกเลิก ยกเลิกการต่ออายุในอนาคตได้ที่ศูนย์ผู้ใช้ การเข้าถึงจะดำเนินต่อไปจนสิ้นสุดระยะเวลาที่ชำระเงินแล้ว การใช้งานแบบโฮสต์อยู่ภายใต้ขีดจำกัดการใช้งานตามสมควรและการป้องกันการละเมิด Creem ดำเนินการชำระเงิน ตรวจสอบราคาและเงื่อนไขปัจจุบันในหน้าแผนก่อนซื้อ: https://app.huaci.app/plans

การติดตั้งส่วนขยายและการใช้คีย์ API ของคุณเองนั้นฟรี ผู้ให้บริการ API ที่คุณเลือกอาจเรียกเก็บเงินแยกต่างหาก ไม่จำเป็นต้องสมัครสมาชิกส่วนขยายนี้สำหรับโหมดนำคีย์มาใช้เอง DeepL ไม่ให้บริการรู้จำรูปภาพ

คำบรรยายวิดีโอแบบทดลอง

คำบรรยายวิดีโอแบบเลือกได้จะปิดไว้โดยค่าเริ่มต้น การรู้จำเสียงขึ้นอยู่กับเวอร์ชันเบราว์เซอร์ อุปกรณ์ และภาษา และอาจไม่พร้อมใช้งาน จะใช้การรู้จำในเครื่องเมื่อรองรับ โดยจะไม่สลับไปใช้การรู้จำบนคลาวด์โดยไม่แจ้ง เฉพาะเมื่อคุณเลือกการรู้จำบนคลาวด์อย่างชัดเจนเท่านั้นที่เสียงแท็บจะถูกส่งไปยังบริการเสียงของเบราว์เซอร์ (Microsoft Azure ใน Edge) ข้อความที่รู้จำได้จะเป็นไปตามโหมดการแปลที่คุณเลือก เราไม่ให้บริการถอดเสียง/วิดีโอแบบโฮสต์ ฟีเจอร์ทดลองนี้ไม่รับประกันว่าทุกวิดีโอจะแปลได้

ความเป็นส่วนตัว

• คำขอในโหมดนำคีย์มาใช้เองจะส่งตรงไปยังผู้ให้บริการที่คุณเลือกหรือปลายทาง HTTPS คีย์ของคุณจะอยู่ในที่จัดเก็บภายในส่วนขยายและไม่ซิงค์ผ่านบัญชีเบราว์เซอร์ของคุณ
• โหมดโฮสต์จะส่งข้อความหรือรูปภาพที่ร้องขอผ่านเซิร์ฟเวอร์ของเราไปยังผู้ให้บริการโมเดล เซิร์ฟเวอร์ของเราไม่เก็บข้อความต้นฉบับ รูปภาพ หรือคำแปล
• ไฟล์ PDF ทั้งฉบับจะประมวลผลในเครื่องและไม่ถูกอัปโหลด
• บัญชีจะเก็บที่อยู่อีเมล ชื่อผู้ใช้ และบันทึกที่จำเป็นสำหรับการยืนยันตัวตน การใช้งาน เครดิต และการเรียกเก็บเงิน ไม่มีการโฆษณา ไม่มี SDK ติดตาม หรือการสร้างลายนิ้วมืออุปกรณ์
• โค้ดส่วนขยายที่เรียกใช้งานได้ทั้งหมดรวมอยู่ในแพ็กเกจ ซอร์สโค้ดเผยแพร่ภายใต้ GPL-3.0

เริ่มต้นใช้งาน

ติดตั้ง เลือกภาษาเป้าหมายที่ต้องการ และใช้การทดลองใช้แบบโฮสต์หรือกำหนดค่าคีย์ API ของคุณเองในการตั้งค่า เลือกข้อความบนหน้าเว็บทั่วไปและเลือก “แปลเป็น…” จากเมนูบริบท ปุ่มลัด: Alt+Shift+T หรือ Command+Shift+Y บน macOS

หน้าเว็บที่เบราว์เซอร์ป้องกันและร้านค้าส่วนขยายไม่อนุญาตให้แสดงคำแปลทับ คำขอข้อความเดี่ยวจำกัดที่ 6,000 ตัวอักษร การแปล PDF และพื้นที่ใช้การแบตช์ ปลายทาง API แบบกำหนดเองต้องใช้ HTTPS และการอนุญาตสำหรับโฮสต์ที่เลือก
