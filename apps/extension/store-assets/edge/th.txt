อ่านไปแปลไป: เปลี่ยนบทความบนเว็บให้เป็นหน้าอ่านสองภาษาคู่กัน หรือเลือกข้อความ คลิกขวา แล้วดูคำแปลได้ทันทีบนหน้าเว็บ

Huaci – นักแปล AI และตัวอ่านสองภาษา เป็นส่วนขยาย Microsoft Edge โอเพนซอร์สสำหรับการอ่านสองภาษาและการแปลข้อความที่เลือก พื้นที่บนหน้าเว็บ รูปภาพ และเอกสาร PDF ทั้งฉบับ ใช้การแปลแบบโฮสต์ได้โดยไม่ต้องใช้คีย์ API หรือเชื่อมต่อบัญชี OpenAI, DeepSeek หรือ DeepL ของคุณเอง

การอ่านสองภาษา (ใหม่ใน 2.2.0)

คลิกขวาบนหน้าเว็บทั่วไปโดยไม่เลือกข้อความ แล้วเลือก “อ่านบทความนี้แบบสองภาษา” ส่วนขยายจะตรวจจับชื่อเรื่องและเนื้อหาของบทความบนอุปกรณ์ของคุณ โดยตัดส่วนนำทาง แถบด้านข้าง ช่องโฆษณา และวิดเจ็ตแนะนำออก แล้วเปิดหน้าอ่านที่สะอาดตาถัดจากแท็บ โดยแต่ละย่อหน้าต้นฉบับจะเรียงเคียงข้างกับคำแปล ส่งเฉพาะข้อความบทความที่ทำความสะอาดแล้วเท่านั้นเพื่อการแปล

• แบบเคียงข้างกัน แบบเรียงซ้อน แบบแปลเท่านั้น หรือแบบต้นฉบับเท่านั้น; รูปลักษณ์สว่าง มืด หรือตามระบบ; ปรับจานสี ฟอนต์ ขนาด ความสูงบรรทัด และความกว้างหน้าได้
• บันทึกบทความพร้อมคำแปลไว้บนอุปกรณ์ของคุณและเปิดใหม่ได้ในภายหลังจากรายการทางด้านขวาโดยไม่ต้องแปลซ้ำ; ลบบทความที่บันทึกไว้ได้ทุกเมื่อ

ถ้อยคำทางเลือกและการตั้งค่าถ้อยคำ

บนหน้าอ่าน ในป๊อปอัปการเลือกข้อความ ในแผงการแปล และบนหน้า PDF คลิกที่คำในคำแปล (หรือเลือกสองสามคำ) เพื่อดูถ้อยคำทางเลือกพร้อมบันทึกสั้นๆ หรือพิมพ์ถ้อยคำของคุณเอง ตัวเลือกของคุณจะถูกบันทึกไว้บนอุปกรณ์ของคุณเป็นการตั้งค่าถ้อยคำ และจะถูกนำไปใช้กับการแปลครั้งต่อๆ ไปที่มีคำต้นฉบับเดียวกัน จัดการได้ในการตั้งค่า DeepL ไม่มีถ้อยคำทางเลือก

หกวิธีในการแปล

• การอ่านสองภาษา: ตามที่อธิบายข้างต้น
• ข้อความที่เลือก: แปลข้อความในภาษาใดก็ได้ รวมถึงภาษาจีน ในป๊อปอัปที่เลื่อนได้ สตรีมผลลัพธ์เมื่อรองรับ ขยายต้นฉบับเพื่อเปรียบเทียบ คัดลอกคำแปล หรือเปลี่ยนภาษาปลายทาง
• พื้นที่บนหน้าเว็บ: เพิ่มปุ่มแปลให้กับส่วนที่เลือกของเว็บไซต์ กฎจะถูกบันทึกตามโดเมน และคุณสามารถคืนค่าข้อความต้นฉบับได้
• รูปภาพ: จดจำข้อความ วาดโครงร่างแต่ละข้อความตามเส้นตัวอักษร และวางคำแปลกลับทับต้นฉบับโดยไม่ให้ข้อความทับกัน ข้อความภาษาญี่ปุ่นแนวตั้งจะคงแนวตั้งเมื่อแปลเป็นภาษาจีน ญี่ปุ่น หรือเกาหลี ตรวจสอบและแก้ไขรูปร่างที่ตรวจพบก่อนแปล แปลเฉพาะพื้นที่ที่เลือก และส่งออกรูปภาพที่แปลแล้ว การจดจำต้องใช้โมเดลที่รองรับภาพ; โหมดโฮสต์รวมการจดจำภาพ
• PDF ทั้งฉบับ: เปิด PDF ในเบราว์เซอร์และเลือกแปลทั้งเอกสารจากเมนูบริบท PDF จะถูกแยกวิเคราะห์ในเครื่อง; ส่งเฉพาะข้อความที่แยกออกมาเพื่อการแปล เปรียบเทียบต้นฉบับและคำแปล รักษาเค้าโครงหน้า รูปภาพ และตาราง และพิมพ์หรือบันทึกเป็น PDF หน้าที่สแกนโดยไม่มีข้อความที่แยกออกมาไม่รองรับการแปลทั้งเอกสาร
• แผงการแปล: วางข้อความลงในมุมมองต้นฉบับและคำแปลโดยเฉพาะ เลือกภาษาต้นฉบับและภาษาปลายทาง และแปลโดยไม่ต้องเลือกบนหน้าเว็บ

24 ภาษา

เลือกภาษาจีนตัวย่อ จีนตัวเต็ม อังกฤษ สเปน โปรตุเกส ฝรั่งเศส เยอรมัน อิตาลี ดัตช์ รัสเซีย ยูเครน โปแลนด์ ตุรกี อาหรับ ฮิบรู เปอร์เซีย ฮินดี เบงกาลี อูรดู อินโดนีเซีย เวียดนาม ไทย ญี่ปุ่น หรือเกาหลี ภาษาของอินเทอร์เฟซ ภาษาต้นฉบับ และภาษาปลายทางมีความเป็นอิสระต่อกัน การรองรับของผู้ให้บริการแตกต่างกันตามภาษาและคุณสมบัติ รองรับอินเทอร์เฟซที่เขียนจากขวาไปซ้าย

บัญชี ทดลองใช้ฟรี และการสมัครสมาชิกแบบเลือกได้

การแปลแบบโฮสต์ไม่ต้องใช้คีย์ API การติดตั้งเบราว์เซอร์ใหม่ที่เข้าเกณฑ์จะได้รับการทดลองใช้แบบแขก; การลงชื่อเข้าใช้ด้วยรหัสยืนยันทางอีเมลหรือ Google จะให้บัญชีและเครดิตทดลองใช้เพิ่มเติม เครดิตทดลองใช้ไม่มีวันหมดอายุและถูกหักตามปริมาณข้อความที่แปล (1 เครดิตต่อ 500 ตัวอักษร); การแปลที่ล้มเหลวจะไม่ถูกเรียกเก็บเงิน ยอดคงเหลือ การสมัครสมาชิก และการใช้งานของคุณใช้ร่วมกับศูนย์ผู้ใช้ที่ https://app.huaci.app/

หลังจากเครดิตทดลองใช้หมด การแปลแบบโฮสต์ต้องมีการสมัครสมาชิกที่ใช้งานอยู่ แผนปัจจุบันคือ US$3.99 ต่อเดือน หรือ US$29.99 ต่อปี บวกภาษีที่เกี่ยวข้อง การสมัครสมาชิกจะต่ออายุอัตโนมัติจนกว่าจะยกเลิก ยกเลิกการต่ออายุในอนาคตได้ที่ศูนย์ผู้ใช้; การเข้าถึงจะดำเนินต่อไปจนสิ้นสุดระยะเวลาที่ชำระเงิน การใช้งานแบบโฮสต์อยู่ภายใต้ขีดจำกัดการใช้งานที่สมเหตุสมผลและการป้องกันการละเมิด Creem ดำเนินการชำระเงิน ยืนยันราคาและเงื่อนไขปัจจุบันได้ที่หน้าแผนก่อนซื้อ: https://app.huaci.app/plans

การติดตั้งส่วนขยายและการใช้คีย์ API ของคุณเองนั้นฟรี ผู้ให้บริการ API ที่คุณเลือกอาจเรียกเก็บเงินแยกต่างหาก ไม่จำเป็นต้องสมัครสมาชิกส่วนขยายนี้สำหรับโหมดนำคีย์มาเอง DeepL ไม่มีการจดจำภาพ

คำบรรยายวิดีโอแบบทดลอง

คำบรรยายวิดีโอแบบเลือกได้จะปิดไว้โดยค่าเริ่มต้น การรู้จำเสียงขึ้นอยู่กับเวอร์ชันเบราว์เซอร์ อุปกรณ์ และภาษา และอาจไม่พร้อมใช้งาน จะใช้การรู้จำในเครื่องเมื่อรองรับ; จะไม่สลับไปใช้การรู้จำบนคลาวด์โดยไม่แจ้ง เฉพาะเมื่อคุณเลือกการรู้จำบนคลาวด์อย่างชัดเจนเท่านั้นที่เสียงแท็บจะถูกส่งไปยังบริการเสียงของเบราว์เซอร์ (Microsoft Azure ใน Edge) ข้อความที่รู้จำได้จะเป็นไปตามโหมดการแปลที่คุณเลือก เราไม่ให้บริการถอดเสียง/วิดีโอแบบโฮสต์ คุณสมบัติทดลองนี้ไม่รับประกันว่าวิดีโอทุกเรื่องจะแปลได้

ความเป็นส่วนตัว

• คำขอแบบนำคีย์มาเองจะส่งตรงไปยังผู้ให้บริการที่คุณเลือกหรือปลายทาง HTTPS คีย์ของคุณจะอยู่ในที่จัดเก็บภายในส่วนขยายและไม่ซิงค์ผ่านบัญชีเบราว์เซอร์ของคุณ
• โหมดโฮสต์จะส่งข้อความหรือรูปภาพที่ร้องขอผ่านเซิร์ฟเวอร์ของเราไปยังผู้ให้บริการโมเดล เซิร์ฟเวอร์ของเราไม่เก็บข้อความต้นฉบับ รูปภาพ หรือคำแปล
• ไฟล์ PDF ทั้งฉบับจะถูกประมวลผลในเครื่องและไม่ถูกอัปโหลด การอ่านสองภาษาจะตรวจจับบทความบนอุปกรณ์ของคุณ; บทความที่บันทึกไว้และการตั้งค่าถ้อยคำจะอยู่ในที่จัดเก็บภายในส่วนขยาย
• บัญชีจะเก็บที่อยู่อีเมล ชื่อผู้ใช้ และบันทึกที่จำเป็นสำหรับการรับรองความถูกต้อง การใช้งาน เครดิต และการเรียกเก็บเงิน ไม่มีโฆษณา ไม่มี SDK ติดตาม หรือการสร้างลายนิ้วมืออุปกรณ์
• โค้ดส่วนขยายที่เรียกใช้งานได้ทั้งหมดรวมอยู่ในแพ็กเกจ ซอร์สโค้ดมีให้ภายใต้ GPL-3.0

เริ่มต้นใช้งาน

ติดตั้ง เลือกภาษาปลายทางที่ต้องการ และใช้การทดลองใช้แบบโฮสต์หรือกำหนดค่าคีย์ API ของคุณเองในการตั้งค่า บนหน้าเว็บทั่วไป คลิกขวาโดยไม่เลือกข้อความแล้วเลือก “อ่านบทความนี้แบบสองภาษา” หรือเลือกข้อความแล้วเลือก “แปลเป็น…” คีย์ลัด: Alt+Shift+T หรือ Command+Shift+Y บน macOS

หน้าเว็บที่ได้รับการป้องกันโดยเบราว์เซอร์และร้านค้าส่วนขยายไม่อนุญาตให้แสดงคำแปลซ้อนทับ คำขอข้อความเดี่ยวจำกัดที่ 6,000 ตัวอักษร; การแปล PDF พื้นที่ และการอ่านสองภาษาใช้การแบตช์ การตรวจจับบทความใช้ฮิวริสติก ดังนั้นฟอรัม เครือข่ายสังคม และหน้าที่อยู่หลังการเข้าสู่ระบบอาจไม่ถูกตรวจจับอย่างสมบูรณ์ ปลายทาง API ที่กำหนดเองต้องใช้ HTTPS และการอนุญาตสำหรับโฮสต์ที่เลือก
