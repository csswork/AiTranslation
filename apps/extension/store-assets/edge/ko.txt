번역하면서 읽기: 웹 기사를 나란히 이중 언어로 읽을 수 있는 페이지로 바꾸거나, 텍스트를 선택하고 마우스 오른쪽 버튼을 클릭하여 페이지에서 바로 번역을 확인하세요.

Huaci – AI 번역 및 이중 언어 읽기는 이중 언어 읽기와 선택한 텍스트, 웹페이지 영역, 이미지 및 전체 PDF 문서 번역을 위한 오픈 소스 Microsoft Edge 확장 프로그램입니다. API 키 없이 호스팅 번역을 사용하거나, 자신의 OpenAI, DeepSeek 또는 DeepL 계정을 연결하세요.

이중 언어 읽기 (2.2.0의 새로운 기능)

텍스트를 선택하지 않은 일반 웹페이지에서 마우스 오른쪽 버튼을 클릭하고 “이 글을 이중 언어로 읽기”를 선택하세요. 확장 프로그램은 기기의 문서 제목과 본문을 감지하고, 탐색 메뉴, 사이드바, 광고 슬롯 및 추천 위젯을 제외하며, 각 원문 단락이 번역문 옆에 정렬된 깔끔한 읽기 페이지를 탭 옆에 엽니다. 정리된 기사 텍스트만 번역을 위해 전송됩니다.

• 나란히, 위아래로 쌓기, 번역만 또는 원문만; 밝게, 어둡게 또는 시스템 설정 따르기; 조정 가능한 색상 팔레트, 글꼴, 크기, 줄 높이 및 페이지 너비.
• 기사와 번역을 기기에 저장하고 나중에 오른쪽 목록에서 다시 열어 재번역 없이 볼 수 있습니다. 저장된 기사는 언제든지 삭제할 수 있습니다.

대체 표현 및 표현 선호

읽기 페이지, 선택 팝업, 번역 패널 및 PDF 페이지에서 번역문의 단어를 클릭하거나(또는 몇 개의 단어를 선택) 짧은 설명과 함께 대체 표현을 확인하거나 직접 입력할 수 있습니다. 선택한 표현은 기기에 표현 선호로 저장되며, 동일한 원문 용어가 포함된 이후 번역에 적용됩니다. 설정에서 관리할 수 있습니다. DeepL은 대체 표현을 제공하지 않습니다.

여섯 가지 번역 방법

• 이중 언어 읽기: 위에서 설명한 대로입니다.
• 선택한 텍스트: 중국어를 포함한 모든 언어의 텍스트를 이동 가능한 팝업에서 번역합니다. 지원되는 경우 결과를 스트리밍하고, 원문을 확장하여 비교하고, 번역을 복사하거나 대상 언어를 변경할 수 있습니다.
• 웹페이지 영역: 웹사이트의 선택한 부분에 번역 버튼을 추가합니다. 규칙은 도메인별로 저장되며 원문 텍스트를 복원할 수 있습니다.
• 이미지: 텍스트를 인식하고, 각 문단을 획을 따라 윤곽을 표시하고, 문단이 서로 겹치지 않도록 원본 위에 번역을 배치합니다. 세로 일본어 텍스트는 중국어, 일본어 또는 한국어로 번역될 때 세로로 유지됩니다. 번역 전에 감지된 도형을 검토 및 편집하고, 선택한 영역을 번역하고, 번역된 이미지를 내보낼 수 있습니다. 인식에는 비전 지원 모델이 필요하며, 호스팅 모드에는 이미지 인식이 포함됩니다.
• 전체 PDF: 브라우저에서 PDF를 열고 컨텍스트 메뉴에서 전체 문서 번역을 선택하세요. PDF는 로컬에서 구문 분석되며 추출된 텍스트만 번역을 위해 전송됩니다. 원문과 번역을 비교하고, 페이지 레이아웃, 그림 및 표를 유지하며, 인쇄하거나 PDF로 저장할 수 있습니다. 추출 가능한 텍스트가 없는 스캔 페이지는 전체 문서 번역에서 지원되지 않습니다.
• 번역 패널: 전용 원문 및 번역 보기에 문단을 붙여넣고, 원문 및 대상 언어를 선택하고, 웹페이지 선택 없이 번역합니다.

중국어 간체, 중국어 번체, 영어, 스페인어, 포르투갈어, 프랑스어, 독일어, 이탈리아어, 네덜란드어, 러시아어, 우크라이나어, 폴란드어, 터키어, 아랍어, 히브리어, 페르시아어, 힌디어, 벵골어, 우르두어, 인도네시아어, 베트남어, 태국어, 일본어 또는 한국어를 선택하세요. 인터페이스 언어, 원문 언어 및 번역 대상은 독립적입니다. 제공자 지원은 언어 및 기능에 따라 다릅니다. 오른쪽에서 왼쪽으로 쓰는 인터페이스가 지원됩니다.

계정, 무료 체험 및 선택적 구독

호스팅 번역에는 API 키가 필요하지 않습니다. 새로 적격한 브라우저 설치에는 게스트 체험이 제공되며, 이메일 인증 코드 또는 Google로 로그인하면 계정과 추가 체험 크레딧이 제공됩니다. 체험 크레딧은 만료되지 않으며 번역된 텍스트 양에 따라 차감됩니다(500자당 1 크레딧). 실패한 번역은 청구되지 않습니다. 잔액, 구독 및 사용량은 https://app.huaci.app/ 의 사용자 센터와 공유됩니다.

체험 크레딧이 소진되면 호스팅 번역에는 활성 구독이 필요합니다. 현재 요금제는 월 US$3.99 또는 연 US$29.99이며, 해당 세금이 추가됩니다. 구독은 취소할 때까지 자동으로 갱신됩니다. 사용자 센터에서 향후 갱신을 취소할 수 있으며, 유료 기간이 끝날 때까지 액세스가 계속됩니다. 호스팅 사용은 합리적 사용 및 남용 방지 제한의 적용을 받습니다. Creem이 결제를 처리합니다. 구매 전에 요금제 페이지에서 현재 가격 및 약관을 확인하세요: https://app.huaci.app/plans.

확장 프로그램 설치 및 자체 API 키 사용은 무료입니다. 선택한 API 제공자가 별도로 청구할 수 있습니다. 자체 키 사용 모드에는 이 확장 프로그램의 구독이 필요하지 않습니다. DeepL은 이미지 인식을 제공하지 않습니다.

실험적 비디오 자막

선택적 비디오 자막은 기본적으로 꺼져 있습니다. 음성 인식은 브라우저 버전, 기기 및 언어에 따라 달라지며 사용할 수 없을 수 있습니다. 지원되는 경우 로컬 인식이 사용되며, 클라우드 인식으로 조용히 전환되지 않습니다. 클라우드 인식을 명시적으로 선택한 경우에만 탭 오디오가 브라우저 음성 서비스(Edge의 Microsoft Azure)로 전송됩니다. 인식된 텍스트는 선택한 번역 모드를 따릅니다. 우리는 호스팅 오디오/비디오 전사를 제공하지 않습니다. 이 실험적 기능은 모든 비디오를 번역할 수 있음을 보장하지 않습니다.

개인정보 보호

• 자체 키 요청은 선택한 제공자 또는 HTTPS 엔드포인트로 직접 전송됩니다. 키는 로컬 확장 프로그램 저장소에 보관되며 브라우저 계정을 통해 동기화되지 않습니다.
• 호스팅 모드는 요청된 텍스트 또는 이미지를 우리 서버를 통해 모델 제공자에게 전송합니다. 우리 서버는 원문 텍스트, 이미지 또는 번역을 보관하지 않습니다.
• 전체 PDF 파일은 로컬에서 처리되며 업로드되지 않습니다. 이중 언어 읽기는 기기에서 기사를 감지하며, 저장된 기사 및 표현 선호는 로컬 확장 프로그램 저장소에 유지됩니다.
• 계정은 인증, 사용량, 크레딧 및 청구에 필요한 이메일 주소, 사용자 이름 및 기록을 보관합니다. 광고, 추적 SDK 또는 기기 지문 채취는 없습니다.
• 모든 실행 가능한 확장 프로그램 코드는 패키지에 포함되어 있습니다. 소스는 GPL-3.0에 따라 제공됩니다.

시작하기

설치하고, 원하는 대상 언어를 선택하고, 호스팅 체험을 사용하거나 설정에서 자체 API 키를 구성하세요. 일반 웹페이지에서 텍스트를 선택하지 않고 마우스 오른쪽 버튼을 클릭하고 “이 글을 이중 언어로 읽기”를 선택하거나, 텍스트를 선택하고 “번역 대상…”을 선택하세요. 키보드 단축키: Alt+Shift+T, 또는 macOS에서 Command+Shift+Y.

브라우저 보호 페이지 및 확장 프로그램 스토어는 번역 오버레이를 허용하지 않습니다. 단일 텍스트 요청은 6,000자로 제한되며, PDF, 영역 및 이중 언어 읽기 번역은 일괄 처리를 사용합니다. 기사 감지는 휴리스틱이므로 포럼, 소셜 네트워크 및 로그인 뒤의 페이지는 완전히 감지되지 않을 수 있습니다. 사용자 지정 API 엔드포인트는 HTTPS 및 선택한 호스트에 대한 권한이 필요합니다.

독립 프로젝트이며 Microsoft, OpenAI, DeepSeek 또는 DeepL과 제휴하지 않습니다. 이름은 호환 서비스를 식별하며 해당 소유자의 상표로 남아 있습니다.
