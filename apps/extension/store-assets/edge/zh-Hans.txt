划词 – AI 翻译与双语阅读是一款开源 Microsoft Edge 扩展，用于双语阅读，以及翻译选中文本、网页区域、图片和整份 PDF 文档。无需 API 密钥即可使用托管翻译，也可连接你自己的 OpenAI、DeepSeek 或 DeepL 账户。

双语阅读（2.2.0 新增）

在未选中文本的普通网页上右键单击，选择“双语阅读这篇文章”。扩展会在你的设备上检测文章标题和正文，排除导航、侧边栏、广告位和推荐组件，并在标签页旁打开一个干净的阅读页面，每个原文段落与其译文并排对齐。仅清理后的文章文本会被发送用于翻译。

• 并排、堆叠、仅译文或仅原文；浅色、深色或跟随系统外观；可调整配色、字体、字号、行高和页面宽度。
• 将文章及其译文保存在你的设备上，之后可从右侧列表重新打开，无需再次翻译；可随时删除已保存的文章。

替代措辞与措辞偏好

在阅读页面、选择弹窗、翻译面板和 PDF 页面上，点击译文中的某个词（或选中几个词）可查看带简短说明的替代译法，或输入你自己的译法。你的选择会作为措辞偏好保存在你的设备上，并应用于之后包含相同源术语的翻译。可在设置中管理。DeepL 不提供替代措辞。

六种翻译方式

• 双语阅读：如上所述。
• 选中文本：在可移动弹窗中翻译任意语言的文本，包括中文。在支持的情况下流式输出结果，展开原文以作对比，复制译文，或更改目标语言。
• 网页区域：为网站的选定部分添加翻译按钮。规则按域名保存，你可以恢复原文。
• 图片：识别文本，沿笔画勾勒每个段落，并将译文放回原文之上，段落之间互不遮挡。竖排日文翻译为中文、日文或韩文时保持竖排。翻译前可查看并编辑检测到的形状，翻译选定区域，并导出翻译后的图片。识别需要具备视觉能力的模型；托管模式包含图片识别。
• 整份 PDF：在浏览器中打开 PDF，从上下文菜单中选择整份文档翻译。PDF 在本地解析；仅提取的文本会被发送用于翻译。对比原文和译文，保留页面布局、图形和表格，并可打印或另存为 PDF。无可提取文本的扫描页面不支持整份文档翻译。
• 翻译面板：将一段文本粘贴到专用的原文与译文视图中，选择源语言和目标语言，无需在网页上选择即可翻译。

实验性视频字幕

可选视频字幕默认关闭。语音识别取决于浏览器版本、设备和语言，可能不可用。在支持的情况下使用本地识别；绝不会静默切换到云端识别。仅当你明确选择云端识别时，标签页音频才会发送到浏览器语音服务（Edge 中的 Microsoft Azure）。识别出的文本遵循你选择的翻译模式。我们不提供托管的音频/视频转写。此实验性功能不保证每个视频都能翻译。

隐私

• 自带密钥请求直接发送到你选择的提供商或 HTTPS 端点。你的密钥保存在本地扩展存储中，不会通过浏览器账户同步。
• 托管模式通过我们的服务器将请求的文本或图片发送给模型提供商。我们的服务器不保留原始文本、图片或译文。
• 整份 PDF 文件在本地处理，不会上传。双语阅读在你的设备上检测文章；已保存的文章和措辞偏好保留在本地扩展存储中。
• 账户保留身份验证、使用、额度和计费所需的电子邮件地址、用户名和记录。无广告、跟踪 SDK 或设备指纹识别。
• 所有可执行扩展代码均包含在包中。源代码在 GPL-3.0 下提供。

快速开始

安装，选择你偏好的目标语言，使用托管试用或在设置中配置你自己的 API 密钥。在普通网页上，未选中文本时右键单击并选择“双语阅读这篇文章”，或选中文本并选择“翻译为…”。键盘快捷键：Alt+Shift+T，或在 macOS 上为 Command+Shift+Y。

浏览器保护页面和扩展商店不允许翻译浮层。单次文本请求限制为 6,000 个字符；PDF、区域和双语阅读翻译使用批处理。文章检测为启发式，因此论坛、社交网络和登录后的页面可能无法完整检测。自定义 API 端点需要 HTTPS 和所选主机的权限。
