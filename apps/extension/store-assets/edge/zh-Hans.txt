边读边译：选中文本，右键点击，译文即显示在页面上。

AI Translator 是一款开源的 Microsoft Edge 扩展，用于翻译选中的文本、网页区域、图片和整份 PDF 文档。无需 API 密钥即可使用托管翻译，也可连接你自己的 OpenAI、DeepSeek 或 DeepL 账户。

五种翻译方式

• 选中文本：在可移动弹窗中翻译任意语言的文本，包括中文。在支持的情况下流式输出结果，展开原文进行对照，复制译文，或更改目标语言。
• 网页区域：为网站的指定部分添加翻译按钮。规则按域名保存，你可以恢复原文。
• 图片：识别文字并在图片上叠加译文。翻译选定区域，在本地调整文本框，并导出翻译后的图片。识别需要具备视觉能力的模型；托管模式包含图片识别。
• 整份 PDF：在浏览器中打开 PDF，从右键菜单中选择整份文档翻译。PDF 在本地解析；仅提取出的文本会被发送用于翻译。对照原文与译文，保留页面布局、插图和表格，并可打印或另存为 PDF。无可提取文本的扫描页面不支持整份文档翻译。
• 翻译面板：将一段文字粘贴到专门的原文与译文视图中，选择源语言和目标语言，无需在网页上选中内容即可翻译。

24 种语言

可选择简体中文、繁体中文、英语、西班牙语、葡萄牙语、法语、德语、意大利语、荷兰语、俄语、乌克兰语、波兰语、土耳其语、阿拉伯语、希伯来语、波斯语、印地语、孟加拉语、乌尔都语、印度尼西亚语、越南语、泰语、日语或韩语。界面语言、源语言和翻译目标相互独立。服务商支持因语言和功能而异。支持从右到左的界面。

实验性视频字幕

可选视频字幕默认关闭。语音识别取决于浏览器版本、设备和语言，可能不可用。在支持的情况下使用本地识别；绝不会静默切换到云端识别。仅当你明确选择云端识别时，标签页音频才会发送到浏览器语音服务（Edge 中为 Microsoft Azure）。识别出的文本遵循你选择的翻译模式。我们不提供托管的音频/视频转写。此实验性功能不保证每个视频都能翻译。

隐私

• 自带密钥请求直接发送到你选择的服务商或 HTTPS 端点。你的密钥保存在本地扩展存储中，不会通过浏览器账户同步。
• 托管模式通过我们的服务器将请求的文本或图片发送给模型服务商。我们的服务器不保留原始文本、图片或译文。
• 整份 PDF 文件在本地处理，不会上传。
• 账户保留认证、使用、额度和计费所需的电子邮箱地址、用户名和记录。无广告、跟踪 SDK 或设备指纹识别。
• 所有可执行的扩展代码均包含在安装包中。源代码以 GPL-3.0 提供。

快速上手

安装，选择你偏好的目标语言，然后使用托管试用或在设置中配置你自己的 API 密钥。在普通网页上选中文本，从右键菜单中选择“翻译为…”。键盘快捷键：Alt+Shift+T，macOS 上为 Command+Shift+Y。

受浏览器保护的页面和扩展商店不允许翻译浮层。单次文本请求限制为 6,000 个字符；PDF 和区域翻译使用分批处理。自定义 API 端点需要 HTTPS 及所选主机的权限。
