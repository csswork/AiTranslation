Huaci آپ کے پڑھے جانے والے صفحے پر AI ترجمہ لاتا ہے: منتخب متن، دو لسانی مضامین، تصاویر، PDFs اور وہ ویب سائٹس جنہیں آپ خودکار ترجمے کے لیے منتخب کرتے ہیں۔

پڑھیں اور ترجمہ کریں
- متن منتخب کریں اور ترجمے کے لیے دائیں کلک کریں، یا فلوٹنگ سلیکشن بٹن یا کی بورڈ شارٹ کٹ استعمال کریں۔
- کسی مضمون کو صاف دو لسانی قاری میں پڑھیں جہاں اصل اور ترجمہ شدہ پیراگراف ساتھ ساتھ ہوں۔ لے آؤٹ، ظاہری شکل اور ٹائپوگرافی ایڈجسٹ کریں، پھر مضمون اور ترجمہ اس براؤزر میں محفوظ کریں۔
- جن ویب صفحے کے حصوں کو آپ باقاعدگی سے استعمال کرتے ہیں ان میں ترجمہ بٹن شامل کریں۔
- تصاویر میں متن کا ترجمہ کریں۔ متن کے حصوں کو مقامی طور پر دیکھیں اور ایڈجسٹ کریں، لے آؤٹ درست کریں اور ترجمہ شدہ تصویر برآمد کریں۔
- ٹول بار پاپ اپ کھولیں > Translate entire PDF، پھر مقامی متن پر مبنی PDF منتخب کریں۔ فائل آپ کے ڈیوائس پر پارس ہوتی ہے؛ صرف نکالا گیا متن ترجمے کے لیے بھیجا جاتا ہے۔ اصل اور ترجمہ شدہ صفحات کا موازنہ کریں اور نتیجہ PDF کے طور پر پرنٹ کریں۔
- صفحے کے context menu سے Translate this website فعال کریں۔ Huaci اس ڈومین کو مقامی طور پر یاد رکھتا ہے اور براؤزنگ کے دوران viewport کے قریب متن کا ترجمہ کرتا ہے، جب تک آپ یہ خصوصیت بند نہ کریں۔
- ترجمے میں کسی لفظ پر کلک کر کے معاون AI providers پر متبادل الفاظ دیکھیں، اور اپنی پسندیدہ اصطلاحات مقامی طور پر محفوظ کریں۔

اپنی ترجمہ سروس منتخب کریں
مفت آزمائش اور اکاؤنٹ کریڈٹس کے ساتھ hosted translation استعمال کریں، یا اپنا OpenAI، DeepSeek، DeepL یا مطابق HTTPS API منسلک کریں۔ Provider خصوصیات مختلف ہیں؛ DeepL تصویر کی شناخت یا متبادل الفاظ کی حمایت نہیں کرتا۔

مفت کریڈٹس ختم ہونے کے بعد hosted translation ایک بامعاوضہ سروس ہے۔ متن کی قیمت 1 کریڈٹ فی 500 Unicode حروف ہے، فی درخواست کوئی کم از کم حد نہیں۔ اختیاری subscriptions اور موجودہ قیمتیں https://app.huaci.app/plans پر دکھائی گئی ہیں۔ اپنی API key استعمال کرتے وقت آپ کا provider استعمال کی قیمت وصول کر سکتا ہے۔ ایکسٹینشن انسٹال کرنے سے کوئی بامعاوضہ subscription شروع نہیں ہوتی۔

رازداری
Provider keys، ترتیبات، ویب سائٹ قواعد، الفاظ کی ترجیحات اور محفوظ مضامین مقامی ایکسٹینشن اسٹوریج میں رہتے ہیں اور آپ کے براؤزر اکاؤنٹ کے ذریعے sync نہیں ہوتے۔ Hosted translation آپ کی درخواست کردہ مواد Huaci اکاؤنٹ سروس اور اس کے ترتیب شدہ model providers کو بھیجتا ہے؛ bring-your-own-key درخواستیں آپ کے منتخب provider کو جاتی ہیں۔ مکمل PDF فائلیں اپ لوڈ نہیں ہوتیں۔ Huaci آپ کی براؤزنگ ہسٹری جمع نہیں کرتا۔

Firefox desktop 142 یا بعد کا ورژن درکار ہے۔ Firefox براؤزر کا بلٹ ان Translator یا تجرباتی ویڈیو captions کے لیے استعمال ہونے والی Chrome tab-audio APIs فراہم نہیں کرتا، اس لیے یہ خصوصیات اس ایڈیشن میں دستیاب نہیں۔ محفوظ براؤزر صفحات اور بلٹ ان PDF viewer میں تبدیلی نہیں کی جا سکتی؛ اس کے بجائے مقامی PDF فائل picker استعمال کریں۔
