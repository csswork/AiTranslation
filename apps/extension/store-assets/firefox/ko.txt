Huaci는 읽고 있는 페이지에 AI 번역을 제공합니다. 선택한 텍스트, 이중 언어 문서, 이미지, PDF, 자동 번역할 웹사이트를 지원합니다.

읽기 및 번역
- 텍스트를 선택해 우클릭으로 번역하거나, 선택 영역에 뜨는 버튼 또는 키보드 단축키를 사용하세요.
- 원문과 번역 문단이 나란히 정렬된 깔끔한 이중 언어 리더로 문서를 읽을 수 있습니다. 레이아웃, 모양, 타이포그래피를 조정한 뒤 문서와 번역을 이 브라우저에 저장하세요.
- 자주 쓰는 웹페이지 영역에 번역 버튼을 추가하세요.
- 이미지 속 텍스트를 번역합니다. 텍스트 영역을 로컬에서 검토·조정하고 레이아웃을 고친 뒤 번역된 이미지를 내보내세요.
- 툴바 팝업 > 전체 PDF 번역을 열고 로컬 텍스트 기반 PDF를 선택하세요. 파일은 기기에서 파싱되며 추출된 텍스트만 번역을 위해 전송됩니다. 원문과 번역 페이지를 비교하고 결과를 PDF로 인쇄하세요.
- 페이지 컨텍스트 메뉴에서 이 웹사이트 번역을 활성화하세요. Huaci는 해당 도메인을 로컬에 기억하고 기능을 끌 때까지 탐색 중 뷰포트 근처의 텍스트를 번역합니다.
- 지원되는 AI 제공업체에서 번역문의 단어를 클릭해 다른 표현을 확인하고, 선호하는 용어를 로컬에 저장하세요.

번역 서비스 선택
무료 체험과 계정 크레딧이 있는 호스팅 번역을 사용하거나, 자체 OpenAI, DeepSeek, DeepL 또는 호환 HTTPS API를 연결하세요. 제공업체별 기능은 다르며, DeepL은 이미지 인식과 다른 표현 기능을 지원하지 않습니다.

호스팅 번역은 무료 크레딧 사용 후 유료 서비스입니다. 텍스트는 500 유니코드 문자당 1 크레딧으로 청구되며 요청당 최소 금액은 없습니다. 선택적 구독과 현재 가격은 https://app.huaci.app/plans 에서 확인하세요. 자체 API 키를 사용하면 제공업체가 사용료를 부과할 수 있습니다. 확장 프로그램 설치만으로 유료 구독이 시작되지는 않습니다.

개인정보
제공업체 키, 설정, 웹사이트 규칙, 용어 선호, 저장된 문서는 로컬 확장 프로그램 저장소에 보관되며 브라우저 계정으로 동기화되지 않습니다. 호스팅 번역은 요청한 콘텐츠를 Huaci 계정 서비스와 구성된 모델 제공업체로 전송하며, 자체 키 요청은 선택한 제공업체로 전송됩니다. 전체 PDF 파일은 업로드되지 않습니다. Huaci는 브라우징 기록을 수집하지 않습니다.

Firefox 데스크톱 142 이상이 필요합니다. Firefox는 브라우저 내장 Translator와 실험적 비디오 자막에 사용되는 Chrome 탭 오디오 API를 제공하지 않으므로 이 에디션에서는 해당 기능을 사용할 수 없습니다. 보호된 브라우저 페이지와 내장 PDF 뷰어는 수정할 수 없으므로 로컬 PDF 파일 선택기를 사용하세요.
