Huaci นำการแปลด้วย AI มาสู่หน้าที่คุณกำลังอ่าน ทั้งข้อความที่เลือก บทความสองภาษา รูปภาพ PDF และเว็บไซต์ที่คุณเลือกให้แปลอัตโนมัติ

อ่านและแปล
- เลือกข้อความแล้วคลิกขวาเพื่อแปล หรือใช้ปุ่มลอยที่ปรากฏเมื่อเลือกข้อความ หรือใช้คีย์ลัด
- อ่านบทความในตัวอ่านสองภาษาแบบเรียบง่าย ย่อหน้าต้นฉบับและคำแปลเรียงตรงกัน ปรับเลย์เอาต์ รูปลักษณ์ และการจัดตัวอักษรได้ แล้วบันทึกบทความและคำแปลไว้ในเบราว์เซอร์นี้
- เพิ่มปุ่มแปลให้บริเวณของเว็บเพจที่คุณใช้งานเป็นประจำ
- แปลข้อความในรูปภาพ ตรวจและปรับพื้นที่ข้อความในเครื่อง แก้เลย์เอาต์ และส่งออกรูปภาพที่แปลแล้ว
- เปิดป๊อปอัปบนแถบเครื่องมือ > แปล PDF ทั้งไฟล์ แล้วเลือกไฟล์ PDF ข้อความในเครื่อง ไฟล์จะถูกแยกวิเคราะห์บนอุปกรณ์ของคุณ มีเพียงข้อความที่แยกออกมาที่ถูกส่งไปแปล เปรียบเทียบหน้าต้นฉบับกับหน้าที่แปล และพิมพ์ผลลัพธ์เป็น PDF
- เปิดใช้ แปลเว็บไซต์นี้ จากเมนูคลิกขวาของหน้า Huaci จะจดจำโดเมนนั้นไว้ในเครื่อง และแปลข้อความใกล้บริเวณที่มองเห็นขณะคุณท่องเว็บ จนกว่าคุณจะปิดฟีเจอร์นี้
- คลิกคำในคำแปลเพื่อดูคำเลือกอื่นบนผู้ให้บริการ AI ที่รองรับ และบันทึกคำที่คุณต้องการไว้ในเครื่อง

เลือกบริการแปลของคุณ
ใช้การแปลแบบโฮสต์ซึ่งมีช่วงทดลองใช้ฟรีและเครดิตในบัญชี หรือเชื่อมต่อ API แบบ HTTPS ของ OpenAI, DeepSeek, DeepL หรือผู้ให้บริการที่เข้ากันได้ของคุณเอง ฟีเจอร์ของผู้ให้บริการแตกต่างกัน DeepL ไม่รองรับการรู้จำภาพหรือคำเลือกอื่น

การแปลแบบโฮสต์เป็นบริการแบบชำระเงินเมื่อเครดิตฟรีหมด คิดค่าบริการข้อความ 1 เครดิตต่อ 500 อักขระ Unicode โดยไม่มีขั้นต่ำต่อคำขอ แพ็กเกจสมัครสมาชิกแบบเลือกได้และราคาปัจจุบันแสดงที่ https://app.huaci.app/plans เมื่อใช้คีย์ API ของคุณเอง ผู้ให้บริการของคุณอาจคิดค่าบริการการใช้งาน การติดตั้งส่วนขยายไม่ได้เริ่มการสมัครสมาชิกแบบชำระเงิน

ความเป็นส่วนตัว
คีย์ผู้ให้บริการ การตั้งค่า กฎของเว็บไซต์ การตั้งค่าคำ และบทความที่บันทึกไว้ เก็บอยู่ในที่จัดเก็บของส่วนขยายในเครื่อง และไม่ซิงก์ผ่านบัญชีเบราว์เซอร์ของคุณ การแปลแบบโฮสต์ส่งเนื้อหาที่คุณขอไปยังบริการบัญชี Huaci และผู้ให้บริการโมเดลที่กำหนดไว้ ส่วนคำขอที่ใช้คีย์ของคุณเองจะส่งไปยังผู้ให้บริการที่คุณเลือก ไฟล์ PDF ทั้งไฟล์จะไม่ถูกอัปโหลด Huaci ไม่เก็บประวัติการท่องเว็บของคุณ

ต้องใช้ Firefox เดสก์ท็อป 142 ขึ้นไป Firefox ไม่มี Translator ในตัวของเบราว์เซอร์หรือ API เสียงแท็บของ Chrome ที่ใช้ในคำบรรยายวิดีโอแบบทดลอง ดังนั้นฟีเจอร์เหล่านั้นจึงใช้ไม่ได้ในเวอร์ชันนี้ หน้าเบราว์เซอร์ที่ได้รับการป้องกันและตัวอ่าน PDF ในตัวไม่สามารถแก้ไขได้ ให้ใช้ตัวเลือกไฟล์ PDF ในเครื่องแทน
