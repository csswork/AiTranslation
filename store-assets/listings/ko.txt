웹페이지에서 텍스트를 선택하고 마우스 오른쪽 버튼을 클릭하면 탭을 전환하거나 복사하여 붙여넣을 필요 없이 떠 있는 패널에 번역이 표시됩니다.

AI Selection Translator는 Manifest V3 기반으로 제작된 오픈 소스 Chrome 확장 프로그램입니다. 자신의 OpenAI, DeepSeek 또는 DeepL API 키를 사용하여 선택한 텍스트, 페이지 영역, 이미지 속 텍스트를 원하는 언어로 번역하세요.

▍네 가지 번역 방법

• 선택한 텍스트
텍스트를 선택하고 마우스 오른쪽 버튼 메뉴에서 “Translate to…”를 선택하세요. 번역은 화면 중앙의 패널에 표시되며, 지원되는 경우 스트리밍 출력과 펼칠 수 있는 원문 보기를 제공합니다.

중국어를 포함한 모든 언어의 선택 항목을 번역할 수 있습니다. 숫자, 문장 부호 또는 이모지만 포함된 선택 항목은 번역 제안을 트리거하지 않습니다.

패널에서 대상 언어를 직접 변경하여 원래 선택 항목을 다시 번역할 수 있습니다. 선택한 경우에만 기본값으로 저장됩니다.

• 페이지 영역
웹페이지의 특정 영역에 번역 버튼을 추가합니다. 버튼을 클릭하면 해당 영역의 텍스트가 번역으로 대체되며, 필요할 때 원본을 복원할 수 있습니다.

규칙은 도메인별로 저장되므로 웹사이트를 다시 방문하면 버튼이 다시 나타납니다. 더 긴 영역은 일괄 처리되며 번역이 점진적으로 표시됩니다.

• 이미지
이미지를 마우스 오른쪽 버튼으로 클릭하면 텍스트를 인식하고 감지된 위치에 번역을 오버레이합니다. 긴 이미지는 인식을 위해 더 작은 섹션으로 분할됩니다.

대상 언어를 변경하면 인식된 텍스트를 재사용하므로 동일한 이미지를 다시 스캔할 필요가 없습니다. 이미지 인식에는 비전 기능을 지원하는 제공자와 모델이 필요합니다.

• 번역 패널
왼쪽에 원문, 오른쪽에 번역이 표시되는 전용 페이지를 엽니다. 더 긴 문장이나 브라우저 외부의 텍스트에 사용하세요.

24개 대상 언어 중에서 선택할 수 있습니다: 중국어 간체, 중국어 번체, 영어, 스페인어, 포르투갈어, 프랑스어, 독일어, 이탈리아어, 네덜란드어, 러시아어, 우크라이나어, 폴란드어, 터키어, 아랍어, 히브리어, 페르시아어, 힌디어, 벵골어, 우르두어, 인도네시아어, 베트남어, 태국어, 일본어, 한국어.

원문 언어를 자동으로 감지하거나 직접 선택하세요. 원문 언어, 대상 언어, 인터페이스 언어는 독립적인 설정입니다. 제공자 지원은 언어와 기능에 따라 다릅니다.

▍일상적인 읽기를 위해 설계됨

• 페이지에 머무르기: 작업 흐름을 방해하지 않고 읽으면서 번역합니다.
• 스트리밍 출력: 지원되는 경우 번역이 점진적으로 표시됩니다.
• 밝은 테마와 어두운 테마는 시스템 환경설정을 따릅니다.
• 번역 패널을 드래그하여 위치를 변경하거나 Esc를 눌러 닫을 수 있습니다.
• 키보드 단축키: macOS에서는 ⌘⇧Y, 다른 플랫폼에서는 Alt+Shift+T.
• 오른쪽에서 왼쪽 레이아웃을 포함하여 24개 언어에 대한 현지화된 인터페이스.
• 인터페이스 언어와 독립적으로 기본 번역 언어를 선택하세요.

실험적인 동영상 자막 번역도 선택적 기능으로 제공됩니다. 음성 인식 지원은 브라우저, 기기 및 원문 언어에 따라 다릅니다.

▍개인정보 보호

• 개발자가 운영하는 번역 서버가 없습니다. 번역 요청은 구성한 제공자 또는 사용자 지정 엔드포인트로 직접 전송됩니다.
• 분석, 추적 또는 광고가 없습니다.
• API 키는 chrome.storage.local에 로컬로 저장되며 Chrome 계정을 통해 동기화되지 않습니다.
• 콘텐츠는 사용자가 적극적으로 요청할 때만 번역을 위해 전송됩니다. 개발자는 사용자의 번역 기록을 받지 않습니다.
• 동영상 음성 인식은 지원되는 기기에서 로컬로 실행될 수 있습니다. 선택적 클라우드 인식은 오디오를 브라우저의 음성 인식 서비스로 전송합니다.
• 전체 소스 코드는 검사를 위해 GPL-3.0에 따라 제공됩니다.

▍시작하기

1. 설치 후 설정 페이지가 자동으로 열립니다. 제공자를 선택하고 자신의 API 키를 입력한 다음 “Test connection”을 사용하여 구성을 확인하세요.
2. 인터페이스 언어와 기본 번역 대상을 선택하세요.
3. 웹페이지에서 텍스트를 선택하고 마우스 오른쪽 버튼을 클릭한 다음 “Translate to…”를 선택하여 시작하세요.

Chrome 116 이상이 필요합니다. 실험적인 동영상 기능은 더 새로운 브라우저와 추가 설정이 필요할 수 있습니다.

이 버전은 자신의 제공자 자격 증명을 사용합니다. 모든 API 요금은 선택한 제공자가 청구합니다.

▍알려진 제한 사항

• chrome:// 페이지와 Chrome 웹 스토어를 포함한 브라우저 보호 페이지에서는 콘텐츠 스크립트 주입이 허용되지 않습니다. 해당 페이지에서는 번역 오버레이를 사용할 수 없습니다.
• 개별 텍스트 번역은 6,000자로 제한됩니다. 더 긴 선택 항목은 잘리며 패널에 알림이 표시됩니다.
• 사용자 지정 API 엔드포인트는 해당 도메인에 대한 별도 권한이 필요하며 HTTPS를 사용해야 합니다.
• 사용 가능한 언어, 이미지 인식 및 스트리밍 기능은 제공자와 모델에 따라 다릅니다.

▍이 프로젝트 정보

독립적인 오픈 소스 프로젝트입니다. OpenAI, DeepSeek, DeepL 또는 관련 회사와 제휴하거나 이들의 보증 또는 후원을 받지 않습니다.

ChatGPT, DeepSeek, DeepL 및 기타 제품 이름은 각 소유자의 상표이며 호환되는 서비스를 식별하기 위해서만 사용됩니다.
