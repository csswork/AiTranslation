在網頁上選取文字、按一下右鍵，翻譯就會出現在浮動面板中——不必切換分頁，也不用複製貼上。

AI 劃詞翻譯是以 Manifest V3 打造的開源 Chrome 擴充功能。使用你自己的 OpenAI、DeepSeek 或 DeepL API 金鑰，將選取的文字、頁面區域和圖片中的文字翻譯成你偏好的語言。

▍四種翻譯方式

• 選取文字
選取文字，然後從右鍵選單中選擇「翻譯成…」。翻譯會顯示在置中面板中，並在支援時以串流方式輸出，還可展開查看原文。

任何語言的選取內容——包括中文——都可以翻譯。只包含數字、標點符號或表情符號的選取內容不會觸發翻譯選項。

直接在面板中變更目標語言，即可重新翻譯原始選取內容。只有在你選擇時，才會將其儲存為預設值。

• 頁面區域
為網頁的特定區域新增翻譯按鈕。按一下即可將該區域的文字替換為翻譯，並在需要時還原原文。

規則會依網域儲存，因此當你再次造訪該網站時，按鈕會再次出現。較長的區域會分批處理，翻譯會逐步顯示。

• 圖片
在圖片上按一下右鍵，即可辨識其中的文字，並在偵測到的位置疊加翻譯。長圖片會分割成較小的區段進行辨識。

變更目標語言時會重複使用已辨識的文字，因此同一張圖片不需要再次掃描。圖片辨識需要支援視覺功能的供應商與模型。

• 翻譯面板
開啟專用頁面，左側顯示原文，右側顯示翻譯。可用於較長的段落或來自瀏覽器外部的文字。

可選擇 24 種目標語言：簡體中文、繁體中文、英文、西班牙文、葡萄牙文、法文、德文、義大利文、荷蘭文、俄文、烏克蘭文、波蘭文、土耳其文、阿拉伯文、希伯來文、波斯文、印地文、孟加拉文、烏爾都文、印尼文、越南文、泰文、日文和韓文。

自動偵測來源語言，或明確選取來源語言。來源語言、目標語言和介面語言是各自獨立的設定。供應商支援情形會因語言和功能而異。

▍為日常閱讀而設計

• 留在頁面上：閱讀時即可翻譯，不中斷你的工作流程。
• 串流輸出：在支援的情況下，翻譯會逐步顯示。
• 淺色與深色主題會依照你的系統偏好設定。
• 拖曳翻譯面板即可重新定位，或按 Esc 關閉。
• 鍵盤快速鍵：在 macOS 上為 ⌘⇧Y，在其他平台上為 Alt+Shift+T。
• 提供 24 種語言的在地化介面，包括由右至左的版面配置。
• 可獨立於介面語言選擇你的預設翻譯語言。

實驗性的影片字幕翻譯也可作為選用功能使用。語音辨識支援情形取決於你的瀏覽器、裝置和來源語言。

▍隱私權

• 沒有開發者營運的翻譯伺服器。翻譯要求會直接傳送至你設定的供應商或自訂端點。
• 沒有分析、追蹤或廣告。
• 你的 API 金鑰會儲存在本機的 chrome.storage.local 中，不會透過你的 Chrome 帳戶同步。
• 只有在你主動要求翻譯時，內容才會被傳送出去。開發者不會收到你的翻譯記錄。
• 影片語音辨識可在支援的裝置上於本機執行。選用的雲端辨識會將音訊傳送至瀏覽器的語音辨識服務。

▍開始使用

1. 安裝後，設定頁面會自動開啟。選擇供應商、輸入你自己的 API 金鑰，並使用「測試連線」檢查你的設定。
2. 選擇你的介面語言和預設翻譯目標。
3. 在網頁上選取文字、按一下右鍵，然後選擇「翻譯成…」即可開始。

需要 Chrome 116 或更新版本。實驗性影片功能可能需要較新的瀏覽器和額外設定。

此版本使用你自己的供應商憑證。任何 API 費用均由你選擇的供應商收取。

▍已知限制

• 瀏覽器保護的頁面，包括 chrome:// 頁面和 Chrome 線上應用程式商店，不允許注入內容指令碼。因此無法在這些頁面使用翻譯疊加層。
• 個別文字翻譯限制為 6,000 個字元。較長的選取內容會被截斷，並在面板中顯示通知。
• 自訂 API 端點需要為其網域取得個別權限，且必須使用 HTTPS。
• 可用的語言、圖片辨識和串流功能取決於你的供應商和模型。
