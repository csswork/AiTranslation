Eine Chrome-Erweiterung. Fremdsprachige Texte im Web, ganze Bereiche und sogar Text in Bildern lassen sich an Ort und Stelle ins Chinesische übersetzen. Die Übersetzung erscheint Wort für Wort als Stream und nutzt Ihren eigenen API-Schlüssel – dazwischen liegt kein Server.

Zu Chrome hinzufügen Quellcode ansehen
Chrome 116+ Keine Server · Keine Statistik Vier Übersetzungswege

Features

Vier Einstiege, alle im Kontextmenü

Kein Tab-Wechsel, kein Kopieren und Einfügen. Wo die Passage steht, die Sie nicht verstehen, dort findet auch die Übersetzung statt.

01

Auswahlübersetzung

Markieren Sie eine Passage nicht-chinesischen Textes und wählen Sie per Rechtsklick „Ins Chinesische übersetzen“; die Übersetzung erscheint Wort für Wort in einem Popup in der Bildschirmmitte.

  • Ist die Auswahl bereits Chinesisch, erscheint der Menüeintrag nicht; dasselbe gilt für reine Zahlen, Satzzeichen und Emojis
  • Das Popup ist zentriert und verschiebbar, schließt mit Esc oder einem Klick auf den Hintergrund – keine kleine Sprechblase, die dem Cursor folgt
  • Ein einklappbarer Ausgangstextbereich zum Mitlesen
  • Es gibt auch einen Kurzbefehl: Alt+Shift+T (unter macOS Command+Shift+Y)
Platzhalter für Demo-Video assets/demo-selection.mp4

02

Elementübersetzung

Klicken Sie mit der rechten Maustaste auf einen Bereich der Seite, um dort eine Übersetzungsschaltfläche anzubringen. Ein Klick ersetzt den Text im Bereich an Ort und Stelle durch die chinesische Übersetzung.

  • Regeln werden pro Domain gespeichert; beim nächsten Besuch derselben Website wird die Schaltfläche automatisch angebracht
  • Lange Inhalte werden in Stapeln gesendet und während der Übersetzung ersetzt, sodass Sie nicht auf den gesamten Bereich warten müssen
  • Gespeicherte Regeln lassen sich auf der Verwaltungsseite einzeln ansehen und löschen
Platzhalter für Demo-Video assets/demo-element.mp4

03

Bildübersetzung

Ein Rechtsklick auf ein Bild erkennt den darin enthaltenen Text; anschließend wird die Übersetzung an der erkannten Position über das Originalbild gelegt.

  • Lange Bilder werden vor der Erkennung in Kacheln geteilt; die Schnittkanten werden automatisch in die Leerzeilen zwischen den Textzeilen verschoben, sodass kein Satz geteilt wird
  • Vor der Übergabe wird nach Gesamtpixelzahl statt nach der längsten Kante skaliert, damit die Breite langer Bilder nicht zusammengedrückt wird
  • Das Ergebnis öffnet sich in einem eigenen Fenster, sodass Sie es mit dem Originalbild vergleichen können
Platzhalter für Demo-Video assets/demo-image.mp4

04

Übersetzungsbereich

Eine eigenständige Seite: links der Ausgangstext, rechts die Übersetzung – geeignet für zusammenhängende Textpassagen, die nicht auf einer Webseite stehen.

  • Über ein Dutzend Zielsprachen zur Auswahl, nicht auf Chinesisch beschränkt
  • Erkennt die Eingabesprache automatisch: Chinesisch wird standardmäßig ins Englische übersetzt, alle anderen Sprachen ins Chinesische
  • Anbieter und Zielsprache befinden sich in der Symbolleiste; jederzeit umschalten und neu übersetzen

Privacy

Ohne Server gibt es nichts, was abfließen könnte

Inhalte werden nur dann gesendet, wenn Sie die Übersetzung selbst auslösen, und ausschließlich an den von Ihnen gewählten Anbieter. Das ist kein Versprechen, sondern eine Tatsache, die sich im Quellcode Zeile für Zeile nachprüfen lässt.

Ein einziger Ausgang

Alle Anfragen an Übersetzungsanbieter stehen in einer einzigen Datei, src/lib/providers.js, und gehen nur an den in den Einstellungen gewählten Anbieter. Der übrige Code sendet Ihre Inhalte nirgendwohin.

Kein Backend

Der Autor betreibt keine Server und setzt keine Statistik, kein Tracking, keine Werbung und keine SDKs von Drittanbietern ein. Was Sie übersetzt haben, lässt sich hier nicht nachvollziehen.

Schlüssel bleibt auf Ihrem Gerät

Der API-Schlüssel liegt in chrome.storage.local, wird nicht über das Chrome-Konto synchronisiert und dient nur der Authentifizierung gegenüber dem von Ihnen gewählten Anbieter. Beim Deinstallieren der Erweiterung wird er mit entfernt.

Vollständige Angaben finden Sie in der Datenschutzerklärung sowie im vollständigen, unter GPL-3.0 veröffentlichten Quellcode.

Install

In vier Schritten eingerichtet

Wird derzeit im Entwicklermodus geladen. Erfordert Chrome 116 oder höher sowie einen eigenen API-Schlüssel.

Quellcode besorgen – laden Sie auf GitHub das ZIP herunter und entpacken Sie es, oder klonen Sie das Repository direkt mit git clone.
Erweiterungsseite öffnen – geben Sie chrome://extensions/ in die Adressleiste ein und aktivieren Sie oben rechts den „Entwicklermodus“.
Erweiterung laden – klicken Sie auf „Entpackte Erweiterung laden“ und wählen Sie den eben entpackten Ordner.
API-Schlüssel eintragen – bei der ersten Installation öffnet sich die Einstellungsseite automatisch. Anbieter wählen, Schlüssel einfügen und auf „Verbindung testen“ klicken.

Unterstützt die APIs von ChatGPT (OpenAI) und DeepSeek; jederzeit umschaltbar. Beide verwenden standardmäßig die jeweils günstigste Stufe – Übersetzen ist eine häufige Aufgabe mit kurzen Eingaben, teurere Modelle sind dafür nicht nötig.

Installieren und vergessen

Bis zum nächsten Mal, wenn Sie wieder eine Passage markieren, die Sie nicht verstehen.
