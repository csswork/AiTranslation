# 商店审核账号

仅用于商店审核人员独立测试。普通用户仍使用邮箱验证码或 Google 登录；不提供通用密码登录，也不为任何邮箱配置固定验证码。

## 权限与期限

- `/review-login` 是英文专用表单，不加入普通用户的登录入口或导航。凭据只通过同源 POST 提交，不放在 URL。
- 运营者通过服务器命令行建立新的 `review_` 用户名普通账号，不能把既有客户或管理员转成审核账号。审核账号不能由 `admin grant` 授予管理员权限。
- 默认随机凭据有 256 位熵，只保存 SHA-256；默认 30 天有效，最多 30 天。正常验证码、OAuth、管理员二步验证和扩展 ID 白名单均不绕过。
- 首次建立账号一次性赠送 1000.00 点（500000 个整数额度），没有伪造订单或订阅。轮换凭据不重复赠送；点数仍由现有服务端账本精确扣减。
- 审核账号的网页、扩展和关联网页会话均受审核截止时间限制；一年滚动续期不能越过截止时间。撤销或轮换会作废该账号已有的全部会话。
- 新账号不标记邮箱已验证；邮箱验证状态只能由正常验证码或 OAuth 流程确认。

## 创建或轮换

先部署迁移 `011_review_access.sql`。在 VPS 的应用目录运行，使用只有操作者可读的目录保存输出：

```sh
node --env-file=/etc/huaci/backend.env scripts/review.mjs create edge-review@huaci.app review_msedge /绝对路径/私有目录/edge-review.json
```

输出文件以 `0600` 独占创建，包含登录地址、账号、随机凭据及准确到期时间。不会在终端输出凭据；拒绝覆盖已有文件。轮换时使用新的输出文件名。凭据文件不能提交、进入公开商店素材包或扩展安装包；将凭据交给指定的审核人员后妥善保存或删除。

```sh
node --env-file=/etc/huaci/backend.env scripts/review.mjs revoke edge-review@huaci.app
```

创建、轮换和撤销写入管理审计；不记录明文凭据。提前结束审核时运行撤销命令。

## 审核人员步骤

1. 在将安装扩展的同一个 Edge 配置文件里打开 `https://app.huaci.app/review-login`，使用审核备注提供的账号和访问密钥登录。
2. 回到扩展点击登录并确认授权。若扩展先打开了普通 `/login`，可在该标签页改为 `/review-login`，授权上下文会保留，登录后继续原授权。
3. 点数已发放，无需提供模型 API Key 或付款即可测试托管文字、图片及 PDF 提取文字的翻译。实验字幕功能仍受浏览器支持限制。

此入口不代替正式 Edge 扩展 ID 的后台白名单配置及生产 PKCE 回调测试。

## 迁移与回退

`011` 只新增 `review_access`，不修改普通用户的数据或既有迁移。正常发布先执行迁移再切换代码。回退至不识别审核期限的旧代码前，必须用当前代码撤销所有审核账号的登录和会话；保留该表及审计，不直接删表恢复旧会话。

验证覆盖：凭据哈希、权限隔离、同源表单、失败限流、过期与撤销、轮换幂等、现有登录方式、会话期限及完整扩展 PKCE 流程。
