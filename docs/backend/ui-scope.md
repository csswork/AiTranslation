# VPS 用户管理界面与管理员界面：首版功能审核稿

状态：用户管理界面与管理员界面都已按本稿实现首版，进度与差异见 [apps/backend/README.md](../../apps/backend/README.md)。试用改为访客试用与注册赠送（都不过期），付费为单一订阅方案（月付、年付，无限使用），支付服务为 Creem。

两套界面都归 `apps/backend`，部署在 VPS，共用 `api.huaci.app` 后端；域名尚未配置。扩展是主要使用入口，官网与两套界面读取同一账号、额度账本和订阅数据。

## 两套界面的边界

| | 用户管理界面（用户端） | 管理员界面（管理端） |
| --- | --- | --- |
| 建议域名 | `app.huaci.app` | `admin.huaci.app` |
| 使用者 | 注册用户 | 手动指定的运营管理员 |
| 登录 | Google、X、邮箱验证码 | 独立管理入口，管理员账号并启用二步验证 |
| 数据范围 | 只读写当前用户自己的数据 | 按权限查看和处理全部用户数据，关键操作写入审计 |
| 权限验证 | 服务端按当前会话校验用户身份 | 服务端校验管理员权限；普通用户会话不能调用管理接口 |
| 功能编号 | U1–U8 | A1–A9 |

两套界面入口、导航和权限分开，不在用户端里通过隐藏菜单提供管理功能。

## 账号资料最小化

账号资料仅保留必要的 **email 和用户名（username）**。用户名由用户填写或系统生成；不导入第三方真实姓名或昵称，不提供头像、昵称或个人资料页。

登录所必需的内部用户 ID、平台身份绑定、邮箱验证状态和会话，以及订阅、订单、点数账本等业务记录单独管理，不扩展为个人资料。第三方 OAuth 返回的头像、姓名、昵称及其他额外个人资料不入库、不缓存、不写日志，也不返回给网页或扩展。

认证库选型和默认用户模型必须满足上述要求。若库默认包含姓名、头像等字段，需要定制模型或调整实现；不得为兼容库而增加额外账号资料。用户名不作为独立的昵称字段重复保存。

## 用户管理界面

| 编号 | 功能 | 首版内容 |
| --- | --- | --- |
| U1 | 注册与登录 | Google、X、邮箱验证码；验证邮箱、登录、退出。第三方资料不足时补充并验证邮箱。 |
| U2 | 账户总览 | 用户名、必要的账号邮箱；试用/付费状态、剩余点数、试用到期时间、当前套餐、订阅有效期与下次扣款时间（如适用）。 |
| U3 | 套餐与订阅 | 套餐和权益说明；开通、升级/降级、取消自动续订、查看生效时间与到期状态；通过支付服务商的订阅管理入口处理支持的操作。 |
| U4 | 订单与账单 | 支付时间、金额、币种、支付/退款状态；查看支付服务商提供的收据或账单，重试未完成的付款。 |
| U5 | 用量与点数记录 | 点数收入单独保留表格；点数支出、翻译请求按 UTC 日展示图表，支持本月、近 7 天、近 30 天筛选和悬停数值，支出与请求明细可展开。默认仅保留计费元数据。 |
| U6 | 邮箱、用户名与登录方式 | 管理用户名；验证和更换邮箱；在验证身份后绑定登录方式。已有账号绑定新平台不得重复领取试用点数。 |
| U7 | 登录会话 | 查看有效的网站/扩展会话及过期状态；退出指定会话或全部会话。会话列表不采集设备型号、位置或设备指纹。 |
| U8 | 扩展与帮助入口 | 安装扩展、使用说明和问题反馈链接；说明托管翻译与自带 Key 模式的区别，网站不接收用户自带的模型 API Key。 |

用户界面只操作当前用户自己的数据。试用额度与订阅权益由服务端发放和判断；点数用尽停止托管翻译，自带 Key 模式继续使用。

U2、U5 及扩展中的点数、赠送和流水统一显示两位小数；后台按实际字符额度精确记账，不设单次最低扣点，不按展示精度截断余额。即使显示为 `0.00`，仍由服务端判断能否完成请求。A3、A6 共用同一精确账本，人工补发和 A4 的赠送配置支持两位小数；固定换算不作为可调运营规则。见 [精确额度记账](credit-accounting.md)。

U3 的升级、降级、取消以及点数变更的生效规则，需在正式接入支付服务时写清楚，不能仅凭浏览器支付成功页面更新权益。

## 管理员界面

| 编号 | 功能 | 首版内容 |
| --- | --- | --- |
| A1 | 管理员登录与权限 | 手动指定管理员账号、独立管理入口、服务端权限验证；管理员启用二步验证。普通用户注册不会获得管理权限。 |
| A2 | 运营概览 | 注册/付费用户数、订阅收入、退款、托管用量、模型 API 成本与失败率。按 API、经营、增长、分布、性能分区展示，提供日期筛选、悬停数值与可折叠明细；语言与地区使用本地世界地图，可切换安装、使用和收入，语言偏好保留全局汇总。汇总与趋势使用同一报表时区的自然日范围。成本估算与已核对账单分开标记；金额保留币种。 |
| A3 | 用户管理 | 按邮箱、用户名或内部用户 ID 搜索；展示邮箱、用户名及必要的验证状态、套餐、试用、点数与用量；冻结/恢复托管服务、撤销会话；二次确认后删除用户及其数据（订单与防滥用哈希保留但解除关联）。 |
| A4 | 套餐与试用配置 | 设置试用点数和有效期、套餐点数、支付商品关联；套餐规则保留版本，既有订阅按对应规则处理。 |
| A5 | 订单与订阅管理 | 查订单、付款、续费、取消、失败和退款状态；与支付平台核对或重新同步。退款首版从支付平台发起，结果回写后台。 |
| A6 | 点数与额度账本 | 全局账本与用户详情分开显示点数收入表格、支出与翻译请求日图表和可展开明细；收入可按类型筛选。人工补发/调整点数必须填写原因并留记录；排查重复发放和未完成结算。 |
| A7 | 托管服务配置 | 启停文字/图片/视频服务、提供商和模型；设置单次请求上限、并发和限流规则；密钥由 VPS 配置，界面显示配置状态。 |
| A8 | 异常与任务处理 | 查看翻译失败、邮件投递、支付回调、后台任务异常；按幂等规则重试可恢复任务。 |
| A9 | 管理操作审计 | 记录管理员、时间、操作对象和原因；覆盖用户冻结、点数调整、套餐变更、订阅操作与服务配置修改。 |

管理员首版以单一管理员角色起步。用户的自带 API Key 只在用户本机，管理界面无法读取它；默认翻译记录仅包含计费与排错所需的元数据。

## 各端如何配合

| 功能 | Chrome 扩展 | Vercel 官网 | VPS 用户端 | VPS 管理端 |
| --- | --- | --- | --- | --- |
| 登录/退出 | 首要入口 | 登录入口与当前状态 | 完整登录/注册流程 | 独立管理员登录（A1） |
| 点数/试用/套餐 | 弹窗与设置页直接展示 | 登录后简要展示 | 总览及详细用量记录 | 查看用户状态（A3）、配置规则（A4）、有据调整（A6） |
| 购买/管理订阅 | 打开用户端或支付结账页 | 链接到用户端 | 完整操作与账单 | 核对、同步与退款处理（A5） |
| 翻译 | 托管和自带 Key 两种模式 | 产品介绍 | 首版以账户管理为主 | 托管服务配置与异常处理（A7、A8） |

## 暂列后续功能

以下不包含在当前基础功能范围，可在审核时调整：团队账户、多级客服/财务角色、邀请返利、优惠券管理、积分转赠、复杂报表和导出、客服工单、独立网页翻译工作台。

用户注销/删除账号的入口及其订阅处理规则，需要在正式上线前补齐；不把“退出登录”当作关闭账号或取消订阅。

审核可直接引用 U1–U8、A1–A9 编号提出增删。通过后再冻结首版范围，并完成后端技术栈与详细接口设计。
