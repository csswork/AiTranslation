v1.0.0
2026-09-15

第一个版本

  • 划词翻译：选中非中文文字后右键翻译，译文在屏幕中央的弹窗里流式显示。选中的文字本身是中文时，菜单不出现。
  • 元素翻译：右键页面上的某个区域给它挂一个翻译按钮，点击后就地替换区域内的文字；规则按域名记住，可在管理页维护。
  • 图片翻译：右键图片识别其中的文字，译文按位置盖回原图。长图会先按内容切块，切缝避开文字行。
  • 翻译面板：独立页面，左原文右译文，目标语言可任选。
  • 支持接入 ChatGPT（OpenAI）、DeepSeek 与 DeepL 的 API，在弹窗或设置页随时切换。
  • API Key 存于 chrome.storage.local，不随 Chrome 账号同步。
