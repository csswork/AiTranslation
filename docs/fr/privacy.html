Politique de confidentialité

Dernière mise à jour : 2026-09-30 · Source Markdown

En une phrase

Cette extension ne collecte, ne stocke et ne téléverse aucune donnée utilisateur vers nos serveurs — nous n’avons aucun serveur. Le contenu que vous demandez à traduire n’est envoyé qu’à la plateforme d’IA que vous avez configurée.

Ce qui est envoyé

Ce n’est que lorsque vous déclenchez vous-même une traduction (menu contextuel, raccourci clavier, clic sur un bouton de traduction) que les éléments suivants sont envoyés en HTTPS à la plateforme que vous avez choisie dans les paramètres :

ContenuMoment de l’envoiEnvoyé à
Le texte que vous avez sélectionnéLors d’une traduction par sélectionLa plateforme que vous avez choisie
Le texte contenu dans la zone que vous avez désignéeLorsque vous cliquez sur le bouton de traduction de l’élémentIdem
L’image sur laquelle vous avez fait un clic droitLors d’une traduction d’imageIdem
Le texte que vous saisissez dans le panneau de traductionLorsque vous cliquez sur TraduireIdem

Les plateformes disponibles sont OpenAI (ChatGPT), DeepSeek et DeepL ; les requêtes sont envoyées respectivement à https://api.openai.com, https://api.deepseek.com et, pour DeepL, à https://api-free.deepl.com (avec une clé payante : https://api.deepl.com). Le traitement de ces contenus relève de la politique de confidentialité propre à chaque plateforme :

  • OpenAI：openai.com/policies/privacy-policy
  • DeepSeek：platform.deepseek.com/downloads
  • DeepL：deepl.com/en/privacy

Jamais envoyé : le contenu des pages que vous n’avez pas demandé à traduire, votre historique de navigation, les cookies et les données de formulaire. L’extension n’analyse ni ne téléverse rien en arrière-plan.

Ce qui reste sur votre machine

Les données suivantes sont conservées sur votre appareil via chrome.storage.local. Elles ne sont pas synchronisées avec votre compte Chrome et ne quittent jamais votre navigateur :

  • API Key — utilisée uniquement pour authentifier vos requêtes auprès de la plateforme que vous avez choisie
  • Préférences — langue cible, modèle utilisé, réglages des fonctionnalités
  • Règles de traduction d’éléments — les entrées « domaine + sélecteur CSS » que vous avez ajoutées vous-même

Vous pouvez effacer ces données à tout moment depuis la page de paramètres, ou simplement désinstaller l’extension (la désinstallation les supprime toutes).

Ce que nous ne faisons pas

  • Aucun serveur, aucune collecte de données
  • Aucune statistique, aucun traçage, aucune publicité, aucun SDK tiers
  • Aucune vente, location ou partage de données avec des tiers
  • Aucune utilisation pour l’évaluation de crédit ou à des fins sans rapport avec les fonctions de l’extension

L’intégralité du code source de l’extension est publique sous GPL-3.0, ce qui vous permet de le vérifier : github.com/csswork/AiTranslation.
