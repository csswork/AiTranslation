v1.0.0
2026-09-15

Première version

  • Traduction par sélection : sélectionnez un texte non chinois, puis faites un clic droit pour le traduire ; la traduction s’affiche en flux dans une fenêtre au centre de l’écran. Si le texte sélectionné est déjà en chinois, l’entrée de menu n’apparaît pas.
  • Traduction d’éléments : faites un clic droit sur une zone de la page pour y attacher un bouton de traduction ; un clic remplace le texte de la zone sur place. Les règles sont mémorisées par domaine et peuvent être gérées depuis la page de gestion.
  • Traduction d’images : faites un clic droit sur une image pour reconnaître le texte qu’elle contient ; la traduction est replacée sur l’image d’origine aux positions détectées. Les images longues sont d’abord découpées selon leur contenu, les jointures évitant les lignes de texte.
  • Panneau de traduction : une page autonome, texte source à gauche et traduction à droite ; la langue cible est libre.
  • Compatible avec les API de ChatGPT (OpenAI), DeepSeek et DeepL, avec un changement de plateforme possible à tout moment depuis la fenêtre ou la page de paramètres.
  • L’API Key est conservée dans chrome.storage.local et n’est pas synchronisée avec votre compte Chrome.
