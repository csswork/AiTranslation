Une extension Chrome. Le texte étranger d’une page, des zones entières, et même le texte contenu dans les images : tout est traduit en chinois sur place. La traduction apparaît mot après mot, en flux, avec votre propre API Key — sans passer par aucun serveur.

Features

Quatre entrées, toutes dans le menu contextuel

Pas besoin de changer d’onglet ni de copier-coller. Là où se trouve le passage que vous ne comprenez pas, la traduction s’y produit.

01

Traduction par sélection

Sélectionnez un passage en langue étrangère, faites un clic droit et choisissez « Traduire en chinois » ; la traduction apparaît mot après mot dans une fenêtre au centre de l’écran.

  • Si la sélection est déjà en chinois, l’entrée de menu n’apparaît pas ; il en va de même pour les nombres, la ponctuation et les emojis seuls
  • La fenêtre est centrée et déplaçable, se ferme avec Esc ou un clic sur l’arrière-plan — pas une petite bulle qui suit le curseur
  • Un panneau de texte source repliable pour lire en regard de la traduction
  • Un raccourci clavier existe aussi : Alt+Shift+T (sur macOS : Command+Shift+Y)
Vidéo de démonstration (emplacement réservé) assets/demo-selection.mp4

02

Traduction d’éléments

Faites un clic droit sur une zone de la page pour y attacher un bouton de traduction. Un clic, et le texte de la zone est remplacé sur place par sa traduction en chinois.

  • Les règles sont mémorisées par domaine : la prochaine fois que vous revenez sur le même site, le bouton s’attache automatiquement
  • Les contenus longs sont envoyés par lots et remplacés au fil de la traduction, sans attendre que tout le bloc soit terminé
  • Les règles enregistrées peuvent être consultées et supprimées une par une depuis la page de gestion
Vidéo de démonstration (emplacement réservé) assets/demo-element.mp4

03

Traduction d’images

Faites un clic droit sur une image, reconnaissez le texte qu’elle contient, puis replacez la traduction sur l’image d’origine aux positions détectées.

  • Les images longues sont découpées en blocs avant la reconnaissance, les jointures étant automatiquement déplacées vers les lignes vides entre les textes, pour ne jamais couper une phrase en deux
  • Avant l’envoi, les images sont redimensionnées selon le nombre total de pixels et non selon le côté le plus long : la largeur d’une image longue n’est pas écrasée
  • Le résultat s’ouvre dans une fenêtre séparée, à comparer avec l’image d’origine
Vidéo de démonstration (emplacement réservé) assets/demo-image.mp4

04

Panneau de traduction

Une page autonome : le texte source à gauche, la traduction à droite, idéale pour les passages qui ne se trouvent pas sur une page web.

  • Une douzaine de langues cibles disponibles, pas seulement le chinois
  • Détecte automatiquement la langue d’entrée : le chinois est traduit par défaut en anglais, toutes les autres langues en chinois
  • La plateforme et la langue cible sont dans la barre d’outils ; vous pouvez changer et retraduire à tout moment
Vidéo de démonstration (emplacement réservé) assets/demo-panel.mp4

Privacy

Pas de serveur, rien à divulguer

Le contenu ne quitte votre navigateur que lorsque vous déclenchez vous-même une traduction, et uniquement vers la plateforme que vous avez choisie. Ce n’est pas une promesse, c’est un fait que vous pouvez vérifier ligne par ligne dans le code source.

Un seul point de sortie

Toutes les requêtes vers une plateforme de traduction se trouvent dans un seul fichier, src/lib/providers.js, et ne partent que vers la plateforme sélectionnée dans vos paramètres. Aucun autre code n’envoie votre contenu où que ce soit.

Aucun serveur

L’auteur n’exploite aucun serveur et n’utilise ni statistiques, ni traçage, ni publicité, ni SDK tiers. Ce que vous traduisez nous est inconnu.

Votre clé reste sur votre machine

L’API Key est stockée dans chrome.storage.local, elle n’est pas synchronisée avec votre compte Chrome et sert uniquement à vous authentifier auprès de la plateforme que vous avez choisie. La désinstallation de l’extension la supprime également.

Tous les détails se trouvent dans la politique de confidentialité, ainsi que dans l’intégralité du code source, public sous GPL-3.0.

Install

Installation en quatre étapes

Actuellement chargée en mode développeur. Nécessite Chrome 116 ou une version ultérieure, ainsi qu’une API Key personnelle.

Récupérez le code source — téléchargez le fichier ZIP depuis GitHub et décompressez-le, ou faites directement git clone du dépôt.
Ouvrez la page des extensions — saisissez chrome://extensions/ dans la barre d’adresse, puis activez le « Mode développeur » en haut à droite.
Chargez l’extension — cliquez sur « Charger l’extension non empaquetée », puis sélectionnez le dossier que vous venez d’extraire.
Renseignez votre API Key — la page de paramètres s’ouvre automatiquement à la première installation. Choisissez la plateforme, collez la clé, puis cliquez sur « Tester la connexion » pour vérifier que tout fonctionne.

Compatible avec les API de ChatGPT (OpenAI) et de DeepSeek, que vous pouvez changer à tout moment. Les deux utilisent par défaut leur modèle le moins cher — la traduction est un travail fréquent et à entrées courtes, inutile de payer pour du haut de gamme.

Installez-la, puis oubliez-la

Jusqu’à la prochaine fois, où vous sélectionnerez un passage que vous ne comprenez pas.
