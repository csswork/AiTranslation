# Huaci · 划词

[English](../../README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Español](README.es.md) · **العربية**

**Huaci — مترجم بالذكاء الاصطناعي وقارئ ثنائي اللغة.** كان اسمه سابقًا «AI 划词翻译 / AI Translator»، وتغيّر الاسم في الإصدار 2.2.0 مع الاحتفاظ بمعرّفات الإضافة وصفحاتها في المتاجر.

اقرأ المقالات بلغات أخرى وترجم الصور وملفات PDF داخل المتصفح. اعرض النص الأصلي والترجمة بمحاذاة الفقرات، وانقر على كلمة مترجمة لاختيار صياغة بديلة، واحفظ المقالات مع ترجماتها على جهازك. يوفّر Huaci أيضًا ترجمة النص المحدد ومناطق الصفحة ولوحة ترجمة مستقلة. يمكنك استخدام مفتاح API الخاص بك أو خدمة الترجمة المستضافة بنظام الرصيد، دون مفتاح خاص.

[الموقع الرسمي](https://huaci.app/) · [متجر Chrome](https://chromewebstore.google.com/detail/ai-translator/hogimafgjmlpdlnepojgigjkhaccbcbj) · [إضافات Edge](https://microsoftedge.microsoft.com/addons/detail/mojcgjimlkkbohomcijkmoefpeekmohe) · [دليل الإضافة](../../apps/extension/README.md)

## معاينة

تعرض هذه اللقطات والتسجيلات **نسخة التطوير الحالية 2.2.0** المحمّلة في Chrome، مع استخدام نماذج فعلية للتعرّف والترجمة. يجري التحضير لإصدار القراءة ثنائية اللغة والصياغات البديلة وترجمة الصور وفق أشكال النصوص. راجع [دليل الإضافة](../../apps/extension/README.md#account-and-credits-hosted-mode) لمعرفة حالة التوفّر في المتاجر.

**التعرّف على النصوص في الصور وترجمتها:** اكتشف النص واعرض الترجمة فوقه وفق شكله، وقارنها بالأصل، وعدّل كل ترجمة على حدة، أو حدّد مناطق يدويًا.

## مكوّنات المشروع

مستودع واحد وثلاثة تطبيقات: موقع HTML على Vercel، وخادم خلفي على VPS، وإضافة للمتصفح.

| التطبيق | المجلد | بيئة التشغيل | الحالة |
| --- | --- | --- | --- |
| الموقع | [apps/web](../../apps/web/README.md) | Vercel | صفحات المنتج والخصوصية والشروط وسجل التغييرات بـ11 لغة؛ يستعلم رأس الصفحة عن حالة تسجيل الدخول من app.huaci.app |
| الخادم الخلفي | [apps/backend](../../apps/backend/README.md) | VPS | المصادقة وواجهتا المستخدم والإدارة وواجهة API للإضافة والتجربة للزوار والمحاسبة الدقيقة للرصيد وترجمة النصوص والصور المستضافة واشتراكات Creem؛ نُشرت النسخة الأولى |
| الإضافة | [apps/extension](../../apps/extension/README.md) | Chrome / Edge | إصدار المتاجر: 2.1.0. إصدار الشيفرة: 2.2.0، ويضيف القراءة ثنائية اللغة والصياغات البديلة وتفضيلات المصطلحات وترجمة الصور وفق أشكال النصوص؛ قيد التحضير للنشر |

## التطوير المحلي

تحتاج أدوات التطوير إلى Node.js 22 أو أحدث. وتحتاج معاينة الموقع وإنشاء حزم الإضافة أيضًا إلى Python 3. تتطلب الإضافة نفسها Chrome 116 أو أحدث. تستخدم عمليات بناء الموقع والإضافة واختبارهما المكتبات القياسية دون اعتماديات npm. للخادم الخلفي اعتماديات مستقلة (`cd apps/backend && npm ci`)، ويتطلب PostgreSQL محليًا. يتجاوز `npm test` اختبارات الخادم إذا لم تكن اعتمادياته مثبتة.

<div dir="ltr">

```sh
npm run dev                   # تشغيل الخدمات المحلية؛ Ctrl+C يوقفها معًا
npm test                      # اختبارات الموقع والإضافة
npm run test:web              # اختبارات الموقع فقط
npm run test:extension        # اختبارات الإضافة فقط
npm run dev:web               # http://localhost:8788
npm run build:web             # إنشاء صفحات الموقع بجميع اللغات
npm run check:web             # التحقق من ترجمات الموقع المُولّدة
npm run i18n:extension        # تحديث ترجمات واجهة الإضافة محليًا
npm run check:extension       # التحقق من ترجمات الإضافة المُولّدة
npm run package:extension     # dist/extension/ai-translation-<version>.zip
npm run package:edge          # dist/extension/ai-translation-edge-<version>.zip
npm run test:backend          # يتطلب قاعدة PostgreSQL باسم huaci_test
npm run migrate:backend       # تطبيق ترحيلات قاعدة بيانات الخادم
npm run dev:backend           # http://localhost:8787 — واجهة المستخدم
```

</div>

يشغّل `npm run dev` الخدمات التالية:

| الخدمة | العنوان |
| --- | --- |
| الخادم: واجهة المستخدم وAPI الإضافة واستدعاءات Creem؛ يطبّق الترحيلات المعلّقة قبل البدء | `http://localhost:8787` |
| واجهة الإدارة: عملية الخادم نفسها، مع الاختيار بحسب اسم المضيف | `http://admin.localhost:8787` |
| معاينة الموقع | `http://localhost:8788` |
| مراقبة ترجمات الواجهة؛ حمّل هذا المجلد كإضافة غير محزّمة في Chrome | `apps/extension` |

تُتجاوز الخدمات التي تكون منافذها مشغولة مع توضيح السبب. قبل تشغيل الخادم، نفّذ `npm ci` داخل `apps/backend` واضبط PostgreSQL المحلي وملف `apps/backend/.env.local`.

تظل نقطتا البدء المتوافقتان `bash test/run.sh` و`bash package.sh` متاحتين من جذر المستودع. ويمكن تشغيل سكربتات كل تطبيق من مجلده أيضًا.

في وضع المطوّر في Chrome، يجب أن يشير خيار **تحميل إضافة غير محزّمة** إلى **`apps/extension`** وليس جذر المستودع. قد يؤدي تغيير مسار إضافة التطوير إلى حصولها على معرّف جديد يستلزم إعادة الإعداد. أما تحديثات المتاجر فتستخدم صفحة الإضافة نفسها.

تقرأ أداة توليد ترجمات الواجهة ملف `apps/extension/.env.local` أولًا، وتستخدم `.env.local` في الجذر إذا لم يوجد. وتدعم أيضًا متغيرات بيئة العملية. لا حاجة إلى نقل المفاتيح الموجودة في ملف الجذر. تُحفظ مفاتيح API المستخدمة أثناء التشغيل فقط في `chrome.storage.local`. لا تدخل ملفات البيئة وأدوات الترجمة التطويرية في حزم الإضافة.

## النشر

- **موقع Vercel:** احتفظ بجذر المستودع بوصفه جذر مشروع Vercel. يبني `vercel.json` التطبيق `apps/web` وينشر `apps/web/public` فقط. يعمل سير عمل GitHub عند تغيير الموقع أو إعدادات Vercel أو نقاط بدء البناء المرتبطة بهما.

- **الخادم على VPS:** يُنشر `apps/backend` بصورة مستقلة، وخدمة الحسابات متاحة على `app.huaci.app`. لم تُنفّذ بعد خدمة تفريغ الصوت والفيديو المستضافة. يمكن ترجمة نصوص الترجمة المصاحبة المستخرجة مسبقًا باستخدام ترجمة النصوص المستضافة. راجع [تعليمات النشر](../../apps/backend/deploy/README.md).

- **إضافة المتصفح:** تُنشأ الحزم وتُنشر في المتاجر بصورة منفصلة. تقتصر محتويات ZIP على `manifest.json` و`src/` و`icons/` و`_locales/` وملف `LICENSE` في الجذر.

راجع [توثيق البنية](../architecture.md) لمعرفة المسؤوليات ومقابلات المجلدات القديمة وأولويات التطوير. توجد قواعد تطوير المستودع في [AGENTS.md](../../AGENTS.md).
