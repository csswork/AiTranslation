選取，按右鍵，
然後繼續閱讀。

一個 Chrome 擴充功能。網頁裡的外文、整塊區域、甚至圖片裡的文字，都能就地翻譯成中文。譯文會逐字串流出現，用的是你自己的 API Key——中間不經過任何伺服器。

安裝到 Chrome 檢視原始碼
Chrome 116+ 無伺服器 · 無統計 四種翻譯方式

Features

四個入口，都在右鍵選單裡

不用切換分頁，不用複製貼上。看不懂的那一段在哪裡，翻譯就發生在哪裡。

01

劃詞翻譯

選取一段非中文文字，按右鍵點選「翻譯成中文」，譯文會在螢幕中央的彈出視窗中逐字出現。

  • 選取的本來就是中文時，選單不會出現；純數字、標點、表情符號也是如此
  • 彈出視窗置中且可拖曳，按 Esc 或點擊背景即可關閉，不是追著游標跑的小氣泡
  • 可收合的原文面板，方便對照閱讀
  • 也有鍵盤快速鍵：Alt+Shift+T（macOS 為 Command+Shift+Y）
示範影片預留位置 assets/demo-selection.mp4

02

元素翻譯

在網頁上的某個區域按右鍵，為它掛上一個翻譯按鈕。點一下，區域裡的文字就會就地換成中文。

  • 規則會依網域記住，下次再來同一個網站，按鈕會自動掛上
  • 長內容分批送出，邊翻譯邊取代，不用等整塊完成
  • 累積的規則可以在管理頁面逐條查看和刪除
示範影片預留位置 assets/demo-element.mp4

03

圖片翻譯

在圖片上按右鍵，辨識圖片裡的文字，再把譯文依辨識到的位置覆蓋回原圖上。

  • 長圖會先切塊再辨識，切縫會自動移到文字之間的空白行，不會把一句話切成兩半
  • 送交辨識前依總像素縮放，而不是依最長邊，長圖的寬度不會被壓縮掉
  • 結果會在獨立視窗中開啟，可以和原圖對照觀看
示範影片預留位置 assets/demo-image.mp4

04

翻譯面板

一個獨立頁面，左邊貼原文、右邊輸出譯文，適合處理成段的、不在網頁上的文字。

  • 十餘種目標語言可選，不限於中文
  • 自動判斷輸入語言：中文預設翻譯成英文，其他語言預設翻譯成中文
  • 平台和目標語言就在工具列上，隨時切換重新翻譯
示範影片預留位置 assets/demo-panel.mp4

Privacy

沒有伺服器，就沒有可以洩漏的地方

只有你主動觸發翻譯時，內容才會送出，而且只傳往你自己選定的那家平台。這不是一句承諾，而是可以照著原始碼逐行核對的事實。

只有一個出口

所有傳往翻譯平台的請求都寫在 src/lib/providers.js 這一個檔案裡，只會傳往你在設定中選擇的那家平台。其餘程式碼不會把你的內容傳到任何地方。

沒有伺服器端

作者不營運任何伺服器，也沒有統計、追蹤、廣告或第三方 SDK。你翻譯過什麼，我們無從得知。

Key 留在本機

API Key 儲存在 chrome.storage.local，不透過 Chrome 帳號同步，僅用於向你選擇的平台驗證。移除擴充功能時會一併清除。

完整說明請見隱私權政策，以及 GPL-3.0 下公開的全部原始碼。

Install

四步裝好

目前以開發人員模式載入。需要 Chrome 116 或以上版本，以及一個你自己的 API Key。

取得原始碼 ——在 GitHub 上 Download ZIP 後解壓縮，或直接 git clone 儲存庫。
開啟擴充功能頁面 ——在網址列輸入 chrome://extensions/，開啟右上角的「開發人員模式」。
載入擴充功能 ——點選「載入未封裝項目」，選取剛才那個資料夾。
填入 API Key ——首次安裝時會自動開啟設定頁面。選好平台、貼上 Key，點選「測試連線」確認可以連線。

支援串接 ChatGPT（OpenAI）與 DeepSeek 的 API，隨時可以切換。兩者都預設選用各自最便宜的等級——翻譯是高頻率、短輸入的工作，沒必要用貴的。

裝好之後，就忘了它

直到下一次，你又選取了一段看不懂的文字。
