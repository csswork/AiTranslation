隱私權政策

最後更新：2026-09-30 · Markdown 原稿

一句話總結

本擴充功能不會收集、儲存或上傳任何使用者資料到我們的伺服器——我們沒有伺服器。 你要翻譯的內容，只會傳送到你自己設定的那家 AI 平台。

會傳送出去的內容

只有在你主動觸發翻譯時（右鍵選單、快速鍵、點擊翻譯按鈕）， 下列內容才會透過 HTTPS 傳送到你在設定中選擇的平台：

內容傳送時機傳送至
你選取的文字使用劃詞翻譯時你選擇的平台
你指定區域內的文字點擊元素上的翻譯按鈕時同上
你按右鍵的那張圖片使用圖片翻譯時同上
你在翻譯面板輸入的文字點擊翻譯時同上

可選的平台為 OpenAI（ChatGPT）、DeepSeek 與 DeepL，請求分別傳往 https://api.openai.com、https://api.deepseek.com， 以及 DeepL 的 https://api-free.deepl.com（付費 Key 為 https://api.deepl.com）。 這些內容如何被處理，適用該平台本身的隱私權政策：

  • OpenAI：openai.com/policies/privacy-policy
  • DeepSeek：platform.deepseek.com/downloads
  • DeepL：deepl.com/en/privacy

不會傳送：你沒有主動翻譯的頁面內容、瀏覽記錄、Cookie、表單資料。 擴充功能不會在背景自動掃描或上傳任何東西。

只儲存在你本機的內容

下列資料透過 chrome.storage.local 儲存在你這台裝置上， 不透過 Chrome 帳號同步，不會離開你的瀏覽器：

  • API Key —— 僅用於在請求標頭中向你選擇的平台驗證
  • 偏好設定 —— 目標語言、使用的模型、各項開關
  • 元素翻譯規則 —— 你手動新增的「網域 + CSS 選擇器」

你可以隨時在設定頁面清除這些資料，或直接移除擴充功能（移除時會一併刪除）。

我們不做的事

  • 不架設任何伺服器，不收集任何資料
  • 不使用統計、追蹤、廣告或任何第三方 SDK
  • 不出售、不出租、不分享任何資料給第三方
  • 不用於信用評估或與擴充功能無關的用途

擴充功能的全部原始碼以 GPL-3.0 公開，可自行核實： github.com/csswork/AiTranslation。

權限說明

權限用途
contextMenus在右鍵選單提供翻譯入口
storage在本機儲存上述設定
scripting在你觸發翻譯時，將所需指令碼注入目前頁面
activeTab僅作用於你目前操作的那個分頁
存取 api.openai.com、api.deepseek.com、api-free.deepl.com、api.deepl.com 向你選定的平台傳送翻譯請求
選用：存取你自己的 API 網域 僅當你填寫了自訂 API 位址（代理或中繼）時申請，且只申請那一個網域；在點擊「測試連線」時彈出授權，不會申請所有網站
內容指令碼符合所有網站 你可能在任何網頁上劃詞翻譯；且需要在按右鍵之前判斷選取文字是否為中文，以決定選單是否出現
