Una extensión de Chrome. El texto en otro idioma de las páginas, zonas enteras e incluso el texto de las imágenes se traducen en el mismo lugar. La traducción aparece palabra por palabra, en streaming, con tu propia API Key y sin pasar por ningún servidor.

Features

Cuatro accesos, todos en el menú contextual

Sin cambiar de pestaña ni copiar y pegar. Donde esté el fragmento que no entiendes, ahí ocurre la traducción.

01

Traducción por selección

Selecciona un fragmento de texto que no esté en chino y haz clic derecho en «Traducir al chino»; la traducción aparece palabra por palabra en una ventana en el centro de la pantalla.

  • Si lo seleccionado ya está en chino, la opción no aparece; lo mismo ocurre con números, signos de puntuación y emojis
  • La ventana está centrada y se puede arrastrar; se cierra con Esc o con un clic en el fondo, y no es una burbuja que persigue el cursor
  • Un panel plegable con el original para leerlo en paralelo
  • También hay atajos de teclado: Alt+Shift+T (en macOS, Command+Shift+Y)
Marcador del vídeo de demostración assets/demo-selection.mp4

02

Traducción de elementos

Haz clic derecho en una zona de la página para ponerle un botón de traducción. Con un clic, el texto de la zona se sustituye en el mismo lugar.

  • Las reglas se recuerdan por dominio, así que la próxima vez que visites el mismo sitio el botón se coloca automáticamente
  • El contenido largo se envía por lotes y se va sustituyendo a medida que se traduce, sin esperar a que termine todo
  • Las reglas guardadas se pueden revisar y eliminar una a una en la página de administración
Marcador del vídeo de demostración assets/demo-element.mp4

03

Traducción de imágenes

Haz clic derecho en una imagen para reconocer el texto que contiene y superpón la traducción en las posiciones detectadas.

  • Las imágenes largas se dividen en bloques antes del reconocimiento y los cortes se desplazan a las líneas en blanco entre textos, para no partir una frase en dos
  • Antes de analizarlas, las imágenes se escalan por píxeles totales y no por el lado más largo, así que la anchura de una imagen larga no se pierde
  • El resultado se abre en una ventana aparte para que lo compares con la imagen original
Marcador del vídeo de demostración assets/demo-image.mp4

04

Panel de traducción

Una página independiente: pega el original a la izquierda y obtén la traducción a la derecha; ideal para párrafos que no están en una página web.

  • Más de diez idiomas de destino disponibles, no solo chino
  • Detecta el idioma de entrada: el chino se traduce al inglés por defecto y los demás idiomas, al chino
  • La plataforma y el idioma de destino están en la barra de herramientas; cámbialos y vuelve a traducir cuando quieras

Privacy

Sin servidores no hay nada que filtrar

El contenido solo sale cuando tú inicias la traducción, y solo hacia la plataforma que hayas elegido. No es una promesa: es un hecho que puedes comprobar línea por línea en el código fuente.

Una única salida

Todas las solicitudes a las plataformas de traducción están en un único archivo, src/lib/providers.js, y solo se envían a la plataforma que hayas seleccionado en los ajustes. Ningún otro código envía tu contenido a ninguna parte.

Sin backend

El autor no opera ningún servidor y no usa estadísticas, telemetría, publicidad ni SDK de terceros. Lo que traduces es algo que aquí no podemos saber.

La clave de API se queda en tu dispositivo

La API Key se guarda en chrome.storage.local, no se sincroniza con tu cuenta de Chrome y solo se usa para autenticar tus solicitudes a la plataforma que elijas. Al desinstalar la extensión se elimina también.

Encontrarás la explicación completa en la política de privacidad y en el código fuente completo, público bajo GPL-3.0.

Install

Instálala en cuatro pasos

Por ahora se carga en modo de desarrollador. Requiere Chrome 116 o posterior y tu propia API Key.

Consigue el código — descarga el ZIP desde GitHub y descomprímelo, o haz directamente git clone del repositorio.
Abre la página de extensiones — escribe chrome://extensions/ en la barra de direcciones y activa el «Modo de desarrollador» de la esquina superior derecha.
Cargar la extensión — haz clic en «Cargar descomprimida» y selecciona la carpeta que acabas de extraer.
Introduce tu API Key — la primera vez que instales la extensión se abrirá la página de ajustes. Elige la plataforma, pega la clave de API y pulsa «Probar conexión» para comprobar que funciona.

Compatible con las API de ChatGPT (OpenAI) y DeepSeek, y puedes cambiar entre ambas cuando quieras. Las dos usan por defecto su modelo más económico: traducir es una tarea frecuente y de textos cortos, así que no hace falta pagar por los caros.
