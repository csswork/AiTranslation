Privacy policy

Política de privacidade

Última atualização: 2026-09-30 · Original em Markdown

Em uma frase

Esta extensão não coleta, não armazena e não envia qualquer dado de usuário aos nossos servidores — não temos servidor. O conteúdo que você pede para traduzir é enviado apenas ao provedor de IA que você mesmo configurou.

O que é enviado

Somente quando você aciona uma tradução (menu de contexto, atalho de teclado ou clique em um botão de tradução) o conteúdo a seguir é enviado por HTTPS ao provedor que você selecionou nas configurações:

ConteúdoQuandoEnviado para
O texto que você selecionouAo usar a tradução de seleçãoO provedor que você escolheu
O texto dentro da área que você marcouAo clicar no botão de tradução do elementoIdem
A imagem em que você clicou com o botão direitoAo usar a tradução de imagensIdem
O texto que você digita no painel de traduçãoAo clicar em traduzirIdem

Os provedores disponíveis são OpenAI (ChatGPT), DeepSeek e DeepL; as solicitações vão para https://api.openai.com, https://api.deepseek.com e, no caso do DeepL, para https://api-free.deepl.com (com uma chave paga, https://api.deepl.com). Como esse conteúdo é tratado é regido pela política de privacidade de cada provedor:

  • OpenAI：openai.com/policies/privacy-policy
  • DeepSeek：platform.deepseek.com/downloads
  • DeepL：deepl.com/en/privacy

Nunca são enviados: conteúdo de páginas que você não pediu para traduzir, histórico de navegação, cookies e dados de formulários. A extensão não varre nem envia nada em segundo plano.

O que fica no seu computador

Os dados a seguir, por meio de chrome.storage.local, são salvos em seu dispositivo. Eles não são sincronizados com a sua conta do Chrome e nunca saem do seu navegador:

  • Chave de API — usada apenas para autenticar as solicitações ao provedor que você escolheu
  • Preferências — idioma de destino, modelo usado e opções de ativação
  • Regras de tradução de elementos — as entradas de "domínio + seletor CSS" que você adicionou manualmente

Você pode apagar todos esses dados na página de configurações a qualquer momento, ou simplesmente desinstalar a extensão (a desinstalação remove tudo).

O que não fazemos

  • Nenhum servidor, nenhuma coleta de dados
  • Nenhum uso de estatísticas, rastreamento, publicidade ou SDK de terceiros
  • Nenhuma venda, aluguel ou compartilhamento de dados com terceiros
  • Nenhum uso para avaliação de crédito ou para finalidades sem relação com as funções da extensão

O código-fonte completo da extensão é público sob a GPL-3.0, para você verificar por conta própria: github.com/csswork/AiTranslation.
