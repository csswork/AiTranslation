Uma extensão para o Chrome. Texto em outro idioma na página, áreas inteiras e até texto dentro de imagens — tudo traduzido no lugar. A tradução aparece palavra por palavra, usando a sua própria chave de API, sem nenhum servidor no meio.

Features

Quatro pontos de entrada, todos no menu de contexto

Sem trocar de aba, sem copiar e colar. Onde estiver o trecho que você não entende, é ali que a tradução acontece.

01

Tradução de seleção

Selecione um trecho de texto que não esteja em chinês, clique com o botão direito e escolha "Traduzir para chinês"; a tradução aparece palavra por palavra em uma janela no centro da tela.

  • Se o texto selecionado já estiver em chinês, o item de menu não aparece; o mesmo vale para números, pontuação e emojis
  • A janela fica centralizada e pode ser arrastada; fecha com Esc ou com um clique no fundo — não é um balãozinho que segue o cursor
  • Um painel recolhível com o texto original para ler lado a lado
  • Também há um atalho de teclado: Alt+Shift+T (no macOS, Command+Shift+Y)
Vídeo de demonstração (espaço reservado) assets/demo-selection.mp4

02

Tradução de elementos

Clique com o botão direito em uma área da página para anexar a ela um botão de tradução. Com um clique, o texto da área é substituído no lugar.

  • As regras são lembradas por domínio; na próxima vez que você visitar o mesmo site, o botão é anexado automaticamente
  • Conteúdos longos são enviados em lotes e substituídos à medida que são traduzidos; você não precisa esperar o bloco inteiro
  • As regras salvas podem ser consultadas e excluídas uma a uma na página de gerenciamento
Vídeo de demonstração (espaço reservado) assets/demo-element.mp4

03

Tradução de imagens

Clique com o botão direito em uma imagem para reconhecer o texto nela e depois sobrepor a tradução à imagem original nas posições detectadas.

  • Imagens longas são divididas em blocos antes do reconhecimento, e os cortes são movidos automaticamente para as linhas em branco entre os textos, sem partir uma frase ao meio
  • As imagens são redimensionadas pelo total de pixels em vez da maior aresta, então a largura de uma imagem longa não é comprimida a ponto de sumir
  • O resultado abre em uma janela separada, para você comparar com a imagem original
Vídeo de demonstração (espaço reservado) assets/demo-image.mp4

04

Painel de tradução

Uma página independente, com o original à esquerda e a tradução à direita, ideal para trechos de texto que não estão em uma página web.

  • Mais de dez idiomas de destino disponíveis, não apenas chinês
  • Detecta automaticamente o idioma de entrada: chinês é traduzido para inglês por padrão, e os demais idiomas para chinês
  • O provedor e o idioma de destino ficam na barra de ferramentas; alterne e traduza de novo quando quiser

Privacy

Sem servidor, não há nada para vazar

O conteúdo só sai do seu navegador quando você aciona uma tradução, e apenas para o provedor que você escolheu. Isso não é uma promessa — é um fato que você pode conferir linha por linha no código-fonte.

Um único ponto de saída

Todas as solicitações aos provedores de tradução ficam em um único arquivo, src/lib/providers.js, e vão apenas para o provedor selecionado nas suas configurações. Nenhum outro trecho de código envia seu conteúdo a lugar algum.

Sem backend

O autor não opera nenhum servidor e não usa estatísticas, rastreamento, publicidade nem SDK de terceiros. O que você traduziu é algo que não temos como saber.

A chave fica no seu computador

A chave de API é armazenada em chrome.storage.local, não é sincronizada com a sua conta do Chrome e serve apenas para autenticar as solicitações ao provedor que você escolheu. Desinstalar a extensão também a remove.

Veja os detalhes completos na Política de privacidade e no código-fonte completo, público sob a GPL-3.0.

Install

Instale em quatro passos

No momento, ela é carregada no modo de desenvolvedor. Requer Chrome 116 ou superior e uma chave de API sua.

Obtenha o código-fonte — baixe o ZIP no GitHub e descompacte, ou use git clone no repositório.
Abra a página de extensões — digite chrome://extensions/ na barra de endereços e ative o "Modo do desenvolvedor" no canto superior direito.
Carregar a extensão — clique em "Carregar sem compactação" e selecione a pasta que você acabou de extrair.
Informe a chave de API — a página de configurações abre na primeira instalação. Escolha o provedor, cole a chave e clique em "Testar conexão" para confirmar que funciona.

Compatível com as APIs do ChatGPT (OpenAI) e do DeepSeek, com troca a qualquer momento. Ambos usam por padrão o nível mais barato de cada um — tradução é um trabalho frequente e de entradas curtas, não há por que pagar por modelos caros.
