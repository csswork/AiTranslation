선택하고, 오른쪽 버튼,
그리고 계속 읽습니다.

Chrome 확장 프로그램입니다. 웹페이지의 외국어, 영역 전체, 심지어 이미지 속 텍스트까지 그 자리에서 중국어로 번역합니다. 번역문은 한 글자씩 스트리밍으로 나타나며, 직접 준비한 API 키를 사용하고 중간에 어떤 서버도 거치지 않습니다.

Chrome에 설치 소스 보기
Chrome 116+ 서버 없음 · 통계 없음 네 가지 번역 방식

Features

네 가지 진입점, 모두 마우스 오른쪽 버튼 메뉴에

탭을 전환할 필요도, 복사해서 붙여 넣을 필요도 없습니다. 이해하지 못한 문단이 있는 곳에서 바로 번역이 이루어집니다.

01

선택 번역

중국어가 아닌 문장을 선택하고 마우스 오른쪽 버튼으로 “중국어로 번역”을 누르면, 번역문이 화면 중앙 팝업에 한 글자씩 나타납니다.

  • 선택한 텍스트가 원래 중국어이면 메뉴가 나타나지 않으며, 숫자, 문장 부호, 이모지도 마찬가지입니다
  • 팝업은 화면 중앙에 있고 드래그할 수 있으며 Esc 또는 배경 클릭으로 닫힙니다. 커서를 따라다니는 작은 말풍선이 아닙니다
  • 접을 수 있는 원문 패널로 나란히 읽습니다
  • 단축키도 있습니다: Alt+Shift+T(macOS는 Command+Shift+Y)
데모 영상 자리 표시자 assets/demo-selection.mp4

02

요소 번역

페이지의 특정 영역을 마우스 오른쪽 버튼으로 클릭해 번역 버튼을 붙입니다. 한 번 누르면 영역 안의 텍스트가 그 자리에서 중국어로 바뀝니다.

  • 규칙은 도메인별로 기억되므로 다음에 같은 사이트에 오면 버튼이 자동으로 붙습니다
  • 긴 내용은 나누어 보내고 번역되는 대로 교체하므로 영역 전체가 끝날 때까지 기다릴 필요가 없습니다
  • 저장된 규칙은 관리 페이지에서 하나씩 확인하고 삭제할 수 있습니다
데모 영상 자리 표시자 assets/demo-element.mp4

03

이미지 번역

이미지를 마우스 오른쪽 버튼으로 클릭해 이미지 속 텍스트를 인식하고, 번역문을 인식된 위치에 맞춰 원본 이미지 위에 덮어씁니다.

  • 긴 이미지는 먼저 분할한 뒤 인식하며, 이음매는 텍스트 사이의 빈 줄로 자동 이동해 한 문장이 두 동강 나지 않습니다
  • 검사 전에 가장 긴 변이 아니라 총픽셀 기준으로 축소하므로 긴 이미지의 너비가 사라지지 않습니다
  • 결과는 별도 창에서 열려 원본 이미지와 나란히 볼 수 있습니다
데모 영상 자리 표시자 assets/demo-image.mp4

04

번역 패널

왼쪽에 원문을 붙여 넣으면 오른쪽에 번역문이 나오는 독립된 페이지로, 웹페이지에 없는 문단 단위 텍스트를 다루기에 적합합니다.

  • 중국어를 포함해 십여 가지 대상 언어를 선택할 수 있습니다
  • 입력 언어를 자동으로 판단합니다: 중국어는 기본적으로 영어로, 다른 언어는 기본적으로 중국어로 번역합니다
  • 플랫폼과 대상 언어는 도구 모음에 있어 언제든 전환해 다시 번역할 수 있습니다

Privacy

서버가 없으면 유출될 곳도 없습니다

직접 번역을 실행할 때만 내용이 전송되며, 직접 선택한 플랫폼으로만 전송됩니다. 이것은 약속이 아니라 소스를 한 줄씩 확인할 수 있는 사실입니다.

출구는 하나뿐

번역 플랫폼으로 가는 모든 요청은 src/lib/providers.js 한 파일에 작성되어 있으며, 설정에서 선택한 플랫폼으로만 전송됩니다. 나머지 코드는 내용을 어디에도 보내지 않습니다.

서버 없음

제작자는 어떤 서버도 운영하지 않으며 통계, 추적, 광고, 제3자 SDK도 없습니다. 무엇을 번역했는지 이쪽에서는 알 수 없습니다.

키는 내 기기에 보관

API 키는 chrome.storage.local에 저장되고 Chrome 계정으로 동기화되지 않으며, 선택한 플랫폼의 인증에만 사용됩니다. 확장 프로그램을 삭제하면 함께 지워집니다.

전체 설명은 개인정보 처리방침과 GPL-3.0으로 공개된 전체 소스에서 확인할 수 있습니다.

Install

네 단계로 설치

현재 개발자 모드로 로드합니다. Chrome 116 이상과 직접 준비한 API 키가 필요합니다.

소스 받기 ——GitHub에서 Download ZIP으로 받아 압축을 풀거나, git clone으로 저장소를 복제합니다.
확장 페이지 열기 ——주소 표시줄에 chrome://extensions/를 입력하고 오른쪽 위의 “개발자 모드”를 켭니다.
확장 프로그램 로드 ——“압축해제된 확장 프로그램을 로드합니다”를 클릭하고 방금 그 폴더를 선택합니다.
API 키 입력 ——처음 설치하면 설정 페이지가 자동으로 열립니다. 플랫폼을 고르고 키를 붙여 넣은 뒤 “연결 테스트”를 눌러 정상 동작을 확인합니다.

ChatGPT(OpenAI)와 DeepSeek API를 연동할 수 있으며 언제든 전환할 수 있습니다. 둘 다 기본적으로 각자의 가장 저렴한 등급을 사용합니다. 번역은 빈도가 높고 입력이 짧은 작업이므로 비싼 모델을 쓸 필요가 없습니다.
