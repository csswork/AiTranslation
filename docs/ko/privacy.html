Privacy policy

개인정보 처리방침

최종 업데이트: 2026-09-30 · Markdown 원문

한 문장 요약

이 확장 프로그램은 어떤 사용자 데이터도 수집, 저장, 업로드하지 않습니다——저희는 서버가 없습니다. 번역할 내용은 직접 설정한 AI 플랫폼으로만 전송됩니다.

전송되는 내용

직접 번역을 실행할 때(마우스 오른쪽 버튼 메뉴, 단축키, 번역 버튼 클릭)만 다음 내용이 HTTPS를 통해 설정에서 선택한 플랫폼으로 전송됩니다:

내용전송 시점전송 대상
선택한 텍스트선택 번역 사용 시선택한 플랫폼
지정한 영역 안의 텍스트요소의 번역 버튼을 클릭할 때위와 같음
마우스 오른쪽 버튼을 누른 이미지이미지 번역 사용 시위와 같음
번역 패널에 입력한 텍스트번역을 클릭할 때위와 같음

선택할 수 있는 플랫폼은 OpenAI(ChatGPT), DeepSeek, DeepL이며, 요청은 각각 https://api.openai.com, https://api.deepseek.com, 그리고 DeepL의 https://api-free.deepl.com(유료 키는 https://api.deepl.com)로 전송됩니다. 이 내용이 어떻게 처리되는지는 해당 플랫폼의 개인정보 처리방침을 따릅니다:

  • OpenAI：openai.com/policies/privacy-policy
  • DeepSeek：platform.deepseek.com/downloads
  • DeepL：deepl.com/en/privacy

전송하지 않습니다: 직접 번역을 요청하지 않은 페이지 내용, 방문 기록, 쿠키, 양식 데이터. 확장 프로그램은 백그라운드에서 아무것도 자동으로 검사하거나 업로드하지 않습니다.

내 기기에만 저장되는 내용

다음 데이터는 chrome.storage.local을 통해 이 기기에 저장되며, Chrome 계정으로 동기화되지 않고 브라우저를 벗어나지 않습니다:

  • API 키 —— 선택한 플랫폼의 요청 헤더 인증에만 사용합니다
  • 환경 설정 —— 대상 언어, 사용하는 모델, 각종 스위치
  • 요소 번역 규칙 —— 직접 추가한 “도메인 + CSS 선택자”

설정 페이지에서 언제든지 이 데이터를 지울 수 있으며, 확장 프로그램을 삭제해도 됩니다(삭제하면 함께 지워집니다).

하지 않는 일

  • 어떤 서버도 운영하지 않고, 어떤 데이터도 수집하지 않습니다
  • 통계, 추적, 광고 또는 어떠한 제3자 SDK도 사용하지 않습니다
  • 어떠한 데이터도 제3자에게 판매, 대여, 공유하지 않습니다
  • 신용 평가나 확장 프로그램 기능과 무관한 용도로 사용하지 않습니다

확장 프로그램의 전체 소스 코드는 GPL-3.0으로 공개되어 있으니 직접 확인할 수 있습니다: github.com/csswork/AiTranslation.

권한 설명

권한용도
contextMenus마우스 오른쪽 버튼 메뉴에 번역 진입점 제공
storage위 설정을 로컬에 저장
scripting번역을 실행할 때 현재 페이지에 필요한 스크립트 주입
activeTab현재 작업 중인 탭에만 적용됩니다
접근: api.openai.com, api.deepseek.com, api-free.deepl.com, api.deepl.com 선택한 플랫폼으로 번역 요청 전송
선택 사항: 사용자 API 도메인 접근 사용자 지정 API 주소(프록시 또는 중계)를 입력한 경우에만 요청하며, 그 도메인 하나만 요청합니다. “연결 테스트”를 클릭할 때 권한 창이 뜨고, 모든 사이트를 요청하지는 않습니다
모든 사이트에 콘텐츠 스크립트 적용 모든 웹페이지에서 선택 번역을 사용할 수 있으며, 메뉴 표시 여부를 정하기 위해 오른쪽 버튼을 누르기 전에 선택한 텍스트가 중국어인지 판단해야 합니다
