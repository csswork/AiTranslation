v1.0.0
2026-09-15

첫 번째 버전

  • 선택 번역: 중국어가 아닌 텍스트를 선택한 뒤 마우스 오른쪽 버튼으로 번역하면, 번역문이 화면 중앙 팝업에 스트리밍으로 표시됩니다. 선택한 텍스트가 중국어이면 메뉴가 나타나지 않습니다.
  • 요소 번역: 페이지의 특정 영역을 마우스 오른쪽 버튼으로 클릭해 번역 버튼을 붙이고, 클릭하면 영역 안의 텍스트가 그 자리에서 바뀝니다. 규칙은 도메인별로 기억되며 관리 페이지에서 유지할 수 있습니다.
  • 이미지 번역: 이미지를 마우스 오른쪽 버튼으로 클릭해 안의 텍스트를 인식하고, 번역문을 인식된 위치에 맞춰 원본 이미지 위에 덮어씁니다. 긴 이미지는 내용에 따라 먼저 분할하며, 이음매는 텍스트 줄을 피합니다.
  • 번역 패널: 독립된 페이지로 왼쪽에 원문, 오른쪽에 번역문이 표시되며 대상 언어를 자유롭게 고를 수 있습니다.
  • ChatGPT(OpenAI), DeepSeek, DeepL API를 연동할 수 있으며 팝업이나 설정 페이지에서 언제든 전환할 수 있습니다.
  • API 키는 chrome.storage.local에 저장되며 Chrome 계정으로 동기화되지 않습니다.
