# 2.3.0 发布记录

日期：2026-11-15。发布前源码基线：`b25f9b9`，在 `main` 分支准备，开始时工作区干净。

## 更新内容

- 本机文字翻译与浏览器语言包管理：免费、免 Key、不计点，下载完成后离线可用。浏览器和设备需支持内置 Translator；不支持识图和换说法。

- 中文与其他语言译文风格指南，沿用此前提交的评测结果；本次发布未更改模型、提示词或参数。
- 图片自动形状、字号、对齐、竖排、背景处理；单段编辑、拖动、调字号、重翻、音效字、缓存与图片切换。
- 已保存文章的拖动和键盘排序，以及演示、实机截图和多语言文档。

主要提交：`816ede0`、`48c0697`（本机翻译），`8a43308`（整站翻译），`71141b5`、`5920db4`、`631e71a`（图片），`d418afb`、`b25f9b9`（评测与风格指南），`1dd9904`（阅读列表）。

## 商店可读性警告

Chrome 于 2026-11-10 对 2.2.0 发出 Red Titanium 警告，指出 `src/vendor/pdfjs/pdf.min.mjs` 和 `pdf.worker.min.mjs` 的代码可读性问题，要求以可读代码重新提交。本次改用 **同版本 `pdfjs-dist@6.3.289` 官方未压缩 legacy** `pdf.mjs`、`pdf.worker.mjs`，附 source map，并同步加载路径。其余保留文件从同一官方 npm 发行包整目录重新复制，不手改供应商代码，不放开 CSP。来源和校验值见 vendor README。

警告是否解除须由 Chrome 审核确认，不能把本地替换描述为商店已认可。

## 2026-11-17 Chrome 草稿拒审与修正

- Chrome 于 2026-11-17 拒绝 2.3.0 草稿（Status：Rejection，Violation reference ID：**Red Titanium**）。邮件点名 `src/vendor/pdfjs/pdf.mjs` 里 legacy 构建打包的 core-js 垫片（`NullProtoObjectViaActiveX` / `NullProtoObjectViaIFrame`，拼接 `'java' + SCRIPT + ':'`），worker 里也有同类代码。
- 修正：改用同版本 `pdfjs-dist@6.3.289` **标准构建** `build/pdf.mjs`、`build/pdf.worker.mjs` 及 source map（不含 core-js，原样复制）；删除单行压缩的 `wasm/*_nowasm_fallback.js` 及其许可证，JPEG 2000 / JBIG2 图片不再解码，不影响文字提取。
- 标准构建所需、Chrome 128 尚无的 API 由扩展自己的可读文件 `src/pdf/compat.js` 补上（`Map`/`WeakMap` 的 `getOrInsert(Computed)`、`Math.sumPrecise`、`Uint8Array` Base64/十六进制、`Response`/`Blob` 的 `bytes()`）；worker 入口改为 `src/pdf/worker.mjs`。`minimum_chrome_version` 由 116 提升到 **128**，商店长介绍与 README 同步；官网的「116+」等扩展上架后再改。
- 验证：Node 中删除上述 API 后加载 `compat.js` 与标准构建，单页 PDF 解析、指纹与文字提取通过；Chrome for Testing 端到端 `tools/capture/pdf-e2e.mjs`（解析、翻译、渲染、导出）通过且控制台无错误；`npm test` 全部通过。未在真实 Chrome 128 上实测。
- 新 Chrome ZIP：`dist/extension/ai-translation-2.3.0.zip`，335 个条目，4,544,512 字节，SHA-256 `033835063157bc0afdc9e2ae52daf88e203816b194957c63da85020f30f09246`。包内已无 core-js、`*.min.mjs` 与 `wasm/` 回退文件；`pdf.worker.mjs` 仍有上游的字体数据长行（旧包里同样存在，未被点名）。
- Edge 2.3.0 仍是送审中的 legacy 构建包，本次未重新打包 Edge。
