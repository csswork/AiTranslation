# 2.3.0 发布记录

日期：2026-11-15。发布前源码基线：`b25f9b9`，在 `main` 分支准备，开始时工作区干净。

## 更新内容

- 本机文字翻译与浏览器语言包管理：免费、免 Key、不计点，下载完成后离线可用。浏览器和设备需支持内置 Translator；不支持识图和换说法。
- 用户明确启用的网站自动翻译：视口附近处理、重复文字复用、目标语言跳过、收费平台首次确认、可单独选择平台。
- 中文与其他语言译文风格指南，沿用此前提交的评测结果；本次发布未更改模型、提示词或参数。
- 图片自动形状、字号、对齐、竖排、背景处理；单段编辑、拖动、调字号、重翻、音效字、缓存与图片切换。
- 已保存文章的拖动和键盘排序，以及演示、实机截图和多语言文档。

主要提交：`816ede0`、`48c0697`（本机翻译），`8a43308`（整站翻译），`71141b5`、`5920db4`、`631e71a`（图片），`d418afb`、`b25f9b9`（评测与风格指南），`1dd9904`（阅读列表）。

## 商店可读性警告

Chrome 于 2026-11-10 对 2.2.0 发出 Red Titanium 警告，指出 `src/vendor/pdfjs/pdf.min.mjs` 和 `pdf.worker.min.mjs` 的代码可读性问题，要求以可读代码重新提交。本次改用 **同版本 `pdfjs-dist@6.3.289` 官方未压缩 legacy** `pdf.mjs`、`pdf.worker.mjs`，附 source map，并同步加载路径。其余保留文件从同一官方 npm 发行包整目录重新复制，不手改供应商代码，不放开 CSP。来源和校验值见 vendor README。

警告是否解除须由 Chrome 审核确认，不能把本地替换描述为商店已认可。
