# 2.4.0 发布记录

日期：2026-11-23。在 `main` 准备；版本号、更新日志、商店资料与安装包均未提交到 git（由用户提交）。

## 更新内容（对外说明）

对外的更新说明只写下面两项，以本机译文缓存为重点：

- **本机译文缓存**：自带 Key（OpenAI 兼容大模型）与 DeepL 的翻译结果加密存在扩展自己的 IndexedDB，同样的内容再翻译时直接使用，不再请求平台，节省用户的 Token 和字符额度。覆盖划词、区域、整站、双语阅读、整份 PDF、图片识别和点词换说法；区域与整站翻译先显示命中的段落。换语言、模型、风格或用词偏好不会命中旧译文；「重新翻译」绕过缓存；设置页可关闭、查看条数、清除。点数翻译与本机翻译不走这层缓存。详见 [本机译文缓存](../local-cache.md)。
- **译文风格**：风格指南补充示例。

同版本还包含自愿分享功能使用记录（默认关闭，见 [usage-sharing.md](../usage-sharing.md)）与商店评价邀请。按用户要求，这两项**不写进**官网更新日志、商店版本说明和审核备注的「新内容」部分；隐私说明、权限理由与数据声明照实写明（`alarms` 权限、User activity）。
