Privacy policy

Политика конфиденциальности

Последнее обновление: 2026-09-30 · Оригинал в Markdown

Вкратце

Это расширение не собирает, не хранит и не передаёт никакие пользовательские данные на наши серверы — у нас нет серверов. Содержимое, которое вы переводите, отправляется только на настроенную вами AI-платформу.

Что отправляется

Только когда вы сами запускаете перевод (контекстное меню, сочетание клавиш, нажатие кнопки перевода), следующие данные отправляются по HTTPS на выбранную вами в настройках платформу:

СодержимоеКогдаКуда
Выделенный вами текстПри переводе выделенного текстаВыбранная вами платформа
Текст внутри указанной вами областиПри нажатии кнопки перевода на элементеТо же
Изображение, на котором вы щёлкнули правой кнопкойПри переводе изображенийТо же
Текст, который вы вводите в панели переводаПри нажатии «Перевести»То же

Доступные платформы — OpenAI (ChatGPT), DeepSeek и DeepL; запросы направляются соответственно на https://api.openai.com, https://api.deepseek.com и на https://api-free.deepl.com для DeepL (с платным ключом — на https://api.deepl.com). Обработка этих данных регулируется собственными политиками конфиденциальности платформ:

  • OpenAI：openai.com/policies/privacy-policy
  • DeepSeek：platform.deepseek.com/downloads
  • DeepL：deepl.com/en/privacy

Не отправляется: содержимое страниц, которое вы не переводили, история браузера, cookie, данные форм. Расширение ничего не сканирует и не загружает в фоновом режиме.

Что остаётся только на вашем устройстве

Следующие данные сохраняются на вашем устройстве через chrome.storage.local, не синхронизируются через аккаунт Chrome и не покидают ваш браузер:

  • API Key — используется только для аутентификации запросов к выбранной вами платформе в заголовке запроса
  • Настройки — целевой язык, используемая модель, переключатели
  • Правила перевода элементов — добавленные вами вручную пары «домен + CSS-селектор»

Вы можете в любой момент очистить эти данные на странице настроек или просто удалить расширение (при удалении они стираются вместе с ним).

Чего мы не делаем

  • Никаких серверов, никакого сбора данных
  • Никакой аналитики, трекинга, рекламы и сторонних SDK
  • Данные не продаются, не сдаются в аренду и не передаются третьим лицам
  • Не используются для оценки кредитоспособности или целей, не связанных с работой расширения

Полный исходный код расширения открыт под GPL-3.0, и вы можете убедиться в этом сами: github.com/csswork/AiTranslation.
