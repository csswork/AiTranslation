Privacy policy

プライバシーポリシー

最終更新：2026-09-30 · Markdown 原稿

一言でいうと

本拡張機能は、ユーザーデータを収集・保存・当方のサーバーへのアップロードを一切行いません — 当方にサーバーはありません。翻訳する内容は、あなた自身が設定した AI プロバイダにのみ送信されます。

送信される内容

あなたが翻訳を明示的に実行したときにのみ（右クリックメニュー、キーボードショートカット、翻訳ボタンのクリック）、以下の内容が HTTPS で、設定で選択したプロバイダへ送信されます：

内容送信タイミング送信先
選択したテキスト選択翻訳の使用時選択したプロバイダ
指定した領域内のテキスト要素上の翻訳ボタンをクリックしたとき同上
右クリックした画像画像翻訳の使用時同上
翻訳パネルに入力したテキスト翻訳をクリックしたとき同上

選択できるプロバイダは OpenAI（ChatGPT）、DeepSeek、DeepL で、リクエストはそれぞれ https://api.openai.com、https://api.deepseek.com、および DeepL の https://api-free.deepl.com（有料 Key の場合は https://api.deepl.com）へ送信されます。これらの内容がどう処理されるかは、各プロバイダ自身のプライバシーポリシーが適用されます：

  • OpenAI：openai.com/policies/privacy-policy
  • DeepSeek：platform.deepseek.com/downloads
  • DeepL：deepl.com/en/privacy

送信しません：あなたが翻訳を指示していないページの内容、閲覧履歴、Cookie、フォームデータ。 拡張機能がバックグラウンドで自動的にスキャンやアップロードを行うことはありません。

お使いの端末にのみ保存される内容

以下のデータは chrome.storage.local を通じてお使いの端末上に保存されます。Chrome アカウントでは同期されず、ブラウザの外に出ることはありません：

  • API Key — 選択したプロバイダへのリクエストヘッダー認証にのみ使用します
  • 環境設定 — 対象言語、使用するモデル、各種のオン・オフ
  • 要素翻訳ルール — 手動で追加した「ドメイン + CSS セレクター」

これらのデータは設定ページからいつでも消去できますし、拡張機能をアンインストールしてもかまいません（アンインストール時にすべて削除されます）。

私たちが行わないこと

  • サーバーを一切設置せず、データも収集しません
  • 統計、トラッキング、広告、サードパーティ SDK を一切使用しません
  • データを第三者へ販売、貸与、共有することはありません
  • 信用評価や、拡張機能の用途と無関係な目的には使用しません

拡張機能の全ソースコードは GPL-3.0 で公開されており、ご自身で確認できます：github.com/csswork/AiTranslation。

権限用途
