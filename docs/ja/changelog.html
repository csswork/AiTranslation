v1.0.0
2026-09-15

最初のバージョン

  • 選択翻訳：中国語以外のテキストを選択して右クリックで翻訳すると、訳文が画面中央のポップアップにストリーミング表示されます。選択したテキスト自体が中国語のときは、メニューは表示されません。
  • 要素翻訳：ページ上の任意の領域を右クリックすると翻訳ボタンが付き、クリックするとその領域内のテキストがその場で置き換わります。ルールはドメインごとに記憶され、管理ページで保守できます。
  • 画像翻訳：画像を右クリックすると中のテキストを認識し、訳文が位置に合わせて元の画像に重ねられます。長い画像は先に内容に応じて分割され、継ぎ目はテキスト行を避けます。
  • 翻訳パネル：独立したページで、左に原文、右に訳文を表示し、対象言語は自由に選べます。
  • ChatGPT（OpenAI）、DeepSeek、DeepL の API に対応し、ポップアップまたは設定ページからいつでも切り替えられます。
  • API Key は chrome.storage.local に保存され、Chrome アカウントでは同期されません。
