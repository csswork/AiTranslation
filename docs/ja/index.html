Chrome 拡張機能です。ページ上の外国語、領域全体、さらには画像内の文字まで、その場で中国語に訳せます。訳文は一字ずつストリーミング表示され、使用するのはご自身の API Key です — 間にサーバーは一切ありません。

Chrome にインストール ソースを見る
Chrome 116+ サーバーなし · 統計なし 4 つの翻訳方法

Features

4 つの入口は、すべて右クリックメニューの中にあります

タブを切り替える必要も、コピー＆ペーストする必要もありません。読めない部分がある場所で、そのまま翻訳が行われます。

01

選択翻訳

中国語以外のテキストを選択し、右クリックで「中国語に翻訳」を選ぶと、訳文が画面中央のポップアップに一字ずつ表示されます。

  • 選択したテキストがもともと中国語の場合はメニューが表示されません。数字だけ、句読点、絵文字も同様です
  • ポップアップは中央に表示され、ドラッグ可能です。Esc または背景のクリックで閉じられ、カーソルを追いかける小さなバブルではありません
  • 折りたたみ可能な原文パネルで、照らし合わせて読めます
  • キーボードショートカットもあります：Alt+Shift+T（macOS では Command+Shift+Y）
デモ動画のプレースホルダー assets/demo-selection.mp4

02

要素翻訳

ページ上の任意の領域を右クリックすると、翻訳ボタンが付きます。クリックすると、その領域内のテキストがその場で中国語に置き換わります。

  • ルールはドメインごとに記憶され、次に同じサイトを訪れたときはボタンが自動的に付きます
  • 長い内容は分割して送信し、翻訳しながら置き換えるため、領域全体の完了を待つ必要はありません
  • 保存したルールは管理ページで 1 件ずつ確認・削除できます
デモ動画のプレースホルダー assets/demo-element.mp4

03

画像翻訳

画像を右クリックすると中のテキストを認識し、訳文を認識した位置に合わせて元の画像に重ねます。

  • 長い画像は先に分割してから認識し、継ぎ目は自動的にテキスト間の空白行へ移されるため、一文が真っ二つになることはありません
  • 送信前に最長辺ではなく総ピクセル数で縮小するため、長い画像の幅がつぶれません
  • 結果は独立したウィンドウで開き、元の画像と見比べられます
デモ動画のプレースホルダー assets/demo-image.mp4

04

翻訳パネル

独立したページで、左に原文を貼り、右に訳文が表示されます。ウェブページ上にない段落を扱うのに適しています。

  • 10 数種類の対象言語から選択でき、中国語に限りません
  • 入力言語を自動判定します：中国語は既定で英語に、その他の言語は既定で中国語に翻訳されます
  • プロバイダと対象言語はツールバーにあり、いつでも切り替えて再翻訳できます

Privacy

サーバーがなければ、漏えいする場所もありません

内容が送信されるのは、あなたが翻訳を明示的に実行したときだけであり、送信先も自分で選んだプロバイダに限られます。これは約束ではなく、ソースコードを一行ずつ確認できる事実です。

出口は 1 つだけ

翻訳プロバイダへのリクエストはすべて src/lib/providers.js という 1 つのファイルに書かれており、設定で選択したプロバイダにのみ送信されます。それ以外のコードがあなたの内容をどこかへ送ることはありません。

サーバーなし

作者はサーバーを一切運営しておらず、統計、トラッキング、広告、サードパーティ SDK もありません。あなたが何を翻訳したかを知る手段はありません。

Key は端末内に保存

API Key は chrome.storage.local に保存され、Chrome アカウント同期の対象外です。選択したプロバイダの認証にのみ使用します。拡張機能をアンインストールすると同時に削除されます。

詳細はプライバシーポリシー、および GPL-3.0 で公開されている全ソースコードをご覧ください。

Install

4 ステップでセットアップ

現在はデベロッパーモードで読み込みます。Chrome 116 以降と、ご自身の API Key が必要です。

ソースを入手 — GitHub で Download ZIP を選んで解凍するか、git clone でリポジトリを取得します。
拡張機能ページを開く — アドレスバーに chrome://extensions/ と入力し、右上の「デベロッパーモード」をオンにします。
拡張機能を読み込む — 「パッケージ化されていない拡張機能を読み込む」をクリックし、先ほどのディレクトリを選択します。
API Key を入力 — 初回インストール時は設定ページが自動的に開きます。プロバイダを選び、Key を貼り付け、「接続テスト」をクリックして通ることを確認します。

ChatGPT（OpenAI）と DeepSeek の API に対応し、いつでも切り替えられます。どちらも既定では各社の最も安価なティアを選択します — 翻訳は高頻度・短入力の作業であり、高価なモデルを使う必要はありません。

インストールしたら、あとは忘れてしまってください
